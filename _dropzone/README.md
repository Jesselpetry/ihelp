# _dropzone

วางไฟล์ใหม่ที่ยังไม่ได้จัดหมวดไว้ที่นี่ แล้วชี้ AI agent ไปที่
[`docs/DROPZONE_SOP.md`](../docs/DROPZONE_SOP.md)

โฟลเดอร์นี้เป็น **staging ชั่วคราว** — เนื้อหาข้างในไม่ถูก commit
(ยกเว้นไฟล์ README.md และ .gitkeep) และจะถูกล้างทุกครั้งที่ประมวลผลเสร็จ

```
คุณ: วางไฟล์ลง _dropzone/
คุณ: "ประมวลผล _dropzone ตาม docs/DROPZONE_SOP.md"
agent: จัดหมวด → เปลี่ยนชื่อ → ย้าย → อัปเดต catalog → อัปโหลด → ล้างโฟลเดอร์
```

> `public/assets/` ถูก gitignore — ไฟล์เสิร์ฟจาก Supabase Storage ต้องรัน
> `npm run assets:sync` ด้วย ไม่งั้นไฟล์จะเปิดได้ในเครื่องแต่ 404 บน production
>
> **ข้อสอบเก่าเป็นเนื้อหาจำกัดสิทธิ์** — จะถูกอัปโหลดเข้า bucket แบบปิดและเสิร์ฟ
> ให้เฉพาะ insider โดยดูจาก `category: "exam"` (ไม่ใช่ชื่อโฟลเดอร์) ถ้าไม่แน่ใจว่า
> ไฟล์ไหนเป็นข้อสอบ ให้ถือว่าเป็น แล้วรายงานไว้
