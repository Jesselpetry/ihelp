# _dropzone

วางไฟล์ใหม่ที่ยังไม่ได้จัดหมวดไว้ที่นี่ แล้วชี้ AI agent ไปที่
[`docs/DROPZONE_SOP.md`](../docs/DROPZONE_SOP.md)

ตรวจล่าสุด 15 ต.ค. 2569

โฟลเดอร์นี้เป็น **staging ชั่วคราว** — เนื้อหาข้างในไม่ถูก commit
(`.gitignore` ยกเว้นเฉพาะ `README.md` และ `.gitkeep`) และจะถูกล้างทุกครั้งที่ประมวลผลเสร็จ

```
คุณ:   ดาวน์โหลดจาก OnLearn → ~/Downloads/_INBOX/<COURSE>/   (OnLearn ต้องล็อกอิน agent ดึงเองไม่ได้)
agent: คัดลอก (ไม่ใช่ย้าย) เข้า _dropzone/
คุณ:   "ประมวลผล _dropzone ตาม docs/DROPZONE_SOP.md"
agent: จัดหมวด → เปลี่ยนชื่อ → บีบอัด → ย้ายเข้า public/assets/
       → bun run library:build → bun run library:audit
       → (ถามเจ้าของก่อน) bun run assets:sync → bun run library:audit -- --remote
       → ล้างโฟลเดอร์
```

## `_hold/` — ไฟล์ที่ agent ไม่จัดเข้าเอง

agent ย้ายไฟล์มาพักที่ `_hold/` แล้วรายงาน แทนที่จะเดา เมื่อเป็นกรณีใดกรณีหนึ่งนี้

| กรณี | ตัวอย่าง |
|---|---|
| งานของนักศึกษาคนอื่น | ใบงานที่ส่งแล้ว (`-completed`) งานกลุ่มที่มีชื่อเพื่อน |
| ข้อมูลส่วนบุคคลที่ยังไม่เคยแจกให้ทั้งชั้น | รายชื่อ เบอร์ติดต่อ เอกสารเฉพาะบุคคล |
| ไม่รู้ว่าเป็นวิชาไหน หรือขอบเขตสอบไหน | ไฟล์ที่เข้ากันได้สองวิชา และไม่ใช่เอกสารทั้งเทอม |
| อื่น ๆ | ไฟล์เสียหายหรือว่าง · ใหญ่เกิน 20 MB บีบไม่ลง · ดูเหมือนภาพรวมรายวิชาที่จะทับ `summary.md` |

ตั้งชื่อโฟลเดอร์ย่อยเป็น `<วิชา>-<เหตุผล>/` เช่น `mfit-privacy/`

**ไม่ต้องพัก** (เจ้าของคลังตัดสิน 15 ต.ค. 2569): เอกสารที่ผู้สอนแจกทั้งชั้นบน OnLearn
แล้ว (ใบงานแล็บ สไลด์) แม้มีชื่อหรือรหัสของ TA หรือนักศึกษาตัวอย่างอยู่ในภาพ — จัดเข้าคลังตามปกติ

**ไม่จัดเข้า และไม่พัก** (ข้ามแล้วรายงาน): ไฟล์ที่ผ่านการตรวจให้คะแนนแล้ว เช่น Cisco
Packet Tracer `.pka` และหน้าเว็บที่เซฟจากบัญชีส่วนตัว เช่น SecSpace

> `public/assets/` ถูก gitignore — ไฟล์เสิร์ฟจาก Supabase Storage ต้องรัน
> `bun run assets:sync` ด้วย ไม่งั้นไฟล์จะเปิดได้ในเครื่องแต่ 404 บน production
>
> **"หลังล็อกอิน" ไม่เท่ากับ "ส่วนตัว"** — หน้าคลังต้องล็อกอิน IT KMITL ถึงเห็นรายการไฟล์
> แต่ไฟล์ที่ไม่ใช่ข้อสอบอยู่ใน bucket แบบ **สาธารณะ** `ihelp-library` และ path ของไฟล์อยู่ใน repo
> สาธารณะ ให้ถือว่าอะไรก็ตามที่นำเข้าคลังเป็นสาธารณะ
>
> **มีแค่ข้อสอบเก่าที่ส่วนตัวจริง** — จะถูกอัปโหลดเข้า bucket แบบปิด `ihelp-library-exams`
> และเสิร์ฟผ่าน signed URL ให้เฉพาะ insider โดยดูจาก `category: "exam"` (หรือ path ที่มี
> `/exams/`) ไม่ใช่ชื่อโฟลเดอร์อย่างเดียว ถ้าไม่แน่ใจว่าไฟล์ไหนเป็นข้อสอบ ให้ถือว่าเป็น แล้วรายงานไว้
