## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมรับตัวเลข 4 ตัวจากผู้ใช้ตามลำดับ *q1*, *q2*, *p1*, *p2*

กำหนดให้ในระนาบ 2 มิติ จุด **Q** อยู่ที่ตำแหน่ง (*q1*, *q2*) และจุด **P** อยู่ที่ตำแหน่ง (*p1*, *p2*)

จงหาระยะทางแบบยุคลิค (Euclidean distance) ระหว่างจุด **Q** และ **P**
โดยระยะทางแบบยุคลิคระหว่าง **Q** และ **P** ใด ๆ ในระนาบ *n* มิติ มีค่าเท่ากับ

$$d(\mathbf{p}, \mathbf{q}) = d(\mathbf{q}, \mathbf{p}) = \sqrt{(q_1 - p_1)^2 + (q_2 - p_2)^2 + \cdots + (q_n - p_n)^2} = \sqrt{\sum_{i=1}^{n}(q_i - p_i)^2}$$

สำหรับข้อนี้เป็นระนาบ 2 มิติ จึงเหลือแค่:

$$d = \sqrt{(q_1 - p_1)^2 + (q_2 - p_2)^2}$$

## 2. Input Specification

**4 บรรทัด**

- **บรรทัดที่ 1**: ค่า `q1`
- **บรรทัดที่ 2**: ค่า `q2`
- **บรรทัดที่ 3**: ค่า `p1`
- **บรรทัดที่ 4**: ค่า `p2`

ทั้งหมดเป็น **จำนวนจริง**

- **บรรทัดที่ 1**: ระยะทางแบบยุคลิคระหว่างจุด Q และ P — **เป็นจำนวนจริง**

## 5. จุดสำคัญและเทคนิคที่ใช้

### 5.1 จุดตาย: ข้อนี้ **ห้ามปัดทศนิยม**
ดูเอาต์พุตตัวอย่างให้ดี — `1.4142135623730951` มีทศนิยมยาว 16 หลัก
นี่คือค่าเต็มของ `float` ใน Python ดังนั้น **ห้ามใช้ `:.2f` หรือ `round()`** เด็ดขาด

```python
print(distance)              # ✅ ถูก  -> 1.4142135623730951
print(f"{distance:.2f}")     # ❌ ผิด -> 1.41
```

> ต่างจากข้อ Temperature / Elo ที่บังคับ 2 ตำแหน่ง — **ต้องอ่าน Output Spec ทุกข้อเสมอ**

### 5.2 `print(distance)` พอ ไม่ต้องใส่ f-string
`print(f"{distance}")` ให้ผลเหมือน `print(distance)` เป๊ะ แต่ยาวกว่าโดยไม่ได้ประโยชน์
เขียนสั้น ๆ ตรง ๆ อ่านง่ายกว่า

### 5.3 การถอดรากที่สอง — 2 วิธี
```python
import math
distance = math.sqrt(x)      # วิธีที่ 1 ชัดเจนว่ากำลังถอดราก
distance = x ** 0.5          # วิธีที่ 2 ไม่ต้อง import
```
ทั้งสองให้ผลเท่ากัน แต่ `math.sqrt()` สื่อความหมายชัดกว่าเมื่ออ่านโค้ด

### 5.4 `import math` อย่าตั้งชื่อย่อ
```python
import math          # ✅ ถูกตาม PEP-8
import math as m     # ⚠️ ใช้ได้แต่ไม่ควร — ชื่อ m สื่อความหมายไม่ได้
```
`math` มีแค่ 4 ตัวอักษรอยู่แล้ว การย่อไม่ได้ช่วยอะไรแต่ทำให้อ่านยากขึ้น

### 5.5 ระวังลำดับการรับค่า
โจทย์ให้เรียง **q1, q2, p1, p2** ไม่ใช่ q1, p1, q2, p2
ถ้าจับคู่ผิดจะได้ระยะทางผิดทันที — ตัวที่ต้องลบกันคือ `(q1 - p1)` และ `(q2 - p2)`

### 5.6 ทำไมยกกำลังสองแล้วไม่ต้องกลัวค่าติดลบ
`(q1 - p1)` อาจติดลบได้ แต่พอยกกำลังสองจะกลายเป็นบวกเสมอ
เช่น `(-3) ** 2 = 9` — ระยะทางจึงเป็นบวกเสมอตามที่ควรจะเป็น

> **ระวังลำดับตัวดำเนินการ**: `-3 ** 2` ได้ `-9` (ยกกำลังก่อนแล้วค่อยติดลบ)
> แต่ `(-3) ** 2` ได้ `9` — ในโค้ดเราเขียน `(q1 - p1) ** 2` มีวงเล็บครอบอยู่แล้วจึงปลอดภัย
