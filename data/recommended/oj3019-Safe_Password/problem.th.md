## 1. โจทย์จริงจาก iJudge

ผู้จัดการธนาคารได้ตั้งรหัสผ่านตู้เซฟเป็น **H 4567**

งานของนักศึกษาคือการเขียนโปรแกรมเพื่ออ่านตัวอักษรหนึ่งตัวและตัวเลขหนึ่งตัวจากแป้นพิมพ์และตรวจสอบรหัส โดยโปรแกรมจะต้องแสดงผลลัพธ์ดังต่อไปนี้

- หากรหัสถูกต้อง โปรแกรมจะแสดงผล `safe unlocked`
- ถ้าเฉพาะตัวอักษร H เท่านั้นที่ถูกต้อง โปรแกรมจะแสดงผล `safe locked - change digit`
- ถ้าเฉพาะค่าตัวเลขเท่านั้นที่ถูกต้อง โปรแกรมจะแสดงผล `safe locked - change char`
- ถ้ารหัสที่ป้อนผิด (ไม่ตรงกันทั้งตัวอักษรและตัวเลข) โปรแกรมจะแสดงผล `safe locked`

## 2. Input Specification

**2 บรรทัด**

- **บรรทัดที่ 1**: ตัวอักษร
- **บรรทัดที่ 2**: ตัวเลขจำนวนเต็ม

## 3. Output Specification

**บรรทัดที่ 1**: ข้อความ `safe unlocked` หรือ `safe locked - change digit` หรือ `safe locked - change char` หรือ `safe locked`

## 5. จุดสำคัญและเทคนิคที่ใช้

### 5.1 จุดตาย: ตัวพิมพ์ใหญ่-เล็กต่างกัน!
ดูตัวอย่างที่ 1 ให้ดี — อินพุตคือ `h` ตัวเล็ก แต่รหัสที่ถูกคือ `H` ตัวใหญ่
ผลลัพธ์จึงเป็น `safe locked - change char` ไม่ใช่ `safe unlocked`

> **ห้ามใช้ `.lower()` หรือ `.upper()` มาช่วยเทียบเด็ดขาด** เพราะโจทย์ต้องการให้ `h` นับว่า **ผิด**
> เทียบด้วย `==` ตรง ๆ กับ `"H"` เท่านั้น

### 5.2 เทียบตัวเลขเป็น str ง่ายกว่าเป็น int
แม้โจทย์เขียนว่า "ตัวเลขจำนวนเต็ม" แต่การเทียบแบบ **ข้อความ** ปลอดภัยกว่า:

```python
digit = input()              # ไม่ต้อง int()
digit_ok = digit == "4567"
```

ถ้าแปลงเป็น `int` แล้วเทียบกับ `4567` ก็ใช้ได้เหมือนกัน แต่จะพังทันทีถ้าอินพุตมีเลข 0 นำหน้าหรือมีช่องว่างแปลก ๆ

### 5.3 เก็บผลการเทียบไว้ในตัวแปรบูลีน
แทนที่จะเขียนเงื่อนไขซ้ำ ๆ ยาว ๆ ให้เก็บผลไว้ก่อน อ่านง่ายกว่ามาก:

```python
char_ok = char == "H"
digit_ok = digit == "4567"
```

### 5.4 ลำดับการเช็กเงื่อนไข — ใช้ `elif` ให้เป็นประโยชน์
เช็ก **กรณีที่เจาะจงที่สุดก่อน** (ถูกทั้งคู่) แล้วค่อยไล่ลงมา
เมื่อเข้า `elif` แล้ว แปลว่าเงื่อนไขข้างบนไม่จริงไปแล้ว จึงไม่ต้องเขียน `and not ...` ซ้ำ:

```python
if char_ok and digit_ok:
    print("safe unlocked")
elif char_ok:                 # มาถึงตรงนี้ = digit ผิดแน่นอน
    print("safe locked - change digit")
elif digit_ok:                # มาถึงตรงนี้ = char ผิดแน่นอน
    print("safe locked - change char")
else:                         # ผิดทั้งคู่
    print("safe locked")
```

เขียนแบบนี้สั้นและอ่านง่ายกว่า `elif char_ok and not digit_ok:` ซึ่งเป็นการเช็กสิ่งที่รู้อยู่แล้วซ้ำอีกรอบ

### 5.5 ใช้ค่าคงที่ (Constant) ตั้งชื่อไว้ด้านบน
ตัวแปรที่เป็นค่าคงที่ตาม PEP-8 เขียนด้วย **ตัวพิมพ์ใหญ่ทั้งหมด** วางไว้นอกฟังก์ชัน:

```python
CORRECT_CHAR = "H"
CORRECT_DIGIT = "4567"
```
