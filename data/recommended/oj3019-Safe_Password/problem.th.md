# OJ 3019: [recommend] Safe Password

## 1. ทำความเข้าใจโจทย์
ตู้เซฟต้องใช้ตัวอักษรที่ถูกต้อง (`'H'`) คู่กับรหัส 4 หลักที่ถูกต้อง (`'4567'`) จึงจะเปิดได้
ผลลัพธ์ขึ้นอยู่กับอินพุตที่รับเข้ามา:
- ถ้าถูกทั้งตัวอักษรและรหัส $\to$ พิมพ์ `safe unlocked`
- ถ้าตัวอักษรถูก แต่รหัสผิด $\to$ พิมพ์ `safe locked - change digit`
- ถ้าตัวอักษรผิด แต่รหัสถูก $\to$ พิมพ์ `safe locked - change char`
- ถ้าผิดทั้งคู่ $\to$ พิมพ์ `safe locked`

## 2. อินพุตและเอาต์พุต
- **อินพุต**:
  - บรรทัดที่ 1: ตัวอักษร (str)
  - บรรทัดที่ 2: รหัส PIN (str)
- **เอาต์พุต**: ข้อความสถานะแบบเป๊ะ ๆ (ตัวพิมพ์ใหญ่-เล็กและช่องว่างต้องตรงทุกตัว)

## 3. จุดสำคัญและเทคนิคที่ใช้
- **ลำดับการตัดสินใจและตรรกะบูลีน**:
  เวลามีหลายเงื่อนไขที่ตรงกันบางส่วน ให้เช็ก**เงื่อนไขที่สำเร็จและเฉพาะเจาะจงที่สุดก่อน** แล้วค่อยเช็กกรณีที่ผิดบางส่วนด้วย `elif` และปิดท้ายด้วย `else` สำหรับกรณีที่เหลือทั้งหมด
  ```python
  if char_match and digit_match:
      ...
  elif char_match and not digit_match:
      ...
  elif not char_match and digit_match:
      ...
  else:
      ...
  ```

## 4. เทสเคส

### เคสที่ 1: ถูกทั้งคู่ (ตู้เซฟเปิด)
- **ทำไมเคสนี้ถึงมีประโยชน์**: ทดสอบกรณีที่ข้อมูลตรงทั้งสองอย่าง
- **อินพุต**:
  ```text
  H
  4567
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
  safe unlocked
  ```

### เคสที่ 2: รหัส PIN ผิดอย่างเดียว
- **ทำไมเคสนี้ถึงมีประโยชน์**: ทดสอบเงื่อนไขที่ตรงบางส่วน (`change digit`)
- **อินพุต**:
  ```text
  H
  1234
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
  safe locked - change digit
  ```

### เคสที่ 3: ตัวอักษรผิดอย่างเดียว
- **ทำไมเคสนี้ถึงมีประโยชน์**: ทดสอบเงื่อนไขที่ตรงบางส่วนอีกด้าน (`change char`)
- **อินพุต**:
  ```text
  A
  4567
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
  safe locked - change char
  ```

### เคสที่ 4: ผิดทั้งคู่
- **ทำไมเคสนี้ถึงมีประโยชน์**: ทดสอบเงื่อนไขสุดท้ายที่เป็น `else` (`safe locked`)
- **อินพุต**:
  ```text
  X
  9999
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
  safe locked
  ```
