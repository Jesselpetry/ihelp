## 💡 กฎง่าย ๆ ก่อนส่ง OJ

1. รันโค้ดใน VS Code ให้ผ่านเรียบร้อยก่อน
2. ทดสอบอย่างน้อย 3 เคสที่ต่างกัน (เคสปกติ, เคสขอบเขต/ค่าน้อยสุด, เคสดักทาง)
3. เช็กรูปแบบเอาต์พุตให้ตรงเป๊ะ (การสะกด ตัวพิมพ์ใหญ่-เล็ก และจำนวนทศนิยม)
4. ต้องอธิบายโค้ดของตัวเองได้ทุกบรรทัด!
