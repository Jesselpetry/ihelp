# OJ 2996: [Recommend] [LEARNING LOGS] สลับตัวอักษร

## 1. ทำความเข้าใจโจทย์
โปรแกรมรับข้อความ 1 บรรทัด แล้วกลับลำดับตัวอักษรจากหลังมาหน้า พร้อมกับเปลี่ยนตัวอักษรภาษาอังกฤษทั้งหมดให้เป็นตัวพิมพ์เล็ก

## 2. อินพุตและเอาต์พุต
- **อินพุต**: ข้อความ `text` 1 บรรทัด
- **เอาต์พุต**: ข้อความที่กลับด้านแล้ว และเป็นตัวพิมพ์เล็กทั้งหมด

## 3. จุดสำคัญและเทคนิคที่ใช้
- **การตัดข้อความแบบเดินถอยหลัง (Slicing ด้วย step ติดลบ)**:
  ใน Python การตัดข้อความเขียนได้ในรูปแบบ `string[start:stop:step]`
  ถ้าใส่ `step = -1` และไม่ระบุ start กับ stop (เขียนเป็น `text[::-1]`) Python จะไล่อ่านข้อความจากตัวสุดท้ายย้อนมาตัวแรกให้เลย ใช้เวลา $O(N)$ โดยไม่ต้องเขียนลูปเอง
- **การแปลงเป็นตัวพิมพ์เล็ก**:
  เมท็อด `.lower()` จะเปลี่ยนตัวพิมพ์ใหญ่ทั้งหมดเป็นตัวพิมพ์เล็ก ส่วนตัวที่ไม่ใช่ตัวอักษร (ตัวเลข ช่องว่าง เครื่องหมายวรรคตอน) จะไม่ถูกเปลี่ยน

## 4. เทสเคส

### เคสที่ 1: ประโยคปกติที่มีทั้งพิมพ์ใหญ่และพิมพ์เล็ก
- **ทำไมเคสนี้ถึงมีประโยชน์**: ทดสอบการกลับด้านแบบมาตรฐาน ที่มีทั้งช่องว่างและตัวพิมพ์ใหญ่ปนพิมพ์เล็ก
- **อินพุต**:
  ```text
  Hello World
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
  dlrow olleh
  ```

### เคสที่ 2: มีตัวเลขปนกับตัวอักษร
- **ทำไมเคสนี้ถึงมีประโยชน์**: เช็กว่าตัวเลขและสัญลักษณ์ยังคงเดิม ในขณะที่ตัวอักษรถูกเปลี่ยนเป็นพิมพ์เล็ก
- **อินพุต**:
  ```text
  Python 3.10
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
  01.3 nohtyp
  ```

### เคสที่ 3: ตัวอักษรเดียว / เป็นพิมพ์เล็กอยู่แล้ว
- **ทำไมเคสนี้ถึงมีประโยชน์**: เช็กกรณีขอบเขตที่มีตัวอักษรแค่ตัวเดียว
- **อินพุต**:
  ```text
  A
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
  a
  ```
