## 5. จุดสำคัญและเทคนิคที่ใช้

### 5.1 การตัดข้อความแบบเดินถอยหลัง (Slicing ด้วย step ติดลบ)
ใน Python การตัดข้อความเขียนได้ในรูปแบบ `string[start:stop:step]`
ถ้าใส่ `step = -1` และไม่ระบุ start กับ stop (เขียนเป็น `text[::-1]`) Python จะไล่อ่านข้อความจากตัวสุดท้ายย้อนมาตัวแรกให้เลย โดยไม่ต้องเขียนลูปเอง

```python
text = "harry"
print(text[::-1])   # yrrah
```

### 5.2 ทางเลือกแบบใช้ index (ตรงตามโน้ตของผู้ออกโจทย์)
โน้ตของผู้ออกโจทย์บอกว่าอยากให้ฝึก "เข้าถึงตัวอักษรด้วย index" ซึ่งเขียนได้แบบนี้ ผลลัพธ์เหมือนกันเป๊ะ:

```python
text = input()
print((text[4] + text[3] + text[2] + text[1] + text[0]).lower())
```

หรือใช้ลูปเดินถอยหลัง:

```python
result = ""
for i in range(len(text) - 1, -1, -1):
    result += text[i]
print(result.lower())
```

> แบบ `[::-1]` สั้นและอ่านง่ายที่สุด แต่ควรเข้าใจแบบ index ด้วย เพราะข้อสอบอาจถามให้อธิบายทีละบรรทัด

### 5.3 การแปลงเป็นตัวพิมพ์เล็ก
เมท็อด `.lower()` จะเปลี่ยนตัวพิมพ์ใหญ่ทั้งหมดเป็นตัวพิมพ์เล็ก ส่วนตัวที่ไม่ใช่ตัวอักษร (ตัวเลข ช่องว่าง เครื่องหมายวรรคตอน) จะไม่ถูกเปลี่ยน

**ลำดับสำคัญไหม?** ไม่สำคัญ — `text[::-1].lower()` กับ `text.lower()[::-1]` ให้ผลเหมือนกัน เพราะการกลับด้านไม่ได้ทำให้ตัวอักษรเปลี่ยนรูป
