# OJ 3237: [Recommend] สามเหลี่ยม (Triangle)

## 1. ทำความเข้าใจโจทย์
รับจำนวนเต็ม $N$ แล้วพิมพ์รูปสามเหลี่ยมสูง $N$ บรรทัด โดยใช้เครื่องหมายดอกจัน (`*`) กับช่องว่าง (` `)

## 2. อินพุตและเอาต์พุต
- **อินพุต**: จำนวนเต็ม $N$ 1 ตัว ($N \ge 1$)
- **เอาต์พุต**: $N$ บรรทัด ที่ประกอบกันเป็นรูปสามเหลี่ยม

## 3. จุดสำคัญและเทคนิคที่ใช้
- **การคูณข้อความ (`"*" * count`)**:
  ใน Python เอาข้อความคูณด้วยจำนวนเต็มได้ มันจะพิมพ์ซ้ำตามจำนวนนั้นเลย ไม่ต้องเขียนลูปซ้อนลูป:
  - `" " * spaces` ใช้สร้างช่องว่างด้านหน้า
  - `"*" * stars` ใช้สร้างกลุ่มดอกจัน

### รูปแบบสามเหลี่ยมที่เจอบ่อยใน PSCP:
1. **สามเหลี่ยมชิดขวา (เจอบ่อยที่สุดใน PSCP)**:
   สำหรับแถวที่ $i$ ตั้งแต่ $1$ ถึง $N$:
   - ช่องว่าง: $N - i$
   - ดอกจัน: $i$
   ```python
   for i in range(1, n + 1):
       print(" " * (n - i) + "*" * i)
   ```
2. **สามเหลี่ยมชิดซ้าย**:
   ```python
   for i in range(1, n + 1):
       print("*" * i)
   ```
3. **สามเหลี่ยมแบบพีระมิด**:
   ```python
   for i in range(1, n + 1):
       print(" " * (n - i) + "*" * (2 * i - 1))
   ```

## 4. เทสเคส (แบบชิดขวา)

### เคสที่ 1: ความสูง $N = 3$
- **ทำไมเคสนี้ถึงมีประโยชน์**: กรณีมาตรฐานขนาดเล็ก มองเห็นรูปทั้งหมดได้ในทีเดียว
- **อินพุต**:
  ```text
  3
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
    *
   **
  ***
  ```

### เคสที่ 2: ความสูง $N = 1$
- **ทำไมเคสนี้ถึงมีประโยชน์**: เป็นกรณีขอบเขตที่น้อยที่สุด
- **อินพุต**:
  ```text
  1
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
  *
  ```

### เคสที่ 3: ความสูง $N = 5$
- **ทำไมเคสนี้ถึงมีประโยชน์**: ทดสอบความสูงที่มากขึ้น และเช็กว่าช่องว่างแต่ละแถวเรียงตรงคอลัมน์กันจริง
- **อินพุต**:
  ```text
  5
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
      *
     **
    ***
   ****
  *****
  ```
