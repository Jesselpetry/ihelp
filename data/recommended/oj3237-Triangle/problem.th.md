## 1. ทำความเข้าใจโจทย์

รับจำนวนเต็ม `n` แล้วพิมพ์รูปสามเหลี่ยมสูง `n` บรรทัด โดยวาดด้วยเลข `0` และ `1`

รูปสามเหลี่ยมนี้เป็นแบบ **ชิดซ้าย** และ **กลวงตรงกลาง**:
- **ขอบ** ของรูปวาดด้วยเลข `0`
- **ข้างในที่กลวง** เติมด้วยเลข `1`

> [!IMPORTANT]
> ข้อนี้ **ไม่ใช้ดอกจัน (`*`) และไม่มีช่องว่างนำหน้า** แถวที่ `i` มีตัวอักษร `i` ตัวพอดี

## 2. Input Specification

**1 บรรทัด**

- จำนวนเต็ม `n` (ความสูงของสามเหลี่ยม)

## 3. Output Specification

**n บรรทัด** ประกอบกันเป็นรูปสามเหลี่ยมกลวง

## 5. จุดสำคัญและเทคนิคที่ใช้

### 5.1 มองรูปให้ออกก่อน: แถวไหนเป็นขอบบ้าง

ลองแยกแถวของ `n = 7` ออกมาดู:

| แถวที่ | เอาต์พุต | เป็นอะไร |
| :---: | :--- | :--- |
| 1 | `0` | **ขอบบน** (ยอดสามเหลี่ยม) |
| 2 | `00` | ขอบซ้าย + ขอบขวา ติดกันพอดี ไม่มีที่ว่างตรงกลาง |
| 3 | `010` | ขอบซ้าย + กลวง 1 ตัว + ขอบขวา |
| 4 | `0110` | ขอบซ้าย + กลวง 2 ตัว + ขอบขวา |
| 5 | `01110` | ขอบซ้าย + กลวง 3 ตัว + ขอบขวา |
| 6 | `011110` | ขอบซ้าย + กลวง 4 ตัว + ขอบขวา |
| 7 | `0000000` | **ขอบล่าง** (ฐานสามเหลี่ยม) ทึบทั้งแถว |

สรุปเป็นกฎได้ว่า:
- **แถวแรก (i = 1)** และ **แถวสุดท้าย (i = n)** เป็นขอบ ให้พิมพ์ `0` จำนวน `i` ตัว
- **แถวกลาง** พิมพ์ `0` + `1` จำนวน `(i - 2)` ตัว + `0`

### 5.2 ทำไมแถวกลางถึงเป็น `(i - 2)`
แถวที่ `i` มีตัวอักษรทั้งหมด `i` ตัว ในจำนวนนี้เป็นขอบซ้าย 1 ตัว และขอบขวา 1 ตัว
ที่เหลือจึงเป็นส่วนกลวง = `i - 2` ตัว

### 5.3 แถวที่ 2 ทำงานถูกอัตโนมัติ
`i = 2` เข้าเงื่อนไขแถวกลาง จะได้ `"0" + "1" * 0 + "0"` = `"00"` ✅
เพราะ `"1" * 0` คือข้อความว่าง — **ไม่ต้องเขียน `if` ดักแถวที่ 2 แยก**

### 5.4 แต่แถวที่ 1 ต้องดัก!
ถ้าปล่อยให้ `i = 1` เข้าเงื่อนไขแถวกลาง จะได้ `"0" + "1" * (-1) + "0"` = `"00"` ซึ่ง **ผิด** (ต้องเป็น `"0"` ตัวเดียว)

> ใน Python การคูณข้อความด้วยจำนวนลบ (`"1" * -1`) ไม่ error แต่คืนข้อความว่าง — จึงเป็นบั๊กเงียบที่หายาก
> ต้องดักด้วย `if i == 1` เสมอ

### 5.5 รวมเงื่อนไขขอบบน-ขอบล่างด้วย `in`
แถวแรกกับแถวสุดท้ายทำเหมือนกัน (พิมพ์ `0` จำนวน `i` ตัว) จึงรวมเงื่อนไขได้:

```python
if i in (1, n):
    print("0" * i)
else:
    print("0" + "1" * (i - 2) + "0")
```

เขียนแบบนี้สั้นกว่า `if i == 1 or i == n:` และ pylint แนะนำให้ใช้ `in` ด้วย (คำเตือน `consider-using-in`)

### 5.6 ระวังกรณี n = 1 และ n = 2
- `n = 1` → แถวเดียว เข้าเงื่อนไข `i in (1, n)` ทั้งคู่ ได้ `0` ✅
- `n = 2` → ได้ `0` แล้ว `00` (แถว 2 เป็นแถวสุดท้ายพอดี) ✅
- `n = 3` → ได้ `0`, `00`, `000` — **แถวกลางไม่มีเลย** เพราะแถว 2 ถูกครอบด้วยสูตรแถวกลางที่กลวง 0 ตัว และแถว 3 เป็นฐาน ✅
