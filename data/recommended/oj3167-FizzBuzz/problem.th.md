## 5. จุดสำคัญและเทคนิคที่ใช้

### 5.1 ตัวดำเนินการหารเอาเศษ (`%`)
เครื่องหมาย `%` ใช้หาเศษจากการหาร ดังนั้น `i % 3 == 0` หมายความว่า "`i` หารด้วย 3 ลงตัว"

```python
15 % 3   # ได้ 0  -> หารลงตัว
14 % 3   # ได้ 2  -> หารไม่ลงตัว
```

### 5.2 จุดตายของข้อนี้: ลำดับการเช็กเงื่อนไข
เลขที่หารด้วย 15 ลงตัว (เช่น 15, 30, 45) ก็หารด้วย 3 ลงตัว **และ** หารด้วย 5 ลงตัวด้วย
ดังนั้นต้องเช็กเงื่อนไขที่ **เจาะจงที่สุดก่อนเสมอ**:

```python
if i % 15 == 0:        # ✅ เช็ก FizzBuzz ก่อน
    print("FizzBuzz")
elif i % 3 == 0:
    print("Fizz")
elif i % 5 == 0:
    print("Buzz")
else:
    print(i)
```

**ถ้าเรียงผิดจะเกิดอะไรขึ้น:**

```python
if i % 3 == 0:         # ❌ ผิด!
    print("Fizz")
elif i % 15 == 0:      # บรรทัดนี้ไม่มีทางทำงานเลย
    print("FizzBuzz")
```
เลข `15` จะเข้าเงื่อนไขแรก (`15 % 3 == 0` เป็นจริง) แล้วพิมพ์ `Fizz` ออกมา — `elif` ข้างล่างไม่มีโอกาสได้ทำงาน
ตัวอย่างทางการมี `n = 15` พอดี จึงจับผิดข้อนี้ได้ทันที

### 5.3 `% 15` หรือ `% 3 and % 5` ก็ได้
```python
if i % 15 == 0:                        # แบบสั้น
if i % 3 == 0 and i % 5 == 0:          # แบบชัดเจนว่ามาจากเงื่อนไขไหน
```
ทั้งสองถูกต้องเท่ากัน เพราะ 15 คือ ค.ร.น. ของ 3 กับ 5 — เลือกแบบที่ตัวเองอธิบายได้

### 5.4 ทำไมต้อง `range(1, n + 1)`
`range(a, b)` ใน Python จะ **ไม่รวม** `b`
ถ้าเขียน `range(1, n)` จะได้แค่ 1 ถึง `n - 1` ขาดตัวสุดท้ายไป
ต้องเขียน `range(1, n + 1)` จึงจะได้ครบ 1 ถึง `n`

### 5.5 `print(i)` ไม่ต้องแปลงเป็น str
`print()` แปลงค่าเป็นข้อความให้อัตโนมัติอยู่แล้ว ไม่ต้องเขียน `print(str(i))`
