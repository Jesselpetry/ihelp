# OJ 3167: [Recommend] FizzBuzz

## 1. ทำความเข้าใจโจทย์
พิมพ์จำนวนเต็มตั้งแต่ $1$ ถึง $N$ ทีละบรรทัด โดยมีกฎแทนที่ดังนี้:
- ถ้าหารด้วย 3 และ 5 ลงตัวทั้งคู่ (คือหารด้วย 15 ลงตัว) ให้พิมพ์ `FizzBuzz`
- ถ้าหารด้วย 3 ลงตัว ให้พิมพ์ `Fizz`
- ถ้าหารด้วย 5 ลงตัว ให้พิมพ์ `Buzz`
- นอกนั้นให้พิมพ์ตัวเลขนั้นตามปกติ

## 2. อินพุตและเอาต์พุต
- **อินพุต**: จำนวนเต็ม $N$ 1 ตัว ($N \ge 1$)
- **เอาต์พุต**: $N$ บรรทัด แต่ละบรรทัดเป็นข้อความหรือตัวเลขตามกฎด้านบน

## 3. จุดสำคัญและเทคนิคที่ใช้
- **ตัวดำเนินการหารเอาเศษ (`%`)**:
  เครื่องหมาย `%` ใช้หาเศษจากการหาร ดังนั้น `i % 3 == 0` หมายความว่า `i` หารด้วย 3 ลงตัว
- **กฎเช็กจากเงื่อนไขที่เฉพาะเจาะจงที่สุดก่อน**:
  เพราะเลขที่หารด้วย 15 ลงตัว ก็หารด้วย 3 และ 5 ลงตัวด้วยเหมือนกัน เราจึง**ต้อง**เช็ก `i % 15 == 0` (หรือ `i % 3 == 0 and i % 5 == 0`) ก่อนเช็ก `% 3` หรือ `% 5`
  ถ้าเผลอเช็ก `% 3` ก่อน เลข `15` จะออกมาเป็น `Fizz` แทนที่จะเป็น `FizzBuzz` ซึ่งเป็นจุดที่พลาดกันบ่อยมาก

```python
for i in range(1, n + 1):
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
```

## 4. เทสเคส

### เคสที่ 1: ช่วงสั้น ๆ ($N = 5$)
- **ทำไมเคสนี้ถึงมีประโยชน์**: เช็กตัวคูณของ 3 (`Fizz`) และ 5 (`Buzz`) แบบเดี่ยว ๆ
- **อินพุต**:
  ```text
  5
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
  1
  2
  Fizz
  4
  Buzz
  ```

### เคสที่ 2: ช่วงที่ยาวถึงตัวคูณร่วม ($N = 16$)
- **ทำไมเคสนี้ถึงมีประโยชน์**: เช็กว่าเลข 15 ออกมาเป็น `FizzBuzz` ถูกต้อง ซึ่งเป็นจุดที่โจทย์ข้อนี้ต้องการทดสอบจริง ๆ
- **อินพุต**:
  ```text
  16
  ```
- **เอาต์พุตที่ควรได้**:
  ```text
  1
  2
  Fizz
  4
  Buzz
  Fizz
  7
  8
  Fizz
  Buzz
  11
  Fizz
  13
  14
  FizzBuzz
  16
  ```
