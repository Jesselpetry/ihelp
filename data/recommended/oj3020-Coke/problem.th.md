## 1. โจทย์จริงจาก iJudge

Coke กำลังมีโปรโมชั่นใหม่ จากเดิมราคาขวดละ `a บาท` หากนำฝาขวดจำนวน `b ฝา` มาแลก จะซื้อขวดใหม่ได้ในราคา `c บาท` (จากเดิมราคาขวดละ a บาท โดยที่ c <= a) หากต้องการ Coke จำนวน `d ขวด` จะต้องจ่ายเงินน้อยที่สุดเท่าไร

## 2. Input Specification

**4 บรรทัด**

- **บรรทัดที่ 1**: ค่า `a` เป็นจำนวนเต็มบวกหรือศูนย์ (a >= 0)
- **บรรทัดที่ 2**: ค่า `b` เป็นจำนวนเต็มบวกหรือศูนย์ (b >= 0); **b = 0 หมายความว่าไม่สามารถนำฝามาลดราคาได้ ทุกขวดต้องซื้อในราคา a**
- **บรรทัดที่ 3**: ค่า `c` เป็นจำนวนเต็มบวกหรือศูนย์ (c >= 0, c <= a)
- **บรรทัดที่ 4**: ค่า `d` เป็นจำนวนเต็มบวกหรือศูนย์ (d >= 0)

## 3. Output Specification

**1 บรรทัด**

- **บรรทัดที่ 1**: เป็นจำนวนเงินที่ต้องจ่ายน้อยที่สุด (เป็นจำนวนเต็มบวกหรือศูนย์)

## 5. จุดสำคัญและเทคนิคที่ใช้

### 5.1 เข้าใจกลไกก่อน: ซื้อ 1 ขวด = ได้ 1 ฝา
ทุกขวดที่ซื้อ (ไม่ว่าราคาปกติหรือราคาโปร) จะได้ฝามา 1 ฝาเสมอ
ดังนั้นถ้าจะซื้อทั้งหมด `d` ขวด เราจะได้ฝารวม `d` ฝา — แต่ฝาใบสุดท้ายเอาไปแลกไม่ทันแล้ว

### 5.2 สูตร $O(1)$ แทนการวนลูป
แทนที่จะจำลองการซื้อทีละขวดด้วย `while` (ซึ่งช้าและเขียนพลาดง่าย) คำนวณตรง ๆ ได้เลย:

```python
promo_bottles = max(d - 1, 0) // b     # จำนวนขวดที่ได้ราคาโปร
normal_bottles = d - promo_bottles     # ที่เหลือซื้อราคาปกติ
total = promo_bottles * c + normal_bottles * a
```

**ทำไมต้อง `d - 1`?**
ขวดแรกยังไม่มีฝาเลย ต้องซื้อราคาเต็มเสมอ ฝาที่เอาไปแลกได้จริงจึงมีแค่ `d - 1` ฝา

### 5.3 ตรวจสูตรกับตัวอย่างที่ 1 (`a=10, b=3, c=7, d=50`)
- `promo_bottles = (50 - 1) // 3 = 49 // 3 = 16` ขวด
- `normal_bottles = 50 - 16 = 34` ขวด
- รวม = `16 × 7 + 34 × 10` = `112 + 340` = **`452`** ✅

### 5.4 ตรวจสูตรกับตัวอย่างที่ 2 (`a=1, b=10, c=0, d=50`)
- `promo_bottles = (50 - 1) // 10 = 49 // 10 = 4` ขวด
- `normal_bottles = 50 - 4 = 46` ขวด
- รวม = `4 × 0 + 46 × 1` = **`46`** ✅

### 5.5 กรณีขอบเขตที่ต้องดัก
| กรณี | ทำไมต้องระวัง | วิธีจัดการ |
| :--- | :--- | :--- |
| `b = 0` | `// 0` จะเกิด `ZeroDivisionError` โปรแกรมพังทันที | ดักด้วย `if` แล้วให้ `promo_bottles = 0` |
| `d = 0` | ไม่ซื้อเลย ต้องได้ `0` และ `(0-1)//b` จะติดลบ | ใช้ `max(d - 1, 0)` ป้องกัน |

`max(d - 1, 0)` ทำให้ไม่ต้องเขียน `if d == 0: return` แยกอีกบรรทัด — ครอบคลุมในนิพจน์เดียว

### 5.6 `//` คือหารปัดลง
`49 // 3` ได้ `16` (ไม่ใช่ 16.33) เพราะปัดเศษทิ้ง ซึ่งตรงกับความจริงที่ว่าฝาไม่ครบ `b` ใบก็แลกไม่ได้
ถ้าใช้ `/` ธรรมดาจะได้ `float` แล้วเอาไปคูณจะได้คำตอบมีจุดทศนิยม ผิด Output Spec ทันที
