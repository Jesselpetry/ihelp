## 1. โจทย์จริงจาก iJudge

ร้านก๋วยเตี๋ยวร้านหนึ่งมีชามที่ต้องเก็บเพื่อเตรียมล้างจำนวน `N` ใบ ชามทั้งหมดอาจจะ
มีขนาดที่ไม่เท่ากัน ในการเก็บชามโดยการซ้อนกันนั้น ถ้าชามด้านบนมีขนาดเล็กกว่าชาม
ด้านล่างจะทำให้กองชามนั้นไม่ล้มลงง่าย และตามที่ทราบกัน ถ้ากองชามล้ม ชามก็คงจะแตก
กระจายเป็นแน่แท้

คุณได้ข้อมูลขนาดของชาม `N` ใบเป็นจำนวนเต็ม `N` จำนวน จำนวนเต็มเหล่านี้จะแทนขนาดของ
ชาม ค่าที่มากกว่าแสดงถึงขนาดที่ใหญ่กว่า ให้หาว่าจะนำชามมาซ้อนกันเป็นกองโดยที่ในแต่ละ
กองชามด้านบนจะต้องมีขนาดเล็กกว่าชามด้านล่าง จะต้องใช้จำนวนกองที่น้อยที่สุดกี่กอง

พิจารณาตัวอย่างด้านล่าง ที่ `N = 10` และมีรายการของขนาดของชามดังนี้

```text
1, 5, 2, 7, 3, 2, 7, 3, 8, 4
```

สังเกตว่าคุณสามารถซ้อนชามเป็นสองกองได้ เนื่องจากคุณไม่สามารถเรียงชามทั้งหมดเป็นกอง
เดียวได้ ดังนั้นจำนวนกองที่น้อยที่สุดที่ทำได้คือ 2 กอง

สำหรับข้อนี้ในการเรียงชามให้เป็นกองนั้นจะทำอย่างไรก็ได้ แต่ละกองจะมีชามกี่ใบก็ได้
โจทย์สนใจแค่จำนวนกองเท่านั้น

## 2. Input Specification

- บรรทัดแรก: `N` (`1 ≤ N ≤ 100,000`) แทนจำนวนชาม
- อีก `N` บรรทัด: ขนาดของชามแต่ละใบ (จำนวนเต็ม `1..300`) บรรทัดละหนึ่งใบ

## 3. Output Specification

มีหนึ่งบรรทัด เป็นจำนวนกองชามน้อยที่สุดที่เป็นไปได้
