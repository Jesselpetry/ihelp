## 5. จุดสำคัญและเทคนิคที่ใช้

### 5.1 เทคนิคแปลงผ่านหน่วยกลาง (Hub-and-Spoke)
มี 4 หน่วย ถ้าเขียนแยกทุกคู่จะได้ $4 \times 3 = 12$ กรณี เยอะและพลาดง่ายมาก
แทนที่จะทำแบบนั้น ให้ใช้ **เซลเซียสเป็นหน่วยกลาง** แล้วแปลง 2 ขั้น:

```
หน่วยต้นทาง  ──►  เซลเซียส  ──►  หน่วยปลายทาง
```

เขียนสูตรแค่ 6 อัน (ไม่นับ C ที่ไม่ต้องแปลง) แทนที่จะเป็น 12 อัน

**ขั้นที่ 1 — แปลงเข้าเซลเซียส:**

| หน่วยต้นทาง | สูตร |
| :--- | :--- |
| `C` | `celsius = temp` |
| `F` | `celsius = (temp - 32) * 5 / 9` |
| `K` | `celsius = temp - 273.15` |
| `R` | `celsius = (temp - 491.67) * 5 / 9` |

**ขั้นที่ 2 — แปลงออกจากเซลเซียส:**

| หน่วยปลายทาง | สูตร |
| :--- | :--- |
| `C` | `result = celsius` |
| `F` | `result = celsius * 9 / 5 + 32` |
| `K` | `result = celsius + 273.15` |
| `R` | `result = (celsius + 273.15) * 9 / 5` |

### 5.2 ตรวจสูตรกับตัวอย่างที่ 2 (`100 R` → `C`)
- เข้าเซลเซียส: `(100 - 491.67) * 5 / 9` = `-391.67 * 5 / 9` = `-217.594...`
- ปลายทางเป็น C อยู่แล้ว ไม่ต้องแปลงต่อ
- พิมพ์ `:.2f` ได้ **`-217.59`** ✅

### 5.3 แยกเป็นฟังก์ชันย่อย อ่านง่ายและตรวจง่าย
เขียนเป็น 2 ฟังก์ชันตามขั้นตอน ทำให้โค้ดสั้นและอธิบายได้ทีละส่วน:

```python
def to_celsius(value, unit):
    """แปลงจากหน่วย unit มาเป็นเซลเซียส"""
    if unit == "F":
        return (value - 32) * 5 / 9
    if unit == "K":
        return value - 273.15
    if unit == "R":
        return (value - 491.67) * 5 / 9
    return value          # unit == "C"
```

จากนั้นเรียกซ้อนกันในบรรทัดเดียว:

```python
result = from_celsius(to_celsius(temperature, source_unit), target_unit)
```

### 5.4 ทำไมใช้ `if` หลายตัวแทน `if / elif`
เมื่อในบล็อกมี `return` แล้ว การ `return` จะจบฟังก์ชันทันที ไม่ไหลไปเช็กเงื่อนไขถัดไปอยู่แล้ว
จึงไม่จำเป็นต้องเขียน `elif` — และ `return value` บรรทัดสุดท้ายทำหน้าที่เป็น `else` ไปในตัว

> **ข้อดีที่สำคัญ**: วิธีนี้ทำให้ฟังก์ชัน **มีค่าส่งกลับเสมอ** ต่างจากการเขียน `if/elif` ต่อกันโดยไม่มี `else` ซึ่งถ้าอินพุตหลุดจากทุกเงื่อนไข ตัวแปรจะไม่ถูกกำหนดค่าและเกิด error

### 5.5 อย่าลืม `:.2f`
โจทย์กำหนดทศนิยม 2 ตำแหน่งชัดเจน ต้องใช้ `print(f"{result:.2f}")`
ถ้า `print(result)` เฉย ๆ จะได้ `310.75000000000006` ซึ่งผิดทันที
