## 5. จุดสำคัญและเทคนิคที่ใช้

### 5.1 จุดตายของข้อนี้: ต้อง "ตัดทิ้ง" ไม่ใช่ "ปัดเศษ"

ข้อนี้อัตราผ่านแค่ 57.50% เพราะคนส่วนใหญ่พลาดตรงนี้ ลองดูปีที่ 2 ของตัวอย่างที่ 2:

| วิธีคิด | ปีที่ 1 | ปีที่ 2 | ผลลัพธ์ |
| :--- | :--- | :--- | :--- |
| ไม่ตัดเศษเลย | 103.81 | 107.7645... | `107.76` หรือ `107.77` (แล้วแต่การปัด) |
| **ตัดเศษทุกปี (ถูกต้อง)** | 103.81 | 107.76 | **`107.76`** |

โจทย์บอกว่า *"เศษสตางค์ตั้งแต่หลักที่สามขึ้นไป**ของมูลค่าที่เพิ่มขึ้น**ในแต่ละปี ให้ตัดทิ้ง"*
แปลว่าต้องตัดเศษ **ทุก ๆ ปี** ระหว่างลูป ไม่ใช่เก็บค่าเต็มไว้แล้วค่อยตัดตอนพิมพ์

### 5.2 อย่าใช้ float คำนวณเงินโดยตรง

`float` เก็บเลขทศนิยมได้ไม่เป๊ะ พอวนลูปหลายปีความคลาดเคลื่อนจะสะสมจนคำตอบเพี้ยนไป 1 สตางค์
วิธีที่ปลอดภัยคือ **แปลงเงินเป็นจำนวนเต็มหน่วย "สตางค์"** แล้วคำนวณด้วยจำนวนเต็มล้วน:

```python
satang = round(price * 100)          # 100.00 บาท -> 10000 สตางค์
for _ in range(years):
    satang += satang * 381 // 10000  # // คือหารปัดลง = ตัดเศษทิ้งพอดี
```

ตัวดำเนินการ `//` (floor division) กับจำนวนเต็มบวก ให้ผลเป็นการ "ตัดเศษทิ้ง" พอดีตามที่โจทย์ต้องการ

### 5.3 ทำไมเป็น `* 381 // 10000`
- อัตราเงินเฟ้อ 3.81% = คูณ `0.0381`
- เขียนเป็นเศษส่วนจำนวนเต็มคือ `381 / 10000`
- ดังนั้น `satang * 381 // 10000` คือ "3.81% ของยอดปัจจุบัน แล้วตัดเศษทิ้ง"

### 5.4 ตอนพิมพ์ ห้ามแปลงกลับเป็น float!

จุดนี้พลาดกันบ่อยและทำให้โปรแกรม **crash** เป็น `OverflowError`:

```python
print(f"{satang / 100:.2f}")   # ❌ OverflowError เมื่อ k เยอะ
```

เพราะ `int` ของ Python ใหญ่ได้ไม่จำกัด แต่ `float` เก็บได้สูงสุดราว $1.8 \times 10^{308}$
พอ `k` มาก ๆ ยอด `satang` จะใหญ่เกินกว่าที่ `float` รับไหว การหาร `/ 100` จึงพังทันที:

```text
OverflowError: integer division result too large for a float
```

**วิธีแก้**: แยกส่วน "บาท" กับ "สตางค์" ด้วยเลขจำนวนเต็มล้วน ไม่ต้องแตะ `float` เลย

```python
print(f"{satang // 100}.{satang % 100:02d}")   # ✅ ปลอดภัยทุกขนาด
```

- `satang // 100` คือจำนวนบาท (หารปัดลง)
- `satang % 100` คือเศษสตางค์ที่เหลือ
- `:02d` บังคับให้สตางค์มี 2 หลักเสมอ เช่น 5 สตางค์ ต้องพิมพ์เป็น `05` ไม่ใช่ `5`

> ถ้าลืม `:02d` แล้วยอดเป็น 103 บาท 5 สตางค์ จะพิมพ์ออกมาเป็น `103.5` แทนที่จะเป็น `103.05` ซึ่งผิด
