## ✅ Self-check ก่อนออกจากบ้าน

ตอบได้ทุกข้อภายใน 10 วินาที = พร้อมสอบ

1. `A` ขนาด 3×5 → `T: R? → R?`  → **R⁵ → R³**
2. ถอดรหัสใช้สูตรอะไร → **`X = Y A⁻¹`**
3. `A⁻¹ =` ? → **`adj(A)/det(A)`** และ **adj ต้อง transpose**
4. `det = 0` แปลว่าเวกเตอร์ชุดนั้น… → **ขึ้นต่อกันเชิงเส้น (dependent)**
5. เมทริกซ์สามเหลี่ยม eigenvalue คือ… → **สมาชิกแนวทแยงหลัก**
6. "พหุนามดีกรีเท่ากับ 3 พอดี" เป็น vector space ไหม → **ไม่เป็น (พังสัจพจน์ข้อ 1)**
7. `T₂∘T₁` เมทริกซ์คือ… → **`A₂A₁`**
8. `u · v = 0` แปลว่า… → **ตั้งฉาก θ = 90°**
9. Cramer ใช้ได้เมื่อ… → **จัตุรัส และ `det(A) ≠ 0`**
10. `det(2A)` เมื่อ A เป็น 3×3 และ `det(A)=5` → **`2³ × 5 = 40`**
