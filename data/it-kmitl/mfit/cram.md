# 🔢 ข้อ 1–2 · Cryptography (เข้ารหัส/ถอดรหัส)

## ตารางแปลงอักขระ — ท่องให้ขึ้นใจ

```
0 = ช่องว่าง   1=A  2=B  3=C  4=D  5=E  6=F  7=G  8=H  9=I  10=J
11=K 12=L 13=M 14=N 15=O 16=P 17=Q 18=R 19=S 20=T
21=U 22=V 23=W 24=X 25=Y 26=Z
```
**ทริค:** จำแค่ **E=5, J=10, O=15, T=20, Y=25** แล้วนับขึ้น-ลงจากหมุดพวกนี้

## สูตรหลัก

```
เข้ารหัส:   Y = X A          (X = เมทริกซ์แถว 1×n , A = กุญแจ n×n invertible)
ถอดรหัส:   X = Y A⁻¹
```

> 🚨 **คูณด้านขวาเสมอ!** `XA` ไม่ใช่ `AX` — สลับแล้วผิดทั้งข้อ

## ขั้นตอนเข้ารหัส (5 ขั้น)

1. แปลงอักขระ → ตัวเลข (**ช่องว่างนับเป็น 0 ด้วย ห้ามข้าม**)
2. แบ่งเป็นบล็อกละ **n ตัว** (n = ขนาดกุญแจ; ปีก่อนใช้ **3×3** → บล็อกละ 3)
3. **ไม่ครบบล็อก → เติม 0 ท้าย**
4. คูณแต่ละบล็อก: `[a b c] · A`
5. เรียงผลลัพธ์ต่อกันเป็น cryptogram (**มีค่าติดลบได้ ปกติ**)

## ขั้นตอนถอดรหัส (4 ขั้น)

1. หา `A⁻¹` — สูตร: **`A⁻¹ = adj(A) / det(A)`**
2. แบ่ง cryptogram เป็นบล็อกละ n
3. คูณ `[y₁ y₂ y₃] · A⁻¹`
4. แปลงเลขกลับเป็นอักขระ

### หา adj(A) สำหรับ 3×3 (ขั้นตอนที่คนพลาดมากสุด)

```
1) หาโคแฟกเตอร์ทั้ง 9 ตัว:  Cᵢⱼ = (−1)^(i+j) · Mᵢⱼ
2) วางเป็นเมทริกซ์ [Cᵢⱼ]
3) *** TRANSPOSE ***  →  adj(A) = [Cᵢⱼ]ᵀ      ← ลืมข้อนี้ = ผิดทั้งข้อ
4) A⁻¹ = adj(A)/det(A)
```

ตารางเครื่องหมาย: `+ − + / − + − / + − +`

## ⚠️ กับดักข้อ 1–2

| กับดัก | วิธีกัน |
|---|---|
| ลืมนับช่องว่าง = 0 | นับตัวอักษร**รวมช่องว่าง**ก่อนแบ่งบล็อกเสมอ |
| ลืมเติม 0 ให้ครบบล็อก | ความยาวต้องหารด้วย n ลงตัว |
| คูณ `AX` แทน `XA` | X เป็นแถว → อยู่ **ซ้าย** เสมอ |
| ลืม transpose ตอนหา adj | เขียน "**ᵀ**" ตัวใหญ่ ๆ ไว้ในกระดาษทด |
| ถอดรหัสด้วย A แทน A⁻¹ | เช็กว่าผลลัพธ์ต้องอยู่ในช่วง 0–26 |

**✅ เช็กคำตอบ:** ตัวเลขที่ถอดได้ต้องอยู่ใน **0–26 ทุกตัว** ถ้าหลุดช่วง = คำนวณผิด

# 🔢 ข้อ 3 · แก้ระบบสมการเชิงเส้น (15 นาที · หนักสุดในครึ่งแรก)

## เลือกวิธีให้ถูก — ตารางตัดสินใจ

| สถานการณ์ | ใช้วิธี | เหตุผล |
|---|---|---|
| โจทย์ถามหา **ตัวแปรเดียว** (เช่น "หา x₂") | **Cramer** | กางแค่ 2 det ไม่ต้องแก้ทั้งระบบ |
| จัตุรัส + ต้องการ **ทุกตัวแปร** | **Gauss-Jordan** | อ่านคำตอบได้เลย ไม่ต้องแทนย้อน |
| **ไม่จัตุรัส** หรือ `det = 0` | **Gauss-Jordan เท่านั้น** | Cramer ใช้ไม่ได้เด็ดขาด |
| สมการเยอะ ตัวเลขสวย | Gaussian + back-substitution | เร็วกว่า Gauss-Jordan เล็กน้อย |

## Cramer's Rule

```
xᵢ = det(Aᵢ) / det(A)      โดย Aᵢ = แทน "คอลัมน์ที่ i" ของ A ด้วย b
```
**ใช้ได้เมื่อ: จัตุรัส AND det(A) ≠ 0 เท่านั้น**

## Gauss-Jordan — ลำดับที่ทำให้ไม่หลง

```
[A | b]  →  ทำคอลัมน์ 1 ให้เป็น (1,0,0)ᵀ
         →  ทำคอลัมน์ 2 ให้เป็น (0,1,0)ᵀ
         →  ทำคอลัมน์ 3 ให้เป็น (0,0,1)ᵀ
[I | x]  →  อ่านคำตอบจากคอลัมน์ขวาสุดได้เลย
```

**Elementary row operations 3 แบบ:**
1. สลับ 2 แถว
2. คูณแถวด้วยค่าคงที่ ≠ 0
3. บวกพหุคูณของแถวหนึ่งเข้าอีกแถว ← **ใช้ตัวนี้เป็นหลัก เลี่ยงเศษส่วน**

> 💡 **ทริคเลี่ยงเศษส่วน:** ถ้าตัวนำเป็น 2 หรือ 3 อย่ารีบหาร — หาแถวอื่นที่มี 1 มาสลับขึ้นมาก่อน หรือใช้ `R₂ − R₃` สร้าง 1 ขึ้นมา

## จำนวนผลเฉลย — อ่านจาก row-echelon form

| รูปแบบที่เห็น | ความหมาย |
|---|---|
| ได้ `I` เต็ม | **ผลเฉลยเดียว** |
| แถว `[0 0 0 \| c]` เมื่อ c ≠ 0 | **ไม่มีผลเฉลย** (inconsistent) |
| แถวศูนย์ล้วน `[0 0 0 \| 0]` | **ผลเฉลยอนันต์** (มี free variable) |

**ระบบเอกพันธ์ `Ax = 0`:** มีผลเฉลยเสมอ · ถ้า **ตัวแปร > สมการ → อนันต์แน่นอน**

**✅ เช็กคำตอบ: แทนค่ากลับทั้ง 3 สมการ — ใช้เวลา 30 วินาที คุ้มมาก**

# 🔢 ข้อ 4 · Dot Product, Norm, มุม (5 นาที · ของฟรี)

```
u · v  = u₁v₁ + u₂v₂ + … + uₙvₙ            → ได้ "ตัวเลข"
‖u‖    = √(u₁² + u₂² + … + uₙ²)
u · u  = ‖u‖²                              ← ถามบ่อยมาก
cos θ  = (u · v) / (‖u‖ ‖v‖)
```

## ตารางอ่านมุมทันที

| `u · v` | มุม θ | |
|---|---|---|
| **= 0** | **90° (ตั้งฉาก / orthogonal)** | หยุดคำนวณได้เลย |
| > 0 | แหลม (0°–90°) | |
| < 0 | ป้าน (90°–180°) | |

## มุมที่ออกบ่อย (จำค่าไว้ ไม่ต้องกดเครื่องคิดเลข)

| cos θ | θ |
|---|---|
| 1 | 0° |
| √3/2 | 30° |
| √2/2 ≈ 0.707 | **45°** |
| 1/2 | **60°** |
| 0 | **90°** |
| −1/2 | 120° |
| −√2/2 | 135° |

## สูตรเสริมที่อาจโผล่

```
‖cu‖ = |c| · ‖u‖                    ← ค่าสัมบูรณ์!
unit vector:  û = u / ‖u‖
ระยะห่าง:      d(u,v) = ‖u − v‖
```

## ⚠️ กับดัก
- ลืมถอดราก (ตอบ `‖u‖²` แทน `‖u‖`)
- `u · u` กับ `‖u‖` สับกัน — `u·u = ‖u‖²` **ไม่ใช่** `‖u‖`
- เครื่องคิดเลขตั้งเป็น RAD แทน DEG → **เช็กก่อนเข้าห้องสอบ**

# 🔢 ข้อ 5–6 · ปริภูมิเวกเตอร์ (Vector Space) — 10 นาที

> **รูปแบบคำถามจริง: "ให้บอกว่าผิดสัจพจน์ข้อไหน เพราะอะไร"** — อาจารย์**แจกสัจพจน์ 10 ข้อมาให้ในข้อสอบ** แต่ต้องชี้ให้ถูกข้อ

## สัจพจน์ 10 ข้อ (ตัวที่พังจริงมีแค่ 2 ตัว)

| # | สัจพจน์ | ชื่อ |
|---|---|---|
| **1** | `u + v ∈ V` | 🔥 **Closure under addition** |
| 2 | `u + v = v + u` | Commutative |
| 3 | `(u+v)+w = u+(v+w)` | Associative |
| 4 | มี `0 ∈ V` | Additive identity |
| 5 | มี `−u ∈ V` | Additive inverse |
| **6** | `cu ∈ V` | 🔥 **Closure under scalar multiplication** |
| 7 | `c(u+v) = cu + cv` | Distributive |
| 8 | `(c+d)u = cu + du` | Distributive |
| 9 | `c(du) = (cd)u` | Associative |
| 10 | `1·u = u` | Scalar identity |

> 🎯 **99% ของโจทย์พังที่ข้อ 1 หรือ ข้อ 6** — ตรวจ 2 ข้อนี้ก่อนเสมอ (แล้วค่อยดูข้อ 4 กรณีไม่มีเวกเตอร์ศูนย์)

## วิธีทำ 3 ขั้น (ใช้ได้ทุกข้อ)

```
1) จัดรูปเซตให้เป็นพารามิเตอร์เดียว   เช่น {(x,y) : y = 2x}  →  {(x, 2x) : x ∈ R}
2) เช็กข้อ 1 :  หยิบ v₁=(x₁,2x₁), v₂=(x₂,2x₂)  →  v₁+v₂ = (x₁+x₂, 2(x₁+x₂))  ✓ ยังอยู่ในรูปเดิม
3) เช็กข้อ 6 :  cv₁ = (cx₁, 2(cx₁))                                          ✓ ยังอยู่ในรูปเดิม
→ เป็น vector space
```

## ตารางเซตที่ออกสอบบ่อย (ท่องตารางนี้ = ได้ฟรี)

| เซต | เป็น VS? | ถ้าไม่ พังข้อไหน |
|---|---|---|
| `R`, `R²`, `Rⁿ` | ✅ | — |
| `Mₘ,ₙ` (เมทริกซ์ m×n ทั้งหมด) | ✅ | — |
| `Pₙ` = พหุนามดีกรี **ไม่เกิน** n | ✅ | — |
| `{(x, 2x) : x ∈ R}` (เส้นตรงผ่านจุดกำเนิด) | ✅ | — |
| **พหุนามดีกรี = 2 พอดี** | ❌ | **ข้อ 1** — `2x² + (−2x²) = 0` ดีกรีไม่ใช่ 2 แล้ว |
| **พหุนามดีกรี = 4 พอดี** | ❌ | **ข้อ 1** (เหตุผลเดียวกัน) + ข้อ 4 ไม่มีศูนย์ |
| `{(x,y) : x ≥ 0, y ≥ 0}` (ควอดรันต์ 1) | ❌ | **ข้อ 6** — คูณ `−1` แล้วหลุด |
| **เซตจำนวนเต็ม** | ❌ | **ข้อ 6** — `½ × 3 = 1.5` ไม่ใช่จำนวนเต็ม |
| `{(x,y) : x + y = 1}` | ❌ | **ข้อ 4** ไม่มี `0` + ข้อ 1 |
| เมทริกซ์ singular (det = 0) | ❌ | **ข้อ 1** — `[1 0;0 0] + [0 0;0 1] = I` |

## ⚠️ กับดักอันดับ 1
**"ดีกรีเท่ากับ n พอดี" ≠ "ดีกรีไม่เกิน n"**
- ดีกรี**เท่ากับ** → ❌ ไม่เป็น
- ดีกรี**ไม่เกิน / at most** → ✅ เป็น

# 🔢 ข้อ 7 · อิสระเชิงเส้น / ขึ้นต่อกันเชิงเส้น (10 นาที)

## นิยาม + กฎทอง

```
c₁v₁ + c₂v₂ + … + cₖvₖ = 0

ได้ c₁ = c₂ = … = 0 อย่างเดียว   →   อิสระเชิงเส้น (independent)
ได้คำตอบอื่นด้วย                  →   ขึ้นต่อกันเชิงเส้น (dependent)
```

> 🎯 อาจารย์เขียนเน้นไว้เลย: **"ถ้าคำตอบ = 0 จะเป็นอิสระเชิงเส้น"**

## ทางลัดตามจำนวนเวกเตอร์ (เลือกให้ถูก = ประหยัด 8 นาที)

| กรณี | ทางลัด |
|---|---|
| **มีเวกเตอร์ศูนย์อยู่ในเซต** | **dependent ทันที** ไม่ต้องคำนวณ |
| **2 เวกเตอร์** | dependent ⟺ **เป็นพหุคูณกัน** (หารกันดูทีละตัว) |
| **จำนวนเวกเตอร์ > มิติ** (เช่น 4 ตัวใน R³) | **dependent ทันที** |
| **n เวกเตอร์ใน Rⁿ** (จัตุรัสพอดี) | หา **det** → `det ≠ 0` = independent · `det = 0` = dependent |
| **อื่น ๆ** | ตั้ง augmented matrix `[v₁ v₂ v₃ \| 0]` → Gauss-Jordan |

## วิธีมาตรฐาน (เมื่อทางลัดใช้ไม่ได้)

```
1) วางเวกเตอร์เป็น "คอลัมน์" ของเมทริกซ์  →  [v₁ v₂ v₃ | 0]
2) Gauss-Jordan
3) ได้ I เต็ม (ไม่มี free variable)  →  independent
   มีแถวศูนย์ / free variable        →  dependent
```

## ⚠️ กับดัก
- `det = 0` → **dependent** (ไม่ใช่ independent) — คนสลับกันบ่อยมาก
- วางเวกเตอร์เป็น**แถว**แทนคอลัมน์ — ผลเรื่อง independence เหมือนกัน แต่ถ้าโจทย์ให้เขียนความสัมพันธ์ต่อจะงง
- ตอบว่า dependent แล้วไม่เขียนความสัมพันธ์ (ถ้าโจทย์ถามต่อ)

# 🔢 ข้อ 8 · เมทริกซ์มาตรฐานของการแปลงเชิงเส้น (10 นาที)

## 4 รูปแบบย่อยที่ออก (จากตัวอย่างจริงของอาจารย์)

### 8.1 หา image และ preimage

```
image ของ v      =  แทน v ลงใน T ตรง ๆ         →  T(v)
preimage ของ w   =  ตั้งสมการ T(v) = w แล้วแก้หา v   ← ต้องแก้ระบบสมการ
```

**ตัวอย่างสไตล์อาจารย์:** `T(v₁,v₂) = (v₁+v₂, v₁−v₂)`, หา preimage ของ `w = (3,19)`
```
v₁ + v₂ =  3   …(1)
v₁ − v₂ = 19   …(2)
(1)+(2):  2v₁ = 22  →  v₁ = 11,  v₂ = −8      →  preimage = (11, −8)
```

### 8.2 หามิติ n, m จากเมทริกซ์ A

```
A ขนาด m × n   ⟹   T : Rⁿ → Rᵐ
        ↑   ↑
      แถว  คอลัมน์
```
> 🚨 **คอลัมน์ = n = ต้นทาง · แถว = m = ปลายทาง** — A ขนาด 3×4 → `T: R⁴ → R³` **ไม่ใช่** R³→R⁴

### 8.3 หา standard matrix จากสูตร T

**วิธีเร็วที่สุด — จัดเรียงตัวแปรแล้วอ่านสัมประสิทธิ์เป็นแถว**

```
T(x, y, z) = (3z − 2y, 4x + 11z)

จัดใหม่:  ( 0x − 2y + 3z ,  4x + 0y + 11z )

A = [ 0  −2   3 ]      ← 2×3  →  T: R³ → R²
    [ 4   0  11 ]
```

**วิธีตรวจ:** `A = [T(e₁) T(e₂) T(e₃)]` วาง image ของเวกเตอร์ฐานเป็น **คอลัมน์**

### 8.4 Composition

```
T = T₂ ∘ T₁   ⟹   A = A₂ A₁       ← ตัวที่ทำ "ทีหลัง" อยู่ "ซ้าย"
T′ = T₁ ∘ T₂  ⟹   A′ = A₁ A₂

A₂A₁ ≠ A₁A₂  (โจทย์มักให้หาทั้งสองอันเพื่อดักตรงนี้)
```

## ⚠️ กับดักข้อ 8
| กับดัก | กัน |
|---|---|
| เรียงสัมประสิทธิ์ตามที่โจทย์เขียน แทนที่จะเรียง x,y,z | **เขียน `0x + 0y + 0z` เติมให้ครบก่อนเสมอ** |
| สลับ n กับ m | ท่อง "**คอลัมน์คือต้นทาง**" |
| `T₂∘T₁ = A₁A₂` | ท่อง "**ทีหลังอยู่ซ้าย**" |
| วาง `T(eᵢ)` เป็นแถวแทนคอลัมน์ | ได้ `Aᵀ` → ผิด |

# 🔢 ข้อ 9 · การแปลงเชิงเส้นมีตัวผกผัน (10 นาที)

> อาจารย์เขียนกำกับไว้ว่า **"ไปหาเพิ่ม น่าจะยากกว่านี้"** → คาดว่าเป็น 3×3 ที่ไม่ใช่รูปสามเหลี่ยมง่าย ๆ

## ขั้นตอน 4 ขั้น

```
1) เขียน standard matrix A  (เติม 0 ให้ครบทุกตัวแปร)
2) หา det(A)
       det(A) ≠ 0  →  T หาตัวผกผันได้ (invertible)
       det(A) = 0  →  หาไม่ได้  →  ตอบแค่นี้ จบ
3) หา A⁻¹  (Gauss-Jordan: [A | I] → [I | A⁻¹]  หรือ  adj(A)/det(A))
4) เขียนกลับเป็นฟังก์ชัน:  T⁻¹(x₁,x₂,x₃) = A⁻¹ · (x₁,x₂,x₃)ᵀ
```

## ตัวอย่างสไตล์อาจารย์

`T(x₁,x₂,x₃) = (x₁, x₁+x₂, x₁+x₂+x₃)`

```
A = [1 0 0]        det = 1 ≠ 0  →  invertible
    [1 1 0]
    [1 1 1]

A⁻¹ = [ 1  0  0]    →  T⁻¹(x₁,x₂,x₃) = (x₁,  x₂−x₁,  x₃−x₂)
      [−1  1  0]
      [ 0 −1  1]
```

## ⚠️ กับดัก
- ลืมตรวจ `det` ก่อน แล้วไปเสียเวลาหา A⁻¹ ของเมทริกซ์ที่ singular
- หา `A⁻¹` ได้แล้วแต่**ลืมเขียนกลับเป็นฟังก์ชัน** (โจทย์ถามหา `T⁻¹` ไม่ใช่ `A⁻¹`)
- **✅ เช็ก:** `T⁻¹(T(v)) = v` — เลือก v ง่าย ๆ เช่น (1,2,3) แทนดู

# 🔢 ข้อ 10 · ค่าเจาะจง + เวกเตอร์เจาะจง (20 นาที · หนักสุด)

## นิยาม

```
A x = λ x        (x ≠ 0)
λ = eigenvalue (ค่าเจาะจง)   ·   x = eigenvector (เวกเตอร์เจาะจง)
```

## ขั้นตอน 4 ขั้น (ตามที่อาจารย์เฉลย)

```
① หา λ ก่อน:   det(λI − A) = 0     →  แก้สมการลักษณะเฉพาะ
② แทน λ แต่ละค่าลงใน (λI − A)
③ ทำเป็น row-echelon form (ทำแถวให้เป็นศูนย์)
④ แก้ระบบเอกพันธ์ → ตั้ง free variable = t → เขียนเวกเตอร์เจาะจง
```

## 🔥 ทางลัดที่ต้องจับให้ได้ใน 5 วินาที

> **ถ้า A เป็นเมทริกซ์สามเหลี่ยม (บน/ล่าง/ทแยง) → eigenvalue = สมาชิกบนแนวทแยงหลัก**
> ไม่ต้องกางสมการลักษณะเฉพาะเลย! (ตัวอย่างจริงของอาจารย์เป็นสามเหลี่ยมบนพอดี)

## การเขียน `λI − A` (คนพลาดตรงนี้เยอะ)

```
        [λ 0 0]   [a b c]     [λ−a   −b    −c ]
λI−A =  [0 λ 0] − [d e f]  =  [ −d  λ−e   −f  ]
        [0 0 λ]   [g h i]     [ −g   −h   λ−i ]
```
> **แนวทแยงเป็น `λ − aᵢᵢ` · นอกแนวทแยงเปลี่ยนเครื่องหมายทั้งหมด**

## ✅ เช็กคำตอบ 2 ชั้น (ทำทุกครั้ง — ใช้ 1 นาที)

```
Σλᵢ = trace(A)   (ผลรวมแนวทแยงหลัก)
Πλᵢ = det(A)
A x = λ x        ← แทน eigenvector กลับไปคูณ ต้องได้ λ เท่า
```

## ⚠️ กับดักข้อ 10
| กับดัก | กัน |
|---|---|
| เซ็นต์ผิดตอนทำ `λI − A` | นอกแนวทแยง **ต้องกลับเครื่องหมายทุกตัว** |
| ตอบ eigenvector เป็น **0** | eigenvector **ต้องไม่ใช่เวกเตอร์ศูนย์** ตามนิยาม |
| เจอ eigenvalue ซ้ำแล้วตกใจ | ปกติ — แค่ eigenspace อาจมีมิติ > 1 |
| ลืมว่า eigenvector คูณค่าคงที่ได้ | `t·(1,−2,1)` กับ `(2,−4,2)` ถูกทั้งคู่ — เลือกอันที่เป็นจำนวนเต็มสวย ๆ |
| กางสมการลักษณะเฉพาะทั้งที่เป็นสามเหลี่ยม | เสียเวลา 10 นาทีฟรี ๆ |

# 🧰 ภาคผนวก · สูตรสำรอง (เผื่อออกนอก blueprint)

## Determinant

```
2×2:  det = ad − bc
3×3:  กางโคแฟกเตอร์ตามแถว/คอลัมน์ที่มีศูนย์เยอะสุด
      Cᵢⱼ = (−1)^(i+j) Mᵢⱼ

det(Aᵀ) = det(A)             det(AB) = det(A)det(B)
det(cA) = cⁿ det(A)  ← n!    det(A⁻¹) = 1/det(A)
det(สามเหลี่ยม) = ผลคูณแนวทแยง
det(adj A) = [det(A)]ⁿ⁻¹
```

**ผลของ row operation ต่อ det:** สลับแถว → ×(−1) · คูณแถวด้วย k → ×k · **บวกพหุคูณเข้าแถวอื่น → ไม่เปลี่ยน**

## เมทริกซ์

```
(AB)ᵀ = BᵀAᵀ          (AB)⁻¹ = B⁻¹A⁻¹        ← สลับลำดับทั้งคู่
A⁻¹ (2×2) = 1/(ad−bc) · [ d  −b ]
                        [−c   a ]
AB ≠ BA (โดยทั่วไป)
A symmetric ⟺ A = Aᵀ         AAᵀ, AᵀA symmetric เสมอ
```

## Cross Product (ถ้าโผล่มา)

```
u × v = (u₂v₃−u₃v₂ ,  u₃v₁−u₁v₃ ,  u₁v₂−u₂v₁)
```
> พจน์กลางกลับเครื่องหมาย! ตรวจด้วย `(u×v)·u = 0` และ `(u×v)·v = 0`

## Diagonalization / Orthogonal (ถ้าโผล่มา)

```
P⁻¹AP = D        P = [eigenvectors เป็นคอลัมน์]   D = diag(λ)  ← ลำดับต้องตรงกัน
diagonalizable ⟺ มี eigenvector อิสระครบ n ตัว
มี λ ต่างกัน n ค่า  →  diagonalizable แน่นอน
P orthogonal ⟺ P⁻¹ = Pᵀ  ⟺ คอลัมน์ orthonormal    →  det(P) = ±1
A orthogonally diagonalizable ⟺ A symmetric
```

## Rotation ใน R²

```
[cos θ   −sin θ]
[sin θ    cos θ]
```
