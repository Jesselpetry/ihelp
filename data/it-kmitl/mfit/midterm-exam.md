## พาร์ตที่ 1 · ปรนัย

### ข้อ 1 — ตอบ ค. `AᵀB`

**หลักการ:** `(m × n)(n × p)` จะหาค่าได้ก็ต่อเมื่อ **จำนวนคอลัมน์ของตัวหน้า = จำนวนแถวของตัวหลัง**

| ตัวเลือก | ขนาดที่คูณ | ผล |
|---|---|---|
| ก. `ABC` | (3×4)(4×2) = 3×2 → (3×2)(2×3) = **3×3** | ✅ หาได้ |
| ข. `CAB` | (2×3)(3×4) = 2×4 → (2×4)(4×2) = **2×2** | ✅ หาได้ |
| **ค. `AᵀB`** | `Aᵀ` = **4×3**, `B` = **4×2** → 3 ≠ 4 | ❌ **undefined** |
| ง. `BC` | (4×2)(2×3) = **4×3** | ✅ หาได้ |

**ทำไมตัวเลือกอื่นผิด:** ทุกตัวมีมิติสอดคล้องกันหมด
**กับดัก:** นักศึกษามักคิดว่า "transpose แล้วต้องคูณได้" — จริง ๆ การ transpose **สลับมิติ** จาก 3×4 เป็น 4×3 ทำให้คอลัมน์กลายเป็น 3 ซึ่งไม่ตรงกับแถวของ `B` ที่มี 4
> **นิสัยที่ต้องสร้าง:** เขียนขนาดกำกับใต้ทุกตัวก่อนคูณเสมอ

---

### ข้อ 2 — ตอบ ก. 16

```
det(2Aᵀ A⁻¹) = det(2Aᵀ) · det(A⁻¹)          [det(XY) = det(X)det(Y)]
             = 2⁴ · det(Aᵀ) · det(A⁻¹)      [det(cA) = cⁿ det(A), n = 4]
             = 16 · det(A) · 1/det(A)       [det(Aᵀ) = det(A), det(A⁻¹) = 1/det(A)]
             = 16 · 3 · (1/3)
             = 16
```

**ทำไมตัวเลือกอื่นผิด:**
- **ข. 48** — มาจากการคิดว่า `det(2Aᵀ) = 2⁴·3 = 48` แล้วลืมคูณ `det(A⁻¹) = 1/3` ต่อ
- **ค. 6** — ผิดสองชั้นพร้อมกัน: ใช้ `det(cA) = c·det(A)` (**ผิด!** ต้องเป็น `cⁿ`) **และ** ลืมคูณ `det(A⁻¹)` ต่อ → เหลือ `2 · det(A) = 2 · 3 = 6`
- **ง. 1/16** — ใช้เลขชี้กำลังกลับเครื่องหมายเป็น `det(cA) = c⁻ⁿ det(A)` → `2⁻⁴ · 3 · (1/3) = 1/16`

**กับดักหลัก:** `det(cA) = cⁿ det(A)` — **เลขชี้กำลัง n คือขนาดเมทริกซ์** ไม่ใช่คูณตรง ๆ

### ข้อ 3 — ตอบ ข. `{(x, y, z) : x + y = 1}`

**Test for a Subspace** ต้องผ่าน 3 ข้อ: `0 ∈ W` · ปิดใต้การบวก · ปิดใต้การคูณสเกลาร์

**ตัวเลือก ข. ล้มเหลวตั้งแต่ข้อแรก:** แทน `(0,0,0)` → `0 + 0 = 0 ≠ 1` → **ไม่มีเวกเตอร์ศูนย์** → ไม่เป็น subspace
และยังไม่ปิดใต้การบวกด้วย: `(1,0,0) + (0,1,0) = (1,1,0)` แต่ `1 + 1 = 2 ≠ 1`

**ทำไมตัวเลือกอื่นเป็น subspace:**
- **ก.** สมการ **เอกพันธ์** `x + 2y − z = 0` → `(0,0,0)` สอดคล้อง ✓ · ถ้า `u, v` สอดคล้อง `(u₁+v₁) + 2(u₂+v₂) − (u₃+v₃) = 0 + 0 = 0` ✓ · `cu` ก็ได้ `c·0 = 0` ✓
  (เซตผลเฉลยของระบบเอกพันธ์เป็น subspace เสมอ)
- **ค.** เมทริกซ์ศูนย์สมมาตร ✓ · `(A+B)ᵀ = Aᵀ + Bᵀ = A + B` ✓ · `(cA)ᵀ = cAᵀ = cA` ✓
- **ง.** พหุนามศูนย์ให้ `p(0) = 0` ✓ · `(p+q)(0) = p(0)+q(0) = 0` ✓ · `(cp)(0) = c·0 = 0` ✓

**กับดัก:** เงื่อนไขที่ **เท่ากับค่าคงที่ที่ไม่ใช่ศูนย์** (`= 1`) ทำให้ไม่เป็น subspace เสมอ — ให้มองหาเลข "≠ 0" ทางขวาของสมการก่อน

### ข้อ 4 — ตอบ ค. มีผลเฉลยเป็นจำนวนอนันต์

**ทฤษฎี:** ระบบเอกพันธ์ `Ax = 0`
1. **มีผลเฉลยเสมอ** อย่างน้อยคือ `x = 0` → ตัดข้อ ก. ทิ้งทันที (ไม่มีทาง inconsistent)
2. ถ้า **จำนวนตัวแปร > จำนวนสมการ** → มี free variable อย่างน้อย 1 ตัว → **มีผลเฉลยไม่ชัด (nontrivial) เป็นจำนวนอนันต์**

ในที่นี้ 5 ตัวแปร แต่มีเพียง 3 สมการ → rank ของ `A` ≤ 3 → free variable ≥ 5 − 3 = 2 ตัว

**ทำไมตัวเลือกอื่นผิด:**
- **ก.** ระบบเอกพันธ์ไม่มีทางไม่มีผลเฉลย เพราะ `x = 0` สอดคล้องเสมอ
- **ข.** จะเป็นจริงก็ต่อเมื่อ rank = จำนวนตัวแปร ซึ่งเป็นไปไม่ได้เมื่อสมการน้อยกว่าตัวแปร
- **ง.** เป็นข้อสรุปเชิงทฤษฎีที่ **ไม่ต้อง** คำนวณ — นี่คือประเด็นที่ข้อสอบต้องการทดสอบ

### ข้อ 8 — ตอบ ง. `P` ต้องเป็นเมทริกซ์สมมาตร

**นิยาม:** `P` เป็น orthogonal ⟺ `P⁻¹ = Pᵀ` ⟺ `PᵀP = PPᵀ = I` ⟺ คอลัมน์ของ `P` เป็นเซต **orthonormal**

**ตัวอย่างค้านของข้อ ง.:** เมทริกซ์การหมุน 90°

```
P = [ 0  −1 ]      Pᵀ = [ 0   1 ]      PᵀP = [1 0]  ✓ orthogonal
    [ 1   0 ]           [−1   0 ]            [0 1]
```

แต่ `P ≠ Pᵀ` → **ไม่สมมาตร** → ข้อ ง. **ผิด**

**ทำไมตัวเลือกอื่นถูก:**
- **ก.** คือนิยามโดยตรง
- **ข.** จาก `PᵀP = I` → `det(Pᵀ)det(P) = 1` → `[det(P)]² = 1` → `det(P) = ±1`
- **ค.** `‖Px‖² = (Px)ᵀ(Px) = xᵀPᵀPx = xᵀIx = xᵀx = ‖x‖²` → รักษาความยาว

**กับดัก:** สับสนระหว่าง **orthogonal matrix** (`P⁻¹ = Pᵀ`) กับ **symmetric matrix** (`A = Aᵀ`) — เป็นคนละสมบัติ และ **orthogonal diagonalization** ต้องใช้ทั้งคู่ (A สมมาตร, P ตั้งฉาก) จึงมักสับสนกัน

### ข้อ 9 — ตอบ ข. ไม่ diagonalizable เพราะหาเวกเตอร์เจาะจงอิสระได้เพียง 2 ตัว

**ทฤษฎี:** `A` ขนาด n × n **diagonalizable ⟺ มีเวกเตอร์เจาะจงที่อิสระเชิงเส้นครบ n ตัว**

- `λ = 2` (ซ้ำ 2 ครั้ง) แต่ eigenspace มิติ **1** → ให้เวกเตอร์อิสระได้ 1 ตัว
- `λ = 5` (ซ้ำ 1 ครั้ง) → ให้เวกเตอร์อิสระ 1 ตัว
- รวม **2 ตัว < 3** → **ไม่ diagonalizable**

**ทำไมตัวเลือกอื่นผิด:**
- **ก.** "มีค่าเจาะจงครบ 3 ค่า" นับซ้ำไม่ได้ — เงื่อนไขเพียงพอคือ "มีค่าเจาะจง **ต่างกัน** n ค่า" ซึ่งกรณีนี้มีเพียง 2 ค่าที่ต่างกัน
- **ค. ผิดที่เหตุผล** — การมีค่าเจาะจงซ้ำ **ไม่ได้** แปลว่า diagonalize ไม่ได้
  > ตัวอย่างค้าน: `I₃` มี `λ = 1` ซ้ำ 3 ครั้ง แต่เป็นเมทริกซ์ทแยงมุมอยู่แล้ว (eigenspace มิติ 3)
  > สิ่งที่ตัดสินคือ **มิติของ eigenspace เท่ากับ multiplicity หรือไม่**
- **ง.** orthogonally diagonalizable ⟺ `A` เป็น symmetric ซึ่งโจทย์ไม่ได้ให้ข้อมูลนี้ และถ้า `A` สมมาตรจริง eigenspace ของ `λ = 2` จะต้องมีมิติ 2 (ขัดกับโจทย์)

### ข้อ 10 — ตอบ ง. `A` เป็นเมทริกซ์สมมาตร

**Equivalent Conditions ของ invertible matrix** (ทุกข้อสมมูลกัน):
`A` invertible ⟺ `det(A) ≠ 0` ⟺ `Ax = b` มีผลเฉลยเดียวทุก `b` ⟺ `Ax = 0` มีเฉพาะ trivial solution ⟺ `A` reduce ได้เป็น `Iₙ` ⟺ คอลัมน์ (และแถว) ของ `A` อิสระเชิงเส้น ⟺ rank(A) = n

**ตัวอย่างค้านของข้อ ง.** (สมมาตรแต่ไม่ invertible):

```
A = [1  1]     A = Aᵀ ✓ สมมาตร     det(A) = 1 − 1 = 0  →  ไม่ invertible
    [1  1]
```

และในทางกลับกัน `A = [1 2; 3 4]` invertible (det = −2) แต่ไม่สมมาตร
→ **ความสมมาตรกับความ invertible ไม่เกี่ยวข้องกันเลย**

**ทำไมตัวเลือกอื่นถูก:** ก. ข. ค. อยู่ในรายการ equivalent conditions ทั้งหมด

### ข้อ 22 — เฉลย

#### (ก) `W = {A ∈ M₂,₂ : tr(A) = 0}` **เป็น** ปริภูมิย่อยของ `M₂,₂`

ให้ `A = [a b; c d]` โดย `tr(A) = a + d = 0` นั่นคือ `W = {[a b; c −a] : a, b, c ∈ R}`

**ตรวจตาม Test for a Subspace ทั้ง 3 ข้อ**

**1) `W` ไม่ว่าง และมีเวกเตอร์ศูนย์**
เมทริกซ์ศูนย์ `O = [0 0; 0 0]` มี `tr(O) = 0 + 0 = 0` → `O ∈ W` ✓

**2) ปิดใต้การบวก**
ให้ `A, B ∈ W` → `tr(A) = 0` และ `tr(B) = 0`
`tr(A + B) = (a₁₁+b₁₁) + (a₂₂+b₂₂) = (a₁₁+a₂₂) + (b₁₁+b₂₂) = tr(A) + tr(B) = 0 + 0 = 0`
→ `A + B ∈ W` ✓

**3) ปิดใต้การคูณสเกลาร์**
ให้ `A ∈ W` และ `c ∈ R`
`tr(cA) = ca₁₁ + ca₂₂ = c(a₁₁ + a₂₂) = c · tr(A) = c · 0 = 0`
→ `cA ∈ W` ✓

**สรุป:** ครบทั้ง 3 เงื่อนไข → **`W` เป็นปริภูมิย่อยของ `M₂,₂`** (มีมิติ 3)

> **หมายเหตุเปรียบเทียบ:** ถ้าเปลี่ยนเงื่อนไขเป็น `tr(A) = 1` จะ **ไม่เป็น** subspace ทันที เพราะเมทริกซ์ศูนย์ไม่อยู่ในเซต

```
              | λ−2    2    −3  |
det(λI − A) = |  0    λ−3    2  |
              |  0     1    λ−2 |

= (λ−2) · [ (λ−3)(λ−2) − 2(1) ]
= (λ−2) · [ λ² − 5λ + 6 − 2 ]
= (λ−2)(λ² − 5λ + 4)
= (λ−2)(λ−1)(λ−4)
```

**✅ สมการลักษณะเฉพาะ:** `(λ − 2)(λ − 1)(λ − 4) = 0` หรือ `λ³ − 7λ² + 14λ − 8 = 0`
**✅ ค่าเจาะจง:** `λ₁ = 1, λ₂ = 2, λ₃ = 4`

#### (ข) เวกเตอร์เจาะจง

> *สัญกรณ์:* `x₁, x₂, x₃` คือองค์ประกอบของเวกเตอร์ที่กำลังแก้หา ส่วน `v₁, v₂, v₃` คือเวกเตอร์เจาะจงที่ได้

**`λ = 1`:** แก้ `(1·I − A)x = 0`
```
[ −1    2   −3 ][x₁]   [0]
[  0   −2    2 ][x₂] = [0]
[  0    1   −1 ][x₃]   [0]
```
จากแถวที่ 3: `x₂ = x₃` · จากแถวที่ 1: `−x₁ + 2x₂ − 3x₃ = 0` → `−x₁ + 2x₃ − 3x₃ = 0` → `x₁ = −x₃`
ให้ `x₃ = 1` → **`v₁ = (−1, 1, 1)`**  (เวกเตอร์เจาะจงของ `λ = 1`)

**`λ = 2`:** แก้ `(2I − A)x = 0`
```
[ 0    2   −3 ][x₁]   [0]
[ 0   −1    2 ][x₂] = [0]
[ 0    1    0 ][x₃]   [0]
```
จากแถวที่ 3: `x₂ = 0` · แทนในแถวที่ 2: `2x₃ = 0` → `x₃ = 0` · `x₁` เป็นอิสระ
ให้ `x₁ = 1` → **`v₂ = (1, 0, 0)`**  (เวกเตอร์เจาะจงของ `λ = 2`)

**`λ = 4`:** แก้ `(4I − A)x = 0`
```
[ 2    2   −3 ][x₁]   [0]
[ 0    1    2 ][x₂] = [0]
[ 0    1    2 ][x₃]   [0]
```
จากแถวที่ 2: `x₂ = −2x₃` · แทนในแถวที่ 1: `2x₁ + 2(−2x₃) − 3x₃ = 0` → `2x₁ = 7x₃` → `x₁ = 7x₃/2`
ให้ `x₃ = 2` → **`v₃ = (7, −4, 2)`**  (เวกเตอร์เจาะจงของ `λ = 4`)

**ตรวจ:** `A(7,−4,2)ᵀ = (2·7 −2(−4) + 3·2, 3(−4) −2(2), −(−4) + 2(2)) = (14+8+6, −12−4, 4+4) = (28, −16, 8) = 4(7,−4,2)` ✓

#### (ค) `A` **แปลงเป็นเมทริกซ์ทแยงมุมได้**

**เหตุผล:** `A` ขนาด 3 × 3 มีค่าเจาะจง **ต่างกัน 3 ค่า** (1, 2, 4) → ตามทฤษฎีบท "ถ้าเมทริกซ์ n × n มีค่าเจาะจงต่างกัน n ค่า แล้วเวกเตอร์เจาะจงที่สมนัยจะอิสระเชิงเส้น" → มีเวกเตอร์เจาะจงอิสระครบ 3 ตัว → **diagonalizable**

**เขียน `P` และ `D`** (เรียงคอลัมน์ของ `P` ให้ตรงกับลำดับใน `D`):

```
      [ 1   −1    7 ]              [ 2   0   0 ]
P  =  [ 0    1   −4 ]        D  =  [ 0   1   0 ]
      [ 0    1    2 ]              [ 0   0   4 ]
       λ=2  λ=1   λ=4
```

`det(P) = 1(1·2 − (−4)(1)) = 1(2 + 4) = 6 ≠ 0` → `P` invertible ✓

**ยืนยัน:** `P⁻¹AP = D` — ตรวจได้จาก `AP = PD` โดยตรวจทีละคอลัมน์
คอลัมน์ 1: `A(1,0,0)ᵀ = (2,0,0)ᵀ = 2(1,0,0)ᵀ` ✓
คอลัมน์ 2: `A(−1,1,1)ᵀ = (−2−2+3, 3−2, −1+2) = (−1,1,1)ᵀ = 1·(−1,1,1)ᵀ` ✓
คอลัมน์ 3: `A(7,−4,2)ᵀ = (28,−16,8)ᵀ = 4(7,−4,2)ᵀ` ✓

#### (ง) ตรวจสอบด้วย trace และ det

```
Σλ = 1 + 2 + 4 = 7        tr(A) = 2 + 3 + 2 = 7          ✓
Πλ = 1 × 2 × 4 = 8        det(A) = 2[(3)(2) − (−2)(−1)] = 2(6 − 2) = 8   ✓
```

**⚠️ จุดผิดพลาดที่พบบ่อย**
1. **สลับลำดับคอลัมน์ของ `P` กับสมาชิกใน `D`** — ถ้า `P` คอลัมน์แรกเป็น eigenvector ของ `λ = 2` แล้ว `D` ตำแหน่ง (1,1) ต้องเป็น 2 ไม่ใช่ 1
2. ใช้ `det(A − λI)` แล้วลืมว่าดีกรีคี่จะได้เครื่องหมายกลับกัน (แต่รากเท่ากัน — ไม่มีผลต่อคำตอบ)
3. เวกเตอร์เจาะจงเป็นเศษส่วนแล้วไม่คูณให้เป็นจำนวนเต็ม — ทำได้เพราะ eigenvector คูณค่าคงที่ใดก็ยังเป็น eigenvector
4. **ตอบว่าไม่ diagonalizable เพราะ `A` ไม่สมมาตร** — ผิด! ไม่สมมาตรก็ diagonalize ได้ (แค่ **P จะไม่ orthogonal** เท่านั้น)


`det(A′) = 0` → **`A′` เป็นเมทริกซ์เอกฐาน (singular) หา `A′⁻¹` ไม่ได้** → **ถอดรหัสกลับไม่ได้เลย**

> สาเหตุ: ทุกผลลัพธ์ของ `XA′` ตกอยู่บนเส้นตรงเส้นเดียว (`y = 2x`) แทนที่จะกระจายทั่วระนาบ

**เหตุใดจึงนิยม `det(A) = ±1`:**
เพราะ `A⁻¹ = adj(A) / det(A)` — ถ้า `A` มีสมาชิกเป็นจำนวนเต็มและ `det(A) = ±1` แล้ว `A⁻¹` **จะมีสมาชิกเป็นจำนวนเต็มทั้งหมด** (ไม่มีเศษส่วน) ทำให้
1. ผลการถอดรหัสเป็นจำนวนเต็มพอดี ตรงกับรหัสอักขระ 0–26
2. ไม่มีความคลาดเคลื่อนจากการปัดเศษ
3. คำนวณเร็วและตรวจสอบง่าย

(เมทริกซ์จำนวนเต็มที่มี `det = ±1` เรียกว่า **unimodular matrix**)

**⚠️ จุดผิดพลาดที่พบบ่อย**
