## Step 4 — ระบุ Pattern รูปแบบคำถาม (สิ่งที่นำมาใช้ออกข้อสอบใหม่)

**P1 · "หาค่า หรือ บอกว่า Undefined"** — ไม่ถามแค่คำนวณ แต่แทรกนิพจน์ที่ *มิติไม่สอดคล้อง* ปนมาด้วย → บังคับให้เช็กขนาดก่อนคูณ

**P2 · "จับคู่นิพจน์ที่ดูคล้ายกัน"** — เช่น `Ab^T + Bb^T` คู่กับ `(A+B)b^T` / `ab − ba` คู่กับ `−(4b)(7a)` และ `−28ba` → ทดสอบว่าเข้าใจ **สมบัติการแจกแจงและการไม่สลับที่**

**P3 · "จงแสดงวิธีทำ"** — ให้คะแนนขั้นตอน ไม่ใช่คำตอบเดียว → ข้อสอบใหม่ต้องมี rubric ย่อย

**P4 · "…หรือไม่ เพราะเหตุใด"** — คำตอบต้องระบุ **สัจพจน์/เงื่อนไขที่ถูกละเมิด** อย่างเจาะจง ไม่ใช่ตอบว่า "ไม่เป็น" ลอย ๆ

**P5 · "เปิดทางเลือกวิธี"** — W3 ให้เลือก Cramer / Gaussian / Gauss-Jordan → ข้อสอบใหม่ควรมีข้อที่บังคับวิธี และข้อที่เปิดให้เลือกเอง

**P6 · "ทำสองทางแล้วเปรียบเทียบ"** — W6 ให้หา `T₂∘T₁` **และ** `T₁∘T₂` → จุดประสงค์คือให้เห็นว่า **ผลลัพธ์ไม่เท่ากัน**

**P7 · "คำนวณแล้วพิสูจน์ยืนยัน"** — W4 ข้อ 5: หา `u × v` **แล้วแสดงว่าตั้งฉากกับทั้งสองเวกเตอร์** → มีขั้นตรวจสอบในตัวโจทย์

**P8 · "ให้ P มาเลย"** — W7 ข้อ 2 ให้เมทริกซ์ `P` มาให้ ไม่ต้องหาเอง → ลดภาระคำนวณ แต่ทดสอบว่าเข้าใจนิยาม `P⁻¹AP = D`

| # | กับดัก | ร่องรอยในโจทย์เก่า |
|---|---|---|

| T4 | **ลืมว่า det ของ 5×5 ต้องลดรูปด้วย row operation ก่อน** ไม่งั้นกาง cofactor 120 เทอม | W2 ข้อ 1 |
| T5 | **สับสน `\|A⁻¹\|` กับ `A⁻¹`** — คำตอบคือ `1/det(A)` ไม่ใช่เมทริกซ์ | W2 ข้อ 2 (ระบุชัดว่า "เริ่มต้นด้วยการหา A⁻¹ **จากนั้น**หา det") |

| T7 | **"พหุนามดีกรี 4 ทั้งหมด" ≠ vector space** เพราะไม่มีเวกเตอร์ศูนย์ / ปิดไม่ได้ | W5 ข้อ 1 (ต่างจาก "ดีกรีไม่เกิน 4" ซึ่ง**เป็น**) |
| T8 | **สลับ n กับ m** ใน `T: Rⁿ → Rᵐ` — คอลัมน์ = n, แถว = m | W6 ข้อ 2 (A ขนาด 3×4 → n=4, m=3) |
| T9 | **เขียน standard matrix สลับลำดับตัวแปร** | W6 ข้อ 3: `T(x,y,z) = (3z+2y, 4x−11z)` เรียงสลับตั้งใจ |

| T12 | **2 เวกเตอร์เป็นอิสระเชิงเส้นไหม** — ดูแค่ว่าเป็นพหุคูณกันหรือไม่ ไม่ต้องตั้งระบบ | W5 ข้อ 4 |

# ส่วนที่ 3 · Topic-by-Topic Summary (สรุปเนื้อหารายหัวข้อ)

## 📘 Week 1 — Matrices และการดำเนินการ

### นิยามพื้นฐาน

- **เมทริกซ์ `A = [aᵢⱼ]` ขนาด m × n** = แถว m, คอลัมน์ n (จำ: **แถวก่อน คอลัมน์หลัง**)
- **Augmented matrix** `[A | b]` = สัมประสิทธิ์ + พจน์คงที่ · **Coefficient matrix** `A` = สัมประสิทธิ์อย่างเดียว

### การดำเนินการ

| การดำเนินการ | เงื่อนไขขนาด | ผลลัพธ์ |
|---|---|---|
| `A + B` | ขนาด **เท่ากันเป๊ะ** m×n | m×n |
| `cA` | ใดก็ได้ | ขนาดเดิม |
| `AB` | **คอลัมน์ของ A = แถวของ B** (m×**n**)(**n**×p) | m×p |
| `Aᵀ` | ใดก็ได้ | n×m |

**สูตรคูณเมทริกซ์:**  `cᵢⱼ = Σₖ aᵢₖ bₖⱼ` (แถวที่ i ของ A · คอลัมน์ที่ j ของ B)

### สมบัติที่ต้องจำ

```
A + B = B + A                    (สลับที่ได้)
AB ≠ BA                          (โดยทั่วไป สลับที่ไม่ได้ !!)
A(BC) = (AB)C                    (เปลี่ยนหมู่ได้)
A(B + C) = AB + AC               (แจกแจงได้)
c(AB) = (cA)B = A(cB)
AIₙ = A = ImA                    (identity)

(Aᵀ)ᵀ = A
(A + B)ᵀ = Aᵀ + Bᵀ
(cA)ᵀ = cAᵀ
(AB)ᵀ = BᵀAᵀ                     ← สลับลำดับ !!
```

- **Symmetric matrix:** `A = Aᵀ` (ต้องเป็นจัตุรัสเสมอ) และ `aᵢⱼ = aⱼᵢ`
- `AAᵀ` และ `AᵀA` **เป็น symmetric เสมอ** (แต่คนละขนาดกัน)
- `B − Bᵀ` เป็น **skew-symmetric** (แนวทแยงหลักเป็น 0 เสมอ)

## 📘 Week 2 — Inverse และ Determinants

### Inverse

- `A` **invertible / nonsingular** ⟺ มี `A⁻¹` ที่ `AA⁻¹ = A⁻¹A = I` ⟺ `det(A) ≠ 0`
- **สูตร 2×2 (ต้องท่องได้):**

```
A = [a  b]        A⁻¹ =    1     [ d  −b]
    [c  d]              ─────── [−c   a]
                        ad − bc
```

- **วิธี Gauss-Jordan:** `[A | I] → row operations → [I | A⁻¹]`
- **สมบัติ:** `(A⁻¹)⁻¹ = A` · `(AB)⁻¹ = B⁻¹A⁻¹` (สลับลำดับ) · `(Aᵀ)⁻¹ = (A⁻¹)ᵀ` · `(cA)⁻¹ = (1/c)A⁻¹`

### Determinant

- **2×2:** `det(A) = ad − bc`
- **Minor `Mᵢⱼ`** = det ของเมทริกซ์ที่ตัดแถว i คอลัมน์ j ทิ้ง
- **Cofactor `Cᵢⱼ = (−1)^(i+j) Mᵢⱼ`** — ตารางเครื่องหมาย:

```
+ − + −
− + − +
+ − + −
− + − +
```

- **Expansion by cofactors** (กางตามแถว i ใดก็ได้): `det(A) = Σⱼ aᵢⱼ Cᵢⱼ`
  → **เลือกกางแถว/คอลัมน์ที่มีศูนย์เยอะที่สุดเสมอ**

### เงื่อนไขที่ทำให้ det = 0

1. มีแถว (หรือคอลัมน์) ที่เป็นศูนย์ทั้งแถว
2. มีสองแถวเหมือนกัน
3. มีแถวหนึ่งเป็นพหุคูณของอีกแถว

### สมบัติของ Determinant

```
det(Aᵀ) = det(A)
det(AB) = det(A)·det(B)
det(cA) = cⁿ·det(A)              ← n = ขนาดเมทริกซ์ (พลาดบ่อย!)
det(A⁻¹) = 1 / det(A)
det(Aᵏ) = [det(A)]ᵏ
det ของเมทริกซ์สามเหลี่ยม = ผลคูณของแนวทแยงหลัก
```

**ผลของ row operation ต่อ det:**

| การกระทำ | ผลต่อ det |
|---|---|
| สลับ 2 แถว | คูณ **−1** |
| คูณแถวด้วย k | คูณ **k** |
| บวกพหุคูณของแถวหนึ่งเข้าอีกแถว | **ไม่เปลี่ยน** ← ใช้ลดรูปได้ฟรี |

### Adjoint

```
adj(A) = [Cᵢⱼ]ᵀ           (เมทริกซ์โคแฟกเตอร์แล้ว transpose)
A⁻¹ = adj(A) / det(A)
det(adj A) = [det(A)]ⁿ⁻¹
```

### การประยุกต์ของ Determinant

**พื้นที่สามเหลี่ยม** จุด (x₁,y₁), (x₂,y₂), (x₃,y₃):

```
Area = ± ½ · det [x₁  y₁  1]
                 [x₂  y₂  1]
                 [x₃  y₃  1]        (เลือกเครื่องหมายให้ได้ค่าบวก)
```

**สมการเส้นตรงผ่าน 2 จุด:**  `det [x y 1; x₁ y₁ 1; x₂ y₂ 1] = 0`

**ปริมาตรเตตระฮีดรอน:** `V = ± ⅙ · det[x₁ y₁ z₁ 1; …4 แถว…]`

### Cryptography (การเข้ารหัสด้วยเมทริกซ์)

1. แปลงตัวอักษรเป็นเลข: **ช่องว่าง = 0, A = 1, B = 2, …, Z = 26**
2. แบ่งเป็น **uncoded row matrices** ขนาด 1×n (เติมช่องว่าง = 0 ให้ครบบล็อก)
3. เข้ารหัส: `Y = X·A` โดย A ต้อง **invertible** ขนาด n×n
4. ถอดรหัส: `X = Y·A⁻¹`
5. เพื่อให้ได้เลขจำนวนเต็ม นิยมเลือก A ที่ `det(A) = ±1`

## 📘 Week 3 — Systems of Linear Equations

### จำนวนผลเฉลย — มีแค่ 3 กรณีเท่านั้น

| กรณี | ความหมายเชิงเรขาคณิต (2 ตัวแปร) | เงื่อนไข |
|---|---|---|
| **ผลเฉลยเดียว** | เส้นตรง 2 เส้นตัดกัน 1 จุด | `det(A) ≠ 0` |
| **ไม่มีผลเฉลย** (inconsistent) | เส้นขนาน | เกิดแถว `[0 0 … 0 \| c]`, c ≠ 0 |
| **ผลเฉลยอนันต์** | เส้นทับกัน | มี free variable |

> ระบบ **homogeneous** (`Ax = 0`) **มีผลเฉลยเสมอ** (อย่างน้อยคือ trivial solution `x = 0`)
> ถ้าตัวแปร **มากกว่า** จำนวนสมการ → มีผลเฉลย **อนันต์** แน่นอน

### วิธีที่ 1 — Inverse Matrix

ใช้ได้เมื่อ A จัตุรัส และ `det(A) ≠ 0`:  **`x = A⁻¹b`**

### วิธีที่ 2 — Cramer's Rule

ใช้ได้เมื่อ **จัตุรัส และ `det(A) ≠ 0` เท่านั้น**

```
xᵢ = det(Aᵢ) / det(A)
```
โดย `Aᵢ` = เอา A มาแทน **คอลัมน์ที่ i** ด้วยเวกเตอร์ b

### วิธีที่ 3 — Gaussian Elimination + Back-Substitution

**Elementary row operations 3 แบบ:** สลับ 2 แถว · คูณแถวด้วยค่าคงที่ ≠ 0 · บวกพหุคูณของแถวหนึ่งเข้าอีกแถว

**Row-echelon form:**
1. แถวศูนย์ล้วนอยู่ล่างสุด
2. ตัวนำ (leading entry) ของแต่ละแถวเป็น **1**
3. ตัวนำของแถวล่างอยู่ **ขวา** ของแถวบน

→ ทำถึง row-echelon form แล้ว **แทนค่าย้อนกลับ**

### วิธีที่ 4 — Gauss-Jordan Elimination

ทำต่อจนได้ **reduced row-echelon form** (คอลัมน์ของตัวนำมีศูนย์ทั้งบนและล่าง) → **อ่านคำตอบได้เลย**

### LU-Factorization

`A = LU` (L = lower triangular ที่แนวทแยง = 1, U = upper triangular)
แก้ `Ax = b` เป็น 2 ขั้น: `Ly = b` (forward) แล้ว `Ux = y` (backward)

### Polynomial Curve Fitting

หาพหุนาม `p(x) = a₀ + a₁x + … + aₙ₋₁xⁿ⁻¹` ผ่าน n จุด → ตั้งระบบ n สมการ n ตัวแปร

## 📘 Week 4 — Vectors ใน Rⁿ

### พื้นฐาน

- `u = (u₁, …, uₙ)`, `u + v = (u₁+v₁, …, uₙ+vₙ)`, `cu = (cu₁, …, cuₙ)`
- **เท่ากัน** ⟺ ทุกองค์ประกอบเท่ากันตำแหน่งต่อตำแหน่ง

### ความยาว (Norm)

```
‖u‖ = √(u₁² + u₂² + … + uₙ²)
‖cu‖ = |c| · ‖u‖                    ← ค่าสัมบูรณ์ !!
unit vector:  û = u / ‖u‖           (normalizing)
d(u, v) = ‖u − v‖
```

### Dot Product

```
u · v = u₁v₁ + u₂v₂ + … + uₙvₙ      ← ได้ "ตัวเลข" (สเกลาร์)

u · v = v · u
u · (v + w) = u·v + u·w
c(u · v) = (cu) · v = u · (cv)
u · u = ‖u‖²                        ← สูตรลัดที่ออกสอบบ่อย
u · u ≥ 0  และ = 0 ⟺ u = 0
```

- **Cauchy-Schwarz:** `|u · v| ≤ ‖u‖‖v‖`
- **Triangle Inequality:** `‖u + v‖ ≤ ‖u‖ + ‖v‖`
- **Pythagorean:** `‖u + v‖² = ‖u‖² + ‖v‖²` ⟺ u ⊥ v

### มุมระหว่างเวกเตอร์

```
cos θ = (u · v) / (‖u‖ ‖v‖)      โดย 0 ≤ θ ≤ π
```

| `u · v` | มุม θ |
|---|---|
| > 0 | แหลม (0 ≤ θ < π/2) |
| **= 0** | **ตั้งฉาก (orthogonal), θ = π/2** |
| < 0 | ป้าน (π/2 < θ ≤ π) |

> **เวกเตอร์ศูนย์ตั้งฉากกับทุกเวกเตอร์**

### Cross Product (เฉพาะ R³ เท่านั้น!)

```
        | i    j    k  |
u × v = | u₁   u₂   u₃ |
        | v₁   v₂   v₃ |

      = (u₂v₃ − u₃v₂) i − (u₁v₃ − u₃v₁) j + (u₁v₂ − u₂v₁) k
```

**สมบัติ:**

```
u × v = −(v × u)                    ← ไม่สลับที่ (anticommutative)
u × u = 0
u × 0 = 0
(u × v) · u = 0  และ  (u × v) · v = 0   ← ตั้งฉากกับทั้งคู่ !!
‖u × v‖ = ‖u‖ ‖v‖ sin θ
```

- `‖u × v‖` = **พื้นที่สี่เหลี่ยมด้านขนาน** ที่มี u, v เป็นด้านประชิด
- `u × v = 0` ⟺ u และ v **ขนานกัน**
- **Triple scalar product** `u · (v × w)` = ปริมาตรของ parallelepiped

## 📘 Week 5 — Vector Spaces, Subspaces, Independence

### สัจพจน์ 10 ข้อของ Vector Space

ให้ V เป็นเซตที่มีการดำเนินการบวก (+) และคูณสเกลาร์ ถ้าสัจพจน์ครบ 10 ข้อ V เป็น **vector space**

**การบวก (Closure + 4 สมบัติ):**
1. `u + v ∈ V` — **ปิดใต้การบวก**
2. `u + v = v + u`
3. `(u + v) + w = u + (v + w)`
4. มี `0 ∈ V` ที่ `u + 0 = u` — **เวกเตอร์ศูนย์**
5. มี `−u ∈ V` ที่ `u + (−u) = 0` — **อินเวอร์สการบวก**

**การคูณสเกลาร์:**
6. `cu ∈ V` — **ปิดใต้การคูณสเกลาร์**
7. `c(u + v) = cu + cv`
8. `(c + d)u = cu + du`
9. `c(du) = (cd)u`
10. `1·u = u`

### ตัวอย่าง Vector Space มาตรฐาน

| เซต | เป็น VS? |
|---|---|
| `R`, `R²`, `Rⁿ` (การดำเนินการมาตรฐาน) | ✅ |
| `Mₘ,ₙ` เมทริกซ์ m×n ทั้งหมด | ✅ |
| `Pₙ` พหุนามดีกรี **ไม่เกิน** n | ✅ |
| `C(−∞, ∞)` ฟังก์ชันต่อเนื่อง | ✅ |
| เซตจำนวนเต็ม (การดำเนินการมาตรฐาน) | ❌ ไม่ปิดใต้สเกลาร์ (½ · 3 = 1.5 ไม่ใช่จำนวนเต็ม) |
| พหุนามดีกรี **เท่ากับ** n พอดี | ❌ ไม่มีเวกเตอร์ศูนย์ + ไม่ปิดใต้การบวก |
| `{(x, y): x ≥ 0, y ≥ 0}` | ❌ ไม่ปิดใต้สเกลาร์ (คูณ −1 หลุด) |

### Test for a Subspace (ทดสอบแค่ 3 ข้อ!)

W ⊆ V (V เป็น vector space) จะเป็น **subspace** ก็ต่อเมื่อ

1. **`0 ∈ W`** (W ไม่ว่าง) ← เช็กข้อนี้ก่อนเสมอ เร็วที่สุด
2. **ปิดใต้การบวก:** u, v ∈ W ⟹ `u + v ∈ W`
3. **ปิดใต้การคูณสเกลาร์:** u ∈ W, c ∈ R ⟹ `cu ∈ W`

> **ไม่ต้อง**ตรวจครบ 10 สัจพจน์ เพราะสืบทอดมาจาก V แล้ว

**ตัวอย่างที่ไม่เป็น subspace:** เซตของเมทริกซ์ **singular** ใน `Mₙ,ₙ` (ไม่ปิดใต้การบวก) · เซตเวกเตอร์ควอดรันต์ที่ 1 ใน `R²`

### Linear Combination & Span

- `w` เป็น **linear combination** ของ `v₁, …, vₖ` ถ้า `w = c₁v₁ + … + cₖvₖ`
  → ตั้งเป็น **ระบบสมการเชิงเส้น** แล้วแก้หา cᵢ
- `S` เป็น **spanning set** ของ V ถ้าทุกเวกเตอร์ใน V เขียนเป็น linear combination ของ S ได้
- `span(S)` **เป็น subspace ของ V เสมอ** และเป็น subspace ที่เล็กที่สุดที่บรรจุ S

### Linear Independence

`S = {v₁, …, vₖ}` **อิสระเชิงเส้น (independent)** ⟺ สมการ

```
c₁v₁ + c₂v₂ + … + cₖvₖ = 0
```

มีผลเฉลยเดียวคือ `c₁ = c₂ = … = cₖ = 0` (trivial)
ถ้ามีผลเฉลยอื่น → **ขึ้นต่อกันเชิงเส้น (dependent)**

**วิธีทำ:** เขียนเป็นระบบสมการ → augmented matrix → Gauss-Jordan
- ได้ `I` ล้วน → **independent**
- มี free variable → **dependent**
- ถ้าเป็นเมทริกซ์จัตุรัส: `det ≠ 0` → independent, `det = 0` → dependent

**ทางลัดที่ต้องจำ:**

| สถานการณ์ | ผล |
|---|---|
| เซตมีเวกเตอร์ศูนย์ | **dependent เสมอ** |
| 2 เวกเตอร์ | dependent ⟺ เป็น**พหุคูณกัน** |
| จำนวนเวกเตอร์ > มิติของสเปซ | **dependent เสมอ** (เช่น 4 เวกเตอร์ใน R³) |
| S dependent (มีมากกว่า 1 ตัว) | มีเวกเตอร์อย่างน้อย 1 ตัวเขียนเป็น combination ของตัวอื่นได้ |

## 📘 Week 6 — Linear Transformations

### นิยาม

`T: V → W` เป็น **linear transformation** ⟺ สำหรับทุก u, v ∈ V และสเกลาร์ c

```
(1) T(u + v) = T(u) + T(v)        (additivity)
(2) T(cu) = c T(u)                (homogeneity)
```

**คำศัพท์:** `V` = domain · `W` = codomain · `T(v) = w` → w คือ **image** ของ v · เซตของ v ทั้งหมดที่ `T(v) = w` คือ **preimage** ของ w · เซตของ image ทั้งหมด = **range**

### สมบัติที่ตามมา

```
T(0) = 0                          ← ใช้ตรวจว่า "ไม่เชิงเส้น" ได้เร็วมาก
T(−v) = −T(v)
T(u − v) = T(u) − T(v)
T(c₁v₁ + … + cₙvₙ) = c₁T(v₁) + … + cₙT(vₙ)
```

**ฟังก์ชันที่ไม่เชิงเส้น:** `T(x,y) = (x + 1, y)` (มีค่าคงที่บวก) · `T(x,y) = (x², y)` (กำลังสอง) · `T(x,y) = (sin x, y)` · `T(x,y) = (|x|, y)`

### Standard Matrix

`T: Rⁿ → Rᵐ` มีเมทริกซ์มาตรฐาน `A` ขนาด **m × n** โดย

```
A = [ T(e₁)  T(e₂)  …  T(eₙ) ]      ← เอา image ของเวกเตอร์ฐานมาวาง "เป็นคอลัมน์"
```

และ `T(v) = Av`

> **จำมิติให้แม่น:** A ขนาด m×n → `T: Rⁿ → Rᵐ`
> **จำนวนคอลัมน์ = n = มิติของ domain** · **จำนวนแถว = m = มิติของ codomain**

**ตัวอย่าง:** `T(x, y, z) = (3z + 2y, 4x − 11z)` → เรียงตัวแปรใหม่เป็น `(0x + 2y + 3z, 4x + 0y − 11z)`

```
A = [0   2    3]      (2 × 3  →  T: R³ → R²)
    [4   0  −11]
```

### Composition

```
T = T₂ ∘ T₁,  T(v) = T₂(T₁(v))       ⟹  A = A₂ A₁      ← ลำดับกลับด้าน !!
```

`T₂∘T₁ ≠ T₁∘T₂` โดยทั่วไป

### Inverse Linear Transformation

`T: Rⁿ → Rⁿ` **invertible** ⟺ `A` invertible ⟺ `det(A) ≠ 0`
และเมทริกซ์มาตรฐานของ `T⁻¹` คือ `A⁻¹`

### Elementary Matrices ใน R² (ต้องจำรูปแบบ)

| การแปลง | เมทริกซ์ |
|---|---|
| สะท้อนแกน x | `[1 0; 0 −1]` |
| สะท้อนแกน y | `[−1 0; 0 1]` |
| สะท้อนเส้น y = x | `[0 1; 1 0]` |
| ขยาย/หดแนวนอน (k) | `[k 0; 0 1]` |
| ขยาย/หดแนวตั้ง (k) | `[1 0; 0 k]` |
| Shear แนวนอน (k) | `[1 k; 0 1]` |
| Shear แนวตั้ง (k) | `[1 0; k 1]` |
| **หมุนทวนเข็ม θ** | `[cos θ  −sin θ; sin θ  cos θ]` |

**Rotation ใน R³ (ทวนเข็มมองจากแกนบวกเข้าหาจุดกำเนิด):**

```
รอบแกน z: [cosθ −sinθ 0; sinθ cosθ 0; 0 0 1]
รอบแกน x: [1 0 0; 0 cosθ −sinθ; 0 sinθ cosθ]
รอบแกน y: [cosθ 0 sinθ; 0 1 0; −sinθ 0 cosθ]     ← เครื่องหมายสลับตำแหน่ง!
```

## 📘 Week 7 — Eigenvalues, Diagonalization, Orthogonal Matrix

### นิยาม

`A` ขนาด n×n · `λ` เป็น **eigenvalue** และ `x ≠ 0` เป็น **eigenvector** ⟺

```
A x = λ x
```

### วิธีหา (4 ขั้นตอน)

1. **ตั้ง characteristic equation:** `det(λI − A) = 0` (หรือ `det(A − λI) = 0`)
2. แก้หา **eigenvalues** `λ₁, λ₂, …`
3. แทน λ แต่ละค่าลงใน `(λI − A)x = 0` แล้วแก้ระบบ homogeneous
4. ได้ **eigenspace** — เขียนเป็น span ของเวกเตอร์อิสระ

> **เมทริกซ์สามเหลี่ยม (หรือทแยงมุม): eigenvalue = สมาชิกบนแนวทแยงหลัก** — ไม่ต้องคำนวณเลย

**ตรวจคำตอบเร็ว:**  `λ₁ + λ₂ + … + λₙ = trace(A)` และ `λ₁λ₂…λₙ = det(A)`

### Diagonalization

- `A` และ `B` **similar** ⟺ มี P invertible ที่ `B = P⁻¹AP` → **มี eigenvalue เหมือนกัน**
- `A` **diagonalizable** ⟺ มี P invertible ที่ `P⁻¹AP = D` (ทแยงมุม)

**เงื่อนไข:** `A` (n×n) diagonalizable **⟺ มี eigenvector ที่อิสระเชิงเส้น n ตัว**

**ขั้นตอน:**
1. หา eigenvalues ทั้งหมด
2. หา eigenvector อิสระของแต่ละ λ — ถ้ารวมกันได้ครบ **n ตัว** → ทำได้
3. `P = [x₁ x₂ … xₙ]` (eigenvector เป็นคอลัมน์)
4. `D = diag(λ₁, …, λₙ)` — **ลำดับ λ ต้องตรงกับลำดับคอลัมน์ของ P**

> **เงื่อนไขเพียงพอ (ไม่จำเป็น):** ถ้า A มี eigenvalue **ต่างกัน n ค่า** → diagonalizable แน่นอน
> แต่ถ้า eigenvalue ซ้ำ **ยังอาจ** diagonalizable ได้ ต้องตรวจมิติของ eigenspace

### Symmetric Matrix

ถ้า `A` symmetric (`A = Aᵀ`):
- **eigenvalue เป็นจำนวนจริงทั้งหมด**
- **diagonalizable เสมอ**
- eigenvector ของ eigenvalue **ต่างกัน จะตั้งฉากกัน**
- ถ้า λ มี multiplicity k → eigenspace มีมิติ k พอดี

### Orthogonal Matrix

`P` เป็น **orthogonal** ⟺ `P⁻¹ = Pᵀ` ⟺ `PᵀP = I`

**สมบัติ:**
- ⟺ **คอลัมน์ของ P เป็นเซต orthonormal** (ตั้งฉากกันทุกคู่ + ยาว 1 ทุกตัว)
- `det(P) = ±1`
- รักษาความยาวและมุม (`‖Px‖ = ‖x‖`)

### Orthogonal Diagonalization

`A` **orthogonally diagonalizable** (`PᵀAP = D` โดย P orthogonal) **⟺ A เป็น symmetric matrix**

**ขั้นตอน:** หา eigenvalue → หา eigenvector → **Gram-Schmidt ภายในแต่ละ eigenspace ที่มิติ > 1** → **normalize ทุกตัว** → ประกอบเป็น P

# ส่วนที่ 4 · Key Pitfalls & Exam Tips

## 🚨 12 กับดักที่ทำคะแนนหายมากที่สุด

### ❌ 1. คูณเมทริกซ์โดยไม่เช็กมิติ
`A` (3×4) และ `b` (1×3): `bA` **หาได้** (1×3 · 3×4 = 1×4) แต่ `Aᵀb` **หาไม่ได้** (4×3 · 1×3)
> **นิสัยที่ต้องสร้าง:** เขียนขนาดกำกับใต้ทุกตัวก่อนลงมือ เช่น `A₃ₓ₄ · b^T₃ₓ₁ = ?₃ₓ₁` ✅

### ❌ 2. `(AB)ᵀ = AᵀBᵀ` — **ผิด!**
ที่ถูกคือ `(AB)ᵀ = BᵀAᵀ` เช่นเดียวกับ `(AB)⁻¹ = B⁻¹A⁻¹` — **อินเวอร์สและทรานสโพสของผลคูณต้องสลับลำดับ**

### ❌ 3. `det(cA) = c·det(A)` — **ผิด!**
ที่ถูกคือ `det(cA) = cⁿ det(A)` เมื่อ A เป็น n×n
> ตัวอย่าง: A เป็น 4×4, `det(A) = 3` → `det(2A) = 2⁴ · 3 = 48` **ไม่ใช่ 6**

### ❌ 4. หา `|A⁻¹|` แล้วตอบเป็นเมทริกซ์
`|A⁻¹|` คือ **ตัวเลข** = `1/det(A)` — โจทย์แนวนี้ (Week 2) จะบังคับให้หา `A⁻¹` ก่อนเพื่อทดสอบว่ารู้ทั้ง 2 อย่าง อย่าตอบผิดชนิด

### ❌ 5. กาง cofactor เมทริกซ์ 4×4/5×5 ตรง ๆ
เสียเวลามหาศาลและพลาดง่าย → **ใช้ row operation "บวกพหุคูณของแถว" ทำให้คอลัมน์หนึ่งเหลือศูนย์เกือบหมดก่อน** (ไม่เปลี่ยนค่า det) แล้วค่อยกาง
> และอย่าลืม: **สลับแถวต้องคูณ −1** · **คูณแถวด้วย k ต้องหารกลับด้วย k**

### ❌ 6. ใช้ Cramer's Rule กับระบบที่ `det(A) = 0`
Cramer ใช้ได้เฉพาะ **จัตุรัส + `det(A) ≠ 0`** เท่านั้น ถ้า det = 0 ต้องเปลี่ยนไปใช้ Gauss-Jordan เพื่อดูว่า "ไม่มีผลเฉลย" หรือ "อนันต์"

### ❌ 7. สับสน "ปิดใต้การบวก" กับ "ปิดใต้การคูณสเกลาร์"
`{(x,y): x ≥ 0, y ≥ 0}` **ปิดใต้การบวก** (บวกกันยังอยู่ควอดรันต์ 1) แต่ **ไม่ปิดใต้สเกลาร์** — คูณ `−1` แล้วหลุด
> **เทคนิคเร็ว:** ตรวจ `0 ∈ W` ก่อน ถ้าไม่มี ตอบ "ไม่เป็น" ได้ทันที แล้วค่อยลองคูณ **สเกลาร์ลบ**

### ❌ 8. "พหุนามดีกรี 4" กับ "ดีกรีไม่เกิน 4"
- **ดีกรีเท่ากับ 4 พอดี** → **ไม่ใช่** vector space (ไม่มีพหุนามศูนย์ + `x⁴ + (−x⁴ + x) = x` ดีกรี 1 หลุดออกจากเซต)
- **ดีกรีไม่เกิน 4 (`P₄`)** → **เป็น** vector space
> อ่านโจทย์ให้ละเอียดว่ามีคำว่า "ไม่เกิน / at most" หรือไม่

### ❌ 9. สลับ n กับ m ใน `T: Rⁿ → Rᵐ`
A ขนาด **m × n** → **คอลัมน์ = n = domain**, **แถว = m = codomain**
> A ขนาด 3×4 → `T: R⁴ → R³` (**ไม่ใช่** R³ → R⁴)

### ❌ 10. เขียน standard matrix ผิดลำดับตัวแปร
`T(x, y, z) = (3z + 2y, 4x − 11z)` → **ต้องจัดเรียงใหม่เป็น x, y, z ก่อน** แล้วอ่านสัมประสิทธิ์เป็นแถว
> และ **composition `T₂∘T₁` → `A₂A₁`** (ตัวที่ทำทีหลังอยู่ซ้าย)

### ❌ 11. eigenvalue ซ้ำ = diagonalize ไม่ได้ — **ผิด!**
ต้องตรวจว่า **มิติของ eigenspace = multiplicity หรือไม่**
> `I` (identity) มี eigenvalue = 1 ซ้ำ n ครั้ง แต่ diagonalizable (เป็นทแยงมุมอยู่แล้ว)
> **แต่** `[3 1; 0 3]` มี λ = 3 ซ้ำ 2 ครั้ง และ eigenspace มิติ 1 → **ไม่** diagonalizable

### ❌ 12. ลืม normalize ตอนทำ orthogonal diagonalization
`P⁻¹AP = D` ใช้ eigenvector ธรรมดาได้ แต่ **`PᵀAP = D` ต้องให้คอลัมน์เป็น orthonormal** — ต้องหารด้วยความยาวทุกตัว ไม่งั้น `P⁻¹ ≠ Pᵀ`

|---|---|
| `A⁻¹` | คูณกลับ `AA⁻¹ = I` |

| eigenvalue | `Σλ = trace(A)` และ `Πλ = det(A)` |

### เทคนิคเก็บคะแนนบางส่วน (Partial Credit)

- โจทย์ "**จงแสดงวิธีทำ**" → **เขียนสูตร/ทฤษฎีที่ใช้ก่อน** แม้จะคำนวณไม่จบ ก็ได้คะแนนขั้นตอน
- โจทย์ "**…หรือไม่ เพราะเหตุใด**" → ต้องมี 3 ส่วน: (1) **ตอบ เป็น/ไม่เป็น** (2) **ระบุสัจพจน์/เงื่อนไขข้อที่ใช้** (3) **ยกตัวอย่างค้าน (counterexample) เป็นตัวเลขจริง**
  > ตอบว่า "ไม่เป็นเพราะไม่ปิด" ได้คะแนนไม่เต็ม — ต้องบอกว่า *ไม่ปิดใต้อะไร* และ *ยกตัวอย่าง*
- โจทย์ "**Undefined**" → เขียนขนาดของทั้งสองตัวประกอบกำกับด้วย เช่น "`Aᵀb`: (4×3)(1×3) — คอลัมน์ของตัวแรก (3) ≠ แถวของตัวหลัง (1) → **undefined**"
- **อย่าลบวิธีที่ทำผิดทิ้ง** ให้ขีดฆ่าเบา ๆ — บางครั้งได้คะแนนขั้นตอน
