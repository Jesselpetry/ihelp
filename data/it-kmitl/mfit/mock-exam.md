### (ข) ถอดรหัส `22, 60, 17, 39, 67, 22`

**ขั้น 1 — หา `det(A)`** (กางตามแถวที่ 1)

```
det(A) = 1[(−2)(1) − (−1)(3)] − 3[(−2)(1) − (−1)(2)] + 1[(−2)(3) − (−2)(2)]
       = 1(−2 + 3) − 3(−2 + 2) + 1(−6 + 4)
       = 1(1) − 3(0) + 1(−2)
       = 1 − 0 − 2 = −1
```

**ขั้น 2 — หาโคแฟกเตอร์ทั้ง 9 ตัว**

```
C₁₁ = +|−2 −1; 3 1| = (−2)(1)−(−1)(3) = −2+3 =  1
C₁₂ = −|−2 −1; 2 1| = −[(−2)(1)−(−1)(2)] = −[−2+2] =  0
C₁₃ = +|−2 −2; 2 3| = (−2)(3)−(−2)(2) = −6+4 = −2

C₂₁ = −| 3  1; 3 1| = −[3(1)−1(3)] = −[0] =  0
C₂₂ = +| 1  1; 2 1| = 1(1)−1(2) = −1
C₂₃ = −| 1  3; 2 3| = −[1(3)−3(2)] = −[−3] =  3

C₃₁ = +| 3  1; −2 −1| = 3(−1)−1(−2) = −3+2 = −1
C₃₂ = −| 1  1; −2 −1| = −[1(−1)−1(−2)] = −[1] = −1
C₃₃ = +| 1  3; −2 −2| = 1(−2)−3(−2) = −2+6 =  4
```

**ขั้น 3 — TRANSPOSE เป็น adj(A)** ← จุดตาย

```
เมทริกซ์โคแฟกเตอร์            adj(A) = ทรานสโพส
[  1   0  −2 ]                [  1   0  −1 ]
[  0  −1   3 ]        →       [  0  −1  −1 ]
[ −1  −1   4 ]                [ −2   3   4 ]
```

**ขั้น 4 — `A⁻¹ = adj(A)/det(A) = adj(A)/(−1) = −adj(A)`**

```
        [ −1    0    1 ]
A⁻¹  =  [  0    1    1 ]
        [  2   −3   −4 ]
```

**ตรวจเร็ว:** แถว 1 ของ `A` × คอลัมน์ 1 ของ `A⁻¹` = `1(−1) + 3(0) + 1(2) = −1 + 0 + 2 = 1` ✓

**ขั้น 5 — คูณ `X = YA⁻¹`**

```
[22  60  17] A⁻¹ :
  x₁ = 22(−1) + 60(0)  + 17(2)  = −22 +   0 + 34 = 12
  x₂ = 22(0)  + 60(1)  + 17(−3) =   0 +  60 − 51 =  9
  x₃ = 22(1)  + 60(1)  + 17(−4) =  22 +  60 − 68 = 14      →  [12  9  14]

[39  67  22] A⁻¹ :
  x₁ = 39(−1) + 67(0)  + 22(2)  = −39 +   0 + 44 =  5
  x₂ = 39(0)  + 67(1)  + 22(−3) =   0 +  67 − 66 =  1
  x₃ = 39(1)  + 67(1)  + 22(−4) =  39 +  67 − 88 = 18      →  [5   1  18]
```

มีแถวหนึ่งเป็น**พหุคูณของอีกแถว** → `det(A′) = 0` → **singular หา `A′⁻¹` ไม่ได้ → ถอดรหัสกลับไม่ได้**

> **ทริคสอบ:** เห็นแถว (หรือคอลัมน์) เป็นพหุคูณกัน → `det = 0` ทันที ไม่ต้องคำนวณ
