### ข้อ 60
```python
box = ['Pen', 'Book', 'Pen', 'Pencil']
d = {}
for item in box:
    d[item] = d.get(item, 1) + 1
print(d)
```
ผลลัพธ์คือข้อใด

1. `{'Pen': 2, 'Book': 1, 'Pencil': 1}`
2. `{'Pen': 3, 'Book': 2, 'Pencil': 2}`
3. `{'Pen': 2, 'Book': 2, 'Pencil': 2}`
4. `{'Pen': 1, 'Book': 1, 'Pencil': 1}`
5. `{'Pen': 3, 'Book': 1, 'Pencil': 1}`

> **เฉลย: 2**
> `d.get(item, 1)` — ถ้ายังไม่มี key จะคืนค่า default `1` แล้วบวก 1 ได้ **2**
> `Pen` เจอครั้งแรกได้ 2 เจอครั้งที่สองได้ `d.get('Pen',1)+1` = 2+1 = **3**
> `Book` และ `Pencil` เจอครั้งเดียว จึงได้ **2** ทั้งคู่
> ⚠️ ถ้าต้องการนับจำนวนจริง ๆ ต้องใช้ `d.get(item, 0) + 1`
