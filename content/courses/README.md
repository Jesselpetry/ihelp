# สรุปรายวิชา — ชั้นปีที่ 1

ไฟล์ `summary.md` หนึ่งไฟล์ต่อหนึ่งรายวิชา ประกอบขึ้นจากการสแกนสื่อการเรียนใน
`kmitl-archive`, `ITF_bank`, `pscp-69070027` และ `ihelp`
ใช้เป็นแหล่งความจริงตั้งต้นสำหรับสร้างคลังข้อสอบ แบบฝึกหัด และข้อสอบจำลองใน Phase 3

## โครงของทุกไฟล์

1. **ภาพรวมรายวิชา** — รหัสวิชา ชื่อไทย/อังกฤษ หน่วยกิต วิชาบังคับก่อน ผู้สอน ตำรา สัดส่วนคะแนน
2. **ขอบเขตเนื้อหา** — ตารางรายสัปดาห์ แยก **ขอบเขตกลางภาค** กับ **ขอบเขตปลายภาค**
3. **สรุปเนื้อหารายหัวข้อ** — มโนทัศน์หลัก ศัพท์เทคนิค สูตร ตารางเปรียบเทียบ
4. **พิมพ์เขียวสำหรับสร้างสื่อต่อยอด** — สัดส่วนคลังข้อสอบ เทมเพลตโจทย์ที่ generate ได้ แนวข้อสอบจำลอง
5. **แหล่งข้อมูลในคลัง** — ไฟล์ที่มีจริง พร้อมหมายเหตุว่าไฟล์ไหนถอดข้อความได้/ไม่ได้

## ข้อควรระวัง

- **ลิขสิทธิ์** — สไลด์บรรยายและ workbook (โดยเฉพาะ Edusoft ของ FE) เป็นของผู้สอน/ผู้จัดพิมพ์
  ห้าม deploy สาธารณะจนกว่าจะได้รับอนุญาต หรือย้ายไปหลังระบบล็อกอิน
- **ข้อมูลส่วนบุคคล** — ไฟล์ที่ลงท้ายด้วย `-Completed` และไฟล์ในคลัง PSCP
  มีชื่อ-นามสกุลจริงและรหัสนักศึกษา ต้อง sanitize ก่อนนำเข้า
- **ความไม่แน่นอน** — จุดที่อนุมานจากชื่อไฟล์หรือลายมือ ถูกกำกับไว้ในเอกสารด้วยคำว่า
  *ยังไม่ยืนยัน* / *ให้ยืนยันกับผู้สอน* เสมอ อย่าตัดคำเตือนเหล่านี้ออกเวลานำไปใช้ต่อ
