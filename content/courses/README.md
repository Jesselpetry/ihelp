## โครงของ `summary.md` ทุกไฟล์

1. **ข้อมูลรายวิชา** — ตารางข้อมูลพื้นฐาน คำอธิบาย สัดส่วนคะแนน วันสำคัญ
2. **ขอบเขตเนื้อหา** — ตารางรายสัปดาห์ **แยกกลางภาค / ปลายภาค**
3. **สรุปเนื้อหารายหัวข้อ** — หนึ่ง `###` ต่อสัปดาห์/บท
4. **สิ่งที่ต้องจำ** — สูตร ตัวเลข ตารางเปรียบเทียบ
5. **การประเมินและเตรียมสอบ** — รูปแบบการประเมิน หัวข้อที่ออกบ่อย จุดที่มักพลาด
6. **แหล่งเรียนรู้** — ลิงก์ในเว็บและช่องทางทางการ

เส้นแบ่งกลางภาค/ปลายภาคของคลังเรียนรู้ (`scope`) อ่านจากหัวข้อ 2 ของไฟล์นี้เท่านั้น
ดูตารางเส้นแบ่งต่อวิชาใน [`docs/DROPZONE_SOP.md`](../../docs/DROPZONE_SOP.md) §2.3

## ข้อควรระวัง

- **ลิขสิทธิ์** — สไลด์บรรยายและ workbook (โดยเฉพาะ Edusoft ของ FE) เป็นของผู้สอน/ผู้จัดพิมพ์
  `summary.md` ของ ITF และ FE ระบุว่าห้ามเผยแพร่สาธารณะ รายการไฟล์ของคลังอยู่หลังล็อกอิน IT KMITL แล้ว
  **แต่ตัวไฟล์ที่ไม่ใช่ข้อสอบอยู่ใน bucket สาธารณะ** และ path ของมันอยู่ใน repo สาธารณะ — "หลังล็อกอิน" ไม่เท่ากับปิด
  ถ้าต้องการให้ไฟล์ใดปิดจริงต้องจัดเป็นหมวดที่จำกัดสิทธิ์ (ดู `isRestrictedAsset()` และ
  [`FILE_STRUCTURE.md`](../../FILE_STRUCTURE.md) §9 "สิทธิ์การเข้าถึง ลิขสิทธิ์ และข้อมูลส่วนบุคคล")
- **ข้อมูลส่วนบุคคล** (กติกาของเจ้าของคลัง 15 ต.ค. 2569) — เอกสารที่ผู้สอนแจกทั้งชั้นบน OnLearn แล้ว
  (ใบงานแล็บ สไลด์) นำเข้าได้แม้มีชื่อหรือรหัสของ TA หรือนักศึกษาตัวอย่างอยู่ในภาพ · ห้ามนำเข้างานของนักศึกษาคนอื่น
  (ใบงานที่ส่งแล้ว `-completed` ของคนอื่น งานกลุ่มที่มีชื่อเพื่อน) และข้อมูลส่วนบุคคลที่ยังไม่เคยแจกทั้งชั้น ·
  `summary.md` และ `blueprint.md` ห้ามระบุชื่อหรือรหัสนักศึกษาคนอื่น · รายละเอียดอยู่ใน
  [`docs/DROPZONE_SOP.md`](../../docs/DROPZONE_SOP.md) Phase 6
