# สรุปรายวิชา — ชั้นปีที่ 1

แต่ละวิชามีสองไฟล์:

- **`summary.md`** — ภาพรวมรายวิชาที่นักศึกษาเห็นบนหน้ารายวิชา ทุกวิชาใช้โครงเดียวกันตาม
  [`docs/COURSE_OVERVIEW_STANDARD.md`](../../docs/COURSE_OVERVIEW_STANDARD.md)
- **`blueprint.md`** — ส่วนสำหรับคนสร้างสื่อ: สเปกคลังข้อสอบ แบบฝึก ข้อสอบจำลอง
  แหล่งที่มาในคลัง (path) และช่องว่างข้อมูล — ไม่ถูก render ในเว็บ

## โครงของ `summary.md` ทุกไฟล์

1. **ข้อมูลรายวิชา** — ตารางข้อมูลพื้นฐาน คำอธิบาย สัดส่วนคะแนน วันสำคัญ
2. **ขอบเขตเนื้อหา** — ตารางรายสัปดาห์ **แยกกลางภาค / ปลายภาค**
3. **สรุปเนื้อหารายหัวข้อ** — หนึ่ง `###` ต่อสัปดาห์/บท
4. **สิ่งที่ต้องจำ** — สูตร ตัวเลข ตารางเปรียบเทียบ
5. **การประเมินและเตรียมสอบ** — รูปแบบการประเมิน หัวข้อที่ออกบ่อย จุดที่มักพลาด
6. **แหล่งเรียนรู้** — ลิงก์ในเว็บและช่องทางทางการ

## ข้อควรระวัง

- **ลิขสิทธิ์** — สไลด์บรรยายและ workbook (โดยเฉพาะ Edusoft ของ FE) เป็นของผู้สอน/ผู้จัดพิมพ์
  ห้าม deploy สาธารณะจนกว่าจะได้รับอนุญาต หรือย้ายไปหลังระบบล็อกอิน
- **ข้อมูลส่วนบุคคล** — ไฟล์ที่ลงท้ายด้วย `-Completed` และไฟล์ในคลัง PSCP
  มีชื่อ-นามสกุลจริงและรหัสนักศึกษา ต้อง sanitize ก่อนนำเข้า
- **ความไม่แน่นอน** — จุดที่อนุมานจากชื่อไฟล์หรือลายมือ ถูกกำกับไว้ในเอกสารด้วยคำว่า
  *ยังไม่ยืนยัน* / *ให้ยืนยันกับผู้สอน* เสมอ อย่าตัดคำเตือนเหล่านี้ออกเวลานำไปใช้ต่อ
