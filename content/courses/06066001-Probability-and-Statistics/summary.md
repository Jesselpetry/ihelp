## 3. สรุปเนื้อหารายหัวข้อ

### บทที่ 1 — ความน่าจะเป็นเบื้องต้น

- **แซมเปิลสเปซ (Sample Space, `S` หรือ `Ω`)** — เซตของผลลัพธ์ที่เป็นไปได้ทั้งหมด
- **เหตุการณ์ (Event)** — สับเซตของแซมเปิลสเปซ
  - การดำเนินการ: `A ∪ B`, `A ∩ B`, `Aᶜ`, `A − B`
  - **เหตุการณ์ไม่เกิดร่วมกัน (mutually exclusive)** — `A ∩ B = ∅`
- **ความน่าจะเป็นแบบคลาสสิก** — `P(A) = n(A) / n(S)`
- **สัจพจน์ของความน่าจะเป็น** ⭐
  1. `P(A) ≥ 0`
  2. `P(S) = 1`
  3. ถ้า `A₁, A₂, …` ไม่เกิดร่วมกัน แล้ว `P(A₁ ∪ A₂ ∪ …) = ΣP(Aᵢ)`
- **สมบัติที่ตามมา** — `P(Aᶜ) = 1 − P(A)` · `P(A ∪ B) = P(A) + P(B) − P(A ∩ B)`

### บทที่ 2 — การนับ

- **กฎการคูณ** — งาน k ขั้น ขั้นละ `n₁, n₂, …, n_k` วิธี → รวม `n₁n₂…n_k` วิธี
- **การเรียงสับเปลี่ยน (Permutation)** ⭐ — **สนใจลำดับ**
  - `P(n, r) = n! / (n − r)!`
  - เรียงของ n ชิ้นที่มีของซ้ำ: `n! / (n₁!n₂!…n_k!)`
  - เรียงเป็นวงกลม: `(n − 1)!`
- **การจัดหมู่ (Combination)** ⭐ — **ไม่สนใจลำดับ**
  - `C(n, r) = n! / [r!(n − r)!]`
- **การเลือกสิ่งของบางส่วน (Sampling)** — เลือกแล้วใส่คืน vs ไม่ใส่คืน

### บทที่ 3 — ความน่าจะเป็นแบบมีเงื่อนไข

- **นิยาม** ⭐ — `P(A | B) = P(A ∩ B) / P(B)` เมื่อ `P(B) > 0`
- **กฎการคูณ** — `P(A ∩ B) = P(B)P(A | B)`
- **กฎความน่าจะเป็นรวม (Total Probability)** — `P(A) = Σᵢ P(Bᵢ)P(A | Bᵢ)`
- **กฎของเบส์ (Bayes' Rule)** ⭐⭐⭐

  ```
  P(Bᵢ | A) = P(Bᵢ) P(A | Bᵢ) / Σⱼ P(Bⱼ) P(A | Bⱼ)
  ```

  โจทย์คลาสสิก: การตรวจโรค (sensitivity/specificity) · เครื่องจักรผลิตของเสีย
- **ความเป็นอิสระต่อกัน** ⭐ — `A`, `B` อิสระกันเมื่อ `P(A ∩ B) = P(A)P(B)`
  (เทียบเท่ากับ `P(A | B) = P(A)`)
  - **อิสระ ≠ ไม่เกิดร่วมกัน** ⭐⭐ (ข้อสอบชอบหลอกจุดนี้)
- ลำดับของการทดลองที่อิสระต่อกัน (Bernoulli trials)

### บทที่ 4 — ตัวแปรสุ่มชนิดไม่ต่อเนื่อง

- **ตัวแปรสุ่ม (Random Variable)** — ฟังก์ชันที่แมปผลลัพธ์ในแซมเปิลสเปซไปเป็นจำนวนจริง
- **PMF (Probability Mass Function)** ⭐ — `p_X(x) = P(X = x)`
  - เงื่อนไข: `p_X(x) ≥ 0` และ `Σₓ p_X(x) = 1`
- **ฟังก์ชันของตัวแปรสุ่ม** — `Y = g(X)`; `p_Y(y) = Σ_{x: g(x)=y} p_X(x)`
- **ค่าคาดหมาย (Expected Value)** ⭐⭐ — `E[X] = Σₓ x · p_X(x)`
  - **กฎของนักสถิติผู้ไร้สำนึก:** `E[g(X)] = Σₓ g(x)p_X(x)`
  - เชิงเส้น: `E[aX + b] = aE[X] + b`
- **ความแปรปรวน (Variance)** ⭐⭐
  - `Var[X] = E[(X − μ)²] = E[X²] − (E[X])²`
  - `Var[aX + b] = a²Var[X]` ⭐ (ค่าคงที่ที่บวกเข้าไปไม่มีผล)
  - ส่วนเบี่ยงเบนมาตรฐาน `σ = √Var[X]`

### บทที่ 5 — ตัวแปรสุ่มไม่ต่อเนื่องหลายตัว

- **Joint PMF** — `p_{X,Y}(x, y) = P(X = x, Y = y)`
- **Marginal PMF** ⭐ — `p_X(x) = Σ_y p_{X,Y}(x, y)` (รวมตามขอบตาราง)
- **Conditional PMF** — `p_{X|Y}(x|y) = p_{X,Y}(x,y) / p_Y(y)`
- **Conditional Expectation** — `E[X | Y = y] = Σₓ x · p_{X|Y}(x|y)`
- **ความเป็นอิสระของตัวแปรสุ่ม** ⭐ — `p_{X,Y}(x,y) = p_X(x)p_Y(y)` สำหรับทุก `x, y`
  - ถ้าอิสระกัน: `E[XY] = E[X]E[Y]` และ `Var[X + Y] = Var[X] + Var[Y]`

### บทที่ 6 — ตัวแปรสุ่มชนิดต่อเนื่อง

- ตัวแปรสุ่มต่อเนื่องมีค่าที่เป็นไปได้ในเซตที่นับไม่ได้ (เช่น อายุการใช้งานเครื่อง เวลารอรถเมล์)
- **PDF (Probability Density Function)** ⭐⭐
  - `P(X ∈ B) = ∫_B f_X(x) dx`
  - `f_X(x) ≥ 0` และ `∫_{−∞}^{∞} f_X(x)dx = 1`
  - **`P(X = a) = 0`** สำหรับทุกค่า `a` ⭐ (จุดที่ต่างจากไม่ต่อเนื่องชัดที่สุด)
  - `E[X] = ∫ x f_X(x)dx` · `Var[X] = ∫ x²f_X(x)dx − (E[X])²`
- **CDF (Cumulative Distribution Function)** ⭐ — `F_X(x) = P(X ≤ x) = ∫_{−∞}^{x} f_X(t)dt`
  - ไม่ลด, `F(−∞) = 0`, `F(∞) = 1`, `f_X(x) = dF_X(x)/dx`
- **การกระจายแบบปกติ (Normal Distribution)** — แนะนำในบทนี้ ใช้จริงในบทที่ 9

### บทที่ 8 — สถิติเบื้องต้น

- **แนวคิดหลัก** ⭐ — อนุมานลักษณะของ **ประชากร (population)** จาก **กลุ่มตัวอย่าง (sample)**
  (ตัวอย่างในเอกสาร: สุ่มคนไทย 1,000 คน เพื่ออนุมานความสูงเฉลี่ยของคนทั้งประเทศ ~70 ล้านคน)
- **สถิติสรุป (Summary Statistics)** ⭐⭐

| ค่า | สูตร | หมายเหตุ |
|---|---|---|
| ค่าเฉลี่ยตัวอย่าง | `x̄ = (1/n)Σxᵢ` | ไวต่อค่าผิดปกติ |
| มัธยฐาน (median) | ค่ากลางเมื่อเรียงแล้ว | ทนต่อค่าผิดปกติ |
| ฐานนิยม (mode) | ค่าที่พบบ่อยที่สุด | |
| **ความแปรปรวนตัวอย่าง** | `s² = Σ(xᵢ − x̄)² / (n − 1)` | หารด้วย **n − 1** ⭐ (unbiased) |
| ส่วนเบี่ยงเบนมาตรฐาน | `s = √s²` | |
| พิสัย (range) | `max − min` | |
| ควอไทล์ / IQR | `Q3 − Q1` | ใช้หา outlier |

- **ข้อมูลสรุปเชิงภาพ (Graphical Summaries)** — histogram, box plot (พร้อม whisker และ outlier),
  stem-and-leaf, scatter plot

### บทที่ 9 — การกระจายแบบปกติ

- **สัญลักษณ์** — `X ∼ N(μ, σ²)`
- **การกระจายแบบปกติมาตรฐาน** ⭐ — `Z ∼ N(0, 1)` (μ = 0, σ = 1)
- **การแปลงเป็นคะแนนมาตรฐาน** ⭐⭐⭐

  ```
  Z = (X − μ) / σ
  ```

  พิสูจน์ได้ว่า `E[Z] = 0` และ `Var[Z] = 1` เพราะ `Z` เป็น linear transformation ของ `X`
- **การใช้ตาราง Z** — ตารางในภาคผนวกให้ **พื้นที่ทางซ้ายของค่า Z**
  - `P(X > a) = 1 − P(Z ≤ z)`
  - `P(a < X < b) = Φ(z_b) − Φ(z_a)`
- **กฎ 68–95–99.7** — ภายใน `±1σ`, `±2σ`, `±3σ`
- โจทย์ย้อนกลับ: ให้เปอร์เซ็นไทล์ → หาค่า `x`

### บทที่ 10 — CLT และช่วงความเชื่อมั่น

- **ทฤษฎีบทขีดจำกัดส่วนกลาง (CLT)** ⭐⭐⭐
  - ถ้า `n` ใหญ่พอ (มักใช้ `n ≥ 30`) การกระจายของ `x̄` จะเข้าใกล้ปกติ
    **ไม่ว่าประชากรจะกระจายแบบใด**
  - `x̄ ∼ N(μ, σ²/n)`; **standard error** `SE = σ/√n`
- **ช่วงความเชื่อมั่นของค่าเฉลี่ย** ⭐⭐⭐

| กรณี | สูตร | เงื่อนไข |
|---|---|---|
| **ตัวอย่างใหญ่** (`n ≥ 30` หรือรู้ `σ`) | `x̄ ± z_{α/2} · (s/√n)` | ใช้ตาราง Z |
| **ตัวอย่างเล็ก** (`n < 30`, ไม่รู้ `σ`) | `x̄ ± t_{α/2, n−1} · (s/√n)` | ใช้ตาราง t, **df = n − 1** |

- ค่า z ที่ใช้บ่อย ⭐ — 90% → 1.645 · **95% → 1.96** · 99% → 2.576
- การตีความ: "ถ้าสุ่มซ้ำหลายครั้ง 95% ของช่วงที่สร้างจะครอบคลุมค่า `μ` จริง"
- การหาขนาดตัวอย่างจากความคลาดเคลื่อนที่ยอมรับได้: `n = (z σ / E)²`

### บทที่ 11 — การทดสอบสมมติฐาน

- **สมมติฐาน** ⭐ — `H₀` (null, สมมติฐานหลัก) vs `H₁` / `Hₐ` (alternative)
- **ขั้นตอนมาตรฐาน** ⭐⭐
  1. ตั้ง `H₀` และ `H₁` (หางเดียว/สองหาง)
  2. กำหนดระดับนัยสำคัญ `α` (0.10, 0.05, 0.01)
  3. คำนวณค่าสถิติทดสอบ
  4. หา P-value หรือค่าวิกฤต
  5. สรุป — **P-value < α → ปฏิเสธ `H₀`**
- **ค่าสถิติทดสอบ**

| กรณี | สูตร |
|---|---|
| ตัวอย่างใหญ่ | `z = (x̄ − μ₀) / (s/√n)` |
| ตัวอย่างเล็ก | `t = (x̄ − μ₀) / (s/√n)`, df = `n − 1` |

- **ความผิดพลาด 2 ชนิด** ⭐⭐ — Type I (ปฏิเสธ `H₀` ที่จริง, ความน่าจะเป็น `α`) ·
  Type II (ไม่ปฏิเสธ `H₀` ที่เท็จ, ความน่าจะเป็น `β`)

### บทที่ 12 — การทดสอบสมมติฐานแบบไคสแควร์

- ใช้เมื่อต้องการทดสอบว่า **ค่าที่สังเกตได้ต่างจากค่าที่คาดหวังอย่างมีนัยสำคัญหรือไม่**
- **ขั้นตอน** ⭐⭐
  1. `H₀`: ค่าที่สังเกตตรงกับค่าที่คาดหวัง · `H₁`: แตกต่างกัน
  2. คำนวณ

     ```
     χ² = Σᵢ (Oᵢ − Eᵢ)² / Eᵢ
     ```

     โดย `Oᵢ` = ค่าที่สังเกต, `Eᵢ` = ค่าที่คาดหวัง, `k` = จำนวนประเภท
  3. หา P-value จากตารางไคสแควร์ที่ **df = k − 1**
  4. P-value ยิ่งน้อย ยิ่งมีหลักฐานปฏิเสธ `H₀`
- ตัวอย่างมาตรฐาน: ลูกเต๋ายุติธรรมหรือไม่ · การทดสอบความเป็นอิสระในตารางแจกแจงสองทาง (df = `(r−1)(c−1)`)

### บทที่ 13 — สหสัมพันธ์และการถดถอย

- **สหสัมพันธ์ (Correlation)** ⭐⭐
  - สัมประสิทธิ์สหสัมพันธ์เพียร์สัน `r ∈ [−1, 1]`

    ```
    r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √[Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)²]
    ```

  - `r > 0` สัมพันธ์ทางบวก · `r < 0` ทางลบ · `r ≈ 0` ไม่สัมพันธ์เชิงเส้น
  - **ความสัมพันธ์ ≠ การเป็นสาเหตุ** ⭐
- **การถดถอยเชิงเส้นอย่างง่าย (Simple Linear Regression)** ⭐⭐⭐
  - `ŷ = b₀ + b₁x`
  - `b₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²` · `b₀ = ȳ − b₁x̄`
  - **วิธีกำลังสองน้อยสุด (least squares)** — ทำให้ `Σ(yᵢ − ŷᵢ)²` น้อยที่สุด
  - **`R² = r²`** = สัดส่วนความแปรผันของ `y` ที่อธิบายได้ด้วย `x`
- **การถดถอยเชิงซ้อน (Multiple Linear Regression)** — `ŷ = b₀ + b₁x₁ + … + b_kx_k`

### 5.2 รูปแบบโจทย์ที่ generate ได้อัตโนมัติ

| หัวข้อ | เทมเพลต | วิธีตรวจ |
|---|---|---|
| การนับ | สุ่มโจทย์เรียงคน/เลือกทีม/จัดที่นั่งวงกลม | คำนวณ `P(n,r)`, `C(n,r)` ตรง |
| เบส์ | สุ่ม prior + sensitivity/specificity ของการตรวจโรค | คำนวณตามสูตร |
| PMF | สุ่มตาราง PMF (บังคับให้รวมเป็น 1) → ถาม `E[X]`, `Var[X]` | คำนวณตรง |
| Joint PMF | สุ่มตาราง 3×3 → ถาม marginal, conditional, ตรวจความอิสระ | คำนวณตรง |
| PDF | สุ่ม `f(x) = cx^k` บน `[a,b]` → หา `c`, `E[X]`, `CDF` | อินทิเกรตด้วย `sympy` |
| Normal | สุ่ม `μ`, `σ`, ช่วง → หา `P` | `scipy.stats.norm` |
| CI | สุ่ม `x̄`, `s`, `n`, ระดับความเชื่อมั่น | `scipy.stats` (เลือก z/t อัตโนมัติตาม `n`) |
| Hypothesis test | สุ่มโจทย์เปรียบเทียบค่าเฉลี่ยกับค่าอ้างอิง | คำนวณ `t`/`z` และ P-value |
| ไคสแควร์ | สุ่มตารางความถี่สังเกต/คาดหวัง | `scipy.stats.chisquare` |
| Regression | สุ่มจุดข้อมูล 8–10 จุด | `numpy.polyfit` + `r` |
