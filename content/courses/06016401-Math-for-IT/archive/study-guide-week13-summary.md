## 1. 🔑 u-Substitution — Chain Rule กลับหลัง

### 1.1 ที่มา

Chain Rule บอกว่า:
$$\frac{d}{dx}\Big[F(g(x))\Big]=F'(g(x))\cdot g'(x)$$

ปริพันธ์ทั้งสองข้าง:
$$\int F'(g(x))\,g'(x)\,dx=F(g(x))+C$$

**แปลว่า:** ถ้าเห็น integrand ที่มีรูป **"ฟังก์ชันข้างใน × อนุพันธ์ของข้างใน"** → ให้แทน $u=$ ข้างใน

### 1.2 อุปมา: การ "ถอดเสื้อคลุม"
โจทย์ที่ดูซับซ้อนมักเป็นโจทย์ง่ายที่ **ใส่เสื้อคลุมหนา ๆ ไว้**
$u$-substitution คือการ **ถอดเสื้อคลุมออก ทำโจทย์ง่าย ๆ ข้างใน แล้วสวมเสื้อกลับ**

### 1.3 สูตร
$$\boxed{\;\int f(g(x))\,g'(x)\,dx=\int f(u)\,du \quad\text{เมื่อ } u=g(x),\; du=g'(x)\,dx\;}$$

## 2. 🔑 Pattern: u-Substitution (6 ขั้นตอนตายตัว)

```
ขั้นที่ 1  เลือก u    ← ดูตารางเลือก u ข้างล่าง
ขั้นที่ 2  หา du       du = u′ dx
ขั้นที่ 3  จัด dx      dx = du / u′   (หรือจัด u′dx = du ตรง ๆ)
ขั้นที่ 4  แทนทุกอย่าง  ⚠️ ต้องไม่เหลือ x แม้แต่ตัวเดียว
ขั้นที่ 5  ปริพันธ์เทียบ u  (ตอนนี้ต้องกลายเป็นโจทย์ง่าย)
ขั้นที่ 6  แทน u กลับเป็น x  แล้ว + C
```

### 2.1 ตารางเลือก $u$ (เรียงตามลำดับความสำคัญ)

| เห็นแบบนี้ | เลือก $u$ = |
|:---|:---|
| ก้อนใน**วงเล็บที่ยกกำลัง** $(\ldots)^{n}$ | ก้อนในวงเล็บ |
| ก้อน**ใต้ราก** $\sqrt{\ldots}$ | ก้อนใต้ราก |
| **ตัวส่วน** ของเศษส่วน | ตัวส่วน |
| **เลขชี้กำลัง**ของ $e$ | เลขชี้กำลัง |
| ก้อนใน $\sin(\ldots)$, $\cos(\ldots)$, $\ln(\ldots)$ | ก้อนในวงเล็บ |
| ก้อนที่**อนุพันธ์ของมันโผล่อยู่ที่อื่นใน integrand** | ก้อนนั้น |

> **💡 เกณฑ์ตัดสินสุดท้าย:** เลือก $u$ แล้วดูว่า $du$ "หาเจอ" ใน integrand หรือไม่
> ถ้าเจอ (ต่างกันแค่ค่าคงตัว) → เลือกถูก · ถ้าไม่เจอ → เปลี่ยน $u$ ใหม่

### 2.2 ตัวอย่างเต็ม 1 — **HW13 ข้อ 3**
$$\int\frac{2x^{2}+1}{(2x^{3}+3x)^{2}}\,dx$$

**ขั้นที่ 1** — ตัวส่วนอยู่ในวงเล็บยกกำลัง ⇒ $u=2x^{3}+3x$

**ขั้นที่ 2**
$$du=(6x^{2}+3)\,dx$$

**ขั้นที่ 3** — สังเกตว่า $6x^{2}+3=3(2x^{2}+1)$ ⇒ ตัวเศษของเราคือ $\frac13 du$
$$(2x^{2}+1)\,dx=\tfrac{1}{3}\,du$$

**ขั้นที่ 4** — แทน
$$\int\frac{2x^{2}+1}{(2x^{3}+3x)^{2}}dx=\int\frac{1}{u^{2}}\cdot\frac{1}{3}du=\frac13\int u^{-2}\,du$$

**ขั้นที่ 5**
$$=\frac13\cdot\frac{u^{-1}}{-1}+C=-\frac{1}{3u}+C$$

**ขั้นที่ 6**
$$=\boxed{-\frac{1}{3(2x^{3}+3x)}+C}$$

> ✅ **ตรวจ:** ดิฟกลับ → $-\frac13\cdot(-1)(2x^3+3x)^{-2}(6x^2+3)=\frac{6x^2+3}{3(2x^3+3x)^2}=\frac{2x^2+1}{(2x^3+3x)^2}$ ✅

### 2.3 ตัวอย่างเต็ม 2 — เมื่อต้อง "แก้ $x$ ในรูป $u$"
$$\int x\sqrt{x-1}\,dx$$

$u=x-1 \Rightarrow du=dx$ และ $x=u+1$
$$=\int (u+1)\sqrt{u}\,du=\int\big(u^{3/2}+u^{1/2}\big)du=\frac{2}{5}u^{5/2}+\frac23u^{3/2}+C$$
$$=\boxed{\frac25(x-1)^{5/2}+\frac23(x-1)^{3/2}+C}$$

> 💡 **เทคนิคนี้ใช้เมื่อมี $x$ เกินมา 1 ตัวที่กำจัดด้วย $du$ ไม่ได้** — ให้แก้ $x$ กลับในรูป $u$

### 2.4 u-Substitution ในปริพันธ์**จำกัดเขต** — 2 วิธี

**วิธี A: เปลี่ยนขอบเขตด้วย (แนะนำ — สั้นกว่า ไม่ต้องแทนกลับ)**
```
u = g(x)
ขอบล่าง x = a  →  u = g(a)
ขอบบน  x = b  →  u = g(b)
แล้วคำนวณ ∫ จาก g(a) ถึง g(b) เทียบ u ได้เลย
```

**วิธี B: ไม่เปลี่ยนขอบเขต**
```
ทำเป็นปริพันธ์ไม่จำกัดเขตก่อน → แทน u กลับเป็น x → ค่อยแทนขอบเขตเดิม
```

> ### ⚠️⚠️ กับดักมรณะ ⚠️⚠️
> **ห้ามใช้ขอบเขตเดิม ($a$ ถึง $b$) กับตัวแปร $u$ เด็ดขาด!**
> ```
> ❌ ∫₁³ ... dx  →  ∫₁³ ... du     ← ผิด! ขอบเขตยังเป็นของ x
> ✅ ∫₁³ ... dx  →  ∫_{g(1)}^{g(3)} ... du
> ```
> ถ้าจะใช้ขอบเขตเดิม **ต้องแทน $u$ กลับเป็น $x$ ก่อน** (วิธี B)

**ตัวอย่าง:**
$$\int_{0}^{2}x\sqrt{x^{2}+1}\,dx$$
$u=x^2+1$, $du=2x\,dx \Rightarrow x\,dx=\tfrac12du$
ขอบ: $x=0\Rightarrow u=1$ · $x=2\Rightarrow u=5$
$$=\frac12\int_{1}^{5}u^{1/2}du=\frac12\cdot\frac{2}{3}\Big[u^{3/2}\Big]_1^5=\frac13\big(5\sqrt5-1\big)$$

## 3. 🔑 ปริพันธ์ของฟังก์ชันค่าสัมบูรณ์ — HW13 ข้อ 2

### แนวคิด
$|f(x)|$ **ไม่ใช่ฟังก์ชันเรียบ** — มันหักมุมตรงที่ $f(x)=0$
⇒ **ต้องหั่นช่วงปริพันธ์ตรงจุดหักมุม แล้วทำทีละท่อน**

### Pattern 5 ขั้นตอน
```
1) หาจุดหักมุม: แก้สมการ ข้างใน = 0
2) เช็คว่าจุดนั้นอยู่ใน [a, b] หรือไม่ (ถ้าไม่อยู่ ก็ไม่ต้องหั่น)
3) แตกค่าสัมบูรณ์เป็น piecewise ทีละช่วง
   |u| =  u   เมื่อ u ≥ 0
        −u   เมื่อ u < 0
4) หั่นปริพันธ์ตามช่วง แล้วคำนวณทีละท่อน
5) บวกผลลัพธ์ทุกท่อน  ⚠️ ผลลัพธ์ต้องเป็นบวกเสมอ (พื้นที่)
```

### ตัวอย่างเต็ม — **HW13 ข้อ 2**
$$\int_{1}^{4}|x-3|\,dx$$

**ขั้นที่ 1–2** — จุดหักมุม $x-3=0 \Rightarrow x=3$ ซึ่งอยู่ในช่วง $[1,4]$ ✅

**ขั้นที่ 3** — แตกเป็น 2 กรณี
$$|x-3|=\begin{cases}-(x-3)=3-x &,\ 1\le x<3 \quad(\text{เพราะ } x-3<0)\\[4pt] x-3 &,\ 3\le x\le 4\end{cases}$$

**ขั้นที่ 4** — หั่นแล้วคำนวณ
$$\int_{1}^{4}|x-3|dx=\int_{1}^{3}(3-x)\,dx+\int_{3}^{4}(x-3)\,dx$$

ท่อนที่ 1:
$$\int_{1}^{3}(3-x)dx=\left[3x-\frac{x^{2}}{2}\right]_{1}^{3}=\left(9-\frac92\right)-\left(3-\frac12\right)=\frac92-\frac52=2$$

ท่อนที่ 2:
$$\int_{3}^{4}(x-3)dx=\left[\frac{x^{2}}{2}-3x\right]_{3}^{4}=(8-12)-\left(\frac92-9\right)=-4+\frac92=\frac12$$

**ขั้นที่ 5**
$$\int_{1}^{4}|x-3|\,dx=2+\frac12=\boxed{\frac{5}{2}}$$

> ✅ **ตรวจด้วยเรขาคณิต:** กราฟ $y=|x-3|$ บน $[1,4]$ คือสามเหลี่ยม 2 รูป
> รูปซ้าย: ฐาน 2 สูง 2 → พื้นที่ $=\frac12(2)(2)=2$
> รูปขวา: ฐาน 1 สูง 1 → พื้นที่ $=\frac12(1)(1)=\frac12$
> รวม $=\frac52$ ✅ **ตรงกัน**

## 4. ฟังก์ชันคู่ / คี่ บนช่วงสมมาตร (สูตรลัดที่คุ้มมาก)

### นิยาม

| ชนิด | เงื่อนไข | ตัวอย่าง | สมมาตร |
|:---|:---|:---|:---|
| **ฟังก์ชันคู่ (even)** | $f(-x)=f(x)$ | $x^2$, $x^4$, $\cos x$, ค่าคงตัว | สมมาตรรอบแกน $y$ |
| **ฟังก์ชันคี่ (odd)** | $f(-x)=-f(x)$ | $x$, $x^3$, $x^5$, $\sin x$, $x^{-3/5}$ | สมมาตรรอบจุดกำเนิด |

### 🔑 สูตรลัด (ประหยัดเวลาได้มหาศาล)

$$\boxed{\;\int_{-a}^{a}f_{\text{คี่}}(x)\,dx=0\;}
\qquad\qquad
\boxed{\;\int_{-a}^{a}f_{\text{คู่}}(x)\,dx=2\int_{0}^{a}f(x)\,dx\;}$$

**เหตุผลเชิงภาพ:** ฟังก์ชันคี่ → พื้นที่ฝั่งซ้าย (ลบ) หักล้างฝั่งขวา (บวก) พอดี → เหลือ 0

### ใช้ตรวจ **HW13 ข้อ 1**
$$\int_{-1}^{1}\left(6x^{5}-\frac{2}{\sqrt[5]{x^{3}}}+3\right)dx$$
- $6x^5$ → **คี่** ⇒ ให้ 0
- $-2x^{-3/5}$ → **คี่** ⇒ ให้ 0
- $3$ → **คู่** ⇒ ให้ $2\int_0^1 3\,dx=2(3)=6$

$$\Rightarrow \boxed{6}$$

> ⚠️ **แต่ในกระดาษสอบ ต้องแสดงวิธีคำนวณเต็มด้วย** — ใช้สูตรลัดเป็น "การตรวจคำตอบ"
> เขียนแค่ "ฟังก์ชันคี่ = 0" อาจถูกมองว่าไม่ได้แสดงวิธีทำ

**วิธีเต็มของข้อนี้:**
$$\int\left(6x^{5}-2x^{-3/5}+3\right)dx=x^{6}-2\cdot\frac{x^{2/5}}{2/5}+3x=x^{6}-5x^{2/5}+3x$$
$$\Big[x^{6}-5x^{2/5}+3x\Big]_{-1}^{1}=(1-5+3)-\big(1-5(1)-3\big)=(-1)-(-7)=\boxed{6}$$
> 💡 หมายเหตุ: $(-1)^{2/5}=\big((-1)^{1/5}\big)^{2}=(-1)^{2}=1$ — **รากที่ 5 ของจำนวนลบมีค่าจริง** อย่าคิดว่านิยามไม่ได้

## 5. การกระจัด vs ระยะทางรวม (Displacement vs Total Distance)

จากสไลด์ Calculus-06 หัวข้อการเคลื่อนที่:

| ถามว่า | สูตร | ความหมาย |
|:---|:---|:---|
| **การกระจัด** (displacement) | $\displaystyle\int_{a}^{b}v(t)\,dt$ | สุดท้ายอยู่ห่างจากจุดเริ่มเท่าไหร่ (มีทิศ) |
| **ระยะทางรวม** (total distance) | $\displaystyle\int_{a}^{b}\big|v(t)\big|\,dt$ | เดินไปทั้งหมดกี่เมตร (ไม่สนทิศ) |

### 🔑 Pattern: หาระยะทางรวม
```
1) แก้ v(t) = 0  → หาเวลาที่วัตถุกลับทิศ
2) หั่นช่วง [a,b] ด้วยเวลาเหล่านั้น
3) เช็คเครื่องหมายของ v ในแต่ละช่วงย่อย
4) ปริพันธ์ทีละช่วง แล้วใส่ค่าสัมบูรณ์ก่อนบวกรวม
```

**ตัวอย่าง:** $v(t)=t^{2}-4t+3=(t-1)(t-3)$ บน $[0,4]$
- $v>0$ บน $[0,1]$ และ $[3,4]$ · $v<0$ บน $[1,3]$
- การกระจัด $=\int_0^4 v\,dt=\left[\frac{t^3}{3}-2t^2+3t\right]_0^4=\frac{64}{3}-32+12=\frac{4}{3}$
- ระยะทางรวม $=\left|\int_0^1\right|+\left|\int_1^3\right|+\left|\int_3^4\right|=\frac43+\frac43+\frac43=4$

## 6. การประมาณค่าเชิงตัวเลข (ถ้าอาจารย์สอน)

**Trapezoidal Rule:**
$$\int_a^b f(x)dx\approx\frac{b-a}{2n}\Big[f(x_0)+2f(x_1)+2f(x_2)+\cdots+2f(x_{n-1})+f(x_n)\Big]$$

**Simpson's Rule ($n$ เป็นเลขคู่):**
$$\int_a^b f(x)dx\approx\frac{b-a}{3n}\Big[f(x_0)+4f(x_1)+2f(x_2)+4f(x_3)+\cdots+4f(x_{n-1})+f(x_n)\Big]$$
(สัมประสิทธิ์: $1,4,2,4,2,\ldots,4,1$)

## 7. ตารางสูตร Week 13

$$\int f(g(x))g'(x)dx=\int f(u)du \qquad u=g(x),\ du=g'(x)dx$$

**u-Sub จำกัดเขต:** $\displaystyle\int_{a}^{b}f(g(x))g'(x)dx=\int_{g(a)}^{g(b)}f(u)\,du$ ← **เปลี่ยนขอบเขต!**

**ค่าสัมบูรณ์:** หั่นที่จุดที่ข้างใน $=0$

**คู่/คี่:** $\displaystyle\int_{-a}^{a}(\text{คี่})=0$, $\displaystyle\int_{-a}^{a}(\text{คู่})=2\int_{0}^{a}$

**การเคลื่อนที่:** การกระจัด $=\int v\,dt$ · ระยะทางรวม $=\int|v|\,dt$

**สูตร u-Sub ที่ออกบ่อย:**
$$\int\frac{u'}{u}dx=\ln|u|+C \qquad \int e^{u}u'\,dx=e^{u}+C \qquad \int u^{n}u'\,dx=\frac{u^{n+1}}{n+1}+C$$

## 8. 🚨 Pitfall Alerts — จุดที่ นศ. มักโดนตัดเป็น 0 คะแนน

### ❌ Pitfall 1: แทน $u$ แล้วยังเหลือ $x$ ค้างอยู่
```
❌ ∫ x²√(x³+1) dx = ∫ x²√u du     ← ยังมี x² ค้าง!
✅ du = 3x²dx ⇒ x²dx = du/3 ⇒ = (1/3)∫√u du
```
**กฎเหล็ก: หลังขั้นที่ 4 ต้องไม่มี $x$ เหลือแม้แต่ตัวเดียว** ถ้าเหลือ = เลือก $u$ ผิด

### ❌ Pitfall 2: ปริพันธ์จำกัดเขตแล้วลืมเปลี่ยนขอบเขต
**กับดักมรณะ** — ผลลัพธ์เป็นตัวเลขที่ผิด แต่ดูเหมือนถูก จับไม่ได้ตอนตรวจ
**นิสัยกันตาย: เขียนตารางเปลี่ยนขอบเขตทุกครั้ง**
```
x = a  →  u = ___
x = b  →  u = ___
```

### ❌ Pitfall 3: ลืมแทน $u$ กลับเป็น $x$ (กรณีปริพันธ์ไม่จำกัดเขต)
ตอบเป็น $u$ ค้างไว้ = ยังทำไม่จบ = 0 คะแนน

### ❌ Pitfall 4: ค่าสัมบูรณ์ — ไม่หั่นช่วง
$\int_1^4|x-3|dx \neq \left[\frac{(x-3)^2}{2}\right]_1^4$ ← **ผิด**
ต้องหั่นที่ $x=3$ เสมอ

### ❌ Pitfall 5: ค่าสัมบูรณ์ — แตกกรณีสลับข้าง
สำหรับ $x<3$: $x-3$ **เป็นลบ** ⇒ $|x-3|=-(x-3)=3-x$
คนมักเผลอเขียน $x-3$ สำหรับช่วงซ้าย → ได้คำตอบติดลบ (ผิดแน่นอน เพราะพื้นที่ต้องเป็นบวก)

### ❌ Pitfall 6: ปริพันธ์ค่าสัมบูรณ์แล้วได้คำตอบติดลบ
$\int|f|$ **ต้องเป็นบวกเสมอ** ได้ลบ = ผิดแน่นอน → กลับไปเช็คขั้นตอนแตกกรณี

### ❌ Pitfall 7: คิดว่า $(-1)^{2/5}$ นิยามไม่ได้
$(-1)^{2/5}=\big(\sqrt[5]{-1}\big)^{2}=(-1)^2=1$ — **รากที่เป็นเลขคี่ของจำนวนลบมีค่าจริง**
(HW13 ข้อ 1 ตกม้าตายตรงนี้เยอะ)

### ❌ Pitfall 8: ลืม $+C$ (อีกแล้ว)
u-Substitution แบบไม่จำกัดเขต **ต้องมี $+C$** เหมือนเดิม

### ❌ Pitfall 9: ใช้สูตรลัดคู่/คี่แล้วไม่แสดงวิธี
เขียนแค่ "ฟังก์ชันคี่ ⇒ 0" ในข้อสอบที่สั่ง "แสดงวิธีทำ" อาจได้ 0
**ใช้เป็นการตรวจ ไม่ใช่การตอบ**
