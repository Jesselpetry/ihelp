> *"Calculus is the mathematics of **changes**."*
> *"The calculus is a **limit machine**."*

**แปลเป็นภาษาคน:**

| คณิตที่เคยเรียน (Precalculus) | แคลคูลัส |
|:---|:---|
| **นิ่ง** — รถวิ่ง 100 กม. ใน 2 ชม. → เร็วเฉลี่ย 50 กม./ชม. | **เคลื่อนไหว** — ณ **วินาทีนี้เป๊ะ ๆ** เข็มไมล์ชี้เท่าไหร่? |

ทั้ง 3 อย่างในคอลัมน์ขวา "ทำตรง ๆ ไม่ได้" — เพราะมันต้องการ *ช่วงที่แคบเป็นศูนย์*

## 1. ฟังก์ชัน (Function) — ทวนให้แน่นใน 5 นาที

### 1.1 นิยามแบบภาพ: เครื่องหยอดเหรียญ

```
   x  ──►  [  f  ]  ──►  f(x)
 (input)  (เครื่อง)   (output)
```

**กฎเหล็กของฟังก์ชัน: หยอด 1 input ต้องได้ output เดียวเท่านั้น**
หยอด $x=2$ แล้วบางทีออก $5$ บางทีออก $7$ → **ไม่ใช่ฟังก์ชัน**

### 1.2 Domain / Range

| ศัพท์ | ภาษาคน | วิธีหา |
|:---|:---|:---|
| **Domain** | "หยอดอะไรเข้าไปได้บ้าง" | เอาทุกจำนวนจริง แล้ว**ตัดตัวที่ทำให้พัง**ออก |
| **Range** | "ออกมาได้ค่าอะไรบ้าง" | ดูจากกราฟ หรือย้อนหา |

**3 อย่างที่ทำให้ฟังก์ชันพัง (ต้องตัดออกจาก domain):**

1. **ตัวส่วนเป็น 0** → $f(x)=\dfrac{1}{x-3}$ ⇒ ตัด $x=3$ ⇒ Domain $=\{x\mid x\neq 3\}$
2. **รากที่สองของจำนวนลบ** → $f(x)=\sqrt{x-5}$ ⇒ ต้อง $x-5\ge 0$ ⇒ Domain $=[5,\infty)$
3. **log/ln ของจำนวน ≤ 0** → $f(x)=\ln(x+2)$ ⇒ ต้อง $x+2>0$ ⇒ Domain $=(-2,\infty)$

### 1.3 One-to-One (หนึ่งต่อหนึ่ง)
output แต่ละตัวมาจาก input ตัวเดียว — ทดสอบด้วย **Horizontal Line Test** (ลากเส้นแนวนอน ต้องตัดกราฟไม่เกิน 1 จุด)

## 2. ลิมิต (Limit) — หัวใจของสัปดาห์นี้

### 2.1 ความคิดหลัก: "เดินเข้าไปใกล้ ๆ แต่ไม่เหยียบ"

$$\lim_{x\to c} f(x) = L$$

อ่านว่า: *"เมื่อ $x$ **เข้าใกล้** $c$ แล้ว $f(x)$ **เข้าใกล้** $L$"*

**⚠️ จุดที่คนพลาดกันมากที่สุดตั้งแต่บรรทัดแรก:**

> ลิมิตถามว่า **"ขากำลังเดินเข้าไป มันมุ่งหน้าไปที่ค่าไหน"**
> ลิมิต **ไม่ได้ถาม**ว่า "ที่จุด $x=c$ พอดี ค่าคือเท่าไหร่"

### อุปมา: เดินไปหาประตูห้อง

คุณเดินเข้าหาประตูห้อง 301 ทีละก้าว — 10 เมตร, 5 เมตร, 1 เมตร, 10 ซม., 1 ซม. …
**ลิมิตคือ "ประตูห้อง 301"** — คือที่ที่คุณกำลังจะไปถึง

แม้ห้อง 301 จะถูก**ล็อกไว้** (คือ $f(c)$ ไม่นิยาม) หรือแม้ป้ายหน้าห้องเขียนผิดเป็น "302" (คือ $f(c)$ มีค่า แต่เป็นค่าอื่น)
**ลิมิตก็ยังเป็น 301 อยู่ดี** เพราะลิมิตสนใจแค่ "ทาง" ไม่สนใจ "ตัวจุดหมาย"

### 2.2 ลิมิตซ้าย–ขวา (One-Sided Limits)

| สัญลักษณ์ | ความหมาย |
|:---|:---|
| $\lim\limits_{x\to c^{-}} f(x)$ | เดินเข้าหา $c$ **จากทางซ้าย** (ค่าน้อยกว่า $c$) |
| $\lim\limits_{x\to c^{+}} f(x)$ | เดินเข้าหา $c$ **จากทางขวา** (ค่ามากกว่า $c$) |

**กฎตัดสิน:**
$$\lim_{x\to c}f(x)=L \iff \lim_{x\to c^{-}}f(x)=\lim_{x\to c^{+}}f(x)=L$$

> **ซ้ายไม่เท่าขวา ⇒ ลิมิตไม่มีค่า (does not exist, DNE)**

**เมื่อไหร่ต้องแยกซ้าย-ขวา?** จำ 3 สัญญาณนี้:
1. โจทย์มี **ค่าสัมบูรณ์** $|\,\cdot\,|$
2. โจทย์เป็น **ฟังก์ชันแยกกรณี (piecewise)** และจุดที่ถามคือรอยต่อ
3. โจทย์เขียน $c^-$ หรือ $c^+$ มาให้เอง

### 2.3 กฎลิมิตพื้นฐาน (ใช้ได้เมื่อทุกลิมิตย่อยมีค่า)

$$\lim_{x\to c} b = b \qquad \lim_{x\to c} x = c \qquad \lim_{x\to c} x^n = c^n$$

$$\lim_{x\to c}\big[f(x)\pm g(x)\big]=\lim f \pm \lim g \qquad
\lim_{x\to c}\big[b\,f(x)\big]=b\lim f$$

$$\lim_{x\to c}\big[f(x)g(x)\big]=\big(\lim f\big)\big(\lim g\big) \qquad
\lim_{x\to c}\frac{f(x)}{g(x)}=\frac{\lim f}{\lim g}\;\;\big(\lim g \neq 0\big)$$

$$\lim_{x\to c}\big[f(x)\big]^{n}=\Big[\lim_{x\to c} f(x)\Big]^{n} \qquad
\lim_{x\to c}\sqrt[n]{x}=\sqrt[n]{c}$$

## 3. 🔑 Pattern วิธีทำ: "ผังตัดสินใจ 3 ชั้น"

**นี่คือเครื่องมือที่ใช้ได้กับข้อลิมิต 95% ของวิชานี้** ทำตามลำดับเสมอ:

```
                    ┌─────────────────────────┐
   ขั้นที่ 1        │  แทนค่า x = c ลงไปเลย   │
                    └───────────┬─────────────┘
                                ▼
              ┌──────────────────────────────────┐
              │ ได้ตัวเลขปกติ (เช่น 16, −1/4)?    │──► ✅ จบ! นั่นคือคำตอบ
              └──────────────┬───────────────────┘
                             ▼ ได้ 0/0
                    ┌─────────────────────────┐
   ขั้นที่ 2        │  รูปแบบยังไม่กำหนด       │
                    │  (Indeterminate 0/0)     │
                    └───────────┬─────────────┘
                                ▼
        ┌───────────────────────┴────────────────────────┐
        ▼                                                ▼
  มีเครื่องหมาย √ ?                              ไม่มี √ (พหุนาม)
        │                                                │
        ▼                                                ▼
  【Rationalizing】                              【Dividing Out】
  คูณสังยุคทั้งเศษและส่วน                        แยกตัวประกอบ แล้วตัดตัวที่เป็น 0
        │                                                │
        └───────────────────┬────────────────────────────┘
                            ▼
   ขั้นที่ 3        ตัดตัวที่ทำให้เป็น 0 ทิ้ง → กลับไปทำขั้นที่ 1 ใหม่
```

### 3.1 Pattern A — แทนค่าตรง ๆ (Direct Substitution)

ใช้ได้เมื่อฟังก์ชันเป็นพหุนาม / ตรรกยะที่ส่วนไม่เป็นศูนย์ / รากที่ค่าในรากไม่ติดลบ

**ตัวอย่าง (ตรงกับ HW8 ข้อ 1):**
$$\lim_{x\to 6}(x-2)^2 = (6-2)^2 = 4^2 = \boxed{16}$$

**เทมเพลตการเขียนที่ TA ให้ผ่าน:**
```
lim (x−2)²        ← เขียน lim ไว้ก่อน
x→6
= (6−2)²          ← บรรทัดนี้ค่อยแทนค่า (ตอนนี้ lim หายไปได้แล้ว)
= 4²
= 16
```

### 3.2 Pattern B — Dividing Out (แยกตัวประกอบแล้วตัด)

**ใช้เมื่อ:** แทนค่าแล้วได้ $\dfrac{0}{0}$ และ **ไม่มีราก**

**ขั้นตอน:**
1. แทนค่า → ยืนยันว่าได้ $\frac{0}{0}$ (เขียนบรรทัดนี้ให้ TA เห็นด้วย!)
2. แยกตัวประกอบเศษ และ/หรือ ส่วน
3. **ตัดวงเล็บที่ทำให้เป็นศูนย์** ออกจากทั้งเศษและส่วน
4. แทนค่าใหม่

**ตัวอย่าง (HW8 ข้อ 6):**
$$\lim_{t\to 3}\frac{t^2-9}{t-3}
\;\overset{\text{แทนค่า}}{=}\;\frac{0}{0}\;\text{(indeterminate)}$$
$$=\lim_{t\to 3}\frac{\cancel{(t-3)}(t+3)}{\cancel{(t-3)}}
=\lim_{t\to 3}(t+3)=3+3=\boxed{6}$$

> **ทำไมตัดได้?** เพราะลิมิตบอกว่า $t$ **เข้าใกล้** 3 แต่ **ไม่เท่ากับ** 3
> ดังนั้น $t-3 \neq 0$ จริง ๆ → ตัดได้อย่างถูกกฎหมาย

### 3.3 Pattern C — Rationalizing (คูณสังยุค)

**ใช้เมื่อ:** ได้ $\frac{0}{0}$ และ **มีเครื่องหมายราก**

**สังยุค (conjugate)** = ตัวเดิมแต่สลับเครื่องหมายกลาง
$\sqrt{A}-B \;\longrightarrow\; \sqrt{A}+B$

เพราะ $(\sqrt{A}-B)(\sqrt{A}+B)=A-B^2$ → **รากหายไป**

**ขั้นตอน:**
1. แทนค่า → ได้ $\frac{0}{0}$
2. คูณทั้งเศษและส่วนด้วยสังยุค**ของฝั่งที่มีราก**
3. กระจายเฉพาะ**ฝั่งที่มีราก** — **อีกฝั่งอย่าเพิ่งกระจาย! ปล่อยเป็นวงเล็บไว้**
4. ตัดตัวประกอบ แล้วแทนค่า

**ตัวอย่าง (HW8 ข้อ 8):**
$$\lim_{x\to 0}\frac{\sqrt{4+x}-2}{x}\;\overset{\text{แทนค่า}}{=}\;\frac{\sqrt{4}-2}{0}=\frac{0}{0}$$

คูณสังยุค $(\sqrt{4+x}+2)$:
$$=\lim_{x\to 0}\frac{(\sqrt{4+x}-2)}{x}\cdot\frac{(\sqrt{4+x}+2)}{(\sqrt{4+x}+2)}
=\lim_{x\to 0}\frac{(4+x)-4}{x(\sqrt{4+x}+2)}$$
$$=\lim_{x\to 0}\frac{\cancel{x}}{\cancel{x}(\sqrt{4+x}+2)}
=\frac{1}{\sqrt{4}+2}=\frac{1}{4}$$

$$\boxed{\dfrac{1}{4}}$$

> **💡 เคล็ดลับ:** ขั้นที่ 3 คือจุดที่คนพลาดเยอะสุด — **อย่ากระจายตัวส่วน**
> ปล่อย $x(\sqrt{4+x}+2)$ ไว้แบบนั้น เพราะเราต้องการเห็น $x$ เพื่อตัดกับเศษ

### 3.4 Pattern D — ค่าสัมบูรณ์ (แตกเป็น piecewise)

**นิยาม:**
$$|u| = \begin{cases} u & , u \ge 0\\ -u & , u < 0\end{cases}$$

**ขั้นตอน:**
1. หาจุดที่ข้างในเป็นศูนย์ (เรียก **จุดหักมุม**)
2. เทียบว่า $c$ ที่โจทย์ให้ อยู่ **ซ้าย** หรือ **ขวา** ของจุดหักมุม
3. ถ้า $c$ อยู่ห่างจากจุดหักมุม → ใช้กรณีนั้นกรณีเดียว แทนค่าได้เลย
4. ถ้า $c$ **คือ** จุดหักมุมพอดี → **ต้องแยกซ้าย-ขวา**

**ตัวอย่าง (HW8 ข้อ 4):**
$$\lim_{y\to 4} 3|y-1|$$
จุดหักมุมคือ $y=1$ แต่เราเดินเข้าหา $y=4$ ซึ่งอยู่ **ขวา** ของ 1 → บริเวณนั้น $y-1>0$ ⇒ $|y-1|=y-1$
$$=3(4-1)=3(3)=\boxed{9}$$

**ตัวอย่างที่ต้องแยกซ้ายขวา:**
$$\lim_{x\to 2}\frac{|x-2|}{x-2}$$
- ขวา: $x>2 \Rightarrow |x-2|=x-2 \Rightarrow \lim\limits_{x\to2^+}\frac{x-2}{x-2}=1$
- ซ้าย: $x<2 \Rightarrow |x-2|=-(x-2) \Rightarrow \lim\limits_{x\to2^-}\frac{-(x-2)}{x-2}=-1$
- $1\neq-1 \Rightarrow$ **ลิมิตไม่มีค่า (DNE)**

### 3.5 Pattern E — ลิมิตอนันต์ และลิมิตที่อนันต์

**(ก) ลิมิตอนันต์ (Infinite Limit) — เส้นกำกับแนวตั้ง**
เมื่อแทนค่าแล้วได้ $\dfrac{\text{ไม่ใช่ศูนย์}}{0}$ → ลิมิตพุ่งไป $\pm\infty$ (ไม่ใช่ $\frac00$! อย่าไปแยกตัวประกอบ)
$$\lim_{x\to 0^+}\frac{1}{x}=+\infty,\qquad \lim_{x\to 0^-}\frac{1}{x}=-\infty$$
ต้องดูเครื่องหมายทีละข้าง → $x=0$ คือ **เส้นกำกับแนวตั้ง (vertical asymptote)**

**(ข) ลิมิตที่อนันต์ (Limit at Infinity) — เส้นกำกับแนวนอน**
$$\lim_{x\to\pm\infty}\frac{1}{x^{n}}=0 \quad (n>0)$$

**เทคนิค: หารทุกพจน์ด้วย $x$ กำลังสูงสุดของตัวส่วน**
$$\lim_{x\to\infty}\frac{3x^2+5x}{2x^2-1}
=\lim_{x\to\infty}\frac{3+\frac{5}{x}}{2-\frac{1}{x^2}}
=\frac{3+0}{2-0}=\frac{3}{2}$$

**สูตรลัด (เอาไว้ตรวจคำตอบ — แต่ในกระดาษต้องแสดงวิธีหารด้วย):**

| เทียบดีกรี | ผลลัพธ์ |
|:---|:---|
| ดีกรีเศษ **<** ดีกรีส่วน | $0$ |
| ดีกรีเศษ **=** ดีกรีส่วน | อัตราส่วนสัมประสิทธิ์นำ |
| ดีกรีเศษ **>** ดีกรีส่วน | $\pm\infty$ (DNE) |

## 4. ความต่อเนื่อง (Continuity)

### 4.1 นิยามแบบภาพ
**"วาดกราฟได้โดยไม่ต้องยกปากกา"** — ไม่มีรู ไม่มีกระโดด ไม่มีเส้นพุ่งขึ้นฟ้า

### 4.2 นิยามแบบทางการ — **เช็ค 3 เงื่อนไข** (ออกสอบทุกปี!)

$f$ ต่อเนื่องที่ $x=c$ ก็ต่อเมื่อครบทั้ง 3 ข้อ:

| # | เงื่อนไข | ภาษาคน |
|:-:|:---|:---|
| ① | $f(c)$ **นิยามได้** | จุดนั้นมีค่าจริง ๆ ไม่ใช่รู |
| ② | $\lim\limits_{x\to c} f(x)$ **มีค่า** | ซ้าย = ขวา |
| ③ | $\lim\limits_{x\to c} f(x) = f(c)$ | ที่ที่มุ่งไป = ที่ที่อยู่จริง |

> **เขียนในกระดาษสอบให้เขียนทั้ง 3 ข้อเสมอ** แม้ข้อไหนจะชัดเจนก็ตาม — นี่คือ "วิธีทำทีละขั้นตอน" ที่ TA ต้องการเห็น

### 4.3 ประเภทของความไม่ต่อเนื่อง

| ประเภท | ภาพ | ลักษณะ | "ซ่อมได้ไหม" |
|:---|:---|:---|:---|
| **Removable** | รูเล็ก ๆ ○ | $\lim$ มีค่า แต่ $\neq f(c)$ หรือ $f(c)$ ไม่นิยาม | ✅ ซ่อมได้ (นิยาม $f(c)$ ใหม่ให้เท่าลิมิต) |
| **Jump** | กระโดดเป็นขั้น | ซ้าย $\neq$ ขวา | ❌ |
| **Infinite** | พุ่งขึ้นฟ้า | ลิมิตเป็น $\pm\infty$ | ❌ |

สองอย่างหลังเรียกรวมว่า **Non-removable discontinuity**

### 4.4 🔑 Pattern: โจทย์ "หาค่า $A$ ให้ฟังก์ชันต่อเนื่อง" (ออกสอบบ่อยมาก)

โจทย์แบบนี้ปรากฏในข้อสอบปลายภาคเก่าปี 2559, 2560 และ 2561 **ทุกปี**

**โจทย์แบบ:**
$$f(x)=\begin{cases} x+3 &, x\le 1\\ 2x+A &, x>1\end{cases}\quad \text{ต่อเนื่อง จงหา } A$$

**ขั้นตอน 4 บรรทัด:**
```
1) หาจุดรอยต่อ: x = 1
2) ลิมิตซ้าย:  lim   (x+3) = 1+3 = 4
              x→1⁻
3) ลิมิตขวา:  lim   (2x+A) = 2(1)+A = 2+A
              x→1⁺
4) ต่อเนื่อง ⇒ ซ้าย = ขวา ⇒ 4 = 2 + A ⇒ A = 2
```

**เวอร์ชันยากขึ้น (3 กรณี ต้องหา 2 ตัวแปร) — จากข้อสอบปี 2559:**
$$f(x)=\begin{cases}3x+A &, x<2\\ 5 &, x=2\\ 2x+B &, x>2\end{cases}$$
- ซ้าย: $3(2)+A=6+A=5 \Rightarrow A=-1$
- ขวา: $2(2)+B=4+B=5 \Rightarrow B=1$

## 5. ตารางสูตร Week 8 (ฉีกไปติดผนัง)

$$\lim_{x\to c}b=b \qquad \lim_{x\to c}x^n=c^n \qquad \lim_{x\to c}\sqrt[n]{x}=\sqrt[n]{c}$$

$$\lim_{x\to 0}\frac{\sin x}{x}=1 \qquad \lim_{x\to 0}\frac{1-\cos x}{x}=0 \qquad \lim_{x\to\pm\infty}\frac{1}{x^{n}}=0$$

**สังยุคที่ใช้บ่อย:**

| นิพจน์ | คูณด้วย | ได้ |
|:---|:---|:---|
| $\sqrt{a}-b$ | $\sqrt{a}+b$ | $a-b^2$ |
| $\sqrt{a}-\sqrt{b}$ | $\sqrt{a}+\sqrt{b}$ | $a-b$ |

**การแยกตัวประกอบที่ใช้บ่อย:**

$$a^2-b^2=(a-b)(a+b) \qquad a^3-b^3=(a-b)(a^2+ab+b^2) \qquad a^3+b^3=(a+b)(a^2-ab+b^2)$$

## 6. 🚨 Pitfall Alerts — จุดที่ นศ. มักโดนตัดเป็น 0 คะแนน

### ❌ Pitfall 1: เห็น $\frac{0}{0}$ แล้วตอบว่า "หาค่าไม่ได้"
$\frac{0}{0}$ เรียกว่า **indeterminate form** = "ยังไม่รู้ ต้องทำต่อ"
ไม่ใช่ "ไม่มีคำตอบ" — **นี่คือสัญญาณให้แยกตัวประกอบหรือคูณสังยุค**

### ❌ Pitfall 2: เขียน $\lim$ หายไปกลางคัน
```
❌ ผิด:                        ✅ ถูก:
lim  (t²−9)/(t−3)              lim  (t²−9)/(t−3)
t→3                            t→3
= (t−3)(t+3)/(t−3)             = lim (t−3)(t+3)/(t−3)
= t+3                             t→3
= 6                            = lim (t+3)
                                  t→3
                               = 3+3 = 6
```
**กฎ: ตราบใดที่ยังมี $x$ (หรือ $t$) อยู่ในนิพจน์ ต้องมี $\lim$ นำหน้าเสมอ**
ทิ้ง $\lim$ ได้ตอนแทนค่าจริงแล้วเท่านั้น — TA หลายคนตัดคะแนนตรงนี้

### ❌ Pitfall 3: ตัดเศษ-ส่วนแบบผิดกฎ
```
❌ (x² + 5)/x  ≠  x + 5      ← ตัด x ไม่ได้! เพราะเศษเป็นการ "บวก" ไม่ใช่ "คูณ"
✅ ตัดได้เฉพาะเมื่อเป็น "ตัวประกอบ (factor)" ที่คูณกันอยู่ทั้งเศษและส่วน
```

### ❌ Pitfall 4: ลืมแยกซ้าย-ขวาเมื่อเจอค่าสัมบูรณ์
เห็น $|\cdot|$ ปุ๊บ ให้ถามตัวเองทันที: **"จุดที่ถาม คือจุดหักมุมไหม?"**
ถ้าใช่ → ต้องแยก 2 ข้าง ถ้าไม่แยก = ผิดทั้งข้อ

### ❌ Pitfall 5: กระจายตัวส่วนหลังคูณสังยุค
```
❌ = lim [x] / [x·(√(4+x)+2)]  →  แล้วไปกระจาย x√(4+x)+2x  →  ตัดไม่ได้แล้ว งงต่อ
✅ ปล่อยตัวส่วนเป็นวงเล็บไว้ ตัด x ก่อน ค่อยแทนค่า
```

### ❌ Pitfall 6: ตอบความต่อเนื่องโดยไม่เช็คครบ 3 เงื่อนไข
เขียนแค่ "ลิมิตซ้าย = ลิมิตขวา ⇒ ต่อเนื่อง" → ขาดเงื่อนไข ① และ ③
**เกณฑ์ all-or-nothing = ได้ 0** ทั้งที่คำตอบตัวเลขถูก

### ❌ Pitfall 7: สับสน $\frac{k}{0}$ กับ $\frac{0}{0}$
- $\frac{5}{0}$ (เศษไม่เป็นศูนย์) → **ลิมิตอนันต์** ต้องดูเครื่องหมายซ้าย/ขวา → ตอบ $\pm\infty$ หรือ DNE
- $\frac{0}{0}$ → **ต้องจัดรูปต่อ**
ห้ามใช้วิธีของอันหนึ่งกับอีกอันเด็ดขาด

### ❌ Pitfall 8: HW8 ข้อ 2 — ยกกำลังพลาด
$\lim_{x\to7}(10-x)^4=(10-7)^4=3^4=81$ ไม่ใช่ $12$ หรือ $9$
**ยกกำลังต้องคูณตัวเองครบจำนวนครั้ง** — เขียน $3\times3\times3\times3$ ให้เห็นถ้าไม่มั่นใจ
