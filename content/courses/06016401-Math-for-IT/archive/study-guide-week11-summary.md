## 1. ภาพรวม: $f'$ และ $f''$ บอกอะไรเราบ้าง

นี่คือ **ตารางแม่** ของสัปดาห์นี้ — เข้าใจตารางนี้ = เข้าใจทั้งสัปดาห์

| | เครื่องหมาย | ความหมาย | ภาพกราฟ |
|:---|:---|:---|:---|
| $f'(x)>0$ | บวก | ฟังก์ชัน**เพิ่มขึ้น** | เดินขึ้นเขา ↗ |
| $f'(x)<0$ | ลบ | ฟังก์ชัน**ลดลง** | เดินลงเขา ↘ |
| $f'(x)=0$ | ศูนย์ | ความชันราบ | ยอดเขา / ก้นหุบเขา / จุดพัก |
| $f''(x)>0$ | บวก | **เว้าบน (concave up)** | รูปถ้วยน้ำ ∪ (รองน้ำได้) |
| $f''(x)<0$ | ลบ | **เว้าล่าง (concave down)** | รูปโดม ∩ (น้ำไหลออก) |
| $f''(x)=0$ | ศูนย์ | อาจเป็น**จุดเปลี่ยนเว้า** | ตรงที่ ∪ เปลี่ยนเป็น ∩ |

> **💡 เคล็ดจำความเว้า:** $f''>0$ → เครื่องหมาย **บวก** → ยิ้ม ∪ ("บวกแล้วยิ้ม")
> $f''<0$ → เครื่องหมาย **ลบ** → หน้าบึ้ง ∩

## 2. Critical Numbers (จำนวนวิกฤต) — ประตูสู่ทุกอย่างในบทนี้

### นิยาม
$c$ เป็น **critical number** ของ $f$ ถ้า $c$ อยู่ใน domain ของ $f$ และ

$$f'(c)=0 \qquad\textbf{หรือ}\qquad f'(c) \text{ หาค่าไม่ได้}$$

### ⚠️ คนลืมเงื่อนไขที่สองบ่อยมาก
$f(x)=x^{2/3}$ → $f'(x)=\frac{2}{3}x^{-1/3}=\frac{2}{3\sqrt[3]{x}}$
$f'(0)$ **หาค่าไม่ได้** (ส่วนเป็นศูนย์) แต่ $f(0)=0$ นิยามได้ ⇒ $x=0$ **เป็น critical number**

### วิธีหา
```
1) หา f'(x)
2) จัดให้เป็นเศษส่วนเดียว (รวมเป็น เศษ/ส่วน)
3) เศษ = 0  →  ได้ critical number แบบ f'(c) = 0
   ส่วน = 0  →  ได้ critical number แบบ f'(c) หาค่าไม่ได้ (ถ้า c ยังอยู่ใน domain ของ f)
```

## 3. ค่าสุดขีดบนช่วงปิด (Extrema on a Closed Interval)

### ทฤษฎีบทค่าสุดขีด (Extreme Value Theorem)
ถ้า $f$ **ต่อเนื่อง** บนช่วงปิด $[a,b]$ แล้ว $f$ มีทั้งค่าสูงสุดสัมบูรณ์และต่ำสุดสัมบูรณ์บนช่วงนั้นแน่นอน

### 🔑 Pattern: "Candidate Test" (3 ขั้นตอน — ง่ายที่สุดในบทนี้)

```
ขั้นที่ 1  หา critical numbers ที่อยู่ "ใน" ช่วง (a, b)
ขั้นที่ 2  ทำตาราง: คำนวณ f ที่  ทุก critical number  +  ปลายช่วงทั้งสอง f(a), f(b)
ขั้นที่ 3  เทียบตัวเลข → ตัวมากสุด = ค่าสูงสุดสัมบูรณ์ · ตัวน้อยสุด = ค่าต่ำสุดสัมบูรณ์
```

> ⚠️ **ห้ามลืมปลายช่วง!** นี่คือจุดที่คนพลาดมากที่สุดของหัวข้อนี้
> ค่าสูงสุดมักอยู่ที่ปลายช่วงพอ ๆ กับที่อยู่ที่ critical number

**ตัวอย่าง:** $f(x)=x^{3}-3x^{2}$ บน $[-1,3]$

$f'(x)=3x^2-6x=3x(x-2)=0 \Rightarrow x=0,\,2$ (อยู่ในช่วงทั้งคู่)

| $x$ | $-1$ | $0$ | $2$ | $3$ |
|:---|:---:|:---:|:---:|:---:|
| $f(x)$ | $-4$ | $0$ | $-4$ | $0$ |

⇒ ค่าสูงสุดสัมบูรณ์ $=0$ (ที่ $x=0$ และ $x=3$), ค่าต่ำสุดสัมบูรณ์ $=-4$ (ที่ $x=-1$ และ $x=2$)

## 4. First Derivative Test (การทดสอบอนุพันธ์อันดับหนึ่ง)

### 🔑 Pattern: ตารางเครื่องหมาย (Sign Chart)

```
ขั้นที่ 1  หา f'(x)  แล้วหา critical numbers
ขั้นที่ 2  วาดเส้นจำนวน แบ่งเป็นช่วงย่อยด้วย critical numbers
ขั้นที่ 3  เลือก "เลขทดสอบ" 1 ตัวในแต่ละช่วง แทนใน f'  → ดูแค่ "บวกหรือลบ"
ขั้นที่ 4  อ่านผล
```

| เครื่องหมาย $f'$ รอบ ๆ $c$ | สรุป |
|:---|:---|
| $+ \to -$ (เปลี่ยนบวกเป็นลบ) | $f(c)$ = **ค่าสูงสุดสัมพัทธ์** (local max) |
| $- \to +$ (เปลี่ยนลบเป็นบวก) | $f(c)$ = **ค่าต่ำสุดสัมพัทธ์** (local min) |
| ไม่เปลี่ยน ($+\to+$ หรือ $-\to-$) | ไม่ใช่ค่าสุดขีด (แค่จุดพัก/saddle) |

**ตัวอย่างตารางเครื่องหมาย** ของ $f'(x)=3x(x-2)$:
```
ช่วง         (−∞, 0)      (0, 2)       (2, ∞)
เลขทดสอบ       x = −1       x = 1        x = 3
f'(ทดสอบ)   3(−1)(−3)=+9  3(1)(−1)=−3  3(3)(1)=+9
เครื่องหมาย       +            −             +
f              เพิ่มขึ้น ↗    ลดลง ↘      เพิ่มขึ้น ↗

⇒ x = 0 : + → −  ⇒ local MAX = f(0) = 0
⇒ x = 2 : − → +  ⇒ local MIN = f(2) = −4
```

## 5. ความเว้า, จุดเปลี่ยนเว้า และ Second Derivative Test

### 5.1 หาจุดเปลี่ยนเว้า (Inflection Point)
```
1) หา f''(x)
2) แก้ f''(x) = 0  (และหาจุดที่ f'' หาค่าไม่ได้)
3) ทำตารางเครื่องหมายของ f''
4) จุดที่ f'' "เปลี่ยนเครื่องหมาย" เท่านั้น จึงเป็นจุดเปลี่ยนเว้า
```

> ⚠️ **$f''(c)=0$ ไม่ได้แปลว่าเป็นจุดเปลี่ยนเว้าเสมอไป!**
> ตัวอย่างค้าน: $f(x)=x^{4}$ → $f''=12x^{2}$, $f''(0)=0$ แต่ $f''>0$ ทั้งสองข้าง → **ไม่ใช่** จุดเปลี่ยนเว้า
> **ต้องเปลี่ยนเครื่องหมายจริง ๆ เท่านั้น**

### 5.2 Second Derivative Test (ทางลัดหา local max/min)

ให้ $f'(c)=0$ แล้ว:

| | สรุป | จำง่าย ๆ |
|:---|:---|:---|
| $f''(c)>0$ | $f(c)$ = **local MIN** | ถ้วย ∪ → ก้นถ้วยคือต่ำสุด |
| $f''(c)<0$ | $f(c)$ = **local MAX** | โดม ∩ → ยอดโดมคือสูงสุด |
| $f''(c)=0$ | **สรุปไม่ได้** → กลับไปใช้ First Derivative Test | — |

## 6. Curve Sketching (การวาดกราฟ) — Checklist 7 ข้อ

```
1) Domain            หาว่า x ใช้ได้ถึงไหน
2) จุดตัดแกน         y-intercept: แทน x=0    x-intercept: แก้ f(x)=0
3) เส้นกำกับ          แนวตั้ง: ส่วน = 0        แนวนอน: lim x→±∞ f(x)
4) f'(x)             critical numbers → ตารางเครื่องหมาย → ช่วงเพิ่ม/ลด + local max/min
5) f''(x)            → ตารางเครื่องหมาย → ช่วงเว้าบน/เว้าล่าง + จุดเปลี่ยนเว้า
6) ทำตารางสรุป        รวมข้อมูลทุกจุดสำคัญ (x, y, ประเภทจุด)
7) วาดกราฟ            ลงจุดสำคัญก่อน แล้วลากเส้นตามข้อมูลเพิ่ม/ลด/เว้า
```

### สรุปเส้นกำกับ

| ชนิด | หายังไง |
|:---|:---|
| แนวตั้ง (vertical) | ค่า $x$ ที่ทำให้ตัวส่วน $=0$ แต่ตัวเศษ $\neq 0$ |
| แนวนอน (horizontal) | $\lim\limits_{x\to\pm\infty}f(x)=L$ ⇒ เส้น $y=L$ |
| เฉียง (slant) | เมื่อดีกรีเศษ = ดีกรีส่วน + 1 → หารยาว |

## 7. 🔑 Optimization (การหาค่าเหมาะที่สุด) — หัวใจของ HW11

### 7.1 Pattern 6 ขั้นตอน (ท่องให้ขึ้นใจ)

```
ขั้นที่ 1  วาดรูป + ตั้งชื่อตัวแปรทุกตัว
ขั้นที่ 2  เขียน "ฟังก์ชันเป้าหมาย" (สิ่งที่จะทำให้มาก/น้อยที่สุด)
ขั้นที่ 3  เขียน "สมการเงื่อนไข" (constraint) จากข้อจำกัดในโจทย์
ขั้นที่ 4  ใช้ constraint กำจัดตัวแปรจนเหลือ "ตัวแปรเดียว"  ← ⚠️ ขั้นที่คนติดมากสุด
ขั้นที่ 5  หา domain ที่สมเหตุสมผล  แล้วหา critical numbers
ขั้นที่ 6  ทดสอบ (Candidate Test หรือ 1st/2nd Derivative Test) → ตอบพร้อมหน่วย
```

### 7.2 ตัวอย่างเต็ม — **HW11 ตัวจริง**

> **โจทย์:** จงคำนวณหาพื้นที่ของสามเหลี่ยมหน้าจั่วที่ใหญ่ที่สุด ที่บรรจุอยู่ในวงกลมรัศมี 6 หน่วย
> **ให้ใช้ฟังก์ชันที่มีตัวแปร $h$ เป็นตัวแปรอิสระ**

**ขั้นที่ 1 — วาดรูปและตั้งตัวแปร**
```
                 A  ← ยอดสามเหลี่ยม (อยู่บนวงกลม)
                /|\
               / | \        O = จุดศูนย์กลางวงกลม, รัศมี = 6
              /  |  \
         ────/───O───\────  ← เส้นผ่านศูนย์กลางแนวนอน
            /    |h   \         h = ระยะจาก O ลงมาถึงฐาน BC
           B─────┴─────C
                 a           a = ครึ่งฐาน
```
ให้ $h$ = ระยะตั้งฉากจากจุดศูนย์กลาง $O$ ถึงฐาน $BC$ และ $a$ = ครึ่งความยาวฐาน

**ขั้นที่ 2 — ฟังก์ชันเป้าหมาย**
$$\text{Area}=\tfrac12\times\text{ฐาน}\times\text{สูง}=\tfrac12\,(2a)(6+h)=a(6+h)$$
(ความสูงทั้งหมดของสามเหลี่ยม = จาก $A$ ลงมาถึง $BC$ = $6+h$)

**ขั้นที่ 3 — สมการเงื่อนไข** (พีทาโกรัสในสามเหลี่ยม $OBC'$ รัศมี = ด้านตรงข้ามมุมฉาก)
$$6^{2}=h^{2}+a^{2} \;\Longrightarrow\; a=\sqrt{36-h^{2}}$$

**ขั้นที่ 4 — เหลือตัวแปรเดียว ($h$ ตามที่โจทย์สั่ง)**
$$\boxed{A(h)=(6+h)\sqrt{36-h^{2}}},\qquad 0\le h\le 6$$

**ขั้นที่ 5 — หา critical numbers** (Product Rule + Chain Rule)
$$A'(h)=(1)\sqrt{36-h^{2}}+(6+h)\cdot\frac{-h}{\sqrt{36-h^{2}}}$$
$$=\frac{(36-h^{2})-h(6+h)}{\sqrt{36-h^{2}}}
=\frac{36-h^{2}-6h-h^{2}}{\sqrt{36-h^{2}}}
=\frac{-2h^{2}-6h+36}{\sqrt{36-h^{2}}}$$

ตั้ง $A'(h)=0$ ⇒ เศษ $=0$:
$$-2h^{2}-6h+36=0 \;\Longrightarrow\; h^{2}+3h-18=0 \;\Longrightarrow\; (h+6)(h-3)=0$$
$$h=-6 \;(\text{ทิ้ง เพราะอยู่นอก } [0,6]) \qquad h=3 \;\checkmark$$

**ขั้นที่ 6 — Candidate Test บน $[0,6]$**

| $h$ | $A(h)=(6+h)\sqrt{36-h^{2}}$ | ค่า |
|:---:|:---|:---:|
| $0$ | $6\sqrt{36}=6(6)$ | $36$ |
| $3$ | $9\sqrt{27}=9\cdot 3\sqrt3$ | $27\sqrt3\approx 46.77$ ✅ |
| $6$ | $12\sqrt{0}$ | $0$ |

$$\boxed{\text{พื้นที่มากที่สุด}=27\sqrt{3}\approx 46.77 \text{ ตารางหน่วย (ที่ } h=3)}$$

> 💡 **ข้อสังเกตสวย ๆ:** ที่ $h=3$ ได้ $a=\sqrt{27}=3\sqrt3$ ⇒ ฐาน $=6\sqrt3$, ด้านข้าง $=\sqrt{(3\sqrt3)^2+9^2}=6\sqrt3$
> ⇒ **สามเหลี่ยมด้านเท่า!** สามเหลี่ยมที่ใหญ่ที่สุดในวงกลมคือสามเหลี่ยมด้านเท่าเสมอ
> ใช้ตรวจคำตอบได้ แต่ในกระดาษต้องแสดงวิธีอนุพันธ์

### 7.3 สูตรที่โผล่บ่อยในโจทย์ Optimization

| โจทย์แบบ | ฟังก์ชันเป้าหมาย | Constraint |
|:---|:---|:---|
| กล่องไม่มีฝา ปริมาตรมากสุด | $V=x^2h$ | พื้นที่ผิว $x^2+4xh=S$ |
| ล้อมรั้วพื้นที่มากสุด | $A=xy$ | ความยาวรั้ว $2x+2y=P$ |
| กระป๋องใช้วัสดุน้อยสุด | $S=2\pi r^2+2\pi rh$ | $V=\pi r^2h$ คงที่ |
| ระยะทางสั้นสุดจากจุดถึงเส้นโค้ง | $d^2=(x-x_0)^2+(y-y_0)^2$ | $y=f(x)$ |

> 💡 **เทคนิคระยะทาง:** ให้ minimize $d^{2}$ แทน $d$ — จุดต่ำสุดจุดเดียวกัน แต่ไม่ต้องดิฟราก (ง่ายกว่ามาก)

## 8. Approximation Techniques (เทคนิคประมาณค่า)

### 8.1 Differentials (ผลต่างเชิงอนุพันธ์)
$$dy=f'(x)\,dx \qquad\Longrightarrow\qquad f(x+\Delta x)\approx f(x)+f'(x)\,\Delta x$$

**ตัวอย่าง:** ประมาณ $\sqrt{16.5}$
$$f(x)=\sqrt{x},\ x=16,\ \Delta x=0.5,\ f'(x)=\tfrac{1}{2\sqrt x}=\tfrac18$$
$$\sqrt{16.5}\approx 4+\tfrac18(0.5)=4.0625 \qquad(\text{ค่าจริง}\approx 4.0620)$$

### 8.2 Newton's Method (หารากสมการ)
$$x_{n+1}=x_{n}-\frac{f(x_{n})}{f'(x_{n})}$$
ใช้หาคำตอบโดยประมาณของ $f(x)=0$ — เริ่มจากค่าเดา $x_0$ แล้ววนซ้ำจนตัวเลขนิ่ง

### 8.3 Mean Value Theorem & Rolle's Theorem (ทฤษฎีบทประกอบ)

**Rolle:** ถ้า $f$ ต่อเนื่องบน $[a,b]$, หาอนุพันธ์ได้บน $(a,b)$ และ $f(a)=f(b)$
⇒ มี $c\in(a,b)$ ที่ $f'(c)=0$

**MVT:** ถ้า $f$ ต่อเนื่องบน $[a,b]$ และหาอนุพันธ์ได้บน $(a,b)$
⇒ มี $c\in(a,b)$ ที่
$$f'(c)=\frac{f(b)-f(a)}{b-a}$$

> **ภาษาคน (MVT):** ถ้าขับรถจากกรุงเทพฯ ถึงโคราช 250 กม. ใน 2.5 ชม. (เฉลี่ย 100 กม./ชม.)
> ⇒ ต้องมี**อย่างน้อย 1 ขณะ** ที่เข็มไมล์ชี้ 100 กม./ชม. พอดี

| หัวข้อ | สาระ |
|:---|:---|

## 10. 🚨 Pitfall Alerts — จุดที่ นศ. มักโดนตัดเป็น 0 คะแนน

### ❌ Pitfall 1: ลืมตรวจ **ปลายช่วง** ในโจทย์ช่วงปิด
หา critical number แล้วตอบเลย → ผิดครึ่งหนึ่งของเวลา
**ทุกครั้งที่โจทย์เขียน $[a,b]$ ต้องมี $f(a)$ และ $f(b)$ ในตาราง**

### ❌ Pitfall 2: ลืม critical number แบบ "$f'$ หาค่าไม่ได้"
$f'(x)=\frac{2}{3\sqrt[3]{x}}$ → ไม่มี $x$ ที่ทำให้ $f'=0$ เลย แต่ $x=0$ เป็น critical number
**เช็คทั้ง "เศษ = 0" และ "ส่วน = 0" เสมอ**

### ❌ Pitfall 3: $f''(c)=0$ แล้วสรุปว่าเป็นจุดเปลี่ยนเว้าทันที
ต้องเช็คว่า $f''$ **เปลี่ยนเครื่องหมาย** จริงหรือไม่ ($x^4$ ที่ $x=0$ เป็นตัวอย่างค้าน)

### ❌ Pitfall 4: Optimization แล้วไม่กำจัดตัวแปรให้เหลือตัวเดียว
ดิฟฟังก์ชัน 2 ตัวแปรด้วยเทคนิค 1 ตัวแปร = ผิดทั้งข้อ
**ต้องผ่านขั้นที่ 4 ให้ได้ก่อนดิฟเสมอ**

### ❌ Pitfall 5: ไม่เช็ค domain ที่สมเหตุสมผลของโจทย์
ความยาว/รัศมี/เวลา **เป็นลบไม่ได้** — HW11 ได้ $h=-6$ ต้อง **เขียนบรรทัดบอกว่าทิ้งเพราะอะไร**
ถ้าไม่เขียน TA จะมองว่าวิธีทำไม่สมบูรณ์

### ❌ Pitfall 6: ตอบไม่ตรงคำถาม
โจทย์ถาม "**พื้นที่**มากที่สุด" → ต้องตอบ $27\sqrt3$ ไม่ใช่ตอบ $h=3$
$h=3$ คือ *"ตอบว่าเกิดที่ไหน"* ไม่ใช่ *"ค่ามากสุดคือเท่าไหร่"*
**อ่านคำถามซ้ำก่อนวงกลมคำตอบทุกครั้ง**

### ❌ Pitfall 7: ไม่มีหน่วย
"$27\sqrt3$" → ควรเป็น "$27\sqrt3$ **ตารางหน่วย**"

### ❌ Pitfall 8: HW11 โจทย์สั่ง "ให้ใช้ตัวแปร $h$ เป็นตัวแปรอิสระ" แต่ไปใช้มุมหรือ $a$
**โจทย์ระบุตัวแปรมาแล้ว ต้องใช้ตามนั้น** — ทำถูกด้วยวิธีอื่นก็ยังผิดคำสั่ง
