## 1. อนุพันธ์คืออะไร (แบบไม่มีศัพท์)

### 1.1 ปัญหาต้นเรื่อง: ความชันของเส้นโค้ง

ความชันของ**เส้นตรง** หาง่าย: $m=\dfrac{\Delta y}{\Delta x}=\dfrac{y_2-y_1}{x_2-x_1}$ — ต้องมี **2 จุด**

แต่ความชันของ**เส้นโค้ง ณ จุดเดียว** ล่ะ? มีแค่จุดเดียว จะเอา $\Delta$ มาจากไหน?

**ไอเดียของนิวตัน:**
```
   1) ลากเส้นผ่าน 2 จุด: จุดที่เราสนใจ (x, f(x))  และ จุดข้าง ๆ (x+Δx, f(x+Δx))
      → ได้ "เส้นตัด (secant line)" ความชัน = [f(x+Δx) − f(x)] / Δx

   2) เลื่อนจุดที่สองเข้ามาใกล้ ๆ ทีละนิด  (Δx → 0)

   3) เส้นตัดจะค่อย ๆ หมุนกลายเป็น "เส้นสัมผัส (tangent line)"
      → ความชันของเส้นสัมผัส = ลิมิตของความชันเส้นตัด
```

### 1.2 อุปมา: เข็มไมล์รถยนต์

- $\dfrac{\text{ระยะทางทั้งหมด}}{\text{เวลาทั้งหมด}}$ = **ความเร็วเฉลี่ย** ← นี่คือความชันเส้นตัด
- ตัวเลขบนเข็มไมล์ **ณ วินาทีนี้** = **ความเร็วขณะหนึ่ง** ← นี่คืออนุพันธ์

**อนุพันธ์ = อัตราการเปลี่ยนแปลง ณ ขณะหนึ่ง = ความชันเส้นสัมผัส** (สองอย่างนี้คือเรื่องเดียวกัน)

## 2. นิยามด้วยลิมิต (The Limit Definition) — ออกสอบเกือบทุกปี ⚠️

$$\boxed{\;f'(x)=\lim_{\Delta x\to 0}\frac{f(x+\Delta x)-f(x)}{\Delta x}\;}$$

หรือเขียนแบบ "ที่จุด $c$":
$$f'(c)=\lim_{x\to c}\frac{f(x)-f(c)}{x-c}$$

### 🔑 Pattern: หาอนุพันธ์จากนิยาม (4 ขั้นตอนตายตัว)

**ข้อสอบปลายภาคปี 2560 และ 2559 ออกข้อนี้ตรง ๆ** เช่น
*"$f(x)=3x^2+4x+5$ จงหา $\lim\limits_{\Delta x\to 0}\frac{f(x+\Delta x)-f(x)}{\Delta x}$"*

```
ขั้นที่ 1  หา f(x+Δx)   ← แทน x ทุกตัวด้วย (x+Δx) แล้วกระจายให้หมด
ขั้นที่ 2  ลบ f(x) ออก  ← พจน์ที่ไม่มี Δx จะตัดกันหมด (ถ้าไม่ตัด = คำนวณผิด!)
ขั้นที่ 3  หารด้วย Δx   ← ดึง Δx เป็นตัวประกอบร่วมออกมา แล้วตัด
ขั้นที่ 4  ให้ Δx → 0   ← แทน Δx = 0 ในสิ่งที่เหลือ
```

**ตัวอย่างเต็ม:** $f(x)=3x^2+4x+5$

**ขั้นที่ 1**
$$f(x+\Delta x)=3(x+\Delta x)^2+4(x+\Delta x)+5$$
$$=3\big(x^2+2x\Delta x+(\Delta x)^2\big)+4x+4\Delta x+5$$
$$=3x^2+6x\Delta x+3(\Delta x)^2+4x+4\Delta x+5$$

**ขั้นที่ 2**
$$f(x+\Delta x)-f(x)=\big[3x^2+6x\Delta x+3(\Delta x)^2+4x+4\Delta x+5\big]-\big[3x^2+4x+5\big]$$
$$=6x\Delta x+3(\Delta x)^2+4\Delta x$$
> ✅ เช็ค: $3x^2$, $4x$, $5$ ตัดหมด — ถ้าเหลือ แสดงว่าขั้นที่ 1 ผิด

**ขั้นที่ 3**
$$\frac{f(x+\Delta x)-f(x)}{\Delta x}=\frac{\cancel{\Delta x}\,(6x+3\Delta x+4)}{\cancel{\Delta x}}=6x+3\Delta x+4$$

**ขั้นที่ 4**
$$f'(x)=\lim_{\Delta x\to 0}(6x+3\Delta x+4)=\boxed{6x+4}$$

> **ตรวจคำตอบด้วยกฎลัด:** $\frac{d}{dx}(3x^2+4x+5)=6x+4$ ✅ ตรงกัน
> (แต่ในกระดาษ **ต้องเขียนวิธีนิยาม** ถ้าโจทย์สั่งมาแบบนี้ — ใช้กฎลัดตอบเลย = 0 คะแนน)

## 3. สัญลักษณ์ (Notation) — เจอทั้ง 5 แบบในข้อสอบเดียวกันได้

$$f'(x) \qquad y' \qquad \frac{dy}{dx} \qquad \frac{d}{dx}\big[f(x)\big] \qquad D_x[y]$$

ทุกตัว **ความหมายเดียวกัน** — อ่านว่า "อนุพันธ์ของ $y$ เทียบกับ $x$"

## 4. Differentiability vs Continuity (ความสัมพันธ์ที่ต้องท่อง)

$$\text{หาอนุพันธ์ได้ (differentiable)} \;\Longrightarrow\; \text{ต่อเนื่อง (continuous)}$$

$$\text{ต่อเนื่อง} \;\;\not\Longrightarrow\;\; \text{หาอนุพันธ์ได้}$$

**ตัวอย่างค้าน:** $f(x)=|x|$ ที่ $x=0$
- ต่อเนื่อง ✅ (วาดได้ไม่ยกปากกา)
- แต่หาอนุพันธ์ไม่ได้ ❌ (ความชันซ้าย $=-1$, ความชันขวา $=+1$ ไม่เท่ากัน)

**3 กรณีที่หาอนุพันธ์ไม่ได้:**

| กรณี | ภาพ | ตัวอย่าง |
|:---|:---|:---|
| มุมแหลม (corner/cusp) | ∨ | $|x|$ ที่ $x=0$ |
| เส้นสัมผัสตั้งฉาก | │ | $\sqrt[3]{x}$ ที่ $x=0$ |
| ไม่ต่อเนื่อง | ○ หรือ กระโดด | ฟังก์ชันแยกกรณีที่รอยต่อไม่เชื่อม |

## 5. กฎอนุพันธ์พื้นฐาน (Basic Rules)

### 5.1 สี่กฎแรก — ท่องให้ขึ้นใจ

| ชื่อกฎ | สูตร | ตัวอย่าง |
|:---|:---|:---|
| **Constant Rule** | $\dfrac{d}{dx}[c]=0$ | $\frac{d}{dx}[\pi^5]=0$, $\frac{d}{dx}[5^3]=0$ |
| **Power Rule** | $\dfrac{d}{dx}[x^n]=n\,x^{\,n-1}$ | $\frac{d}{dx}[x^7]=7x^6$ |
| **Constant Multiple** | $\dfrac{d}{dx}[c\,f(x)]=c\,f'(x)$ | $\frac{d}{dx}[5x^3]=15x^2$ |
| **Sum / Difference** | $\dfrac{d}{dx}[f\pm g]=f'\pm g'$ | ทำทีละพจน์ได้เลย |

> ⚠️ **กับดักคลาสสิก:** $\pi^5$ และ $5^3$ เป็น **ค่าคงตัว** (ตัวเลขล้วน) → อนุพันธ์ $=0$
> คนพลาดเพราะเห็นเลขชี้กำลังแล้วนึกว่าต้องใช้ Power Rule
> **Power Rule ใช้ได้เฉพาะเมื่อ "ตัวแปรอยู่ที่ฐาน"** เท่านั้น

### 5.2 🔑 Pattern: จัดรูปก่อนดิฟ (สำคัญมาก!)

Power Rule ใช้กับ $x^n$ เท่านั้น → **ต้องแปลงรากและเศษส่วนให้เป็นเลขชี้กำลังก่อน**

| เห็นแบบนี้ | เขียนใหม่เป็น | แล้วค่อยดิฟ |
|:---|:---|:---|
| $\sqrt{x}$ | $x^{1/2}$ | $\frac{1}{2}x^{-1/2}=\dfrac{1}{2\sqrt{x}}$ |
| $\sqrt[3]{x^2}$ | $x^{2/3}$ | $\frac{2}{3}x^{-1/3}$ |
| $\dfrac{1}{x}$ | $x^{-1}$ | $-x^{-2}=-\dfrac{1}{x^2}$ |
| $\dfrac{4}{x^3}$ | $4x^{-3}$ | $-12x^{-4}=-\dfrac{12}{x^4}$ |
| $\dfrac{1}{2\sqrt{x}}$ | $\frac12 x^{-1/2}$ | $-\frac14 x^{-3/2}$ |

**ตัวอย่างจากข้อสอบเก่า (ปี 2561 ข้อ 4):**
$$y=\pi^5+5^3+2\sqrt{x}+\frac{1}{x}$$

จัดรูปก่อน: $y=\underbrace{\pi^5+5^3}_{\text{ค่าคงตัว}}+2x^{1/2}+x^{-1}$

$$y'=0+0+2\cdot\tfrac12 x^{-1/2}+(-1)x^{-2}=\frac{1}{\sqrt{x}}-\frac{1}{x^{2}}$$

### 5.3 อนุพันธ์ของฟังก์ชันตรีโกณ / ลอการิทึม / เอกซ์โพเนนเชียล

$$\frac{d}{dx}[\sin x]=\cos x \qquad\qquad \frac{d}{dx}[\cos x]=-\sin x$$

$$\frac{d}{dx}[\tan x]=\sec^2 x \qquad \frac{d}{dx}[\cot x]=-\csc^2 x$$

$$\frac{d}{dx}[\sec x]=\sec x\tan x \qquad \frac{d}{dx}[\csc x]=-\csc x\cot x$$

$$\frac{d}{dx}[e^x]=e^x \qquad\qquad \frac{d}{dx}[\ln x]=\frac{1}{x}$$

> **เคล็ดจำ:** ตัวที่ขึ้นต้นด้วย **"co-"** ($\cos,\cot,\csc$) → อนุพันธ์ติด **เครื่องหมายลบ** ทุกตัว

## 6. 🔑 Product Rule (กฎผลคูณ) — HW9 ข้อ 1

### สูตร
$$\boxed{\;\frac{d}{dx}\big[u\cdot v\big]=u'v+uv'\;}$$

### วิธีจำแบบไทย ๆ
> **"ดิฟหน้า × หลัง **+** หน้า × ดิฟหลัง"**

### ⚠️ ความเข้าใจผิดอันดับ 1 ของทั้งวิชา
$$\frac{d}{dx}[u\cdot v]\;\neq\;u'\cdot v'$$
**อนุพันธ์ของผลคูณ ไม่เท่ากับ ผลคูณของอนุพันธ์** — พิสูจน์ง่าย ๆ:
$\frac{d}{dx}[x\cdot x]=\frac{d}{dx}[x^2]=2x$ แต่ $\frac{d}{dx}[x]\cdot\frac{d}{dx}[x]=1\cdot1=1$ ❌

### เทมเพลตการเขียน (เขียนแบบนี้ TA อ่านง่ายและไม่พลาด)
```
ให้ u = ...          u' = ...
    v = ...          v' = ...

y' = u'v + uv'
   = (...)(...)  +  (...)(...)
   = ... กระจาย ...
   = ... รวมพจน์คล้าย ...
```

### ตัวอย่างเต็ม (HW9 ข้อ 1)
$$g(x)=(x^3+7x)(x+3)$$

$$u=x^3+7x \;\Rightarrow\; u'=3x^2+7$$
$$v=x+3 \;\Rightarrow\; v'=1$$

$$g'(x)=u'v+uv'=(3x^2+7)(x+3)+(x^3+7x)(1)$$
$$=3x^3+9x^2+7x+21+x^3+7x$$
$$=\boxed{4x^3+9x^2+14x+21}$$

> **✅ วิธีตรวจ:** กระจาย $g(x)=x^4+3x^3+7x^2+21x$ แล้วดิฟตรง ๆ
> $g'=4x^3+9x^2+14x+21$ ✅ ตรงกัน
> **ใช้ตรวจได้ แต่ถ้าโจทย์สั่ง "ใช้ Product Rule" ต้องแสดง Product Rule ในกระดาษ**

## 7. 🔑 Quotient Rule (กฎผลหาร) — HW9 ข้อ 2, 3

### สูตร
$$\boxed{\;\frac{d}{dx}\left[\frac{u}{v}\right]=\frac{u'v-uv'}{v^{2}}\;}$$

### วิธีจำ (เพลงคลาสสิก)
> **"ล่างดิฟบน ลบ บนดิฟล่าง ส่วนล่างกำลังสอง"**
> หรือแบบอังกฤษ: *"Low d-High minus High d-Low, over Low-squared"*

### ⚠️ **ลำดับสำคัญมาก — เครื่องหมายลบไม่สลับที่ได้**
ต่างจาก Product Rule ที่เป็นบวก (สลับได้) — Quotient Rule เป็น **ลบ**
สลับเป็น $uv'-u'v$ = คำตอบผิดเครื่องหมาย = **0 คะแนน**

### ตัวอย่างเต็ม 1 (HW9 ข้อ 2)
$$f(x)=\frac{6x-5}{x^2+1}$$

$$u=6x-5 \Rightarrow u'=6 \qquad v=x^2+1 \Rightarrow v'=2x$$

$$f'(x)=\frac{(6)(x^2+1)-(6x-5)(2x)}{(x^2+1)^2}$$
$$=\frac{6x^2+6-(12x^2-10x)}{(x^2+1)^2}$$
$$=\frac{6x^2+6-12x^2+10x}{(x^2+1)^2}$$
$$=\boxed{\frac{-6x^2+10x+6}{(x^2+1)^2}}$$

> ⚠️ **จุดตาย:** บรรทัดที่ 2 → 3 ต้อง **กระจายเครื่องหมายลบเข้าไปทุกพจน์**
> $-(12x^2-10x)=-12x^2\mathbf{+}10x$ — คนพลาดตรง $+10x$ กลายเป็น $-10x$ เยอะที่สุด
> **เทคนิคกันพลาด: ใส่วงเล็บให้ครบก่อนกระจายเสมอ**

### ตัวอย่างเต็ม 2 (HW9 ข้อ 3)
$$y=\frac{\sin x}{x^{4}}$$

$$u=\sin x \Rightarrow u'=\cos x \qquad v=x^4 \Rightarrow v'=4x^3$$

$$y'=\frac{(\cos x)(x^4)-(\sin x)(4x^3)}{(x^4)^2}=\frac{x^4\cos x-4x^3\sin x}{x^{8}}$$

ดึง $x^3$ ร่วมจากเศษ แล้วตัดกับส่วน:
$$=\frac{\cancel{x^{3}}\big(x\cos x-4\sin x\big)}{x^{8}}=\boxed{\frac{x\cos x-4\sin x}{x^{5}}}$$

> 💡 **ทำให้ง่ายเสมอ** — TA มองว่า $\frac{x^4\cos x-4x^3\sin x}{x^8}$ "ยังไม่จบ"
> การจัดรูปให้เรียบง่ายที่สุดคือส่วนหนึ่งของ "วิธีทำที่สมบูรณ์"

### 💡 ทางเลี่ยง Quotient Rule
บางข้อ **แปลงเป็นผลคูณแล้วง่ายกว่ามาก**:
$$y=\frac{6x-5}{x^{2}} \;\Rightarrow\; y=6x^{-1}-5x^{-2} \;\Rightarrow\; y'=-6x^{-2}+10x^{-3}$$
**ใช้ได้เมื่อตัวส่วนเป็น $x$ ยกกำลังเดี่ยว ๆ** (ถ้าตัวส่วนเป็นพหุนาม เช่น $x^2+1$ ทำแบบนี้ไม่ได้)

## 8. อัตราการเปลี่ยนแปลง & การเคลื่อนที่ (Rates of Change)

### 8.1 ความหมายทางกายภาพ

| ปริมาณ | สัญลักษณ์ | ได้จาก |
|:---|:---|:---|
| ตำแหน่ง | $s(t)$ | โจทย์ให้มา |
| **ความเร็ว** (velocity) | $v(t)=s'(t)$ | ดิฟตำแหน่ง 1 ครั้ง |
| **ความเร่ง** (acceleration) | $a(t)=v'(t)=s''(t)$ | ดิฟตำแหน่ง 2 ครั้ง |
| อัตราเร็ว (speed) | $|v(t)|$ | ค่าสัมบูรณ์ของความเร็ว |

**ความหมายของเครื่องหมาย:** $v>0$ = เคลื่อนที่ไปทางบวก/ขึ้น, $v<0$ = ไปทางลบ/ลง, $v=0$ = หยุดชั่วขณะ (จุดสูงสุด)

### 8.2 สูตรวัตถุตกอิสระ (ที่ใช้ในสไลด์)
$$s(t)=-\tfrac{1}{2}gt^{2}+v_0 t+s_0$$
โดย $g=9.8\ \text{m/s}^2$ (หรือ $32\ \text{ft/s}^2$), $v_0$ = ความเร็วต้น, $s_0$ = ความสูงเริ่มต้น

### 8.3 สมการเส้นสัมผัส (Tangent Line) — ออกสอบบ่อย

หาเส้นสัมผัสของ $y=f(x)$ ที่จุด $x=a$:
```
1) หา f(a)          ← พิกัด y ของจุดสัมผัส
2) หา f'(x)         ← สูตรความชัน
3) หา m = f'(a)     ← ความชัน ณ จุดนั้น
4) แทนในสมการ:  y − f(a) = m(x − a)
```
**เส้นตั้งฉาก (normal line)** ที่จุดเดียวกันมีความชัน $=-\dfrac{1}{m}$

$$f'(x)=\lim_{\Delta x\to 0}\frac{f(x+\Delta x)-f(x)}{\Delta x}$$

| | สูตร |
|:---|:---|

| Trig | $(\sin x)'=\cos x$, $(\cos x)'=-\sin x$, $(\tan x)'=\sec^2x$ |
| | $(\sec x)'=\sec x\tan x$, $(\csc x)'=-\csc x\cot x$, $(\cot x)'=-\csc^2 x$ |
| Exp/Log | $(e^{x})'=e^{x}$, $(\ln x)'=\frac 1x$ |

## 10. 🚨 Pitfall Alerts — จุดที่ นศ. มักโดนตัดเป็น 0 คะแนน

### ❌ Pitfall 1: $\frac{d}{dx}[uv]=u'v'$
ผิดที่สุดและเจอบ่อยที่สุด **ต้องเป็น $u'v+uv'$**

### ❌ Pitfall 2: Quotient Rule สลับลำดับเศษ
$\dfrac{uv'-u'v}{v^2}$ ← **ผิด** ต้องเป็น $\dfrac{u'v-uv'}{v^2}$ (ดิฟบนมาก่อนเสมอ)

### ❌ Pitfall 3: ลืมกระจายลบใน Quotient Rule
$-(12x^2-10x) \Rightarrow -12x^2+10x$ ไม่ใช่ $-12x^2-10x$
**ตัวป้องกัน:** เขียนวงเล็บครบทุกก้อนก่อน แล้วค่อยกระจายในบรรทัดถัดไป

### ❌ Pitfall 4: ดิฟค่าคงตัวที่หน้าตาเหมือนตัวแปร
$\frac{d}{dx}[\pi^5]=0$, $\frac{d}{dx}[5^3]=0$, $\frac{d}{dx}[e^2]=0$
แต่ $\frac{d}{dx}[e^x]=e^x$ (ตรงนี้ตัวแปรอยู่ที่ **เลขชี้กำลัง** ไม่ใช่ฐาน)

### ❌ Pitfall 5: ไม่จัดรูปรากก่อนดิฟ
เห็น $\sqrt[3]{x^2}$ แล้วเดาสูตร → **ต้องเขียนเป็น $x^{2/3}$ ก่อน** ทุกครั้ง

### ❌ Pitfall 6: ตอบไม่จัดรูปให้ง่ายที่สุด
$\frac{x^4\cos x-4x^3\sin x}{x^8}$ ต้องลดเหลือ $\frac{x\cos x-4\sin x}{x^5}$

### ❌ Pitfall 7: โจทย์สั่ง "ใช้นิยามลิมิต" แต่ตอบด้วยกฎลัด
**อ่านคำสั่งโจทย์ให้ครบ** — คำว่า *"โดยใช้นิยาม"* / *"จงหา $\lim_{\Delta x\to0}\frac{f(x+\Delta x)-f(x)}{\Delta x}$"*
= บังคับให้ทำ 4 ขั้นตอน ใช้ Power Rule ตอบทันที = **0 คะแนน**

### ❌ Pitfall 8: เขียนแค่คำตอบสุดท้าย ไม่ประกาศ $u,v,u',v'$
กติกา all-or-nothing บวก "ต้องแสดงวิธีทำทีละขั้นตอน"
**ประกาศ $u,v,u',v'$ ก่อนเสมอ** = ประกันคะแนนที่ถูกที่สุด
