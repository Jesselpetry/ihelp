## สรุปอ่านสอบ

### 1. Class of Computer

⭐⭐ สไลด์จัดกลุ่มตาม purpose โดยดูจาก**ขนาด** ได้ 4 กลุ่ม

| กลุ่ม | จุดจำ |
|---|---|
| **Microcomputer** (PC) | ใช้ microprocessor เป็น CPU · ใช้ทีละคน |
| **Minicomputer** (mid-range) | multiprocessing · รองรับได้ถึง **200 คน**พร้อมกัน · มี centralized storage |
| **Mainframe** | ผู้ใช้หลักร้อยถึงหลักพัน · ความจุสูงมาก · ใช้ในธนาคาร โทรคมนาคม · ตัวอย่าง IBM z15 |
| **Supercomputer** | เร็ว แรง และแพงที่สุด · ล้านล้านคำสั่งต่อวินาที · พยากรณ์อากาศ จำลองทางวิทยาศาสตร์ |

- Microcomputer แบ่งย่อยเป็น personal computer (desktop, laptop, tablet) · mobile device · game console · **embedded computer** (ฝังอยู่ในผลิตภัณฑ์ที่ใหญ่กว่า)
- **Phablet** = phone + tablet · จอ 5–7 นิ้ว
- **Technological convergence** = เทคโนโลยีที่เคยแยกกันรวมเป็นอุปกรณ์เดียว เช่น มือถือที่เป็นทั้งกล้องและเครื่องเล่นเพลง
- ตัวอย่าง supercomputer ในสไลด์: **Fugaku** — 7,630,848 cores · 442 Pflop/s · อันดับ 1 ของโลก มิ.ย. 2021

### 2. Moore's Law

⭐⭐ ออกสอบบ่อย — จำปีให้แม่น

| ปี | เหตุการณ์ |
|---|---|
| 1965 | Gordon Moore (ผู้ร่วมก่อตั้ง Intel) — จำนวน components บน IC เพิ่ม 2 เท่า **ทุก 1 ปี** |
| 1975 | ปรับเป็น 2 เท่า **ทุก 2 ปี** |
| 2015 | Intel บอกว่าจังหวะจริงใกล้ **2.5 ปี** — การพัฒนา MOSFET ชะลอตั้งแต่ปี 2010 |

### 3. Server และ Client

- **Server** มี 3 แบบ: tower · rack · blade

| | Rack server | Blade server |
|---|---|---|
| ข้อดี | จัดสายง่าย · เปลี่ยนเครื่องที่เสียง่าย · ราคาต่อพลังประมวลผลต่ำ | กินพื้นที่น้อย · จัดการรวมศูนย์ · ใช้สายน้อย |
| ข้อเสีย | กินไฟ ต้องมีระบบระบายความร้อน · กินพื้นที่ · บำรุงรักษานาน | ระบายความร้อนยาก · แพงกว่า · **ไฟดับ = ดับทั้งชุด** |

- **Terminal** พลังประมวลผลจำกัด รับ/ส่งข้อมูลกับ host · **thin client** หน้าตาเหมือน desktop แต่สเปกจำกัด
- **POS terminal** บันทึกการขาย · **ATM** คือ terminal บริการตนเองด้านธนาคาร

### 4. Cloud, Port และการเชื่อมต่อ

- **Cloud computing** = ทรัพยากรและบริการที่เข้าถึงผ่านอินเทอร์เน็ต
- **Port** = จุดต่ออุปกรณ์ต่อพ่วง · **connector** = หัวสายที่เสียบเข้าพอร์ต
- **USB** หนึ่งพอร์ตต่ออุปกรณ์ได้ถึง **127 ชิ้น** · port replicator / docking station ช่วยต่อหลายอุปกรณ์ทีเดียว
- ไร้สาย: Wi-Fi · Bluetooth · **NFC**
- ภาพในคอมพิวเตอร์ประกอบด้วย **pixel** ใช้ระบบสี **RGB**

### 5. Protecting Hardware

| ภัย | วิธีป้องกัน |
|---|---|
| ขโมย | ควบคุมการเข้าถึง · สัญญาณกันขโมย · อุปกรณ์ล็อก · แอปติดตามเครื่อง |
| ไฟฟ้า | **surge protector** กันไฟกระชาก · **UPS** จ่ายไฟต่อเมื่อไฟดับ |

## จุดที่มักพลาด

- Moore's Law ปี **1965 = ทุก 1 ปี** ไม่ใช่ทุก 2 ปี — 2 ปีคือฉบับแก้ปี 1975
- ข้อเสียของ **blade** คือไฟดับแล้วดับทั้งหมด ไม่ใช่ของ rack
- Minicomputer รองรับ **200 คน** · mainframe หลักร้อยถึงหลักพัน — อย่าสลับ
- Embedded computer เป็นหนึ่งในกลุ่ม microcomputer ตามสไลด์

---

## ทดสอบตัวเอง

1. ในปี 1975 Moore ปรับคำทำนายเป็นเท่าไร
2. เซิร์ฟเวอร์ชนิดใดกินพื้นที่น้อยที่สุดแต่ระบายความร้อนยากที่สุด
3. อุปกรณ์ใดจ่ายไฟต่อให้คอมพิวเตอร์เมื่อไฟดับ
4. พอร์ต USB หนึ่งพอร์ตต่ออุปกรณ์ได้สูงสุดกี่ชิ้น
5. คอมพิวเตอร์ในเครื่องซักผ้าจัดเป็นประเภทใด

## แล็บ — Ubuntu บน VMware และคำสั่ง Linux

> ย่อจากใบงานจริง ขั้นตอนเต็มให้ยึดไฟล์ PDF

**เตรียมเครื่อง** — สร้าง VM ใน VMware Workstation แบบ Typical เลือก Linux / Ubuntu 64-bit ·
ดิสก์มากกว่า 25 GB · RAM อย่างน้อย 4 GB · ใส่ไฟล์ ISO · ตั้ง firmware เป็น **UEFI**

**ข้อควรรู้** — `sudo` คือสั่งในฐานะ root · ตอนพิมพ์รหัสผ่านจะไม่แสดงตัวอักษร · `|` (pipe) ส่งผลลัพธ์ต่อให้คำสั่งถัดไป

**คำสั่งที่ใช้** — `ls` · `cd` · `pwd` · `mkdir` · `rmdir` · `touch` · `cat` · `nano` · `cp` · `mv` · `grep` · `man` · `uname -a` · `zip` ·
`sudo apt update` · `sudo apt upgrade -y` · `sudo apt install`

**งานที่ต้องให้ TA ตรวจ**
1. ติดตั้ง Linux ให้ใช้งานได้
2. สร้างและย้ายไปยังโฟลเดอร์ตามที่ระบุ
3. สร้างไฟล์ด้วย `touch` · แก้ไขด้วย `nano` · แสดงด้วย `cat`
4. ใช้ pipe ร่วมกับ `grep` หาไดเรกทอรีที่เป็นเจ้าของได้
5. ลบโฟลเดอร์ที่ระบุ
6. อัปเดตระบบ แล้วติดตั้งและเรียก `fastfetch` (หรือ `neofetch`)
