## สรุปอ่านสอบ

### 1. ระดับของ Storage

⭐⭐ ตารางนี้ออกสอบบ่อย

| ระดับ | ลักษณะ | ตัวอย่าง |
|---|---|---|
| **Primary** | เรียกว่า memory · volatile หรือ non-volatile ก็ได้ | RAM · ROM |
| **Secondary** | เก็บถาวร · non-volatile | HDD · SSD |
| **Offline** | ถอดได้ ต้องมีคนเสียบก่อนเครื่องจะเข้าถึง | CD · DVD · USB flash drive |
| **Tertiary** | เข้าถึงผ่านเครือข่าย · ช้าที่สุด · หุ่นยนต์สลับสื่อเองโดยไม่ต้องมีคน | NAS · SAN · tape |

- **Storage medium** = วัสดุที่เก็บข้อมูล · **storage device** = ตัวอ่าน/เขียน
- **Read** = storage → memory (เทียบ input) · **write** = memory → storage (เทียบ output)
- สไลด์ย้ำ **"It is NOT I/O device"** — storage device ไม่นับเป็นอุปกรณ์ I/O

### 2. ความจุและความเร็ว

⭐⭐⭐ ตารางความจุต้องท่องได้ทั้งตาราง

| หน่วย | ประมาณ | แน่นอน |
|---|---|---|
| KB | 10³ | 2¹⁰ = 1,024 |
| MB | 10⁶ | 2²⁰ = 1,048,576 |
| GB | 10⁹ | 2³⁰ |
| TB · PB · EB · ZB · YB | 10¹² · 10¹⁵ · 10¹⁸ · 10²¹ · 10²⁴ | 2⁴⁰ · 2⁵⁰ · 2⁶⁰ · 2⁷⁰ · 2⁸⁰ |

- เลขชี้กำลังฐาน 10 เพิ่มทีละ 3 · ฐาน 2 เพิ่มทีละ 10
- **Access time** = เวลาหาตำแหน่งบนสื่อ + เวลาส่งจาก memory ไป processor · บางผู้ผลิตบอกเป็น transfer rate แทน
- เร็ว → ช้า: **RAM > SSD > hard disk > USB flash drive > memory card > optical disc**

### 3. Hard Disk และ SSD

- **HDD** = platter แข็งเก็บข้อมูลด้วยอนุภาคแม่เหล็ก · ความจุขึ้นกับจำนวน platter · แบบบันทึก (**longitudinal** ขนานผิว / **perpendicular** ตั้งฉาก จุกว่า) · density
- 3.5 นิ้วสำหรับ desktop · 2.5 นิ้วสำหรับ laptop · **5,400–7,200 RPM**
- **Formatting** = แบ่งดิสก์เป็น track และ sector · **head crash** = หัวอ่านแตะผิวจาน (ผม ฝุ่น ควัน ใหญ่กว่าช่องว่าง) · **disk cache** ยิ่งใหญ่ยิ่งเร็ว
- **SSD** = flash memory มีโปรเซสเซอร์ของตัวเอง · ข้อดี 9 ข้อ: เข้าถึงเร็ว · ถ่ายโอนเร็ว · เงียบ · ทน · เบา · กินไฟน้อย · ร้อนน้อย · อายุยาว · **ไม่ต้อง defragment**

### 4. RAID และ Enterprise Storage

- **RAID** = ดิสก์ 2 ตัวขึ้นไปรวมกัน เพื่อ redundancy, performance หรือทั้งสองอย่าง

| เทคนิค | หลักการ | เน้น |
|---|---|---|
| **Mirroring** | สำเนาเหมือนกันลงอีกดิสก์ | ความทนทาน |
| **Striping** | กระจายข้อมูลลงหลายดิสก์ | ความเร็ว |

| | NAS | SAN |
|---|---|---|
| คืออะไร | **เซิร์ฟเวอร์** | **เครือข่ายความเร็วสูง** |
| ให้พื้นที่กับ | ผู้ใช้และอุปกรณ์บนเครือข่าย | **เซิร์ฟเวอร์อื่น** |

- Enterprise storage ออกแบบเพื่อใช้งานหนัก ประสิทธิภาพสูงสุด และพร้อมใช้สูงสุด · tape เก็บข้อมูลปริมาณมาก

### 5. สื่อแบบถอดได้

| SD card | ความจุสูงสุด |
|---|---|
| SD | 2 GB |
| SDHC | 32 GB |
| SDXC | 2 TB |
| SDUC | 128 TB |

- **Optical disc** อ่านด้วยเลเซอร์ · **pit = 0 · land = 1** · เก็บใน track เดียวเป็นเกลียวจากศูนย์กลางออกขอบ

| รูปแบบ | เขียนได้ |
|---|---|
| CD-ROM · DVD-ROM | อ่านอย่างเดียว |
| CD-R · DVD±R | ครั้งเดียว (WORM) |
| CD-RW · DVD±RW · DVD+RAM | หลายครั้ง |

- อื่น ๆ: magnetic stripe card · smart card · RFID tag · **NFC tag** (ชิป + เสาอากาศ ส่วนใหญ่มีกาวในตัว) · microfilm / microfiche

---

## จุดที่มักพลาด

- **NAS = server · SAN = network** — ตัวลวงยอดนิยม
- **Pit = 0 · land = 1** ไม่ใช่กลับกัน
- Storage device **ไม่ใช่** I/O device แม้ read จะเทียบเท่า input
- SDHC สูงสุด **32 GB** · SDXC **2 TB** — ตัวเลขใกล้กันให้จำแยก
- CD-R เขียนได้ครั้งเดียวแต่**ลบไม่ได้** · RW คือเขียนซ้ำได้

---

## ทดสอบตัวเอง

1. 1 GB เท่ากับกี่ไบต์ถ้านับแบบ 2ⁿ
2. RAID เทคนิคใดเน้นความเร็ว
3. อุปกรณ์ใดให้พื้นที่จัดเก็บกับเซิร์ฟเวอร์อื่นผ่านเครือข่ายความเร็วสูง
4. บนแผ่น optical disc ผิวราบ (land) อ่านได้เป็นเลขอะไร
5. SSD ต่างจาก HDD เรื่อง defragment อย่างไร

**เฉลย** — 1. 2³⁰ = 1,073,741,824 ไบต์ · 2. striping · 3. SAN · 4. 1 · 5. SSD ไม่ต้อง defragment
