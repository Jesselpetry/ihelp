## 3. สรุปเนื้อหารายหัวข้อ — ส่วนที่ 1 (เชิงคำนวณ)

### เศรษฐศาสตร์และระบบเศรษฐกิจ

- **GDP (Gross Domestic Product)** ⭐ — มูลค่ารวมของสินค้าและบริการขั้นสุดท้ายที่ผลิตในประเทศ
  - **Nominal GDP** (ราคาปีปัจจุบัน) vs **Real GDP** (ปรับด้วยเงินเฟ้อ)
  - **GDP growth** = `(GDPₜ − GDPₜ₋₁) / GDPₜ₋₁ × 100`
- **หนี้สาธารณะ (Public Debt)** และอัตราส่วน **Public Debt / GDP** ⭐
- **ระบบเศรษฐกิจ** — ทุนนิยม (capitalism) · สังคมนิยม · คอมมิวนิสต์ · **ระบบผสม (mixed)**
- **อุปสงค์และอุปทาน** — เส้น demand ลาดลง, เส้น supply ลาดขึ้น, จุดดุลยภาพ
- **วัฏจักรธุรกิจ (Business Cycle)** ⭐ — รุ่งเรือง (prosperity) → ถดถอย (recession) →
  ตกต่ำ (depression) → ฟื้นตัว (recovery)
- **รูปแบบการแข่งขัน** ⭐⭐ — แข่งขันสมบูรณ์ · กึ่งแข่งขันกึ่งผูกขาด · ผู้ขายน้อยราย (oligopoly) · ผูกขาด (monopoly)

### มูลค่าเงินตามเวลา (Time Value of Money) ⭐⭐⭐

| แนวคิด | สูตร |
|---|---|
| ดอกเบี้ยเงินต้นคงที่ (simple) | `I = P · r · n` |
| **มูลค่าอนาคต (ทบต้น)** | `FV = PV(1 + r)ⁿ` |
| **มูลค่าปัจจุบัน** | `PV = FV / (1 + r)ⁿ` |
| ทบต้น m ครั้งต่อปี | `FV = PV(1 + r/m)^(m·n)` |
| **อัตราดอกเบี้ยที่แท้จริง (Effective rate)** ⭐ | `EAR = (1 + r/m)^m − 1` |
| มูลค่าอนาคตของเงินรายงวด (annuity) | `FV = PMT · [((1+r)ⁿ − 1) / r]` |
| มูลค่าปัจจุบันของเงินรายงวด | `PV = PMT · [(1 − (1+r)⁻ⁿ) / r]` |
| **NPV** | `NPV = Σ CFₜ/(1+r)ᵗ − เงินลงทุนเริ่มต้น` |

- **ตัวอย่างจากสไลด์:** ดอกเบี้ยนาม 6% ทบต้นปีละ 2 ครั้ง → `EAR = (1 + 0.06/2)² − 1 = 6.09%`
- **Flat rate vs Effective rate** ⭐ — สินเชื่อรถ/ผ่อนสินค้ามักโฆษณา flat rate
  ซึ่งต่ำกว่าอัตราที่แท้จริงเกือบเท่าตัว (โจทย์ที่ออกสอบบ่อย)
- ในคลังมี **ตารางมูลค่าอนาคต** `BFIT_Ref_FutureValueTables.pdf` ให้ใช้เปิดในห้องสอบ

### งบการเงิน (Financial Statements) ⭐⭐

**งบดุล (Balance Sheet)** — ภาพนิ่ง ณ วันใดวันหนึ่ง

```
สินทรัพย์ (Assets) = หนี้สิน (Liabilities) + ส่วนของเจ้าของ (Owner's Equity)
```

| หมวด | รายการ |
|---|---|
| สินทรัพย์หมุนเวียน | เงินสด · ลูกหนี้การค้า · สินค้าคงเหลือ |
| สินทรัพย์ไม่หมุนเวียน | ที่ดิน อาคาร อุปกรณ์ (หัก **ค่าเสื่อมราคาสะสม**) |
| หนี้สินหมุนเวียน | เจ้าหนี้การค้า · เงินกู้ระยะสั้น |
| หนี้สินไม่หมุนเวียน | เงินกู้ระยะยาว · หุ้นกู้ |
| ส่วนของเจ้าของ | ทุนจดทะเบียน · **กำไรสะสม** |

**งบกำไรขาดทุน (Income Statement)** — ผลการดำเนินงานในช่วงเวลาหนึ่ง

```
รายได้จากการขาย
− ต้นทุนขาย (COGS)          = กำไรขั้นต้น (Gross Profit)
− ค่าใช้จ่ายในการดำเนินงาน   = กำไรจากการดำเนินงาน (EBIT)
− ดอกเบี้ยจ่าย               = กำไรก่อนภาษี (EBT)
− ภาษี                       = กำไรสุทธิ (Net Profit)
```

- **Common-size statement** ⭐ — แปลงทุกรายการเป็น % ของยอดขาย (หรือของสินทรัพย์รวม) เพื่อเทียบข้ามบริษัท/ข้ามปี
- **ค่าเสื่อมราคา (Depreciation)** ⭐⭐
  - วิธีเส้นตรง: `ค่าเสื่อมต่อปี = (ราคาทุน − มูลค่าซาก) / อายุการใช้งาน`
  - เป็นค่าใช้จ่ายที่ไม่ใช่เงินสด (non-cash expense)

### สินค้าคงคลัง (Inventory) และ EOQ ⭐⭐

- ต้นทุนที่เกี่ยวข้อง: **ต้นทุนการสั่งซื้อ (ordering cost)** vs **ต้นทุนการเก็บรักษา (holding/carrying cost)**
- กราฟระดับสินค้าคงคลังแบบฟันเลื่อย (sawtooth)
- **Economic Order Quantity**

  ```
  EOQ = √(2DS / H)
  ```

  โดย `D` = ความต้องการต่อปี · `S` = ต้นทุนต่อการสั่งซื้อหนึ่งครั้ง · `H` = ต้นทุนเก็บรักษาต่อหน่วยต่อปี
- จำนวนครั้งที่สั่งต่อปี = `D / EOQ` · ต้นทุนรวม = `(D/Q)S + (Q/2)H`
- โจทย์ที่พบ: มีส่วนลดตามปริมาณ (quantity discount) → ต้องเทียบต้นทุนรวมทุกระดับราคา

### การตลาด (Marketing) ⭐⭐

**STP**
- **Segmentation** — แบ่งตลาดตามภูมิศาสตร์ · ประชากรศาสตร์ · จิตวิทยา · พฤติกรรม
- **Targeting** — เลือกกลุ่มเป้าหมายจากความน่าสนใจของแต่ละส่วน
- **Positioning** — วางตำแหน่งสินค้าในใจผู้บริโภค

**4P (Marketing Mix)**

| P | เนื้อหาในสไลด์ |
|---|---|
| **Product** | ประเภทสินค้า — **convenience** · shopping · specialty · unsought<br>การตัดสินใจเรื่องแบรนด์: multibrand, brand extension, **brand repositioning**<br>สายผลิตภัณฑ์ (product line) และการเพิ่มความยาวของสาย<br>**วงจรชีวิตผลิตภัณฑ์** — introduction → growth → maturity → decline |
| **Price** | **Cost-based pricing** · value-based · **competition-based pricing**<br>**New-product pricing** — market skimming vs market penetration<br>**Price adjustment strategy** — discount, allowance, **segmented pricing**, psychological, promotional, **geographic pricing (FOB)** |
| **Place** | ช่องทางจัดจำหน่าย, ผลของทำเลต่อยอดขาย |
| **Promotion** | โฆษณา · ส่งเสริมการขาย · ขายโดยพนักงาน · **PR (Public Relations)** · point of purchase |

## 4. สรุปเนื้อหารายหัวข้อ — ส่วนที่ 2 (เชิงทฤษฎี)

### บทที่ 1 — ธุรกิจในโลกของการเปลี่ยนแปลง

- **นิยามธุรกิจ** — กิจกรรมที่ผลิตหรือให้บริการเพื่อสนอง **need/want** โดยมุ่ง **กำไร**
- เป้าหมายของธุรกิจและ **ความเสี่ยงที่ธุรกิจต้องเผชิญ**
- ธุรกิจในโลกไร้พรมแดน — รูปแบบการค้าระหว่างประเทศ (ส่งออก/นำเข้า, licensing, franchising, joint venture, FDI),
  อุปสรรค (ภาษี โควตา วัฒนธรรม), แหล่งเงินทุนระหว่างประเทศ
- **รูปแบบการดำเนินธุรกิจ** ⭐⭐⭐

| รูปแบบ | ความรับผิด | ภาษี | ข้อดี | ข้อจำกัด |
|---|---|---|---|---|
| **กิจการเจ้าของคนเดียว** | ไม่จำกัด | บุคคลธรรมดา | ตั้งง่าย ตัดสินใจเร็ว กำไรเป็นของตนทั้งหมด | เงินทุนจำกัด รับผิดไม่จำกัด อายุจำกัด |
| **ห้างหุ้นส่วนสามัญ** | หุ้นส่วนทุกคนไม่จำกัด | — | ระดมทุนได้มากขึ้น | ขัดแย้งกันได้ รับผิดไม่จำกัด |
| **ห้างหุ้นส่วนสามัญนิติบุคคล** | ไม่จำกัด (แต่เป็นนิติบุคคล) | นิติบุคคล | มีสภาพนิติบุคคล | ต้องจดทะเบียน |
| **ห้างหุ้นส่วนจำกัด** | มีทั้งจำกัดและไม่จำกัด | นิติบุคคล | หุ้นส่วนจำพวกจำกัดเสี่ยงเท่าเงินลงทุน | หุ้นส่วนจำกัดบริหารไม่ได้ |
| **บริษัทจำกัด** | จำกัดเท่าค่าหุ้น | นิติบุคคล | ระดมทุนง่าย อายุไม่จำกัด | ตั้งยุ่งยาก เสียภาษีซ้อน |
| **บริษัทมหาชนจำกัด** | จำกัด | นิติบุคคล | ระดมทุนจากมหาชน/ตลาดหลักทรัพย์ | เปิดเผยข้อมูลมาก ถูกกำกับเข้มงวด |

- **การเติบโตของบริษัท** — การควบรวมกิจการ (merger & acquisition) แนวนอน/แนวตั้ง/แบบผสม
- **การเริ่มต้นธุรกิจ** — SME, คุณลักษณะผู้ประกอบการ, สาเหตุที่ธุรกิจขนาดย่อมล้มเหลว,
  แหล่งเงินทุน, **องค์ประกอบของแผนธุรกิจ**
- **แฟรนไชส์** — รูปแบบ ข้อดี (แบรนด์เป็นที่รู้จัก อัตราสำเร็จสูงกว่า) ข้อจำกัด (ค่าธรรมเนียม ข้อจำกัดในการบริหาร)
- **สตาร์ทอัพ** — แหล่งเงินทุน (angel, VC), การเริ่มธุรกิจ

### บทที่ 2 — พื้นฐานการจัดการ

- **นิยาม** — กระบวนการใช้ทรัพยากรที่มีอยู่ให้เกิดความสำเร็จสูงสุด
- **ประสิทธิภาพ (efficiency) vs ประสิทธิผล (effectiveness)** ⭐ — ทำถูกวิธี vs ทำให้บรรลุเป้าหมาย
- **ทรัพยากรการจัดการ 4M** — Man · Money · Material · Machine (บางตำราเพิ่ม Management, Market)
- **ระดับของการจัดการ** ⭐ — ระดับสูง (strategic) · ระดับกลาง (tactical) · ระดับต้น (operational)
- **ฟังก์ชันการจัดการ 4 อย่าง** ⭐⭐⭐
  1. **การวางแผน (Planning)** — วิสัยทัศน์ พันธกิจ เป้าหมาย; แผนกลยุทธ์ / ยุทธวิธี / ปฏิบัติการ
  2. **การจัดองค์กร (Organizing)**
  3. **การนำ (Leading)** — กระบวนการสร้างอิทธิพลต่อพฤติกรรมพนักงาน
  4. **การควบคุม (Controlling)**

### บทที่ 3 — การจัดองค์กร

- **แผนภูมิองค์กร (Organization Chart)** และลำดับชั้นการสั่งการ (chain of command)
- **ช่วงการควบคุม (Span of control)** ⭐ — องค์กรแบบ **แบน (flat)** vs **สูง (tall)**
- **การจัดแบ่งแผนก (Departmentalization)** ⭐⭐ — ตามฟังก์ชัน · ตามผลิตภัณฑ์ · ตามสถานที่ตั้ง · ตามลูกค้า · แบบผสม
- **การกระจายอำนาจ** ⭐ — **centralized** (อำนาจอยู่ส่วนกลาง) vs **decentralized** (กระจายลงล่าง)
- **การลดขนาดองค์กร (Downsizing)** และผลกระทบ
- **โครงสร้างที่เพิ่มความยืดหยุ่น** — **องค์กรแบบเมทริกซ์** (พนักงานมีหัวหน้าสองสาย),
  องค์กรเสมือน (virtual organization), **ผู้ประกอบการภายใน (intrapreneur)**, องค์กรแบบไม่เป็นทางการ
- **โครงสร้างบริษัท** — **บอร์ดอำนวยการ**, **ผลประโยชน์ทับซ้อน (conflict of interest)**,
  ผู้ตรวจสอบภายใน, **กระบวนการควบคุมภายใน (internal control)**
- เทคโนโลยีสารสนเทศทำให้องค์กรแบนลงและกระจายอำนาจได้มากขึ้น

### บทที่ 4 — การจัดการทรัพยากรมนุษย์

**ทฤษฎีแรงจูงใจ** ⭐⭐⭐

| ทฤษฎี | สาระสำคัญ |
|---|---|
| **Taylor** (Scientific Management) | คนทำงานเพื่อเงิน — ออกแบบงานให้มีประสิทธิภาพและจ่ายตามผลงาน |
| **Hawthorne** | ความสนใจจากฝ่ายบริหารและปัจจัยทางสังคมมีผลต่อผลิตภาพมากกว่าสภาพแวดล้อมกายภาพ |
| **Maslow** | ลำดับขั้นความต้องการ 5 ขั้น — กายภาพ → ความปลอดภัย → สังคม → การยอมรับ → **การบรรลุศักยภาพ** |
| **Herzberg** | **ปัจจัยอนามัย (hygiene)** ป้องกันความไม่พอใจ · **ปัจจัยจูงใจ (motivator)** สร้างความพอใจ |
| **McGregor** | **ทฤษฎี X** (คนขี้เกียจ ต้องควบคุม) vs **ทฤษฎี Y** (คนอยากทำงาน ให้อิสระ) |
| **ทฤษฎี Z** (Ouchi) | ผสมแนวญี่ปุ่น — จ้างระยะยาว ตัดสินใจร่วมกัน ดูแลพนักงานแบบองค์รวม |
| **Expectancy** (Vroom) | แรงจูงใจ = ความคาดหวัง × ความเชื่อมโยงผลตอบแทน × คุณค่าของผลตอบแทน |
| **Equity** (Adams) | คนเทียบสัดส่วนผลตอบแทน/ความพยายามของตนกับผู้อื่น |
| **Reinforcement** | พฤติกรรมที่ได้รับการเสริมแรงจะเกิดซ้ำ |

- **เทคนิคสร้างแรงจูงใจ** — ผลตอบแทนที่เหมาะสม · ความมั่นคงในงาน · **ตารางทำงานยืดหยุ่น** ·
  การมีส่วนร่วมของพนักงาน · **การจัดการแบบเปิดตำรา (open-book management)**
- **ทีมและการทำงานเป็นทีม** — ขั้นตอนพัฒนาทีม ⭐ **จัดตั้งทีม → ระดมความคิด → กำหนดบรรทัดฐาน →
  ดำเนินการ → แยกย้าย** (forming, storming, norming, performing, adjourning)
- **กระบวนการ HRM** ⭐⭐
  1. **การวางแผนทรัพยากรมนุษย์** — พยากรณ์ความต้องการ
  2. **การวิเคราะห์งาน (Job Analysis)** → job description + job specification
  3. **การสรรหา (Recruitment)** — ภายใน vs ภายนอก
  4. **การคัดเลือก (Selection)** — ใบสมัคร → ทดสอบ → สัมภาษณ์ → ตรวจสอบประวัติ → จ้าง
  5. **ค่าตอบแทน (Compensation)** — เงินเดือน ค่าจ้าง คอมมิชชัน โบนัส สวัสดิการ
  6. **การฝึกอบรมและพัฒนา**
  7. **การประเมินประสิทธิภาพ** — แบบประเมิน, **การกำหนดค่าคะแนนถ่วงน้ำหนัก**, การประเมินหัวหน้างาน
  8. การดำเนินการกับผลประเมิน และการรับมือกรณีปลดพนักงาน

### บทที่ 5 — ระบบสารสนเทศในธุรกิจ

- **CBIS (Computer-Based Information System)** ⭐ — ฮาร์ดแวร์ · ซอฟต์แวร์ · ข้อมูล · คน · กระบวนการ
- **ขั้นตอนการประมวลผลข้อมูล** — input → process → storage → output
- **บทบาทของ IT ในธุรกิจ** — เพิ่มประสิทธิภาพ ลดต้นทุน สร้างความได้เปรียบในการแข่งขัน
- **กระบวนการทางธุรกิจ (Business Process)** และการเชื่อมกับระบบสารสนเทศ
- **ระบบสารสนเทศตามฟังก์ชันธุรกิจ** ⭐⭐ — ระบบสารสนเทศการขาย/การตลาด · การผลิต ·
  การเงินและบัญชี · ทรัพยากรมนุษย์
- **ระดับของระบบสารสนเทศ** ⭐⭐ — **TPS** (ปฏิบัติการ) → **MIS** (จัดการ) →
  **DSS** (สนับสนุนการตัดสินใจ) → **ESS/EIS** (ผู้บริหารระดับสูง)

### 5.1 คลังข้อสอบ

### 5.2 รูปแบบโจทย์ที่ generate ได้อัตโนมัติ

| หัวข้อ | เทมเพลต | วิธีตรวจ |
|---|---|---|
| GDP | สุ่ม GDP 2 ปี → หา growth rate และ debt/GDP | คำนวณตรง |
| ดอกเบี้ย | สุ่ม `PV`, `r`, `n`, จำนวนงวดทบต้น → หา `FV`, `EAR` | สูตรตรง |
| Flat vs Effective | สุ่มเงื่อนไขผ่อนสินค้า → เทียบสองอัตรา | คำนวณ IRR |
| NPV | สุ่มกระแสเงินสด 4–5 ปี → หา NPV และตัดสินใจลงทุน | คำนวณตรง |
| งบการเงิน | สุ่มรายการ → ให้จัดลงงบดุล/งบกำไรขาดทุน แล้วหา net profit | ตรวจสมดุลบัญชี |
| ค่าเสื่อมราคา | สุ่มราคาทุน/มูลค่าซาก/อายุ → ตารางค่าเสื่อมวิธีเส้นตรง | คำนวณตรง |
| EOQ | สุ่ม `D`, `S`, `H` (+ ส่วนลดตามปริมาณ) | คำนวณตรง |
| การตลาด | ให้สถานการณ์แบรนด์ → เลือกกลยุทธ์ราคา/ตำแหน่งที่เหมาะสม | rubric |

### 5.3 กรณีศึกษา (Case Study)

คลังมีเคสจริง 3 เคส — ใช้เป็นแม่แบบข้อสอบเชิงวิเคราะห์ได้:
