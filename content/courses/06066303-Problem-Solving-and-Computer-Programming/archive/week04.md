- เปรียบเทียบความแตกต่างระหว่าง **`while` loop** (ควบคุมด้วยเงื่อนไข) และ **`for` loop** (ควบคุมด้วยจำนวนรอบหรือลำดับข้อมูล) และเลือกใช้ให้เหมาะกับปัญหาได้
- ใช้งานฟังก์ชัน **`range()`** ได้อย่างแม่นยำ ทั้งแบบ 1 พารามิเตอร์, 2 พารามิเตอร์ และ 3 พารามิเตอร์ รวมถึงการนับถอยหลังด้วย `step` ติดลบ

- ประยุกต์ใช้ **รูปแบบตัวสะสมค่า (Accumulator Pattern)** เพื่อหาผลรวม (Sum), การนับ (Count), การหาค่าสูงสุด/ต่ำสุด (Min/Max), และการต่อข้อความ
- ระบุและแก้ไขข้อผิดพลาดพบบ่อย เช่น **Off-by-one errors** และ **ลูปไม่รู้จบ (Infinite Loops)**

## สรุปอ่านสอบ

### 1. การทำงานซ้ำด้วย `while` Loop (Condition-Controlled Loop)

คำสั่ง `while` ใช้สั่งให้โปรแกรมทำงานซ้ำตราบเท่าที่ **เงื่อนไขทางตรรกะยังคงเป็นจริง (`True`)**:

```python
while condition:
    # คำสั่งที่ต้องการให้ทำซ้ำ
```

#### องค์ประกอบสำคัญ 3 ประการของ Loop ที่ถูกต้อง:
1. **Initial State:** การกำหนดค่าเริ่มต้นให้ตัวแปรควบคุมลูป (ทำก่อนเริ่มเข้าลูป)
2. **Loop Condition:** เงื่อนไขตรวจสอบว่าจะยังวนลูปต่อไปหรือไม่
3. **State Update:** การปรับปรุงค่าตัวแปรควบคุมลูปภายในบล็อก เพื่อให้เงื่อนไขมีโอกาสกลายเป็น `False` ในที่สุด

```python
# ตัวอย่าง: วนพิมพ์ตัวเลข 1 ถึง 5
i = 1             # 1) ค่าเริ่มต้น
while i <= 5:     # 2) เงื่อนไข
    print(i)
    i += 1        # 3) ปรับปรุงค่า (ถ้าลืมบรรทัดนี้ จะกลายเป็น Infinite Loop ทันที!)
```

#### ลูปไม่รู้จบและการใช้ Sentinel Value:
เมื่อไม่ทราบจำนวนรอบล่วงหน้า แต่วนรับข้อมูลไปเรื่อย ๆ จนกว่าจะเจอ "สัญญาณหยุด" (Sentinel Value):
```python
total = 0
while True:
    val = int(input())
    if val == -1:    # Sentinel value คือ -1
        break
    total += val
```

### 2. การทำงานซ้ำด้วย `for` Loop และฟังก์ชัน `range()`

ในภาษา Python คำสั่ง `for` เป็นแบบ **Collection / Sequence-controlled Loop** คือการดึงสมาชิกทีละตัวจาก Iterable Object (เช่น ลิสต์ สตริง หรือ range) มาประมวลผล:

```python
for item in iterable:
    # คำสั่งที่ประมวลผลกับ item
```

#### การสร้างลำดับตัวเลขด้วยฟังก์ชัน `range()`:
`range()` เป็นฟังก์ชัน Built-in ที่สร้าง Sequence ของจำนวนเต็มแบบ Lazy evaluation มี 3 รูปแบบการเรียกใช้:

| รูปแบบ | พารามิเตอร์ | ความหมายและช่วงตัวเลข | ตัวอย่าง | ผลลัพธ์ตัวเลขที่ได้ |
|---|---|---|---|---|
| `range(stop)` | 1 ตัว | เริ่มต้นที่ `0` เพิ่มทีละ `1` ถึง `stop - 1` | `range(5)` | `0, 1, 2, 3, 4` (ทั้งหมด 5 รอบ) |
| `range(start, stop)` | 2 ตัว | เริ่มต้นที่ `start` เพิ่มทีละ `1` ถึง `stop - 1` | `range(2, 6)` | `2, 3, 4, 5` |
| `range(start, stop, step)` | 3 ตัว | เริ่มต้นที่ `start` เพิ่มทีละ `step` ถึงก่อน `stop` | `range(1, 10, 2)` | `1, 3, 5, 7, 9` (เลขคี่) |

> [!IMPORTANT]
> **กฎเหล็กของ `range()`:**
> ค่า **`stop` จะไม่ถูกนับรวมในลำดับเสมอ (Exclusive upper bound)**
> เช่น หากต้องการตัวเลข $1$ ถึง $N$ ต้องระบุเป็น `range(1, n + 1)`

#### การนับถอยหลัง (Negative Step):
หากต้องการวนลูปจากมากไปน้อย ค่า `step` ต้องเป็นจำนวนติดลบ และค่า `start` ต้องมากกว่า `stop`:
```python
# นับถอยหลังจาก 5 ลงมาถึง 1
for i in range(5, 0, -1):
    print(i, end=" ")
# ผลลัพธ์: 5 4 3 2 1
```

### 3. คำสั่งควบคุมลูป: `break`, `continue` และ `else` ใน Loop

| คำสั่ง | พฤติกรรมการทำงาน | ตัวอย่างสถานการณ์ที่ใช้ |
|---|---|---|
| **`break`** | สั่งให้โปรแกรม **ออกจากลูปทันที** โดยไม่ทำคำสั่งที่เหลือในลูปและไม่วนรอบถัดไป | ค้นหาข้อมูลเจอแล้วให้หยุด, เจอสัญญาณหยุด (Sentinel) |
| **`continue`** | สั่งให้ **ข้ามคำสั่งที่เหลือในรอบปัจจุบัน** แล้วกระโดดไปเริ่มรอบถัดไปทันที | กรองข้อมูลที่ไม่ต้องการประมวลผล เช่น ข้ามเลขคู่ หรือข้ามสตริงว่าง |

```python
# ตัวอย่าง continue: พิมพ์เฉพาะเลขคี่
for n in range(1, 6):
    if n % 2 == 0:
        continue
    print(n)  # พิมพ์ 1, 3, 5
```

#### โครงสร้าง `for - else` และ `while - else`:
บล็อก `else` ในลูปเป็นฟีเจอร์เฉพาะของ Python:
- บล็อก `else` จะทำงาน **เมื่อลูปวนซ้ำจนครบตามปกติ** (เงื่อนไขของลูปกลายเป็น `False`)
- บล็อก `else` จะ **ไม่ทำงานเด็ดขาด** หากลูปถูกบังคับให้ออกด้วยคำสั่ง **`break`**

```python
# ตัวอย่าง: ตรวจสอบจำนวนเฉพาะ (Prime Number)
n = int(input())
for i in range(2, int(n ** 0.5) + 1):
    if n % i == 0:
        print("Not Prime")
        break
else:
    print("Prime")  # ทำงานเมื่อลูปวนครบโดยไม่เจอ break เลย
```

### 4. รูปแบบการสะสมค่า (The Accumulator Pattern)

รูปแบบการเขียนโปรแกรมที่สำคัญที่สุดสำหรับการแก้โจทย์ OJ คือการใช้ **ตัวแปรสะสม (Accumulator Variable)**:

```
[กำหนดค่าเริ่มต้น Accumulator นอกลูป] ➔ [วนลูปเพื่อปรับปรุงค่าในตัวแปร] ➔ [แสดงผลลัพธ์หลังจบลูป]
```

#### 4 รูปแบบ Accumulator ที่พบบ่อย:

1. **การหาผลรวม (Sum Accumulator):**
   ```python
   total = 0                      # เริ่มต้นที่ 0
   for val in numbers:
       total += val               # สะสมผลรวม
   ```
2. **การนับความถี่ (Count Accumulator):**
   ```python
   count = 0                      # เริ่มต้นที่ 0
   for ch in text:
       if ch in "aeiouAEIOU":
           count += 1             # นับเพิ่มทีละ 1 เมื่อตรงเงื่อนไข
   ```
3. **การหาค่ามากสุด / น้อยสุด (Min / Max Tracker):**
   - **เทคนิคที่ 1 (แนะนำที่สุด):** อ่านค่าแรกเข้ามาเก็บเป็นค่าเริ่มต้นก่อนเริ่มลูป
     ```python
     n = int(input())
     max_val = int(input())       # ตัวแรกเป็นค่าอ้างอิง
     for _ in range(n - 1):
         val = int(input())
         if val > max_val:
             max_val = val
     ```
   - **เทคนิคที่ 2:** ใช้ค่าอนันต์ `float('inf')` สำหรับ min และ `float('-inf')` สำหรับ max
4. **การสะสมข้อความ (String Accumulator):**
   ```python
   result = ""                    # เริ่มต้นสตริงว่าง
   for ch in original_text:
       if ch.isalnum():
           result += ch           # ต่อข้อความ
   ```

### 5. ลูปซ้อนลูปเบื้องต้น (Nested Loops)

เมื่อต้องการประมวลผลข้อมูลในลักษณะ 2 มิติ เช่น ตาราง หรือพิกัด $(x, y)$:
- **ลูปนอก (Outer loop):** ควบคุมแถวแนวนอน (Row)
- **ลูปใน (Inner loop):** ควบคุมคอลัมน์แนวตั้ง (Column)
- ในแต่ละรอบของลูปนอก ลูปในจะทำงานตั้งแต่ต้นจนจบครบทุกรอบ:

```python
# พิมพ์ตารางดาวขนาด 3 แถว 4 คอลัมน์
for row in range(3):
    for col in range(4):
        print("*", end="")
    print()  # ขึ้นบรรทัดใหม่เมื่อจบคอลัมน์ของแถวนั้น
```

## จุดที่มักพลาด

- **Off-by-One Error ใน `range()`:**
  ต้องการวนลูป $N$ รอบ แต่เขียน `range(N + 1)` (วนเกินเป็น $N+1$ รอบ) หรือต้องการบวกเลข $1$ ถึง $10$ แต่เขียน `range(1, 10)` ทำให้ตัวเลข $10$ ตกหล่น
- **ประกาศตัวแปรสะสมไว้ข้างในลูป:**
  ```python
  # ผิด! total จะถูกรีเซ็ตเป็น 0 ใหม่ทุกรอบลูป
  for i in range(5):
      total = 0
      total += i
  # ถูก: ต้องประกาศ total = 0 ไว้ก่อนเริ่มลูปด้านนอก
  ```
- **กำหนดค่าเริ่มต้นของ Min Tracker ผิดพลาด:**
  กำหนด `min_val = 0` เพื่อหาค่าน้อยที่สุด แต่ชุดข้อมูลนำเข้าเป็นคะแนนสอบที่เป็นจำนวนบวกทั้งหมด เช่น `[15, 80, 45, 90]` ผลลัพธ์สุดท้ายจะกลายเป็น `0` ซึ่งไม่ใช่ข้อมูลในลิสต์!
- **ลืมเปลี่ยนค่าตัวแปรใน `while` Loop:**
  เกิดอาการโปรแกรมค้าง ไม่สิ้นสุดการทำงาน กิน CPU เต็ม 100% จนระบบ OJ ตัดสิทธิ์ด้วย Time Limit Exceeded (TLE)
- **การแก้ไข Iterable ขณะกำลังวนลูป `for`:**
  การสั่งลบหรือเพิ่มสมาชิกในลิสต์ขณะที่กำลังใช้ `for item in my_list:` จะทำให้ Index คลาดเคลื่อนและข้ามสมาชิกบางตัวไปอย่างคาดไม่ถึง

## ทดสอบตัวเอง

1. **โจทย์วิเคราะห์รอบลูป:** คำสั่ง `for i in range(3, 15, 4):` จะวนลูปทั้งหมดกี่รอบ และตัวแปร `i` จะมีค่าเท่าใดบ้างในแต่ละรอบ?
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   วนทั้งหมด <strong>3 รอบ</strong> โดยค่าของ <code>i</code> ในแต่ละรอบคือ <strong>3, 7, 11</strong> (ค่าถัดไปคือ 15 ซึ่งถึงค่า stop พอดี จึงไม่ถูกนับ)
   </details>

2. **โจทย์ผลลัพธ์คำสั่ง `break` / `continue`:** โค้ดด้านล่างนี้จะแสดงผลลัพธ์อะไรออกทางหน้าจอ?
   ```python
   for i in range(1, 6):
       if i == 3:
           continue
       if i == 5:
           break
       print(i, end=" ")
   ```
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   - รอบที่ i=1: พิมพ์ 1<br>
   - รอบที่ i=2: พิมพ์ 2<br>
   - รอบที่ i=3: เจอ <code>continue</code> ข้ามการพิมพ์<br>
   - รอบที่ i=4: พิมพ์ 4<br>
   - รอบที่ i=5: เจอ <code>break</code> หลุดออกจากลูปทันที<br>
   ผลลัพธ์คือ <strong>1 2 4 </strong>
   </details>

3. **โจทย์ `for - else`:** พิจารณาโค้ดต่อไปนี้ ผลลัพธ์ที่พิมพ์ออกมาคือข้อความใด?
   ```python
   found = False
   for x in [2, 4, 6, 8]:
       if x % 2 != 0:
           print("Odd found")
           break
   else:
       print("All even")
   ```
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   แสดงผล <strong>All even</strong> เพราะในลิสต์ไม่มีเลขคี่เลย เงื่อนไข <code>x % 2 != 0</code> ไม่เคยเป็นจริง ทำให้ลูปวนครบทุกตัวตามปกติโดยไม่เจอคำสั่ง <code>break</code> บล็อก <code>else</code> จึงถูกสั่งให้ทำงาน
   </details>

4. **โจทย์ตัวสะสมค่า:** ถ้าต้องการหาผลคูณของจำนวนเต็มตั้งแต่ 1 ถึง $N$ ($N!$) ควรตั้งค่าเริ่มต้นของตัวแปรสะสม `result` เป็นค่าใด เพราะเหตุใด?
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   ต้องตั้งค่าเริ่มต้นเป็น <strong>1</strong> (เอกลักษณ์การคูณ) เพราะหากตั้งเป็น 0 ผลคูณทั้งหมดในลูป <code>result *= i</code> จะกลายเป็น 0 ตลอดไป
   </details>
