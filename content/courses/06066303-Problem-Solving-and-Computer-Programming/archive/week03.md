## สรุปอ่านสอบ

### 1. ตัวดำเนินการเปรียบเทียบ (Comparison Operators)

ตัวดำเนินการเปรียบเทียบใช้ตรวจสอบความสัมพันธ์ระหว่างข้อมูล 2 ค่า และให้ผลลัพธ์เป็นค่าบูลีน (`True` หรือ `False`):

| ตัวดำเนินการ | ความหมายทางคณิตศาสตร์ | สัญลักษณ์ใน Python | ตัวอย่าง | ผลลัพธ์ |
|:---:|---|:---:|---|:---:|
| `==` | เท่ากับ (Equality) | `==` | `5 == 5`<br>`5 == 5.0` | `True`<br>`True` |
| `!=` | ไม่เท่ากับ (Inequality) | `!=` | `5 != 3` | `True` |
| `>` | มากกว่า (Greater than) | `>` | `10 > 20` | `False` |
| `<` | น้อยกว่า (Less than) | `<` | `10 < 20` | `True` |
| `>=` | มากกว่าหรือเท่ากับ | `>=` | `15 >= 15` | `True` |
| `<=` | น้อยกว่าหรือเท่ากับ | `<=` | `7 <= 6` | `False` |

#### คุณสมบัติพิเศษของ Python: Chained Comparisons
ในภาษาอื่น เช่น C/Java การตรวจสอบช่วงต้องเขียน `(x >= 10) && (x <= 20)` แต่ใน Python สามารถเขียนต่อกันแบบคณิตศาสตร์ได้โดยตรง:

```python
x = 15
if 10 <= x <= 20:
    print("In range")  # พิมพ์ In range
```
Python จะแปลงนิพจน์นี้เป็น `(10 <= x) and (x <= 20)` โดยประเมินค่า `x` เพียงครั้งเดียว

#### การเปรียบเทียบสตริง (Lexicographical Comparison):
Python เปรียบเทียบสตริงตามลำดับรหัสอักขระ Unicode (อักษรตัวใหญ่มาก่อนตัวเล็ก):
- `'Apple' < 'Banana'` ➔ `True` (เพราะ `'A'` มีรหัส 65 มาก่อน `'B'` รหัส 66)
- `'apple' > 'Apple'` ➔ `True` (เพราะ `'a'` รหัส 97 มีค่ามากกว่า `'A'` รหัส 65)

### 2. ตัวดำเนินการตรรกศาสตร์ (Boolean Logic Operators)

ใช้เชื่อมโยงนิพจน์เงื่อนไขหลายเงื่อนไขเข้าด้วยกัน:

1. **`not` (นิเสธ):** สลับค่าความจริง จาก `True` เป็น `False` และจาก `False` เป็น `True`
2. **`and` (และ):** จะเป็น `True` ก็ต่อเมื่อเงื่อนไข **ทั้งสองฝั่งเป็นจริงพร้อมกัน**
3. **`or` (หรือ):** จะเป็น `True` ขอเพียงมีเงื่อนไข **ฝั่งใดฝั่งหนึ่งเป็นจริง**

#### ตารางค่าความจริง (Truth Table):
| $A$ | $B$ | `not A` | `A and B` | `A or B` |
|:---:|:---:|:---:|:---:|:---:|
| `True` | `True` | `False` | `True` | `True` |
| `True` | `False` | `False` | `False` | `True` |
| `False` | `True` | `True` | `False` | `True` |
| `False` | `False` | `True` | `False` | `False` |

#### ลำดับความสำคัญของตัวดำเนินการตรรกะ:
$$\text{วงเล็บ } () \quad \succ \quad \text{ตัวดำเนินการเปรียบเทียบ} \quad \succ \quad \text{not} \quad \succ \quad \text{and} \quad \succ \quad \text{or}$$

```python
# ตัวอย่างการวิเคราะห์ลำดับ:
result = True or False and not True
# 1) not True  ➔ False
# 2) False and False ➔ False
# 3) True or False   ➔ True
print(result)  # True
```

#### กฎของเดอมอร์แกน (De Morgan's Laws):
มีประโยชน์มากในการกลับเงื่อนไขเพื่อลดความซับซ้อนของโค้ด:
- `not (A and B)` มีค่าเทียบเท่ากับ `(not A) or (not B)`
- `not (A or B)` มีค่าเทียบเท่ากับ `(not A) and (not B)`

### 3. การประเมินค่าแบบลัดวงจร (Short-circuit Evaluation)

Python จะประเมินค่านิพจน์ตรรกะจากซ้ายไปขวา และจะ **หยุดทันทีที่ทราบผลลัพธ์แน่นอนแล้ว**:

- **สำหรับ `and`:** หากเงื่อนไขแรกเป็น `False` Python จะไม่ตรวจสอบเงื่อนไขที่สองเลย เพราะไม่ว่าเงื่อนไขหลังจะเป็นอะไร ผลลัพธ์สุดท้ายก็ต้องเป็น `False` เสมอ
- **สำหรับ `or`:** หากเงื่อนไขแรกเป็น `True` Python จะไม่ตรวจสอบเงื่อนไขที่สองเลย เพราะผลลัพธ์สุดท้ายเป็น `True` แน่นอนแล้ว

#### ประโยชน์: ใช้เป็น Guard Condition ป้องกัน Error
```python
# หากไม่ใช้ short-circuit กรณี divisor == 0 โปรแกรมจะพังด้วย ZeroDivisionError
if divisor != 0 and (total / divisor) > 2.0:
    print("Valid ratio")

# ถ้า divisor เป็น 0 เงื่อนไข divisor != 0 จะเป็น False ทันที 
# ทำให้ Python ข้ามการคำนวณ total / divisor ไปเลย จึงไม่เกิด Error
```

### 4. ค่า Truthy และ Falsy ในภาษา Python

ใน Python อ็อบเจกต์ทุกชนิดสามารถนำมาทดสอบในคำสั่งเงื่อนไข `if` ได้โดยตรง โดยค่าจะถูกแปลงเป็น Boolean ตามหลักเกณฑ์:

| ค่าประเภท **Falsy** (ประเมินเป็น `False`) | ค่าประเภท **Truthy** (ประเมินเป็น `True`) |
|---|---|
| ค่าคงที่: `False`, `None` | `True` |
| ตัวเลขศูนย์: `0`, `0.0`, `0j` | ตัวเลขที่ไม่ใช่ศูนย์: `1`, `-5`, `0.0001` |
| สตริงว่าง: `""` หรือ `''` | สตริงที่มีอักขระ: `"Hello"`, `" "`, `"0"`, `"False"` |
| โครงสร้างข้อมูลว่าง: `[]`, `()`, `{}`, `set()` | โครงสร้างข้อมูลที่มีสมาชิก: `[0]`, `[None]`, `{'a': 1}` |

```python
name = input()
if name:
    print(f"Hello, {name}")
else:
    print("User entered an empty string!")
```

### 5. โครงสร้างการทำงานแบบมีเงื่อนไข (Conditional Statements)

#### 1) ทางเลือกเดียว: `if`
ทำงานเฉพาะเมื่อเงื่อนไขเป็นจริง:
```python
if score >= 50:
    print("Pass")
```

#### 2) สองทางเลือก: `if - else`
เลือกทำอย่างใดอย่างหนึ่ง:
```python
if score >= 50:
    print("Pass")
else:
    print("Fail")
```

#### 3) หลายทางเลือก: `if - elif - else`
ตรวจสอบเงื่อนไขเรียงจากบนลงล่าง เมื่อพบเงื่อนไขแรกที่เป็นจริง จะทำบล็อกนั้นแล้ว **ข้ามเงื่อนไขที่เหลือทั้งหมดทันที**:

```python
score = float(input())

if score >= 80:
    grade = "A"
elif score >= 70:
    grade = "B"
elif score >= 60:
    grade = "C"
elif score >= 50:
    grade = "D"
else:
    grade = "F"

print(grade)
```

> [!IMPORTANT]
> **ลำดับการเรียงเงื่อนไขมีความสำคัญสูงสุด:**
> หากเขียนสลับเอา `score >= 50` ขึ้นก่อน เมื่อผู้ใช้ได้ 85 คะแนน โปรแกรมจะเข้าเงื่อนไขแรกทันทีและได้เกรด D โดยไม่ลงไปตรวจ `score >= 80` อีกเลย

#### 4) Ternary Operator (Conditional Expression)
การเขียนเงื่อนไขย่อแบบบรรทัดเดียว คืนค่าตามเงื่อนไข:
$$\text{variable} = \text{value\_if\_true} \textbf{ if } \text{condition} \textbf{ else } \text{value\_if\_false}$$

```python
status = "Even" if num % 2 == 0 else "Odd"
```

## จุดที่มักพลาด

- **สับสนระหว่างเครื่องหมาย `=` กับ `==`:**
  - `=` คือการกำหนดค่า (Assignment) ให้ตัวแปร เช่น `x = 10`
  - `==` คือการเปรียบเทียบว่าเท่ากันหรือไม่ เช่น `if x == 10:`
  *(ใน Python การเขียน `if x = 10:` จะเกิด `SyntaxError` ทันที)*
- **กับดักตรรกะ `if x == 'a' or 'b':` (พบบ่อยที่สุดในนักศึกษาปี 1):**
  ```python
  # โค้ดที่ผิด:
  if choice == "yes" or "y":
      print("Confirmed")
  ```
  *ทำไมถึงผิด?* Python จะมองเป็น `(choice == "yes") or ("y")` เนื่องจากสตริง `"y"` เป็นสตริงไม่ว่าง จึงมีค่าเป็น Truthy (`True`) เสมอ ทำให้เงื่อนไขนี้เป็นจริงตลอดเวลาไม่ว่า `choice` จะเป็นอะไรก็ตาม!
  *วิธีแก้ที่ถูกต้อง:*
  ```python
  if choice == "yes" or choice == "y":   # แบบที่ 1
  if choice in ("yes", "y"):             # แบบที่ 2 (กระชับและแนะนำ)
  ```
- **ลืมพิจารณา Boundary Conditions (ค่าขอบเขตพอดี):**
  เช่น โจทย์ระบุ "อายุ 18 ปีขึ้นไป" ต้องใช้ `>= 18` ไม่ใช่ `> 18` เพราะจะทำให้อายุ 18 ปีตกหล่น
- **เงื่อนไขซ้อนที่ไม่จำเป็น (Nested Conditionals Sprawl):**
  การเขียน `if` ซ้อนกัน 4-5 ชั้นทำให้อ่านยากและมีโอกาสหลงบล็อก ให้พยายามยุบด้วยตัวดำเนินการ `and` หรือใช้ Guard Clauses ตรวจสอบกรณีที่ไม่ผ่านแล้วหยุดก่อน

## ทดสอบตัวเอง

1. **โจทย์วิเคราะห์ตรรกะ:** จงหาค่าความจริงของนิพจน์ต่อไปนี้ เมื่อกำหนดให้ `x = 10`, `y = 20`, `z = 0`
   ```python
   (x > y or y > z) and (not (z == 0) or x + y == 30)
   ```
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   แยกพิจารณาทีละส่วน:<br>
   - วงเล็บแรก: <code>(10 > 20 or 20 > 0)</code> ➔ <code>False or True</code> ➔ <strong>True</strong><br>
   - วงเล็บหลัง: <code>(not (0 == 0) or 10 + 20 == 30)</code> ➔ <code>(not True or 30 == 30)</code> ➔ <code>False or True</code> ➔ <strong>True</strong><br>
   - นำมา <code>and</code> กัน: <code>True and True</code> ➔ <strong>True</strong>
   </details>

2. **โจทย์ Short-circuit:** โค้ดด้านล่างนี้จะพิมพ์ค่าอะไร และจะเกิด Runtime Error หรือไม่?
   ```python
   a = 0
   b = 10
   if a != 0 and (b // a) > 2:
       print("Branch 1")
   else:
       print("Branch 2")
   ```
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   พิมพ์ <strong>Branch 2</strong> และ <strong>ไม่เกิด ZeroDivisionError</strong> เพราะ <code>a != 0</code> มีค่าเป็น <code>False</code> กลไก Short-circuit Evaluation ของตัวดำเนินการ <code>and</code> จะหยุดทันทีโดยไม่ประเมินฝั่งขวา <code>(b // a) > 2</code> จึงไหลไปทำงานที่บล็อก <code>else</code>
   </details>

3. **โจทย์หาจุดผิด:** โค้ดตัดเกรดด้านล่างนี้มีข้อผิดพลาดประเภทใด และเมื่อป้อนคะแนน `score = 85` จะได้เกรดอะไร?
   ```python
   score = 85
   if score >= 50:
       grade = "Pass"
   elif score >= 80:
       grade = "Honors"
   else:
       grade = "Fail"
   print(grade)
   ```
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   เป็น <strong>Logic Error</strong> เนื่องจากเรียงเงื่อนไขกว้าง (<code>>= 50</code>) ก่อนเงื่อนไขเฉพาะเจาะจง (<code>>= 80</code>)<br>
   เมื่อ <code>score = 85</code> ซึ่งผ่านเงื่อนไขแรกทันที จึงได้เกรด <strong>Pass</strong> แทนที่จะเป็น Honors ตามที่ควรจะเป็น
   </details>

4. **โจทย์ Truthy/Falsy:** ตัวแปร `data = []` คำสั่ง `val = data or "Default"` จะทำให้ `val` มีค่าเท่ากับข้อความใด?
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   <code>val</code> จะมีค่าเป็น <strong>"Default"</strong> เพราะ <code>data = []</code> เป็นลิสต์ว่าง จัดเป็น Falsy ตัวดำเนินการ <code>or</code> จึงข้ามไปประเมินและคืนค่าอ็อบเจกต์ตัวหลังสุดที่มีค่าเป็น Truthy
   </details>
