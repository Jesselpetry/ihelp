### 1. ลำดับดัชนีและความยาวของสตริง (String Indexing & Length)

สตริง (String หรือ `str`) ใน Python คือลำดับของตัวอักขระ (Sequence of characters) ที่เรียงต่อกัน แต่ละตำแหน่งจะมีดัชนี (Index) กำกับอยู่ 2 ระบบ:

1. **Positive Index (ดัชนีบวก):** เริ่มนับจากทางซ้ายสุดที่ตำแหน่ง `0` ไปจนถึง `len(s) - 1`
2. **Negative Index (ดัชนีดัชนีลบ):** เริ่มนับจากทางขวาสุดที่ตำแหน่ง `-1` ย้อนกลับมาทางซ้ายจนถึง `-len(s)`

```
ตัวอย่างสตริง s = "PYTHON"  (len(s) = 6)

  Positive Index:   0    1    2    3    4    5
  Character:      | P  | Y  | T  | H  | O  | N  |
  Negative Index:  -6   -5   -4   -3   -2   -1
```

- ฟังก์ชัน **`len(s)`** ส่งคืนจำนวนอักขระทั้งหมดในสตริง (ความยาวสตริง)
- การเข้าถึงอักขระเดี่ยว: `s[index]` เช่น `s[0]` คือ `'P'` และ `s[-1]` คือ `'N'`
- **IndexError:** หากระบุดัชนีเกินขอบเขตที่สตริงมีอยู่จริง เช่น `s[6]` หรือ `s[-7]` จะเกิดข้อผิดพลาด `IndexError: string index out of range` ทันที

```python
s = "PYTHON"
print(len(s))    # 6
print(s[0])      # 'P'
print(s[-1])     # 'N'
# print(s[6])    # IndexError: string index out of range
```

### 2. การแบ่งส่วนสตริง (String Slicing)

การดึงข้อความย่อย (Substring) ออกมาจากสตริงหลัก ทำได้โดยใช้ไวยากรณ์:

$$\text{s}[\text{start} : \text{stop} : \text{step}]$$

- **`start` (รวม / Inclusive):** ดัชนีเริ่มต้นของช่วงที่ต้องการดึง
- **`stop` (ไม่รวม / Exclusive):** ดัชนีสิ้นสุด โดย Python จะดึงถึงเพียงแค่ `stop - 1` (หรือก่อนหน้าทิศทางการเดิน)
- **`step` (ก้าว):** ระยะก้าวในการขยับดัชนี ถ้าไม่ระบุจะมีค่าเริ่มต้นเป็น `1`

#### ตารางรูปแบบ Slicing ที่พบบ่อย

| รูปแบบคำสั่ง | ความหมาย | ตัวอย่าง (`s = "Computer"`) | ผลลัพธ์ |
|---|---|---|---|
| `s[start:stop]` | ดึงตั้งแต่ `start` ถึง `stop - 1` | `s[0:4]` | `'Comp'` |
| `s[:stop]` | ละ `start` = เริ่มจากต้นสตริง (ดัชนี 0) | `s[:3]` | `'Com'` |
| `s[start:]` | ละ `stop` = ดึงไปจนสุดปลายสตริง | `s[4:]` | `'uter'` |
| `s[:]` | คัดลอกทั้งสตริง | `s[:]` | `'Computer'` |
| `s[::2]` | ดึงทุก ๆ 2 ก้าว (อักขระตำแหน่งคู่) | `s[::2]` | `'Cmue'` |
| `s[::-1]` | เดินก้าวละ `-1` (กลับด้านข้อความ / Reverse) | `s[::-1]` | `'retupmoC'` |
| `s[5:1:-1]` | ก้าวติดลบ: เริ่มที่ 5 ถอยหลังถึง 2 (ไม่รวม 1) | `s[5:1:-1]` | `'tupm'` |

> [!NOTE]
> ข้อแตกต่างสำคัญระหว่าง Indexing กับ Slicing:
> การเข้าถึงด้วย Index นอกช่วง (`s[100]`) จะทำให้เกิด `IndexError` เสมอ แต่การ **Slicing นอกช่วง (`s[10:20]`) จะไม่ Error** โดย Python จะตัดคืนเท่าที่มี หรือคืนเป็นสตริงว่าง `""`

### 3. คุณสมบัติ Immutability ของสตริง

สตริงใน Python จัดเป็น **Immutable Object** หมายความว่า เมื่อสตริงถูกสร้างขึ้นแล้ว อักขระในตำแหน่งใด ๆ ภายในสตริงนั้น **ไม่สามารถแก้ไข ลบ หรือแทนที่โดยตรงได้**

```python
s = "KMITL"
# s[0] = 'C'   # TypeError: 'str' object does not support item assignment
```

หากต้องการแก้ไขเนื้อหาของสตริง ต้องสร้างสตริงก้อนใหม่ขึ้นมาเสมอ:

```python
# วิธีที่ 1: ใช้ Slicing แล้วต่อสตริงด้วยเครื่องหมาย +
s = "KMITL"
s_new = "C" + s[1:]
print(s_new)   # 'CMITL'

# วิธีที่ 2: แปลงเป็น list ทำการแก้ไข แล้วใช้ .join() รวมกลับ
s_list = list(s)
s_list[0] = 'C'
s_new = "".join(s_list)
print(s_new)   # 'CMITL'
```

### 4. การวนซ้ำบนสตริง (String Traversal)

การท่องเข้าไปในสตริงทีละตัวอักขระมี 2 วิธีหลัก ซึ่งมีข้อดีและจุดประสงค์การใช้งานที่ต่างกัน:

#### 1) วนซ้ำทีละอักขระโดยตรง (`for char in s:`)
เหมาะสำหรับงานที่ต้องการแค่อักขระ ไม่จำเป็นต้องทราบตำแหน่งดัชนี เช่น การนับจำนวนสระ การตรวจสอบอักขระเฉพาะ

```python
text = "problem"
vowel_count = 0
for ch in text:
    if ch in "aeiouAEIOU":
        vowel_count += 1
```

#### 2) วนซ้ำผ่านดัชนี (`for i in range(len(s)):`)
จำเป็นสำหรับกรณีที่ต้องใช้ตำแหน่งดัชนีในการคำนวณ หรือต้องการเข้าถึงอักขระตัวถัดไป/ตัวก่อนหน้า (`s[i+1]`, `s[i-1]`)

```python
text = "aabbbcc"
# ตรวจสอบว่าอักขระติดกันซ้ำกันหรือไม่
for i in range(len(text) - 1):
    if text[i] == text[i + 1]:
        print(f"Duplicate '{text[i]}' found at indices {i} and {i+1}")
```

#### 3) วนซ้ำพร้อมรับทั้ง Index และ Character (`enumerate`)
ช่วยให้เขียนโค้ดได้กระชับและลดโอกาสพิมพ์ผิด

```python
for idx, ch in enumerate("KMITL"):
    print(f"Index {idx} -> {ch}")
```

### 5. เมท็อดของสตริงที่ออกสอบบ่อย (Built-in String Methods)

เมท็อดทุกตัวของสตริงจะ **ไม่แก้ไขสตริงเดิม** แต่จะคืนค่าเป็นสตริงใหม่เสมอ (ตามคุณสมบัติ Immutability)

#### ก. การจัดการรูปแบบตัวอักษรและช่องว่าง
- **`.upper()` / `.lower()`:** แปลงเป็นตัวพิมพ์ใหญ่ / พิมพ์เล็กทั้งหมด
- **`.capitalize()`:** แปลงอักษรตัวแรกสุดเป็นตัวพิมพ์ใหญ่ และตัวที่เหลือเป็นตัวพิมพ์เล็ก
- **`.strip()`:** ตัดอักขระช่องว่าง (Whitespace: space, tab, newline) ที่อยู่หัวและท้ายสตริงออก
- **`.lstrip()` / `.rstrip()`:** ตัดช่องว่างเฉพาะด้านซ้าย (หัว) หรือด้านขวา (ท้าย)

```python
raw = "   Hello Python \n"
clean = raw.strip().lower()   # "hello python"
```

#### ข. การค้นหาและแทนที่
- **`.find(sub)`:** ค้นหาตำแหน่งดัชนีแรกที่พบสตริงย่อย `sub` หากไม่พบจะคืนค่าเป็น `-1`
- **`.count(sub)`:** นับจำนวนครั้งที่พบสตริงย่อย `sub` โดยไม่นับซ้ำตำแหน่งที่ซ้อนทับกัน
- **`.replace(old, new[, count]):`** แทนที่สตริงย่อย `old` ด้วย `new` ตามจำนวนครั้งที่ระบุ (หากไม่ระบุจะแทนที่ทุกตำแหน่ง)

```python
msg = "banana"
print(msg.find("an"))     # 1 (พบครั้งแรกที่ดัชนี 1)
print(msg.find("z"))      # -1 (ไม่พบ ไม่ raise error!)
print(msg.count("a"))     # 3
print(msg.replace("a", "o", 2))  # "bonona"
```

#### ค. การตรวจสอบคุณสมบัติของอักขระ (Boolean Inspection)
เมท็อดกลุ่มนี้คืนค่าเป็น `True` หรือ `False` (สตริงว่าง `""` จะคืน `False` เสมอ):
- **`.isdigit()` / `.isnumeric()`:** ตรวจสอบว่าเป็นตัวเลขทั้งหมดหรือไม่
- **`.isalpha()`:** ตรวจสอบว่าเป็นตัวอักษรทั้งหมดหรือไม่ (ไม่รวมตัวเลขและช่องว่าง)
- **`.isalnum()`:** ตรวจสอบว่าเป็นตัวอักษรหรือตัวเลข (Alphanumeric) ทั้งหมดหรือไม่
- **`.isspace()`:** ตรวจสอบว่าเป็นช่องว่างทั้งหมดหรือไม่
- **`.startswith(prefix)` / `.endswith(suffix)`:** ตรวจสอบว่าขึ้นต้นหรือลงท้ายด้วยข้อความที่กำหนดหรือไม่

#### ง. การตัดและเชื่อมสตริง (`split` & `join`)
- **`s.split(sep=None)`:** หั่นสตริงออกเป็น `list` ของสตริงย่อย
  - หากไม่ใส่ argument (`s.split()`): จะตัดด้วยช่องว่าง (Whitespace) ใด ๆ ต่อเนื่องกันกี่เคาะก็ได้ และจะละเว้นช่องว่างหัวท้ายให้อัตโนมัติ
  - หากระบุ argument (`s.split(",")`): จะตัดด้วยตัวคั่นนั้นอย่างเคร่งครัด
- **`sep.join(iterable)`:** นำสมาชิกทุกตัวใน `iterable` (ที่เป็นสตริง) มาเชื่อมต่อกันโดยคั่นด้วยสตริง `sep`

```python
csv_line = "apple,banana,grape"
fruits = csv_line.split(",")           # ['apple', 'banana', 'grape']
reconstructed = " - ".join(fruits)     # 'apple - banana - grape'
```

### 6. การทดสอบสมาชิก (Membership Operators: `in` / `not in`)

ใช้ตรวจสอบว่ามีสตริงย่อย (Substring) ปรากฏอยู่ภายในสตริงเป้าหมายหรือไม่ โดยคืนค่าเป็นบูลีน (`True`/`False`):

```python
text = "Data Science and Artificial Intelligence"
print("Science" in text)       # True
print("science" in text)       # False (Case-sensitive!)
print("Python" not in text)    # True
```

## จุดที่มักพลาด

- **พยายามแก้ไขสตริงแบบ In-place (`s[0] = 'A'`):** จะเกิด `TypeError: 'str' object does not support item assignment` ต้องจำว่าสตริงเป็น Immutable เสมอ
- **การใช้เงื่อนไขตรวจสอบผลลัพธ์ของ `.find()`:**
  - เมท็อด `.find()` คืน `-1` เมื่อไม่พบสตริงย่อย
  - ใน Python ค่า `-1` มีค่าความจริงเป็น `True`!
  - ❌ **ผิด:** `if s.find("x"):` (จะทำงานเสมอแม้ไม่พบ เพราะ `-1` ถือเป็น `True`)
  - ✅ **ถูก:** `if s.find("x") != -1:` หรือใช้วิธีที่ดีกว่าคือ `if "x" in s:`
- **ความแตกต่างระหว่าง `.split()` กับ `.split(" ")`:**
  - `s = "a   b"` (มีช่องว่าง 3 เคาะ)
  - `s.split()` ได้ `['a', 'b']` (ตัด whitespace ต่อเนื่องกันทั้งหมด)
  - `s.split(" ")` ได้ `['a', '', '', 'b']` (ได้สตริงว่างแทรกเข้ามาตามจำนวนช่องว่าง)
- **การใช้ `.join()` กับข้อมูลที่ไม่ใช่สตริง:**
  - `numbers = [1, 2, 3]`
  - `",".join(numbers)` จะเกิด `TypeError: sequence item 0: expected str instance, int found`
  - ต้องแปลงข้อมูลเป็นสตริงก่อนเสมอ: `",".join(map(str, numbers))` หรือ `",".join([str(x) for x in numbers])`
- **Slicing ก้าวติดลบแล้วระบุ `start` กับ `stop` สลับทิศ:**
  - หาก `step` ติดลบ ทิศทางการเดินคือจากขวาไปซ้าย ดังนั้น `start` ต้องมากกว่า `stop`
  - ตัวอย่าง `s = "abcdef"`
  - `s[1:4:-1]` จะได้สตริงว่าง `""` เพราะเดินจาก 1 ไป 4 ด้วยก้าวถอยหลังไม่ได้
  - ที่ถูกต้องคือ `s[4:1:-1]` ซึ่งจะได้ `'edc'` (ไม่รวมดัชนี 1)
