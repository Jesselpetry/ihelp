### 1. การนิยามฟังก์ชันและการแยกส่วนงาน (Function & Decomposition)

**Functional Decomposition (การแยกส่วนงาน)** คือกระบวนการแตกปัญหาใหญ่ที่ซับซ้อนออกเป็นปัญหาย่อย ๆ ที่อิสระต่อกัน แล้วเขียนฟังก์ชันรองรับแต่ละส่วนงาน ทำให้โค้ด:
- อ่านเข้าใจง่าย (Readability)
- นำกลับมาใช้ซ้ำได้ (Reusability) โดยไม่ต้องเขียนโค้ดเดิมซ้ำซ้อน
- ทดสอบและค้นหาจุดผิดพลาดได้ง่าย (Testability & Debugging)

ไวยากรณ์พื้นฐานในการสร้างฟังก์ชันใน Python:

```python
def function_name(param1, param2):
    """Docstring: อธิบายการทำงานของฟังก์ชัน พารามิเตอร์ และค่าที่ส่งกลับ"""
    # บล็อกคำสั่งการทำงาน (Body)
    return result
```

- คำสำคัญ **`def`** ใช้ประกาศการสร้างฟังก์ชัน ตามด้วยชื่อฟังก์ชันและวงเล็บ `()`
- **Docstring:** ข้อความภายใต้เครื่องหมายคำพูด 3 ชุด (`"""..."""`) ในบรรทัดแรกของฟังก์ชัน ใช้เป็นเอกสารกำกับฟังก์ชัน สามารถเรียกดูได้ผ่าน `help(function_name)` หรือ `function_name.__doc__`

### 2. พารามิเตอร์กับอาร์กิวเมนต์ (Parameters vs Arguments)

ความแตกต่างระหว่างสองคำนี้มักออกสอบบ่อย:

| คำศัพท์ | ความหมาย | ตำแหน่งที่พบ |
|---|---|---|
| **Parameter (พารามิเตอร์)** | ตัวแปรตัวแทนที่กำหนดไว้ในวงเล็บของหัวฟังก์ชัน (Formal Parameter) | บรรทัด `def function_name(...)` |
| **Argument (อาร์กิวเมนต์)** | ค่าจริงหรือตัวแปรที่ผู้เรียกส่งเข้าไปในฟังก์ชันตอนสั่งรัน (Actual Argument) | บรรทัดที่สั่งเรียกใช้งานฟังก์ชัน `f(...)` |

#### รูปแบบการส่งอาร์กิวเมนต์
1. **Positional Arguments:** ส่งค่าตามลำดับตำแหน่งที่ฟังก์ชันกำหนดไว้
   ```python
   def power(base, exp):
       return base ** exp

   print(power(2, 3))   # base=2, exp=3 -> 8
   ```
2. **Keyword Arguments:** ส่งค่าโดยระบุชื่อพารามิเตอร์กำกับไว้ ทำให้ไม่จำเป็นต้องเรียงตามลำดับตำแหน่ง
   ```python
   print(power(exp=3, base=2))   # ได้ผลลัพธ์ 8 เช่นกัน
   ```
3. **Default Parameter Values:** กำหนดค่าเริ่มต้นให้กับพารามิเตอร์ หากผู้เรียกไม่ได้ส่งค่ามา จะใช้ค่าเริ่มต้นนั้นโดยอัตโนมัติ
   ```python
   def greet(name, msg="Hello"):
       return f"{msg}, {name}!"

   print(greet("Somchai"))           # 'Hello, Somchai!'
   print(greet("Somsri", "Good morning")) # 'Good morning, Somsri!'
   ```

> [!WARNING]
> กฎเหล็ก: พารามิเตอร์ที่มีค่า Default **ต้องอยู่ด้านหลังพารามิเตอร์ที่ไม่มีค่า Default เสมอ**
> `def bad_func(a=10, b):` $\rightarrow$ จะเกิด `SyntaxError: non-default argument follows default argument`

### 3. ฟังก์ชันแบบส่งค่ากลับและไม่ส่งค่ากลับ (Fruitful vs Void Functions)

#### 1) Fruitful Functions (ฟังก์ชันที่ส่งค่ากลับ)
คือฟังก์ชันที่มีคำสั่ง `return <value>` เมื่อทำงานจบ ฟังก์ชันจะคืนค่านั้นกลับไปยังตำแหน่งที่เรียกใช้งาน สามารถนำผลลัพธ์ไปเก็บใส่ตัวแปรหรือส่งต่อเข้าสู่นิพจน์อื่นได้

```python
def add(a, b):
    return a + b

result = add(5, 3) * 2   # result = 8 * 2 = 16
```

#### 2) Void Functions (ฟังก์ชันที่ไม่ส่งค่ากลับ)
คือฟังก์ชันที่ทำหน้าที่บางอย่าง (เช่น แสดงผลบนจอ หรือบันทึกไฟล์) แต่ไม่มีคำสั่ง `return` (หรือเขียนแค่ `return` เปล่า ๆ)
- ใน Python ฟังก์ชัน Void **จะส่งคืนค่าพิเศษคือ `None` เสมอ**
- หากนำฟังก์ชัน Void ไปรับค่าใส่ตัวแปร ตัวแปรนั้นจะมีค่าเป็น `None` (ชนิดข้อมูล `NoneType`)

```python
def show_alert(msg):
    print(f"[ALERT] {msg}")
    # ไม่มี return

val = show_alert("Disk full")   # จอแสดง: [ALERT] Disk full
print(val)                      # จอแสดง: None
```

```
เปรียบเทียบการทำงาน:
  Fruitful:  ผู้เรียก ──เรียกใช้งาน──> [ ฟังก์ชัน ] ──ส่งค่า return ──> ผู้เรียกนำไปคำนวณต่อ
  Void:      ผู้เรียก ──เรียกใช้งาน──> [ ฟังก์ชัน ] ──ส่งผลลัพธ์จอ/ไฟล์ ──> ส่งคืน None
```

### 4. ขอบเขตตัวแปร (Variable Scope) และกฎ LEGB

**Scope (ขอบเขต)** คือบริเวณในโปรแกรมที่ตัวแปรนั้นมีตัวตนและสามารถเข้าถึงได้

Python ค้นหาค่าของตัวแปรตามลำดับ **LEGB Rule**:
1. **L — Local:** ตัวแปรที่ประกาศขึ้นภายในฟังก์ชันปัจจุบัน
2. **E — Enclosing:** ตัวแปรในฟังก์ชันชั้นนอกที่ครอบฟังก์ชันปัจจุบันอยู่ (กรณี Nested Function)
3. **G — Global:** ตัวแปรที่ประกาศอยู่นอกสุดของไฟล์สคริปต์
4. **B — Built-in:** ชื่อที่ระบบ Python มีให้อัตโนมัติ เช่น `len`, `range`, `print`, `int`

#### กฎขอบเขตและการทำงาน
- ตัวแปร **Local** จะถูกสร้างขึ้นเมื่อฟังก์ชันเริ่มทำงาน และจะ **ถูกทำลายทิ้ง** เมื่อฟังก์ชันทำงานจบ โค้ดภายนอกฟังก์ชันจะไม่สามารถมองเห็นหรือเรียกใช้ตัวแปร Local ได้
- โค้ดในฟังก์ชันสามารถ **อ่านค่า** ของตัวแปร Global ได้ทันทีโดยไม่ต้องประกาศอะไรเพิ่ม
- หากต้องการ **แก้ไขค่าหรือเขียนทับ (Reassign)** ตัวแปร Global ภายในฟังก์ชัน จำเป็นต้องใช้คีย์เวิร์ด `global` กำกับไว้

```python
x = 10   # Global variable

def test_scope():
    global x
    x = 20   # เปลี่ยนแปลงค่าของ global x ได้สำเร็จ

test_scope()
print(x)     # พิมพ์ 20
```

> [!CAUTION]
> หากพยายามเขียนคำสั่ง `x = x + 1` ภายในฟังก์ชันโดยไม่ประกาศ `global x`
> Python จะมองว่า `x` ทางซ้ายคือตัวแปร Local ทันที ทำให้ `x` ทางขวาเกิดข้อผิดพลาด:
> **`UnboundLocalError: local variable 'x' referenced before assignment`**

### 5. การนำเข้ามอดูล (Module Imports)

มอดูลคือไฟล์ที่มีการรวบรวมฟังก์ชันและตัวแปรที่เกี่ยวข้องไว้ใช้งาน เช่น มอดูลคณิตศาสตร์มาตรฐาน `math`

| รูปแบบการ Import | วิธีเรียกใช้งาน | ข้อดี / ข้อควรระวัง |
|---|---|---|
| `import math` | `math.sqrt(16)` | ป้องกันปัญหาชื่อฟังก์ชันชนกัน (Name collision) แนะนำที่สุด |
| `from math import sqrt, pi` | `sqrt(16)`, `pi` | สะดวก ไม่ต้องพิมพ์ชื่อมอดูลนำหน้า |
| `import math as m` | `m.sqrt(16)` | ใช้นามแฝง (Alias) ย่นย่อชื่อที่ยาว |
| `from math import *` | `sqrt(16)` | ⚠️ ไม่แนะนำ: อาจทำให้ชื่อฟังก์ชันไปทับกับตัวแปรที่เราสร้างไว้ |

#### ฟังก์ชันและค่าคงที่ที่ใช้บ่อยในมอดูล `math`:
- `math.pi`: ค่าคงที่ $\pi \approx 3.14159265...$
- `math.sqrt(x)`: หารากที่สอง $\sqrt{x}$ (ส่งคืนค่าเป็น `float`)
- `math.ceil(x)`: ปัดเศษขึ้นเป็นจำนวนเต็มที่ใกล้ที่สุด
- `math.floor(x)`: ปัดเศษลงเป็นจำนวนเต็มที่ใกล้ที่สุด
- `math.gcd(a, b)`: หาตัวหารร่วมมาก (ห.ร.ม.)
- `math.factorial(n)`: คำนวณ $n!$

### 6. ฟังก์ชันประกอบ (Composite Functions)

ฟังก์ชันประกอบทางคณิตศาสตร์ $(f \circ g)(x) = f(g(x))$ ทำงานโดย:
1. นำค่า $x$ ส่งเข้าไปคำนวณในฟังก์ชันด้านใน $g(x)$ ก่อน
2. นำผลลัพธ์ที่ได้จาก $g(x)$ ส่งเป็นอาร์กิวเมนต์ต่อไปให้ฟังก์ชันด้านนอก $f(...)$

```python
def square(x):
    return x * x

def double(x):
    return x * 2

# คำนวณ square(double(3))
# 1. double(3) = 6
# 2. square(6) = 36
print(square(double(3)))   # 36

# คำนวณ double(square(3))
# 1. square(3) = 9
# 2. double(9) = 18
print(double(square(3)))   # 18
```


5. **`git push origin <branch-name>`:** ส่ง commit ขึ้นสู่ Remote repository บน GitHub
6. **สร้าง Pull Request (PR):** ไปที่หน้า GitHub ของ repository เพื่อเปิด PR ส่งงานให้อาจารย์และ TA ตรวจสอบ

## จุดที่มักพลาด

- **สับสนระหว่าง `print()` กับ `return`:**
  - นำค่าที่ได้จากฟังก์ชันที่สั่งแค่ `print()` ไปคำนวณต่อ เช่น `total = calc_tax(price) + price`
  - หาก `calc_tax` จบด้วย `print()` โดยไม่มี `return` ค่าของ `calc_tax(price)` จะเป็น `None`
  - นำ `None + price` จะเกิดข้อผิดพลาดทันที: `TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'`
- **ลืมส่งค่ากลับใน Fruitful Function ทุกกิ่งเงื่อนไข (Missing return path):**
  ```python
  def check_sign(n):
      if n > 0:
          return "Positive"
      elif n < 0:
          return "Negative"
      # หาก n == 0 ฟังก์ชันนี้จะหลุดออกไปโดยไม่มี return ส่งผลให้ได้ None กลับไป!
  ```
- **การใช้ Default Argument ที่เป็น Mutable Object (เช่น List):**
  - ค่า Default argument จะถูกประเมินค่าเพียง **ครั้งเดียว** ในตอนที่ Python นิยามฟังก์ชัน
  - หากเขียน `def add_item(val, lst=[]): lst.append(val); return lst`
  - ทุกครั้งที่เรียก `add_item` โดยไม่ส่งพารามิเตอร์ตัวที่สอง ค่าจะถูกสะสมใน List ก้อนเดิมข้ามการเรียก ไม่ได้สร้าง List ใหม่ทุกครั้ง!
- **UnboundLocalError จากการเผลอสร้างตัวแปร Local ชื่อเดียวกับ Global:**
  ```python
  count = 0
  def increment():
      print(count)   # พังตรงนี้! เพราะ Python เห็นว่าบรรทัดถัดไปมี count = ...
      count = 5      # จึงถือว่า count คือ Local variable ทันทีตั้งแต่เริ่มฟังก์ชัน
  ```
- **วาง Non-default argument ไว้หลัง Default argument:**
  - `def order(drink="Water", size):` เป็นไวยากรณ์ที่ผิด ต้องแก้เป็น `def order(size, drink="Water"):`
