## อ่านจบแล้วต้องตอบได้

- อธิบายการทำงานของลูปซ้อนลูป (Nested Loops): ลูปนอกควบคุมแถวแนวดิ่ง ($y$ หรือ $i$) ลูปในควบคุมคอลัมน์แนวนอน ($x$ หรือ $j$)
- ควบคุมการแสดงผลด้วย `print(..., end="")` เพื่อพิมพ์ในบรรทัดเดิม และใช้ `print()` ว่างเพื่อขึ้นบรรทัดใหม่เมื่อจบลูปใน
- คำนวณระยะพิกัดและความสมมาตร (Coordinate Mathematics) เช่น `abs(row - mid)` และ `abs(col - mid)` สำหรับรูปทรง Diamond, Arrow และ Cross
- ประยุกต์ใช้สตริงเมท็อดสำหรับการจัดตำแหน่งข้อความและการตีเส้นกรอบ: `.ljust()`, `.rjust()`, `.center()` ร่วมกับการหาความยาวสูงสุดด้วย `max()`
- ระวังและจัดการช่องว่างส่วนเกินท้ายบรรทัด (Trailing Whitespace) ที่ทำให้ระบบ OJ ตรวจไม่ผ่าน

### 1. โครงสร้างลูป 2 มิติ (Row-Major Nested Loops)

การแสดงผลลวดลาย 2 มิติบนหน้าจอคอนโซลทำงานตามลำดับจาก **บนลงล่าง** และจาก **ซ้ายไปขวา** (Row-major order) เสมอ เราไม่สามารถขยับเคอร์เซอร์ย้อนกลับไปบรรทัดบนได้ ดังนั้น:

1. **ลูปนอก (Outer Loop)**: วนรอบตามแนวตั้ง (แกน $Y$ หรือแถว `row` / $i$)
2. **ลูปใน (Inner Loop)**: วนรอบตามแนวนอน (แกน $X$ หรือคอลัมน์ `col` / $j$)
3. **การขึ้นบรรทัดใหม่**: เมื่อลูปในพิมพ์อักขระครบทุกคอลัมน์ในแถวนั้นแล้ว ต้องสั่ง `print()` (ไม่ใส่พารามิเตอร์) หนึ่งครั้งเพื่อขึ้นบรรทัดใหม่สำหรับแถวถัดไป

```python
rows = 4
cols = 5

for r in range(rows):         # ลูปนอก: แถวที่ 0 ถึง 3
    for c in range(cols):     # ลูปใน: คอลัมน์ที่ 0 ถึง 4
        print(f"({r},{c})", end=" ")
    print()                   # จบหนึ่งแถว ให้ขึ้นบรรทัดใหม่
```

```text
(0,0) (0,1) (0,2) (0,3) (0,4) 
(1,0) (1,1) (1,2) (1,3) (1,4) 
(2,0) (2,1) (2,2) (2,3) (2,4) 
(3,0) (3,1) (3,2) (3,3) (3,4) 
```

### 2. คณิตศาสตร์พิกัดและการวาดรูปทรงเรขาคณิต (Coordinate Math)

โจทย์วาดรูปร่าง 2 มิติมักกำหนดขนาด $N$ (มักเป็นเลขคี่เพื่อให้มีจุดกึ่งกลางที่สมบูรณ์) การหาจุดกึ่งกลางและระยะห่างช่วยให้เขียนเงื่อนไขได้สั้นและรวดเร็ว

#### 2.1 จุดกึ่งกลางและระยะห่าง (Midpoint & Distance)

กำหนดให้ $N$ เป็นจำนวนแถว (เลขคี่):
$$\text{mid} = N // 2$$

ระยะห่างของแถวปัจจุบันจากจุดกึ่งกลาง:
$$\text{dist\_r} = |r - \text{mid}| = \text{abs}(r - \text{mid})$$

| ค่า $r$ ($N=5, \text{mid}=2$) | คำนวณ $\text{abs}(r - 2)$ | ลักษณะแถว |
|:---:|:---:|---|
| $r = 0$ | $|0 - 2| = 2$ | ไกลสุด (แถวบนสุด) |
| $r = 1$ | $|1 - 2| = 1$ | ระยะ 1 |
| $r = 2$ | $|2 - 2| = 0$ | **จุดกึ่งกลาง** (แกนสมมาตร) |
| $r = 3$ | $|3 - 2| = 1$ | ระยะ 1 |
| $r = 4$ | $|4 - 2| = 2$ | ไกลสุด (แถวล่างสุด) |

สังเกตว่าค่าระยะห่างจะวิ่งเป็นลำดับสมมาตร: $2 \to 1 \to 0 \to 1 \to 2$

#### 2.2 รูปทรงข้าวหลามตัด (Diamond)
รูปข้าวหลามตัดขนาด $N \times N$ ($N$ เป็นเลขคี่) มีสมบัติว่าผลรวมระยะห่างจากจุดกึ่งกลางทั้งสองแกน $\le \text{mid}$:
$$\text{abs}(r - \text{mid}) + \text{abs}(c - \text{mid}) \le \text{mid}$$

หรือเขียนด้วยเทคนิค String Multiplication ในแต่ละแถว $r$:
- จำนวนช่องว่างด้านหน้า (Leading Spaces) = $\text{abs}(r - \text{mid})$
- จำนวนดาว (`*`) = $N - 2 \times \text{abs}(r - \text{mid})$

```python
n = 5
mid = n // 2

for r in range(n):
    spaces = abs(r - mid)
    stars = n - 2 * spaces
    print(" " * spaces + "*" * stars)
```

```text
  *
 ***
*****
 ***
  *
```

#### 2.3 รูปทรงลูกศร (Arrows)
- **ลูกศรชี้ขวา (Right Arrow)**: หัวลูกศรยื่นไปทางขวา ช่องว่างนำหน้าแถวจะเพิ่มขึ้นจนถึงกึ่งกลางแล้วลดลง หรือความยาวของแถวจะเพิ่มขึ้นเรื่อย ๆ จนถึงกึ่งกลาง
- **ลูกศรชี้ซ้าย (Left Arrow)**: ช่องว่างนำหน้าแถวจะลดลงจนถึงกึ่งกลางแล้วเพิ่มขึ้น
- กุญแจสำคัญคือการหาฟังก์ชันระหว่างแถว $r$ กับจำนวนช่องว่างหรือดาว โดยใช้ `abs(r - mid)` หรือแบ่งเป็น 2 ช่วง (ครึ่งบน $0 \dots \text{mid}$ และครึ่งล่าง $\text{mid}+1 \dots N-1$)

#### 2.4 รูปทรงกากบาทและเส้นทแยงมุม (Cross / Diagonal)
สำหรับตารางขนาด $N \times N$:
- **เส้นทแยงมุมหลัก (Main Diagonal)**: เซลล์ที่แถวเท่ากับคอลัมน์ ($r == c$)
- **เส้นทแยงมุมรอง (Anti-Diagonal)**: เซลล์ที่ผลรวมแถวกับคอลัมน์เท่ากับ $N - 1$ ($r + c == N - 1$)

```python
n = 5
for r in range(n):
    for c in range(n):
        if r == c or r + c == n - 1:
            print("*", end="")
        else:
            print(" ", end="")
    print()
```

```text
*   *
 * * 
  *  
 * * 
*   *
```

### 3. การสร้างกรอบข้อความและการจัดวาง (Framing & Text Alignment)

เมื่อโจทย์ต้องการใส่กรอบล้อมรอบข้อความหลายบรรทัด (เช่น ข้อสอบหรือโจทย์ BigFrame):

1. **หาความยาวข้อความที่ยาวที่สุด**: วนรับค่าข้อความทั้งหมดเก็บลงใน List แล้วใช้ `max(len(s) for s in lines)`
2. **ใช้ String Methods ช่วยจัดตำแหน่ง**:
   - `s.ljust(width, [fillchar])` — จัดข้อความชิดซ้าย เติมช่องว่างด้านขวาจนครบ `width`
   - `s.rjust(width, [fillchar])` — จัดข้อความชิดขวา เติมช่องว่างด้านซ้ายจนครบ `width`
   - `s.center(width, [fillchar])` — จัดข้อความกึ่งกลาง เติมช่องว่างสองข้างอย่างสมดุล
3. **ประกอบเส้นกรอบ**:
   - ขอบบนและล่าง: ใช้ `print("*" * (max_len + 4))` (บวก 4 สำหรับ `*` หน้าหลัง และเว้นวรรค)
   - เนื้อหาในกรอบ: `print(f"* {line.ljust(max_len)} *")`

```python
lines = ["KMITL", "Computer Programming", "Python 3"]
max_len = max(len(s) for s in lines)

# ขอบบน
print("*" * (max_len + 4))

# เนื้อหาแต่ละบรรทัด
for line in lines:
    print(f"* {line.ljust(max_len)} *")

# ขอบล่าง
print("*" * (max_len + 4))
```

```text
************************
* KMITL                *
* Computer Programming *
* Python 3             *
************************
```

### 4. สรุปเปรียบเทียบ: String Multiplication vs Nested Loops

| วิธี | ตัวอย่าง | ข้อดี | เหมาะสำหรับ |
|---|---|---|---|
| **String Multiplication** | `" " * spaces + "*" * stars` | โค้ดสั้น กระชับ ทำงานเร็วกว่าใน Python | รูปร่างตันที่มีแถวสม่ำเสมอ เช่น สี่เหลี่ยม, สามเหลี่ยม, ข้าวหลามตัด |
| **Nested Loops** | `for r in ...:`<br>&nbsp;&nbsp;`for c in ...:` | มีความยืดหยุ่นสูง ตรวจเงื่อนไขพิกัดทีละจุดได้ | ลวดลายโปร่ง, เส้นทแยงมุม, ตารางหมากรุก, ลายตัวเลขรัน |

---

## จุดที่มักพลาด

1. **สลับตัวแปรแถวกับคอลัมน์ ($r$ กับ $c$)**:
   นำตัวแปรลูปนอกไปใช้ในตำแหน่งคอลัมน์ หรือลูปในไปใช้กับแถว ส่งผลให้รูปพลิกแนวทแยง (Transpose) หรือผลลัพธ์บิดเบี้ยว
2. **ช่องว่างส่วนเกินท้ายบรรทัด (Trailing Whitespaces)**:
   ระบบตรวจข้อสอบ OJ ตรวจสอบอย่างละเอียดระดับไบต์ หากพิมพ์ `"*" + " "` เกินไปท้ายบรรทัด ระบบจะตัดสินเป็น `Wrong Answer` หรือ `Presentation Error` ทันที
   > **คำแนะนำ**: พิมพ์เฉพาะช่องว่างนำหน้า (Leading spaces) และอักขระ เมื่อจบลายให้ขึ้นบรรทัดใหม่ทันทีโดยไม่พิมพ์ช่องว่างต่อท้าย
3. **Off-by-One ใน `range()`**:
   ลืมว่า `range(n)` สร้างลำดับ $0$ ถึง $n-1$ หากต้องการแถวที่ $1$ ถึง $n$ ต้องระบุ `range(1, n + 1)`
4. **ความสับสนเมื่อ $N$ เป็นเลขคู่**:
   รูปทรงสมมาตรบางรูปแบบต้องการจุดกึ่งกลาง หากขนาดอินพุตเป็นเลขคู่ ฟังก์ชัน `n // 2` จะให้จุดศูนย์กลางค่อนไปทางหนึ่ง ต้องอ่านเงื่อนไขโจทย์ให้แน่ชัดว่าต้องการปัดเศษอย่างไร

## ทดสอบตัวเอง

### คำถามที่ 1
หากต้องการพิมพ์ตารางหมากรุกขนาด $N \times N$ โดยสลับตัวอักษร `#` และ `.` โดยให้ตำแหน่งมุมซ้ายบน `(0, 0)` เป็น `#` เงื่อนไขในลูปควรเขียนอย่างไร?

<details>
<summary>ดูแนวคิดและเฉลย</summary>

ใช้ผลรวมของดัชนีแถวและคอลัมน์ `(r + c) % 2 == 0`:
เมื่อ $r + c$ เป็นเลขคู่ ให้พิมพ์ `#` และเมื่อเป็นเลขคี่ ให้พิมพ์ `.`
เพราะที่จุดเริ่มต้น `(0, 0)` มีผลรวมคือ $0$ (คู่) เมื่อขยับไปทางขวาหรือลงล่าง ผลรวมจะสลับระหว่างคู่และคี่เสมอ
</details>

### คำถามที่ 2
คำสั่ง `"Hello".center(10, "-")` และ `"Hello".ljust(8, ".")` จะให้ผลลัพธ์เป็นข้อความใด?

<details>
<summary>ดูแนวคิดและเฉลย</summary>

- `"Hello".center(10, "-")`: ความยาวเดิม 5 ต้องเติมให้ครบ 10 ช่อง (ขาด 5 ช่อง ด้านซ้ายเติม 2 ด้านขวาเติม 3) ได้ผลลัพธ์คือ `"--Hello---"`
- `"Hello".ljust(8, ".")`: จัดชิดซ้าย เติมจุดด้านขวา 3 จุด ได้ผลลัพธ์คือ `"Hello..."`
</details>

### คำถามที่ 3
ทำไมการเขียน `print("*" * stars + " " * spaces)` ท้ายบรรทัดจึงอาจทำให้ได้ผลตรวจ Wrong Answer บนระบบ iJudge?

<details>
<summary>ดูแนวคิดและเฉลย</summary>

เพราะการเติม `" " * spaces` หลังรูปดาวตัวสุดท้ายจะสร้าง "Trailing Whitespace" (ช่องว่างท้ายบรรทัด) ซึ่งสายตามนุษย์มองไม่เห็น แต่ระบบตรวจอัตโนมัติเปรียบเทียบสตริงแบบตัวต่อตัว จึงถือว่าผลลัพธ์ไม่ตรงกับ Output มาตรฐานที่ไม่มีช่องว่างท้ายบรรทัด
</details>
