### 2. เทคนิคการไล่โค้ดด้วยตารางสถานะ (Systematic Code Tracing)

> [!IMPORTANT]
> กฎเหล็กในการทำข้อสอบอ่านโค้ด: **"ห้ามไล่โค้ดในหัวเด็ดขาด ให้ขีดตารางทดลงในกระดาษข้อสอบเสมอ"**

การไล่โค้ดทีละบรรทัด (Line-by-line Execution) ร่วมกับการทำ **Variable Tracking Table (ตารางสถานะ)**:
- **แถว (Rows):** แสดงรอบของการทำงาน (Iteration) หรือหมายเลขบรรทัด
- **คอลัมน์ (Columns):** กำหนดให้มีคอลัมน์ของตัวแปรสำคัญทุกตัว, เงื่อนไขที่ตรวจสอบ, และผลลัพธ์ที่พิมพ์ออกทางหน้าจอ (Output Screen)

#### ตัวอย่างการไล่โค้ด:

```python
total = 0
s = "P3S2C1"
for i in range(len(s)):
    if s[i].isdigit():
        val = int(s[i])
        total += val * 2
    else:
        total += 1
print(f"Total={total}")
```

#### ตารางการทดลงกระดาษ (State Table):

| ลำดับรอบ | `i` | `s[i]` | `s[i].isdigit()` | `val` | `total` (ค่าก่อน $\rightarrow$ ค่าใหม่) | จอแสดงผล (Output) |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| ก่อนเริ่ม | — | — | — | — | `0` | — |
| รอบ 0 | 0 | `'P'` | `False` | — | $0 + 1 \rightarrow$ **`1`** | — |
| รอบ 1 | 1 | `'3'` | `True` | 3 | $1 + (3 \times 2) \rightarrow$ **`7`** | — |
| รอบ 2 | 2 | `'S'` | `False` | — | $7 + 1 \rightarrow$ **`8`** | — |
| รอบ 3 | 3 | `'2'` | `True` | 2 | $8 + (2 \times 2) \rightarrow$ **`12`** | — |
| รอบ 4 | 4 | `'C'` | `False` | — | $12 + 1 \rightarrow$ **`13`** | — |
| รอบ 5 | 5 | `'1'` | `True` | 1 | $13 + (1 \times 2) \rightarrow$ **`15`** | — |
| พิมพ์ผล | — | — | — | — | `15` | **`Total=15`** |

### 3. แผนผังจำแนกประเภทข้อผิดพลาด (Diagnosing Python Errors)

ข้อสอบมักถามว่า "โค้ดต่อไปนี้เกิดข้อผิดพลาดประเภทใด":

| ชื่อ Exception | สาเหตุของการเกิด | ตัวอย่างโค้ดที่เกิดปัญหา | ตัวอย่างการแก้ |
|---|---|---|---|
| **`SyntaxError`** | ไวยากรณ์ผิดตั้งแต่ขั้นตอนแปลงโค้ด (Compile-time) เช่น ลืม `:`, วงเล็บไม่ครบ | `if x > 0` (ขาดเครื่องหมาย `:`) | `if x > 0:` |
| **`IndentationError`** | การย่อหน้าไม่ถูกต้อง หรือผสม tab กับ space | `def f():`<br>`print("hi")` (ไม่เว้นวรรค) | `def f():`<br>`    print("hi")` |
| **`NameError`** | อ้างอิงตัวแปรหรือฟังก์ชันที่ยังไม่ได้ประกาศ หรือสะกดชื่อผิด | `print(total_score)` (ตัวแปรยังไม่มีอยู่) | กำหนดค่าตัวแปรก่อนเรียกใช้ |
| **`TypeError`** | การกระทำผิดชนิดข้อมูล เช่น เอาสตริงมาบวกกับตัวเลข หรือส่งอาร์กิวเมนต์ผิดประเภท | `'Score: ' + 100`<br>`len(12345)` | `'Score: ' + str(100)`<br>`len(str(12345))` |
| **`ValueError`** | ชนิดข้อมูลถูก แต่ค่าข้างในไม่ถูกต้องตามที่ฟังก์ชันรับได้ | `int("hello")`<br>`math.sqrt(-4)` | ตรวจสอบด้วย `.isdigit()` ก่อนแปลง |
| **`IndexError`** | ระบุดัชนีของ Sequence (สตริง/ลิสต์) เกินขอบเขตที่มีอยู่ | `s = "CAT"`<br>`print(s[3])` | ตรวจสอบขอบเขต `0` ถึง `len(s)-1` |
| **`ZeroDivisionError`** | การหารหรือการมอดุโลด้วยเลข 0 | `10 / 0`<br>`x % 0` | ตรวจสอบตัวหารก่อนว่าไม่ใช่ 0 |
| **`UnboundLocalError`** | อ้างอิงตัวแปรในฟังก์ชันก่อนกำหนดค่า (เกิดเมื่อมีการเขียนทับตัวแปรชื่อเดียวกับ Global) | `def f():`<br>`  x += 1`<br>(โดยมี `x = 5` อยู่ข้างนอก) | ใส่ `global x` ภายในฟังก์ชัน |

### 4. ลำดับความสำคัญของตัวดำเนินการ (Operator Precedence)

เมื่อมีหลายตัวดำเนินการในบรรทัดเดียวกัน Python จะคำนวณจาก **ลำดับความสำคัญสูงสุดไปต่ำสุด**:

| ลำดับ | ตัวดำเนินการ | รายละเอียดการทำงาน | Associativity |
|:---:|---|---|:---:|
| 1 | `()` | วงเล็บ (คำนวณก่อนเสมอ) | จากในออกนอก |
| 2 | `**` | การยกกำลัง | **ขวาไปซ้าย** ($2^{3^2} = 2^9 = 512$) |
| 3 | `+x`, `-x` | เครื่องหมายบวก/ลบประจำตัวเลข (Unary) | ขวาไปซ้าย |
| 4 | `*`, `/`, `//`, `%` | คูณ, หาร, หารปัดลง, มอดุโล | ซ้ายไปขวา |
| 5 | `+`, `-` | บวก, ลบ (Binary) | ซ้ายไปขวา |
| 6 | `<`, `<=`, `>`, `>=`, `==`, `!=` | ตัวดำเนินการเปรียบเทียบ | ซ้ายไปขวา |
| 7 | **`not`** | นิเสธทางตรรกศาสตร์ | ขวาไปซ้าย |
| 8 | **`and`** | เชื่อมตรรกะ "และ" | ซ้ายไปขวา |
| 9 | **`or`** | เชื่อมตรรกะ "หรือ" | ซ้ายไปขวา |

> [!WARNING]
> ท่องจำลำดับตรรกะ: **`not` มาก่อน `and` และ `and` มาก่อน `or` เสมอ**
> นิพจน์ `True or False and False` จะคำนวณ `False and False` เป็น `False` ก่อน แล้วจึงนำ `True or False` ส่งผลลัพธ์เป็น **`True`**

### 5. กลไก Short-circuit Evaluation ในนิพจน์ตรรกะ

Python ประเมินค่านิพจน์ตรรกะจากซ้ายไปขวา และจะ **หยุดทันทีเมื่อทราบผลลัพธ์ที่แน่นอน**:

1. **`A and B`:**
   - หาก `A` เป็น `False` $\implies$ นิพจน์ทั้งหมดต้องเป็นเท็จแน่นอน Python จะ **ไม่ประเมินค่า `B` ต่อ**
   - ประโยชน์: ใช้ป้องกัน Error ได้ เช่น `if len(s) > 0 and s[0] == 'A':` (หาก `s` ว่าง จะไม่รัน `s[0]` จึงไม่เกิด `IndexError`)
2. **`A or B`:**
   - หาก `A` เป็น `True` $\implies$ นิพจน์ทั้งหมดต้องเป็นจริงแน่นอน Python จะ **ไม่ประเมินค่า `B` ต่อ**

### 6. การหารและมอดุโลกับจำนวนเต็มลบ (Floor Division & Modulo)

Python นิยามการหารปัดลง (`//`) ว่าเป็นการปัดเศษลงสู่ **จำนวนเต็มที่น้อยกว่าหรือเท่ากับค่านั้นเสมอ (Floor towards $-\infty$)**:

$$\text{ผลลัพธ์} = \lfloor a / b \rfloor$$
$$a = (b \times (a // b)) + (a \% b)$$

```python
# การหารจำนวนบวก
print(7 // 2)      # 3   (เพราะ 3.5 ปัดลงเป็น 3)
print(7 % 2)       # 1   (เพราะ 7 = (2 * 3) + 1)

# การหารจำนวนลบ (ออกสอบบ่อยมาก!)
print(-7 // 2)     # -4  (เพราะ -3.5 ปัดลงสู่ลบอนันต์ได้ -4 ไม่ใช่ -3!)
print(-7 % 2)      # 1   (เพราะ -7 = (2 * -4) + 1)

print(7 // -2)     # -4
print(7 % -2)      # -1  (เพราะ 7 = (-2 * -4) + -1)
```

## จุดที่มักพลาด

- **ลืมอัปเดตตัวแปร Accumulator ในตารางทด:** เมื่อวนลูป ตัวแปรผลรวม (เช่น `sum`, `count`, `flag`) มักถูกเปลี่ยนแปลงค่า แต่ผู้สอบมักเผลอใช้ค่าเดิมของรอบก่อนหน้า ทำให้คำนวณรอบถัดไปผิดทั้งหมด
- **ความสับสนเกี่ยวกับช่วงของ `range(start, stop, step)`:**
  - `range(1, 5)` ได้เลข `1, 2, 3, 4` (**ไม่รวม 5**)
  - `range(5, 0, -1)` ได้เลข `5, 4, 3, 2, 1` (**ไม่รวม 0**)
- **การพิมพ์ผลลัพธ์ `print()` ตกหล่นช่องว่างหรือขึ้นบรรทัดใหม่:**
  - `print("A", "B")` มีช่องว่างคั่น 1 ช่องเป็นค่าเริ่มต้น (`A B`)
  - `print("A", "B", sep="")` ไม่มีช่องว่างคั่น (`AB`)
  - หากสั่ง `print("X", end="")` ตัวอักษรต่อไปจะพิมพ์ติดกันในบรรทัดเดิม
- **สมมุติว่าเงื่อนไข `elif` จะถูกตรวจเสมอ:**
  - จำไว้ว่าในโครงสร้าง `if-elif-else` หากมีกิ่งใดกิ่งหนึ่งเป็นจริงแล้ว กิ่งที่เหลือทั้งหมดจะถูก **ข้ามทันที** แม้ว่าเงื่อนไขในกิ่งล่างจะเป็นจริงด้วยก็ตาม
- **การเปรียบเทียบสายอักขระ (Lexicographical Comparison):**
  - `'10' < '2'` ได้ผลลัพธ์เป็น **`True`** เพราะเปรียบเทียบตามรหัส ASCII ของอักขระตัวแรก (`'1'` มาก่อน `'2'`) ไม่ใช่เปรียบเทียบเชิงตัวเลข!

   ```python
   def process(data):
       items = data.split(",")
       total = 0
       for item in items:
           val = item.strip()
           total += int(val)
       return total

   print(process("10, 20, , 40"))
   ```

1. **เฉลยข้อ 1:** พิมพ์ **`-4 -1`**
   - *คำอธิบาย:*
     - $15 / -4 = -3.75$ ปัดลงสู่ลบอนันต์ได้ `-4`
     - จากสมการ $a = (b \times q) + r \implies 15 = (-4 \times -4) + r \implies 15 = 16 + r \implies r = -1$
2. **เฉลยข้อ 2:** พิมพ์ **`geca`**
   - *คำอธิบาย:*
     - ความยาวสตริง `len("abcdefg")` = 7 ดังนั้น `len(s) - 1` = 6
     - `range(6, -1, -2)` จะสร้างลำดับดัชนี: `6, 4, 2, 0`
     - $s[6] = \text{'g'}$, $s[4] = \text{'e'}$, $s[2] = \text{'c'}$, $s[0] = \text{'a'}$
     - นำมาต่อกันได้ `'geca'`
3. **เฉลยข้อ 3:** ได้ค่า **`True`**
   - *คำอธิบาย:*
     - ลำดับที่ 1 (เปรียบเทียบ): `5 > 3` เป็น `True`, `10 == 10` เป็น `True`, `2 == 3` เป็น `False`
     - นิพจน์กลายเป็น: `not True or True and not False`
     - ลำดับที่ 2 (`not`): `not True` ได้ `False`, `not False` ได้ `True`
     - นิพจน์กลายเป็น: `False or True and True`
     - ลำดับที่ 3 (`and`): `True and True` ได้ `True`
     - นิพจน์กลายเป็น: `False or True`
     - ลำดับที่ 4 (`or`): ได้ผลลัพธ์สุดท้ายเป็น `True`
4. **เฉลยข้อ 4:** เกิดข้อผิดพลาด **`ValueError`** ที่บรรทัด `total += int(val)`
   - *คำอธิบาย:* ในสตริง `"10, 20, , 40"` มีสมาชิกตัวที่ 3 เป็นช่องว่างว่างเปล่า เมื่อสั่ง `.strip()` จะได้สตริงว่าง `""` ซึ่งไม่สามารถแปลงเป็นจำนวนเต็มด้วย `int("")` ได้ จึงเกิด `ValueError: invalid literal for int() with base 10: ''`

</details>
