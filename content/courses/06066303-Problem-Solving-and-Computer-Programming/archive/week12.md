- แยกประเภทชนิดข้อมูลที่สามารถเป็น **Key** ของ Dictionary และสมาชิกของ Set ได้ (Immutable / Hashable vs Unhashable types)

- วิเคราะห์และป้องกันข้อผิดพลาดคลาสสิก: `KeyError`, `TypeError: unhashable type`, การแก้ไขขนาด Collection ขณะกำลังวนซ้ำ และหลีกเลี่ยง TLE จากการค้นหาใน List

### 1. โครงสร้างข้อมูล Dictionary (คู่คีย์-ค่า Key-Value Mapping)

Dictionary ใน Python เป็นโครงสร้างข้อมูลประเภท **Associative Array** หรือ **Mapping** ที่จับคู่ระหว่าง **Key (คีย์)** และ **Value (ค่า)** เข้าด้วยกัน แทนที่จะอ้างอิงตำแหน่งด้วยดัชนีตัวเลข $0, 1, 2, \dots$ เหมือนใน List

```python
# การสร้าง Dictionary
empty_dict = {}          # หรือ dict()
student = {
    "id": "67070001",
    "name": "Somchai",
    "gpa": 3.75,
    "passed": True
}
```

#### เปรียบเทียบโครงสร้างข้อมูลหลักใน Python

| คุณสมบัติ | List `[]` | Tuple `()` | Set `{}` | Dictionary `{k: v}` |
|---|---|---|---|---|
| **รูปแบบข้อมูล** | ลำดับค่าเดี่ยว | ลำดับค่าเดี่ยว | กลุ่มค่าเดี่ยวไม่ซ้ำ | คู่ `Key: Value` |
| **การแก้ไขค่า (Mutability)** | Mutable (แก้ไขได้) | Immutable (คงที่) | Mutable (แก้ไขได้) | Mutable (แก้ไขได้) |
| **ลำดับ (Order)** | เรียงตามลำดับดัชนี | เรียงตามลำดับดัชนี | ไม่มีลำดับทางคณิตศาสตร์ | คงลำดับการใส่ (Insertion order)* |
| **สมาชิกซ้ำได้ไหม** | ซ้ำได้ | ซ้ำได้ | **ห้ามซ้ำ** | Key ห้ามซ้ำ (Value ซ้ำได้) |
| **การค้นหา `x in col`** | $O(n)$ — สแกนทีละตัว | $O(n)$ — สแกนทีละตัว | **$O(1)$ เฉลี่ย** — Hashing | **$O(1)$ เฉลี่ย** บน Key |

*\*หมายเหตุ: ตั้งแต่ Python 3.7 เป็นต้นมา Dictionary การันตีการจำลำดับการใส่ข้อมูล (Insertion-order preservation) แต่กลไกการเข้าถึงยังคงอิง Key ไม่สามารถระบุ index ตัวเลขตรงๆ ได้แบบ `dict[0]` เว้นแต่จะมี key ชื่อเลข 0 จริงๆ*

### 2. กลไกการทำงานเบื้องหลัง: Hashing และเงื่อนไขของ Key

ทำไม Dictionary และ Set ถึงค้นหาข้อมูลได้รวดเร็วระดับ $O(1)$?

1. เมื่อระบุ `key` คอมพิวเตอร์จะส่ง `key` เข้าฟังก์ชันแฮชภายใน: `hash(key)` เพื่อแปลงเป็นเลขจำนวนเต็ม
2. ระบบนำตัวเลขแฮชไปคำนวณตำแหน่งในหน่วยความจำ (Bucket Index) แล้วเข้าถึงหรือจัดเก็บข้อมูลได้ในขั้นตอนเดียว ไม่จำเป็นต้องไล่ตรวจทีละตัวตั้งแต่ต้นจนจบ

```
"apple" ---> [ hash("apple") ] ---> 482190342 ---> Index [6] ---> Value: 50
```

#### ข้อกำหนดสำคัญ: ชนิดข้อมูลที่จะเป็น Key ได้ (Hashable / Immutable)

- **เป็น Key ได้ (Immutable):** `int`, `float`, `str`, `bool`, `tuple` (โดยที่สมาชิกทุกตัวใน tuple ต้องเป็น immutable ด้วย), `frozenset`
- **เป็น Key ไม่ได้ (Mutable / Unhashable):** `list`, `set`, `dict` เพราะค่าข้างในเปลี่ยนแปลงได้ หากอนุญาตให้เป็น key ค่า hash จะเปลี่ยน ทำให้ระบบหาตำแหน่งเดิมไม่พบอีกต่อไป

```python
valid_dict = {
    (10, 20): "Coordinate A",   # Tuple เป็น key ได้
    "count": 99,                 # String เป็น key ได้
    42: "Answer"                 # Integer เป็น key ได้
}

# ❌ ผิดพลาด จะทำให้เกิด TypeError: unhashable type: 'list'
# invalid_dict = { [1, 2]: "Point" }
```

### 3. การเข้าถึง แก้ไข และเมธอดสำคัญของ Dictionary

#### 3.1 การอ่านค่า (Accessing Values)

- ใช้เหลี่ยมเล็บ `d[key]`: เข้าถึงค่าโดยตรง **แต่ถ้าไม่มี Key จะเกิด `KeyError` ทันที โปรแกรมพัง**
- ใช้เมธอด `d.get(key, default)`: หากไม่มีคีย์ จะคืนค่า `default` (ถ้าไม่ระบุจะคืนค่า `None`) โดยไม่เกิด Error

```python
score = {"alice": 95, "bob": 80}

# print(score["charlie"])       # ❌ KeyError: 'charlie'
print(score.get("charlie", 0))   # ✅ ได้ 0 (ปลอดภัย เหมาะกับการทำโจทย์)
print(score.get("alice", 0))     # ✅ ได้ 95
```

#### 3.2 การเพิ่มและแก้ไขข้อมูล

```python
data = {}
data["key1"] = "val1"            # เพิ่มคู่ใหม่
data["key1"] = "new_val"         # แก้ไขค่าเดิมของ key1
data.update({"key2": "val2", "key3": "val3"})  # รวมข้อมูลหลายคู่พร้อมกัน
```

#### 3.3 การลบข้อมูล

- `del d[key]`: ลบ key ที่กำหนด (หากไม่มีจะเกิด `KeyError`)
- `d.pop(key, default)`: ลบ key และส่งค่า value กลับมา (หากไม่มีและใส่ default จะคืนค่า default อย่างปลอดภัย)
- `d.clear()`: ล้างข้อมูลทั้งหมดใน dictionary ให้ว่างเปล่า

#### 3.4 การวนลูป (Iteration Patterns)

```python
inventory = {"pencil": 10, "pen": 5, "eraser": 2}

# 1. วนเฉพาะ Key (เป็น default เมื่อวนลูปบน dict)
for item in inventory:
    print(item)  # หรือ inventory.keys()

# 2. วนเฉพาะ Value
for count in inventory.values():
    print(count)

# 3. วนคู่ Key และ Value พร้อมกัน (ใช้บ่อยที่สุด)
for item, count in inventory.items():
    print(f"สินค้า: {item} มีจำนวน {count} ชิ้น")
```

### 4. รูปแบบโค้ดยอดนิยมในการทำข้อสอบและโจทย์ OJ

#### 4.1 รูปแบบการนับความถี่ (Frequency Counter Pattern)

การนับจำนวนครั้งที่ข้อมูลปรากฏ เป็นหนึ่งในโจทย์พื้นฐานที่พบบ่อยที่สุด:

```python
# การนับความถี่ของตัวอักษร
text = "engineering kmitl"
freq = {}

for ch in text:
    if ch == " ":
        continue
    # รูปแบบมาตรฐานด้วย .get()
    freq[ch] = freq.get(ch, 0) + 1

# ผลลัพธ์: {'e': 3, 'n': 3, 'g': 1, 'i': 3, ...}
```

#### 4.2 การจัดกลุ่มข้อมูลตามหมวดหมู่ (Grouping / Bucketing Pattern)

```python
students = [
    ("67070001", "IT"),
    ("67070002", "CS"),
    ("67070003", "IT"),
    ("67070004", "DSBA")
]

groups = {}
for sid, major in students:
    if major not in groups:
        groups[major] = []
    groups[major].append(sid)

# groups = {
#     'IT': ['67070001', '67070003'],
#     'CS': ['67070002'],
#     'DSBA': ['67070004']
# }
```

#### 4.3 การเรียงลำดับ Dictionary (Sorting Dictionaries)

Dictionary ไม่สามารถใช้ `.sort()` ได้ตรงๆ แต่แปลงเป็น List ของ Tuple ด้วย `.items()` เพื่อจัดเรียงได้:

```python
scores = {"Somchai": 85, "Somsak": 92, "Anong": 78, "Wichai": 85}

# 1. เรียงตามชื่อ (Key) ตามลำดับพจนานุกรม
sorted_by_name = sorted(scores.items(), key=lambda x: x[0])

# 2. เรียงตามคะแนน (Value) จากมากไปน้อย
sorted_by_score = sorted(scores.items(), key=lambda x: x[1], reverse=True)

# 3. เรียงหลายเงื่อนไข: คะแนนมากไปน้อย ถ้าเท่ากันเรียงตามชื่อ ก-ฮ
# เทคนิค: ใส่ tuple ใน lambda -> (-คะแนน, ชื่อ)
sorted_multi = sorted(scores.items(), key=lambda x: (-x[1], x[0]))
for name, score in sorted_multi:
    print(f"{name}: {score}")
```

### 5. โครงสร้างข้อมูล Set (เซตและการดำเนินการทางคณิตศาสตร์)

Set คือโครงสร้างข้อมูลที่รวบรวม **สมาชิกที่ไม่ซ้ำกัน (Unique Elements)** และสมาชิกต้องเป็นชนิด Hashable เช่นเดียวกับ Key ของ Dictionary

```python
# การสร้างเซต
empty_set = set()      # ⚠️ ต้องใช้ set() เท่านั้น หากใช้ {} จะได้ dict เปล่า!
primes = {2, 3, 5, 7, 11}
unique_chars = set("mississippi")  # ได้ {'m', 'i', 's', 'p'}
```

#### 5.1 การเพิ่มและลบสมาชิกใน Set

- `s.add(x)`: เพิ่มสมาชิก $x$ เข้าเซต (หากมีอยู่แล้วจะไม่เกิดอะไรขึ้น)
- `s.remove(x)`: นำ $x$ ออกจากเซต **(หากไม่มีจะเกิด `KeyError`)**
- `s.discard(x)`: นำ $x$ ออกจากเซต **(หากไม่มีจะไม่เกิด Error ปลอดภัยกว่า)**
- `s.pop()`: สุ่มหยิบสมาชิก 1 ตัวออกมาแล้วลบออกจากเซต

#### 5.2 การดำเนินการทางคณิตศาสตร์บนเซต (Set Operations)

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
```

| การดำเนินการ | สัญลักษณ์ Operator | เมธอด Method | ความหมาย | ผลลัพธ์ตัวอย่าง |
|---|:---:|---|---|---|
| **Union** | `A | B` | `A.union(B)` | รวมสมาชิกทั้งหมด | `{1, 2, 3, 4, 5, 6}` |
| **Intersection** | `A & B` | `A.intersection(B)` | เอาเฉพาะตัวที่ซ้ำกัน | `{3, 4}` |
| **Difference** | `A - B` | `A.difference(B)` | อยู่ใน A แต่ไม่อยู่ใน B | `{1, 2}` |
| **Symmetric Difference** | `A ^ B` | `A.symmetric_difference(B)` | อยู่ในฝั่งใดฝั่งหนึ่งแต่ไม่ซ้ำกัน | `{1, 2, 5, 6}` |

```python
# ตรวจสอบความเป็นสับเซต
subset_check = {1, 2}.issubset(A)      # True
superset_check = A.issuperset({3, 4})   # True
```

### 6. เทคนิคขั้นสูงเพื่อพิชิตข้อสอบและลดเวลาประมวลผล (Avoid TLE)

ในการทำโจทย์แข่งขันและระบบ OJ ข้อผิดพลาดที่นักศึกษาพบบ่อยที่สุดคือ **Time Limit Exceeded (TLE)** อันเนื่องมาจากการใช้ List ในการตรวจสอบสมาชิก

#### ปัญหา $O(n^2)$ กับการแก้ด้วย Set $O(n)$

```python
# ❌ โค้ดที่เสี่ยงติด TLE: ตรวจสอบ 'in' ใน List ขนาดใหญ่
valid_users = [...]  # มี 100,000 คนใน List
queries = [...]      # ค้นหา 100,000 ครั้ง

for q in queries:
    if q in valid_users:  # ใน List ใช้เวลา O(n) รวมกลายเป็น O(queries * n) = 10^10 รอบ!
        process(q)

# ✅ โค้ดที่รันเร็วระดับ 0.1 วินาที: แปลงเป็น Set ก่อนค้นหา
valid_users_set = set(valid_users)  # แปลงครั้งเดียวใช้ O(n)
for q in queries:
    if q in valid_users_set:        # ใน Set ค้นหาเฉลี่ย O(1) รวมเป็น O(queries)
        process(q)
```

## จุดที่มักพลาด

1. **สับสนระหว่าง Dictionary ว่างกับ Set ว่าง**:
   - `{}` คือ empty `dict` เสมอ
   - เซตว่างต้องเขียน `set()` เท่านั้น
2. **เกิด `KeyError` จากการเรียกคีย์ที่ไม่มีอยู่**:
   - การเขียน `d[k]` ตรงๆ มีความเสี่ยงสูง ให้เปลี่ยนมาใช้ `d.get(k, 0)` หรือเช็คเงื่อนไข `if k in d:` ก่อนเสมอ
3. **การพยายามนำ Mutable Object มาเป็น Key หรือสมาชิกใน Set**:
   - เช่น `{ [1, 2]: "data" }` หรือ `s.add([1, 2, 3])` จะเกิดข้อผิดพลาด `TypeError: unhashable type: 'list'`
   - ทางแก้: หากต้องการใช้ชุดข้อมูลเป็น key ให้แปลงเป็น `tuple([1, 2, 3])` ก่อน
4. **แก้ไขขนาดของ Dictionary หรือ Set ขณะกำลังวนลูป**:
   ```python
   # ❌ จะเกิด RuntimeError: dictionary changed size during iteration
   for k in d:
       if d[k] < 0:
           del d[k]

   # ✅ วิธีที่ถูกต้อง: สร้างสำเนาของ keys ก่อนวนลูป หรือสร้าง dict ใหม่
   for k in list(d.keys()):
       if d[k] < 0:
           del d[k]
   ```
5. **ความแตกต่างระหว่าง `.remove()` กับ `.discard()` ใน Set**:
   - สั่ง `s.remove(99)` ในขณะที่ไม่มี 99 ในเซต โปรแกรมจะแครชด้วย `KeyError`
   - สั่ง `s.discard(99)` ปลอดภัย ไม่เกิดข้อผิดพลาด
6. **สมมติว่า Set มี Index เหมือน List**:
   - เซตไม่มีลำดับที่แน่นอน การเรียก `s[0]` จะเกิด `TypeError: 'set' object is not subscriptable` หากต้องการดึงข้อมูลต้องวน `for` หรือแปลงเป็น `list(s)`

## ทดสอบตัวเอง

1. กำหนด `d = {"a": 1, "b": 2}` คำสั่ง `print(d.get("c", 10))` และ `print(d["c"])` จะให้ผลลัพธ์ต่างกันอย่างไร?
2. ชนิดข้อมูลใดต่อไปนี้สามารถนำมาเป็น Key ของ Dictionary ได้: `[1, 2]`, `(1, [2, 3])`, `(1, 2, 3)`, `{"a": 1}`, `frozenset([1, 2])`? เพราะเหตุใด?

4. หากต้องการนับความถี่ของตัวเลขในลิสต์ที่มีข้อมูล 1,000,000 ตัว จงเขียนโค้ดสั้นๆ ด้วย Dictionary ที่มี Time Complexity รวมไม่เกิน $O(n)$
5. เหตุใดการเขียนโค้ดลบสมาชิกออกจากเซตขณะกำลังรัน `for item in my_set:` จึงเป็นแนวทางที่อันตราย และควรแก้ไขอย่างไร?
