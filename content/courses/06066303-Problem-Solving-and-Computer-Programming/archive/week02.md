### 1. ตัวแปรและการกำหนดค่า (Variables & Dynamic Typing)

ในภาษา Python ตัวแปรไม่ได้ทำหน้าที่เป็น "กล่องเก็บข้อมูล" ที่ต้องจองชนิดข้อมูลตายตัว แต่ทำหน้าที่เป็น **ป้ายชื่อ (Identifier / Pointer)** ที่ชี้ไปยังอ็อบเจกต์ (Object) ในหน่วยความจำ:

- **Dynamic Typing:** ตัวแปรสามารถเปลี่ยนชนิดข้อมูลที่ชี้อยู่ได้ตลอดเวลา เช่น:
  ```python
  x = 100       # x ชี้ไปยัง int object
  x = "KMITL"   # ตอนนี้ x ชี้ไปยัง str object ได้โดยไม่เกิด Error
  ```
- **Multiple Assignment:** กำหนดค่าให้หลายตัวแปรพร้อมกันได้:
  ```python
  a, b = 10, 20       # กำหนดค่าหลายตัวแปรในบรรทัดเดียว
  x = y = z = 0       # กำหนดค่าเดียวกันให้ตัวแปรหลายตัว
  a, b = b, a         # การสลับค่า (Swap) สองตัวแปรโดยไม่ต้องมีตัวแปรพัก (temp)
  ```

#### กฎการตั้งชื่อตัวแปร (Identifier Rules & PEP 8):
1. ต้องประกอบด้วยตัวอักษรภาษาอังกฤษ (`a-z`, `A-Z`), ตัวเลข (`0-9`) หรือเครื่องหมายขีดล่าง (`_`) เท่านั้น
2. **ห้ามขึ้นต้นด้วยตัวเลข** เช่น `1st_place` ❌, `_valid_name` ✔️
3. ตัวพิมพ์เล็กและใหญ่มีความหมายต่างกัน (Case-sensitive) เช่น `total`, `Total`, `TOTAL` คือ 3 ตัวแปรที่แยกจากกัน
4. **ห้ามซ้ำกับคีย์เวิร์ดสงวน (Keywords)** 35 คำของ Python เช่น `def`, `class`, `if`, `while`, `import`, `return`, `None`, `True`
5. **ธรรมเนียม PEP 8:**
   - ตัวแปรทั่วไปและชื่อฟังก์ชัน: ใช้ตัวพิมพ์เล็กคั่นด้วยขีดล่างแบบ `snake_case` เช่น `student_id`, `item_price`
   - ค่าคงที่ (Constants): ใช้ตัวพิมพ์ใหญ่ทั้งหมด เช่น `PI = 3.14159`, `MAX_RETRIES = 5`

### 2. ตัวดำเนินการเลขคณิต (Arithmetic Operators)

Python มีตัวดำเนินการคำนวณพื้นฐาน 7 ตัวที่ออกสอบบ่อย:

| ตัวดำเนินการ | ชื่อเรียก | ความหมายและพฤติกรรมสำคัญ | ตัวอย่าง | ผลลัพธ์ |
|:---:|---|---|---|:---:|
| `+` | Addition | การบวกตัวเลข หรือการต่อสตริง | `10 + 5`<br>`"IT" + "26"` | `15`<br>`"IT26"` |
| `-` | Subtraction | การลบตัวเลข หรือเครื่องหมายลบ (Unary minus) | `10 - 4` | `6` |
| `*` | Multiplication | การคูณตัวเลข หรือการพิมพ์สตริงซ้ำ (String repetition) | `3 * 4`<br>`"=" * 5` | `12`<br>`"====="` |
| `/` | True Division | **การหารจริง** — ได้ผลลัพธ์เป็น `float` เสมอ แม้จะหารลงตัว | `7 / 2`<br>`4 / 2` | `3.5`<br>`2.0` |
| `//` | Floor Division | **การหารปัดลง** — หาผลหารจำนวนเต็มที่ปัดเข้าหาจำนวนที่น้อยกว่าเสมอ | `7 // 2`<br>`-7 // 2` | `3`<br>`-4` |
| `%` | Modulo | **การหาเศษ** — คืนค่าเศษที่เหลือจากการหาร | `7 % 3`<br>`-7 % 3` | `1`<br>`2` |
| `**` | Exponentiation | **การยกกำลัง** | `2 ** 3`<br>`9 ** 0.5` | `8`<br>`3.0` |

#### ความสัมพันธ์เชิงลึกระหว่าง `//` และ `%` (Euclidean Identity):
สำหรับตัวเลข $a$ และ $b$ ใด ๆ สมการนี้จะเป็นจริงเสมอใน Python:
$$a = b \times (a // b) + (a \% b)$$

> [!WARNING]
> **ระวังการหารจำนวนติดลบ!**
> ใน Python การหาร `//` คือการ "ปัดเศษลงเข้าหาจำนวนที่น้อยกว่า (Floor towards $-\infty$)" เสมอ:
> - `7 // 2` ได้ `3` (เพราะ $3.5 \to 3$)
> - `-7 // 2` ได้ `-4` (เพราะ $-3.5$ ปัดลงหาค่าน้อยกว่าคือ $-4$)
> - เมื่อแทนสูตร: $-7 = 2 \times (-4) + (-7 \% 2) \implies -7 = -8 + 1 \implies -7 \% 2 = 1$
> ผลลัพธ์ของ modulo ใน Python จะมีเครื่องหมายเดียวกับตัวหารเสมอ

### 3. ลำดับความสำคัญของตัวดำเนินการ (Operator Precedence)

เมื่อมีหลายตัวดำเนินการในบรรทัดเดียวกัน Python จะประเมินผลตามลำดับความสำคัญจากสูงไปต่ำ:

```
1. วงเล็บ (Parentheses)             : ( ... )
2. การยกกำลัง (Exponentiation)     : **  (ประเมินจากขวาไปซ้าย!)
3. เครื่องหมายหน้าตัวเลข (Unary +/-)  : +x, -x
4. คูณ / หาร / ปัดเศษ / มอดูโล      : * , / , // , %  (ประเมินจากซ้ายไปขวา)
5. บวก / ลบ                        : + , -  (ประเมินจากซ้ายไปขวา)
```

#### ประเด็นสำคัญเรื่อง Right-to-Left Associativity ของ `**`:
- นิพจน์ `2 ** 3 ** 2` จะถูกประเมินจากขวาไปซ้าย:
  $$2 ** (3 ** 2) = 2 ** 9 = 512$$
  *(หากประเมินจากซ้ายไปขวาจะได้ $(2 ** 3) ** 2 = 8 ** 2 = 64$ ซึ่งผิด!)*
- นิพจน์ `-3 ** 2` จะได้ `-9` เพราะ `**` สำคัญกว่าเครื่องหมายลบด้านหน้า (`-(3 ** 2)`) หากต้องการยกกำลังทั้งจำนวนลบต้องใส่วงเล็บ `(-3) ** 2 = 9`

### 4. การจัดรูปแบบข้อความ (String Formatting)

ในการเขียนโปรแกรมส่ง OJ เราต้องพิมพ์ตัวเลขตามสเปก เช่น กำหนดทศนิยม 2 ตำแหน่ง หรือจัดแนวตาราง:

#### 1) f-strings (Formatted String Literals - แนะนำเป็นอันดับแรก)
นำหน้าสตริงด้วย `f` หรือ `F` และใส่ตัวแปรหรือนิพจน์ภายในวงเล็บปีกกา `{expr:format_spec}`:

```python
pi = 3.14159265
count = 7
amount = 1250000.5

# กำหนดทศนิยม 2 ตำแหน่ง
print(f"{pi:.2f}")            # ผลลัพธ์: 3.14

# กำหนดทศนิยม 4 ตำแหน่ง
print(f"{pi:.4f}")            # ผลลัพธ์: 3.1416 (ปัดเศษอัตโนมัติ)

# ใส่ลูกน้ำคั่นหลักพันและทศนิยม 2 ตำแหน่ง
print(f"{amount:,.2f}")       # ผลลัพธ์: 1,250,000.50

# จัดความกว้าง 8 ช่อง เติม 0 ด้านหน้าสำหรับจำนวนเต็ม
print(f"{count:05d}")         # ผลลัพธ์: 00007

# การจัดแนวข้อความ (Alignment):
text = "PSCP"
print(f"{text:<10}!")         # ชิดซ้าย  (กว้าง 10): 'PSCP      !'
print(f"{text:>10}!")         # ชิดขวา   (กว้าง 10): '      PSCP!'
print(f"{text:^10}!")         # กึ่งกลาง (กว้าง 10): '   PSCP   !'
```

#### 2) เมท็อด `.format()`
```python
print("{:.2f}".format(pi))               # 3.14
print("Item: {:<8} Cost: {:>6.2f}".format("Milk", 45.5))
```

### 5. มอดูล `math` และฟังก์ชัน Built-in ทางคณิตศาสตร์

เมื่อต้องการคำนวณทางคณิตศาสตร์ชั้นสูง เช่น ถอดรากที่สอง ฟังก์ชันตรีโกณมิติ หรือการปัดเศษ ต้องนำเข้ามอดูล `math` ด้วย `import math`:

| ฟังก์ชัน / ค่าคงที่ | คำอธิบาย | ตัวอย่างการใช้งาน | ผลลัพธ์ |
|---|---|---|:---:|
| `math.sqrt(x)` | ถอดรากที่สอง ($\sqrt{x}$) ได้ผลลัพธ์เป็น float | `math.sqrt(16)` | `4.0` |
| `math.ceil(x)` | ปัดเศษขึ้นหาจำนวนเต็มที่มากกว่าหรือเท่ากับค่าเดิม | `math.ceil(4.1)`<br>`math.ceil(-2.9)` | `5`<br>`-2` |
| `math.floor(x)` | ปัดเศษลงหาจำนวนเต็มที่น้อยกว่าหรือเท่ากับค่าเดิม | `math.floor(4.9)`<br>`math.floor(-2.1)` | `4`<br>`-3` |
| `math.pi` | ค่าคงที่อัตราส่วนวงกลม $\pi \approx 3.1415926535...$ | `math.pi` | `3.14159...` |
| `math.hypot(x, y)` | หาด้านตรงข้ามมุมฉาก $\sqrt{x^2 + y^2}$ | `math.hypot(3, 4)` | `5.0` |

#### ฟังก์ชัน Built-in (เรียกใช้ได้ทันทีโดยไม่ต้อง import):
- `abs(x)`: ค่าสัมบูรณ์ เช่น `abs(-15)` ได้ `15`
- `min(a, b, c, ...)`: คืนค่าค่าน้อยที่สุด
- `max(a, b, c, ...)`: คืนค่าค่ามากที่สุด
- `pow(base, exp)`: ยกกำลัง คล้าย `base ** exp`
- `round(number, ndigits)`: ปัดเศษตามจำนวนหลักทศนิยม

> [!NOTE]
> **ความจริงเกี่ยวกับ `round()` ของ Python:**
> Python ใช้ระบบ **Round Half to Even (Banker's Rounding)** เมื่อค่าลงท้ายด้วย `.5` พอดี มันจะปัดเข้าหาจำนวนเต็มคู่ที่ใกล้ที่สุด เพื่อลดความเอนเอียงทางสถิติ:
> - `round(2.5)` ได้ `2`
> - `round(3.5)` ได้ `4`
> หากต้องการปัดเศษแบบวิทยาศาสตร์/พาณิชย์ทั่วไปในการจัดรูปแบบแสดงผล ให้ใช้ f-string `f"{val:.0f}"` หรือตรวจสอบเงื่อนไขด้วยตนเอง

## จุดที่มักพลาด

- **ผลหาร `/` ได้ float เสมอ:**
  ผู้เรียนมักสับสนว่าถ้าหารลงตัว เช่น `6 / 3` จะได้ `2` ซึ่งใน Python จะได้ `2.0` (ชนิด `float`) หากโจทย์ต้องการจำนวนเต็มต้องระวังใช้ `//` หรือแคสต์เป็น `int()`
- **ลำดับความสำคัญของเครื่องหมายลบและยกกำลัง:**
  `-2 ** 2` ผลลัพธ์คือ `-4` ไม่ใช่ `4` เพราะ Python มองเป็น `-(2 ** 2)`
- **การปัดเศษติดลบด้วย `//`:**
  เมื่อแบ่งของหรือจัดหน้า ถ้าตัวเลขมีโอกาสติดลบ ค่า `//` จะปัดลงไปทางซ้ายของแกนจำนวนเสมอ
- **Floating Point Arithmetic Inaccuracy:**
  คอมพิวเตอร์เก็บเลขทศนิยมในรูปฐานสอง ทำให้เกิดความคลาดเคลื่อนเล็กน้อย เช่น `0.1 + 0.2` ใน Python จะได้ `0.30000000000000004` ดังนั้นเมื่อเปรียบเทียบค่าทศนิยม อย่าใช้ `a == b` โดยตรง ให้ใช้การเช็คผลต่าง เช่น `abs(a - b) < 1e-9`
- **ลืมครอบชนิดข้อมูลตอนคำนวณเงินหรือเวลา:**
  การคำนวณเงินทอน เช่น ทอนเหรียญ 10, 5, 2, 1 บาท ให้ใช้ลำดับ `//` ตามด้วย `%` เพื่อลดทอนยอดเงินลงมาทีละขั้น

1. **โจทย์ลำดับนิพจน์:** ผลลัพธ์ของนิพจน์ `10 + 2 * 3 ** 2 // 4` ใน Python มีค่าเท่าใด?
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   ลำดับการคำนวณ:<br>
   1) ยกกำลังก่อน: <code>3 ** 2 = 9</code><br>
   2) คูณและหารปัดเศษจากซ้ายไปขวา: <code>2 * 9 = 18</code> จากนั้น <code>18 // 4 = 4</code><br>
   3) บวก: <code>10 + 4 = 14</code><br>
   คำตอบคือ <strong>14</strong>
   </details>

2. **โจทย์การหารและมอดูโล:** จงหาค่าของ `-11 // 3` และ `-11 % 3`
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   -11 หารด้วย 3 ได้ -3.6667 ปัดเศษลงหาจำนวนเต็มที่น้อยกว่าจะได้ <strong>-4</strong><br>
   จากสมการ <code>a = b * (a // b) + (a % b)</code> ➔ <code>-11 = 3 * (-4) + (-11 % 3)</code> ➔ <code>-11 = -12 + 1</code><br>
   ดังนั้น <code>-11 // 3 = -4</code> และ <code>-11 % 3 = 1</code>
   </details>

3. **โจทย์ f-string:** ถ้า `val = 8.5` คำสั่ง `print(f"{val:>8.2f}#")` จะแสดงผลอย่างไร?
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   จัดรูปทศนิยม 2 ตำแหน่งได้ <code>8.50</code> (ความยาว 4 ตัวอักษร) กำหนดความกว้าง 8 ช่องชิดขวา (<code>>8</code>) จะเว้นวรรคข้างหน้า 4 ช่อง แล้วปิดท้ายด้วย <code>#</code><br>
   ผลลัพธ์คือ <code>    8.50#</code>
   </details>

4. **โจทย์การสลับค่า:** โค้ดด้านล่างนี้จะพิมพ์ค่าอะไรออกมา?
   ```python
   x, y = 5, 12
   x, y = y, x + y
   print(x, y)
   ```
   <details>
