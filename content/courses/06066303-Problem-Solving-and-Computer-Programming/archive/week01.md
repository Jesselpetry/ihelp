## สรุปอ่านสอบ

### 1. กระบวนการแก้ปัญหาทางคอมพิวเตอร์ (Problem Solving Steps)

การพัฒนาโปรแกรมคอมพิวเตอร์ไม่ได้เริ่มต้นที่การพิมพ์โค้ด แต่เริ่มต้นจากกระบวนการคิดเชิงตรรกะที่เป็นระบบ 5 ขั้นตอนหลัก:

```
[1. วิเคราะห์ปัญหา] ➔ [2. ออกแบบอัลกอริทึม] ➔ [3. เขียนโปรแกรม] ➔ [4. ทดสอบและแก้ไข] ➔ [5. บำรุงรักษาและเอกสาร]
```

1. **การทำความเข้าใจและวิเคราะห์ปัญหา (Problem Analysis & Specification)**
   - แยกแยะองค์ประกอบหลัก 3 ส่วน:
     - **Input (ข้อมูลเข้า):** มีกี่ตัว ประเภทใด (จำนวนเต็ม ทศนิยม หรือข้อความ) ช่วงของข้อมูลเป็นเท่าใด
     - **Process (กระบวนการประมวลผล):** มีสูตรคำนวณ เงื่อนไข หรือกฎเกณฑ์ใดที่ต้องปฏิบัติ
     - **Output (ข้อมูลออก):** ผลลัพธ์ต้องแสดงรูปแบบใด จำนวนกี่ค่า ข้อความต้องตรงตามสเปกตัวอักษรพิมพ์เล็ก-ใหญ่หรือไม่
2. **การออกแบบขั้นตอนวิธี (Algorithm Design)**
   - วางลำดับขั้นตอนอย่างชัดเจน ไม่กำกวม และทำงานเสร็จสิ้นได้ในจำนวนขั้นตอนจำกัด (Finiteness)
   - ถ่ายทอดความคิดออกมาในรูปแบบ **รหัสเทียม (Pseudocode)** หรือ **ผังงาน (Flowchart)**
3. **การลงรหัสโปรแกรม (Implementation / Coding)**
   - แปลงอัลกอริทึมที่ออกแบบไว้ให้เป็นคำสั่งภาษาคอมพิวเตอร์ (ในวิชานี้คือ **Python 3**)
4. **การทดสอบและแก้ไขข้อผิดพลาด (Testing & Debugging)**
   - ทดสอบด้วยชุดข้อมูลทดสอบ (Test Cases) ที่ครอบคลุม:
     - *Normal Case:* ข้อมูลปกติทั่วไป
     - *Boundary / Edge Case:* ข้อมูลขอบเขต เช่น ค่า 0 ค่าติดลบ ค่าสูงสุด หรือสตริงว่าง
   - ข้อผิดพลาดแบ่งเป็น 3 ชนิด:
     - **Syntax Error:** ผิดไวยากรณ์ภาษา โปรแกรมรันไม่ผ่านตั้งแต่ต้น เช่น ลืมปิดวงเล็บ พิมพ์คีย์เวิร์ดผิด
     - **Runtime Error (Exception):** โปรแกรมรันได้แต่หยุดทำงานกะทันหันขณะประมวลผล เช่น หารด้วยศูนย์ (`ZeroDivisionError`) แปลงสตริงตัวอักษรเป็นตัวเลข (`ValueError`)
     - **Logic Error:** โปรแกรมรันจนจบได้โดยไม่เกิด Error แต่ผลลัพธ์คำนวณออกมาผิดพลาด เกิดจากสูตรหรือเงื่อนไขผิด
5. **การจัดทำเอกสารและบำรุงรักษา (Documentation & Maintenance)**
   - การเขียนคำอธิบายโค้ด (Comments) การตั้งชื่อตัวแปรให้อ่านเข้าใจง่าย (Self-documenting code) และการปรับปรุงโค้ดเมื่อความต้องการเปลี่ยนไป

### 2. ผังงาน (Flowchart) และสัญลักษณ์มาตรฐาน

ผังงานคือรูปภาพหรือแผนภาพที่ใช้สัญลักษณ์มาตรฐานแสดงลำดับขั้นตอนการทำงานของโปรแกรม:

| สัญลักษณ์ | ชื่อเรียกทางเทคนิค | รูปร่าง | ความหมายและการใช้งาน |
|---|---|---|---|
| ![Terminal](data:image/svg+xml;utf8,<svg></svg>) | **Terminal** | วงรี / ขอบมน (Capsule) | จุดเริ่มต้น (**Start**) หรือจุดสิ้นสุด (**Stop / End**) ของโปรแกรม |
| ![Process](data:image/svg+xml;utf8,<svg></svg>) | **Process** | สี่เหลี่ยมผืนผ้า | การประมวลผล การคำนวณทางคณิตศาสตร์ หรือการกำหนดค่าให้ตัวแปร เช่น `x = a + b` |
| ![Input/Output](data:image/svg+xml;utf8,<svg></svg>) | **Input / Output** | สี่เหลี่ยมด้านขนาน (Parallelogram) | การรับข้อมูลเข้าหรือแสดงผลลัพธ์โดยไม่จำเพาะเจาะจงอุปกรณ์ เช่น รับค่าจากคีย์บอร์ด หรือพิมพ์ออกหน้าจอ |
| ![Decision](data:image/svg+xml;utf8,<svg></svg>) | **Decision** | สี่เหลี่ยมขนมเปียกปูน (Diamond) | การตัดสินใจเพื่อตรวจสอบเงื่อนไขทางตรรกะ มีเส้นทางออกจากรูปอย่างน้อย 2 ทางเสมอ (**True / Yes** และ **False / No**) |
| ![Connector](data:image/svg+xml;utf8,<svg></svg>) | **On-page Connector** | วงกลมขนาดเล็ก | จุดเชื่อมต่อเส้นทางของผังงานภายในหน้าเดียวกัน ช่วยลดความซับซ้อนของเส้นโยง |
| ![Off-page Connector](data:image/svg+xml;utf8,<svg></svg>) | **Off-page Connector** | รูปห้าเหลี่ยมคว่ำ | จุดเชื่อมต่อผังงานที่ขึ้นหน้ากระดาษแผ่นใหม่ |
| ![Flow line](data:image/svg+xml;utf8,<svg></svg>) | **Flow Line** | เส้นลูกศร | แสดงทิศทางลำดับการไหลของคำสั่ง (จากบนลงล่าง หรือซ้ายไปขวา) |

#### โครงสร้างการควบคุมพื้นฐาน 3 รูปแบบ (Control Structures)
1. **แบบลำดับ (Sequence):** ประมวลผลจากคำสั่งแรกไปยังคำสั่งถัดไปทีละขั้นตอนตามลำดับ
2. **แบบเลือกทำ (Selection / Decision):** ตรวจสอบเงื่อนไขแล้วเลือกทำเพียงทางเลือกใดทางเลือกหนึ่ง (`if-else`)
3. **แบบวนซ้ำ (Repetition / Iteration):** ทำซ้ำกลุ่มคำสั่งเดิมตราบเท่าที่เงื่อนไขยังคงเป็นจริง (`while`, `for`)

### 3. สภาพแวดล้อมการทำงานของ Python: Interactive vs Script Mode

Python เป็นภาษาประเภท **Interpreted Language** แปลงคำสั่งและประมวลผลทีละบรรทัดผ่าน Python Virtual Machine (PVM):

- **Interactive Mode (REPL - Read-Eval-Print Loop):**
  - เปิดใช้งานผ่าน Command Line / Terminal ด้วยคำสั่ง `python` หรือ `python3` จะปรากฏพร้อมต์ `>>>`
  - พิมพ์คำสั่งแล้วกด Enter โปรแกรมจะประเมินผลลัพธ์และแสดงออกมาทันที
  - เหมาะสำหรับ: การทดสอบไวยากรณ์สั้นๆ เช็คพฤติกรรมฟังก์ชัน หรือคำนวณเลขด่วน
- **Script Mode:**
  - เขียนชุดคำสั่งทั้งหมดบันทึกไว้ในไฟล์ข้อความธรรมดาที่มีนามสกุล `.py` เช่น `main.py`
  - สั่งประมวลผลผ่านคำสั่ง `python3 main.py` ตัวแปลภาษาจะเริ่มอ่านและประมวลผลตั้งแต่บรรทัดแรกจนถึงบรรทัดสุดท้าย
  - เหมาะสำหรับ: โปรแกรมจริง การทำงานที่มีขั้นตอนซับซ้อน และการส่งตรวจบนระบบ iJudge

### 4. ฟังก์ชัน `print()` และการแสดงผล

ฟังก์ชัน `print()` เป็น Built-in Function ใน Python สำหรับส่งข้อมูลออกทางหน้าจอมาตรฐาน (Standard Output):

```python
print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)
```

- **การส่งหลายอาร์กิวเมนต์:** แยกด้วยเครื่องหมายจุลภาค `,` ฟังก์ชันจะแสดงข้อมูลแต่ละตัวต่อกัน
- **พารามิเตอร์ `sep` (Separator):** กำหนดตัวคั่นระหว่างอาร์กิวเมนต์ (ค่าเริ่มต้นคือเคาะวรรค 1 ช่อง `' '`)
- **พารามิเตอร์ `end` (End terminator):** กำหนดสิ่งที่จะพิมพ์ต่อท้ายสุดหลังพิมพ์ข้อมูลครบทุกตัว (ค่าเริ่มต้นคือขึ้นบรรทัดใหม่ `'\n'`)

#### ตัวอย่างการใช้งาน `sep` และ `end`:
```python
# ค่าเริ่มต้น: คั่นด้วยวรรค และขึ้นบรรทัดใหม่
print("Hello", "World")          # ผลลัพธ์: Hello World

# กำหนด sep กำหนดตัวคั่นเป็นขีดกลาง
print("2026", "11", "08", sep="-")  # ผลลัพธ์: 2026-11-08

# กำหนด sep เป็นสตริงว่างเพื่อเชื่อมติดกัน
print("A", "B", "C", sep="")     # ผลลัพธ์: ABC

# กำหนด end เพื่อไม่ให้ขึ้นบรรทัดใหม่
print("Loading", end="...")
print("Done!")                   # ผลลัพธ์: Loading...Done!
```

#### Escape Characters ที่พบบ่อย:
| รหัส Escape | ความหมาย | ตัวอย่าง | ผลลัพธ์ |
|---|---|---|---|
| `\n` | ขึ้นบรรทัดใหม่ (Newline) | `print("Line1\nLine2")` | บรรทัดที่ 1 และ 2 แยกกัน |
| `\t` | แท็บแนวนอน (Horizontal Tab) | `print("ID:\t1234")` | ขยับตำแหน่งข้อความ 1 ช่วงแท็บ |
| `\\` | แสดงเครื่องหมาย Backslash | `print("C:\\Users")` | `C:\Users` |
| `\'` | แสดงเครื่องหมาย Single Quote | `print('It\'s OK')` | `It's OK` |
| `\"` | แสดงเครื่องหมาย Double Quote | `print("Say \"Hi\"")` | `Say "Hi"` |

### 5. การรับข้อมูลด้วย `input()` และชนิดข้อมูลพื้นฐาน

ฟังก์ชัน `input(prompt)` ใช้รับข้อมูลจากผู้ใช้ผ่าน Standard Input (คีย์บอร์ด):
- ตัวโปรแกรมจะหยุดรอจนกว่าผู้ใช้จะพิมพ์ข้อความและกดแป้น **Enter**
- ข้อความที่พิมพ์ทั้งหมด (ไม่รวมตัวตัดบรรทัด Enter) จะถูกส่งกลับมาเป็น **ชนิดสตริง (`str`) เสมอ**

#### ชนิดข้อมูลพื้นฐาน 4 ประเภท (Scalar Data Types):
1. **`int` (Integer):** จำนวนเต็มทั้งบวก ลบ และศูนย์ เช่น `42`, `-7`, `0` ใน Python 3 จำนวนเต็มไม่มีขีดจำกัดขนาด (Arbitrary precision) จึงไม่เกิด Integer Overflow เหมือนภาษา C/Java
2. **`float` (Floating-point):** จำนวนจริงที่มีจุดทศนิยม หรือเขียนในรูปสัญกรณ์วิทยาศาสตร์ เช่น `3.14159`, `-0.5`, `2e3` ($2 \times 10^3$)
3. **`str` (String):** ข้อความหรือลำดับของตัวอักษร ครอบด้วยเครื่องหมาย Single Quote `'...'` หรือ Double Quote `"..."`
4. **`bool` (Boolean):** ค่าความจริงทางตรรกศาสตร์ มีเพียง 2 ค่าคือ `True` และ `False` (ต้องขึ้นต้นด้วยตัวพิมพ์ใหญ่เสมอ)

#### การแปลงชนิดข้อมูล (Type Casting):
เมื่อต้องการนำค่าจาก `input()` ไปคำนวณทางคณิตศาสตร์ ต้องแปลงชนิดข้อมูลด้วยฟังก์ชัน Constructor ให้ตรงตามจุดประสงค์:

```python
# รับจำนวนเต็ม
age = int(input("Enter age: "))

# รับจำนวนทศนิยม
weight = float(input("Enter weight: "))

# ตรวจสอบชนิดข้อมูลด้วย type()
print(type(age))     # <class 'int'>
print(type(weight))  # <class 'float'>
```

## จุดที่มักพลาด

- **`input()` ได้ `str` เสมอ ห้ามลืมแปลงชนิดข้อมูลก่อนบวกเลข:**
  ```python
  x = input()  # ผู้ใช้ป้อน 5
  y = input()  # ผู้ใช้ป้อน 5
  print(x + y) # พิมพ์ "55" ไม่ใช่ 10 เพราะเป็นการเชื่อมสตริง (Concatenation)
  ```
  *วิธีแก้:* ต้องใช้ `x = int(input())` หรือ `float(input())`
- **การเยื้องหน้า (Indentation Error):**
  Python ไม่ใช้วงเล็บปีกกา `{}` กำหนดขอบเขตบล็อกโค้ด แต่ใช้การเยื้องหน้ากระดาษ (แนะนำให้ใช้ Space 4 เคาะ) หากเคาะไม่เท่ากันจะเกิด `IndentationError` ทันที
- **ตัวพิมพ์เล็ก-ใหญ่มีผลต่างกัน (Case Sensitivity):**
  คำสั่งและตัวแปรใน Python แยกตัวพิมพ์เล็ก-ใหญ่ชัดเจน เช่น `Print()` หรือ `PRINT()` จะเกิด `NameError` เพราะชื่อฟังก์ชันที่ถูกต้องคือ `print()` ตัวพิมพ์เล็ก และบูลีนต้องเป็น `True` / `False` ไม่ใช่ `true` / `false`
- **กฎการตั้งชื่อตัวแปร (Variable Naming Rules):**
  - ห้ามขึ้นต้นด้วยตัวเลขเด็ดขาด เช่น `1st_name = "Guy"` ❌
  - ประกอบด้วยตัวอักษรภาษาอังกฤษ ตัวเลข และขีดล่าง `_` เท่านั้น ห้ามมีเว้นวรรคหรือเครื่องหมายพิเศษ เช่น `user-name` ❌, `total$` ❌
  - ห้ามตั้งชื่อซ้ำกับคีย์เวิร์ดสงวน (Reserved Keywords) เช่น `for`, `if`, `class`, `def`, `while`, `True`
- **การพิมพ์ข้อความติดกันด้วย `print()`:**
  ระวังความแตกต่างระหว่าง `print(a, b)` (จะแทรกเว้นวรรค 1 ช่องตรงกลาง) กับ `print(a + b)` (เชื่อมติดกันทันทีโดยไม่มีวรรค และทั้งสองตัวต้องเป็นสตริง)

## ทดสอบตัวเอง

1. **โจทย์วิเคราะห์ขั้นตอน:** หากโปรแกรมคำนวณเกรดได้รับข้อมูลคะแนนดิบ 150 คะแนน (เต็ม 100) แล้วตัดเกรดออกมาเป็น A ข้อผิดพลาดนี้จัดอยู่ในประเภทใด และเกิดขึ้นในขั้นตอนใดของการแก้ปัญหา?
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   จัดเป็น <strong>Logic Error</strong> (เกิดจากการไม่ได้กำหนดเงื่อนไขตรวจสอบช่วงคะแนนที่ถูกต้อง 0–100) เกิดขึ้นจากความบกพร่องในขั้นตอน <strong>Problem Analysis</strong> และ <strong>Algorithm Design</strong>
   </details>

2. **โจทย์ผังงาน:** ในการสร้างผังงาน หากต้องการตรวจสอบว่าจำนวนเต็ม $N$ เป็นจำนวนคู่หรือจำนวนคี่ ต้องใช้สัญลักษณ์รูปทรงใด และมีเส้นทางออกจากสัญลักษณ์นั้นกี่เส้นทาง?
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   ต้องใช้สัญลักษณ์ <strong>Decision (สี่เหลี่ยมขนมเปียกปูน / Diamond)</strong> และมีเส้นทางออกอย่างน้อย <strong>2 เส้นทาง</strong> คือ เส้นทางสำหรับกรณีเงื่อนไขเป็นจริง (True/Yes) และกรณีเป็นเท็จ (False/No)
   </details>

3. **โจทย์ผลลัพธ์คำสั่ง:** โค้ดด้านล่างนี้จะแสดงผลลัพธ์ออกทางหน้าจออย่างไร?
   ```python
   print("IT", "KMITL", sep="*", end="")
   print("2026")
   ```
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   แสดงผลเป็น <code>IT*KMITL2026</code> ในบรรทัดเดียวกัน เนื่องจากบรรทัดแรกกำหนด <code>sep="*"</code> และ <code>end=""</code> ทำให้ไม่มีการเคาะวรรคหรือขึ้นบรรทัดใหม่ก่อนเริ่มพิมพ์คำว่า <code>2026</code>
   </details>

4. **โจทย์ชนิดข้อมูล:** จงบอกชนิดข้อมูลและค่าที่ได้จากนิพจน์ `bool("False")` และ `int(float("3.99"))`
   <details>
   <summary>คลิกเพื่อดูเฉลย</summary>
   - <code>bool("False")</code> ได้ค่า <strong>True</strong> (ชนิด <code>bool</code>) เพราะสตริงไม่ใช่สตริงว่าง (Non-empty string เป็น Truthy ใน Python เสมอ)<br>
   - <code>int(float("3.99"))</code> ได้ค่า <strong>3</strong> (ชนิด <code>int</code>) เพราะแปลงเป็น float ก่อนได้ 3.99 จากนั้น <code>int()</code> จะทำการตัดเศษทศนิยมทิ้งทั้งหมด
   </details>
