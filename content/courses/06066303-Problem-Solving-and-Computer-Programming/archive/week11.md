## สรุปอ่านสอบ

### 1. โครงสร้างเมทริกซ์ 2 มิติ (2D Grid Representation)

ในภาษา Python ไม่มีโครงสร้าง Array 2 มิติมาให้ในตัวแบบภาษา C เราจึงแทนตาราง 2 มิติด้วย **ลิสต์ที่บรรจุลิสต์ไว้ภายใน (Nested List หรือ List of Lists)**:
- ลิสต์หลักภายนอกแทน "ชุดของแถว"
- ลิสต์ย่อยภายในแต่ละตัวแทน "คอลัมน์ของแถวนั้น"

การระบุดัชนีจะใช้รูปแบบ `grid[row][col]` เสมอ:

```python
grid = [
    [10, 20, 30],   # แถวที่ 0
    [40, 50, 60],   # แถวที่ 1
    [70, 80, 90]    # แถวที่ 2
]

print(grid[1][2])   # เข้าถึงแถวที่ 1 คอลัมน์ที่ 2 ได้ค่า 60
```

#### การหามิติของตาราง
- **จำนวนแถว (Rows)**: `rows = len(grid)`
- **จำนวนคอลัมน์ (Cols)**: `cols = len(grid[0])` (สมมติว่าตารางเป็นรูปสี่เหลี่ยมผืนผ้าและมีสมาชิกอย่างน้อยหนึ่งแถว)

### 2. การสร้าง 2D Grid และกับดักตัวคูณ (Grid Creation & Reference Trap)

โจทย์มักต้องการให้เราสร้างตารางขนาด $R \times C$ ที่มีค่าเริ่มต้นเป็น $0$

#### ⚠️ กับดักร้ายแรง: การใช้ตัวคูณสองชั้น
```python
# ผิดอย่างร้ายแรง! ห้ามเขียนแบบนี้เด็ดขาด
grid = [[0] * cols] * rows
```

**สาเหตุที่ผิด**: ตัวคูณชั้นนอก `* rows` ไม่ได้สร้างลิสต์ใหม่ แต่สร้างการอ้างอิง (Reference) ซ้ำ ๆ ไปยังลิสต์แถวเดิมในหน่วยความจำ:

```text
grid ───► [ Row0, Row1, Row2 ]
             │      │     │
             └──────┼─────┘
                    ▼
                 [0, 0, 0]  (ทุกแถวชี้มาที่ลิสต์เดียวกัน!)
```

เมื่อสั่ง `grid[0][0] = 99` ผลลัพธ์จะกลายเป็น:
```python
[[99, 0, 0], [99, 0, 0], [99, 0, 0]]   # เปลี่ยนแปลงไปทุกแถวพร้อมกัน!
```

#### ✅ วิธีการที่ถูกต้อง: ใช้ List Comprehension
ลูปจะสร้างลิสต์แถวใหม่ที่เป็นอิสระจากกันในแต่ละรอบ:
```python
grid = [[0] * cols for _ in range(rows)]
```

### 3. เวกเตอร์ทิศทางและการตรวจสอบขอบเขต (Direction Vectors & Boundary Checking)

ในการเดินบนตารางหรือสำรวจช่องข้างเคียง (เช่น โจทย์ FourDirections, ไฟส่อง, หรือตำบลกระสุนตก) การใช้ $\Delta r$ (ผลต่างแถว) และ $\Delta c$ (ผลต่างคอลัมน์) ช่วยลดความซ้ำซ้อนของโค้ดได้อย่างมหาศาล

> **ระบบพิกัดในเมทริกซ์**:
> - เดิน **ขึ้น (Up)**: แถวลดลง ($dr = -1, dc = 0$)
> - เดิน **ลง (Down)**: แถวเพิ่มขึ้น ($dr = +1, dc = 0$)
> - เดิน **ซ้าย (Left)**: คอลัมน์ลดลง ($dr = 0, dc = -1$)
> - เดิน **ขวา (Right)**: คอลัมน์เพิ่มขึ้น ($dr = 0, dc = +1$)

```python
# กำหนดเวกเตอร์ 4 ทิศทาง: บน, ล่าง, ซ้าย, ขวา
DIRECTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]

# สำรวจช่องข้างเคียงรอบพิกัด (r, c)
for dr, dc in DIRECTIONS:
    nr = r + dr
    nc = c + dc
    
    # Boundary Checking: ตรวจสอบว่าพิกัดใหม่อยู่ภายในขอบเขตตารางหรือไม่
    if 0 <= nr < rows and 0 <= nc < cols:
        print(f"ช่องข้างเคียงที่ถูกต้อง: ({nr}, {nc}) ค่าคือ {grid[nr][nc]}")
```

### 4. การแปลงรูปทรงเมทริกซ์ (Matrix Transformation)

#### 4.1 การทรานสโพส (Transposition — สลับแถวเป็นคอลัมน์)
เปลี่ยนขนาดจาก $R \times C$ เป็น $C \times R$ โดยสมาชิกที่ $(r, c)$ จะย้ายไปอยู่ที่ $(c, r)$

```python
# วิธี List Comprehension
transposed = [[grid[r][c] for r in range(rows)] for c in range(cols)]

# วิธี Pythonic ด้วย zip และ Argument Unpacking (*)
transposed = [list(col) for col in zip(*grid)]
```

#### 4.2 การหมุนตาราง 90 องศาตามเข็มนาฬิกา (Clockwise Rotation)
การหมุน 90° ตามเข็มนาฬิกาเทียบเท่ากับ **การสลับลำดับแถวจากล่างขึ้นบน แล้วนำไป Transpose**:
$$Rotated = Transpose(ReverseRows(Grid))$$

```python
rotated = [list(col) for col in zip(*grid[::-1])]
```

### 5. การสำรวจเซลล์และการคำนวณรัศมี (Neighborhood Scanning)

สำหรับโจทย์จำลอง เช่น ระเบิดลงในรัศมี $K$ หรือการฉายแสงไฟ เราสามารถคำนวณระยะห่างระหว่างจุด $(r, c)$ กับศูนย์กลาง $(cr, cc)$ ได้สองรูปแบบหลัก:

| รูปแบบระยะห่าง | สูตรทางคณิตศาสตร์ | ลักษณะพื้นที่ครอบคลุม |
|---|:---:|---|
| **Manhattan Distance** | $|r - cr| + |c - cc| \le K$ | รูปข้าวหลามตัด (Diamond) รอบจุด |
| **Chebyshev / Box Distance** | $\max(|r - cr|, |c - cc|) \le K$ | รูปสี่เหลี่ยมจัตุรัสรอบจุด (เช่น การเดินของ King ในหมากรุก) |
| **Euclidean Distance** | $(r - cr)^2 + (c - cc)^2 \le K^2$ | รูปวงกลมรอบจุด |

---

## จุดที่มักพลาด

1. **กับดัก `[[0] * C] * R`**: ลืมใช้ List Comprehension ทำให้แถวทั้งหมดผูกติดกัน
2. **สับสนระบบแกนระหว่าง $(x, y)$ กับ $(r, c)$**:
   - พิกัดคาร์ทีเซียน: $(x, y) \implies x$ คือแนวนอน (คอลัมน์), $y$ คือแนวดิ่ง (แถว)
   - ดัชนีเมทริกซ์: `grid[r][c]` $\implies r$ มาก่อน และ $r$ วิ่งจากบนลงล่าง!
   - หากโจทย์ป้อนค่า $x, y$ ต้องแมปเป็น `grid[y][x]` หรือ `grid[r][c]` ให้ถูกต้อง
3. **ลืม Boundary Checking ก่อนเข้าถึงข้อมูล**:
   การคำนวณพิกัดใหม่แล้วนำไปเรียก `grid[nr][nc]` ทันที อาจเกิด `IndexError: list index out of range` หรือหาก $nc = -1$ ใน Python จะกลายเป็นการดึงสมาชิกจากตัวท้ายแถวแบบเงียบ ๆ ส่งผลให้ผลลัพธ์ผิดพลาดโดยไม่มี Error เตือน
4. **จำนวนคอลัมน์ในแต่ละแถวไม่เท่ากัน (Ragged Grid)**:
   หากอินพุตมีจำนวนสมาชิกแต่ละบรรทัดไม่เท่ากัน การใช้ `len(grid[0])` คุมคอลัมน์ทุกแถวอาจทำให้หลุดขอบเขต ต้องตรวจสอบความยาวของแต่ละแถวแยกกัน

### คำถามที่ 1
โค้ดต่อไปนี้จะพิมพ์ผลลัพธ์อะไรออกมา?
```python
matrix = [[0] * 3] * 3
matrix[1][1] = 5
print(matrix[0][1], matrix[1][1], matrix[2][1])
```

<details>
<summary>ดูแนวคิดและเฉลย</summary>

พิมพ์ `5 5 5`
เพราะการสร้างตารางด้วย `[[0] * 3] * 3` ทำให้แถวที่ 0, 1 และ 2 เป็นลิสต์ก้อนเดียวกันในหน่วยความจำ เมื่อแก้ไขตำแหน่งคอลัมน์ที่ 1 ในแถวใดแถวหนึ่ง สมาชิกคอลัมน์ที่ 1 ของทุกแถวจะเปลี่ยนเป็น 5 ทั้งหมด
</details>

### คำถามที่ 2
หากต้องการตรวจว่าพิกัด `(r, c)` อยู่ในตารางขนาด $5 \times 7$ (5 แถว 7 คอลัมน์) หรือไม่ เงื่อนไข `if` ในภาษา Python ควรเขียนอย่างไรให้ปลอดภัยที่สุด?

<details>
<summary>ดูแนวคิดและเฉลย</summary>

```python
if 0 <= r < 5 and 0 <= c < 7:
    # พิกัดถูกต้อง
```
ต้องตรวจสอบว่า $r$ อยู่ในช่วง $[0, 4]$ และ $c$ อยู่ในช่วง $[0, 6]$ และต้องระวังไม่ให้ติดลบ เพราะใน Python ดัชนีติดลบจะไม่เกิด IndexError ทันทีแต่จะไปดึงสมาชิกท้ายตาราง
</details>

### คำถามที่ 3
ผลลัพธ์ของ `[list(x) for x in zip(*[[1, 2], [3, 4]])]` คืออะไร?

<details>
<summary>ดูแนวคิดและเฉลย</summary>

ได้ `[[1, 3], [2, 4]]`
เป็นการทำ Matrix Transposition โดย `*` จะกระจายแถว `[1, 2]` และ `[3, 4]` ออกมา แล้ว `zip()` จะจับคู่สมาชิกคอลัมน์เดียวกันเข้าด้วยกัน ได้คู่ `(1, 3)` และ `(2, 4)`
</details>
