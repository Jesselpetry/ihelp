## สรุปสาระสำคัญอ่านสอบ

### 1. ลอจิกเกตพื้นฐาน (Logic Gates)

- **AND Gate (`·` หรือเขียนติดกัน):** ให้เอาต์พุต `1` เมื่อทุกอินพุตเป็น `1` เท่านั้น ($Y = A \cdot B$)
- **OR Gate (`+`):** ให้เอาต์พุต `1` เมื่อมีอินพุตใดอินพุตหนึ่งเป็น `1` ($Y = A + B$)
- **NOT Gate (Inverter, `′` หรือ Overbar):** กลับค่าทางตรรกะ ($Y = A'$)
- **NAND Gate:** ตรงข้ามกับ AND ($Y = (AB)'$) — เป็น **Universal Gate**
- **NOR Gate:** ตรงข้ามกับ OR ($Y = (A + B)'$) — เป็น **Universal Gate**
- **XOR Gate (`⊕`):** Exclusive-OR ให้เอาต์พุต `1` เมื่ออินพุตทั้งสองมีค่าต่างกัน ($Y = A \oplus B = A'B + AB'$)
- **XNOR Gate (`⊙`):** Equivalence / Exclusive-NOR ให้เอาต์พุต `1` เมื่ออินพุตทั้งสองมีค่าเหมือนกัน ($Y = (A \oplus B)' = AB + A'B'$)

### 2. กฎพีชคณิตบูลีนที่ต้องจำ ⭐⭐⭐

| กฎทางพีชคณิต | รูปแบบ AND | รูปแบบ OR |
|---|---|---|
| **Identity Law** | $A \cdot 1 = A$ | $A + 0 = A$ |
| **Null / Dominance** | $A \cdot 0 = 0$ | $A + 1 = 1$ |
| **Idempotent Law** | $A \cdot A = A$ | $A + A = A$ |
| **Complement Law** | $A \cdot A' = 0$ | $A + A' = 1$ |
| **Involution Law** | $(A')' = A$ | — |
| **Commutative Law** | $AB = BA$ | $A + B = B + A$ |
| **Associative Law** | $A(BC) = (AB)C$ | $A + (B + C) = (A + B) + C$ |
| **Distributive Law** | $A(B + C) = AB + AC$ | $A + BC = (A + B)(A + C)$ ⭐ |
| **Absorption Law** | $A(A + B) = A$ | $A + AB = A$ |
| **De Morgan's Laws** | $(AB)' = A' + B'$ | $(A + B)' = A'B'$ |
| **Useful Simplification** | $A(A' + B) = AB$ | $A + A'B = A + B$ ⭐ |

> [!TIP]
> กฎการกระจายรูป OR: $A + BC = (A + B)(A + C)$ และกฎลดรูป $A + A'B = A + B$ คือสูตรที่ใช้บ่อยที่สุดในการทำข้อสอบแสดงวิธีทำ

## ปฏิบัติการ Logisim (Lab 02)

- ตรวจสอบตารางความจริงของลอจิกเกตแต่ละชนิดโดยใช้ Probe และ Pin
- การสร้างวงจร **`numDecoderV6`**: ออกแบบวงจรถอดรหัสเลขฐานสองเพื่อขับหลอดแสดงผลแบบ 7-Segment (แสดงตัวเลข 0–9)
- การสร้างวงจรบวกเลขฐานสองขนาด 2 บิต (2-bit Binary Adder):
  - ประกอบด้วย Half Adder (บิตต่ำสุด) และ Full Adder (บิตถัดไปที่มี Carry-in)
  - ทดสอบผลรวม ($S_1, S_0$) และตัวทด ($C_{out}$)

## ข้อควรระวังและกับดักข้อสอบ

- **การประยุกต์ De Morgan ซ้อนกันหลายชั้น:** ระวังการกระจายบาร์ยาว ต้องค่อย ๆ ตัดบาร์ทีละชั้นพร้อมเปลี่ยนเครื่องหมายระหว่างพจน์ (AND เปลี่ยนเป็น OR, OR เปลี่ยนเป็น AND)
- **วงจร Universal Gate:** เมื่อโจทย์สั่งให้สร้างวงจรจาก NAND Gate ล้วน หรือ NOR Gate ล้วน ให้ใส่ Double Inversion $(F'')'$ แล้วใช้ De Morgan แปลงพจน์ข้างใน
- ห้ามเขียนสมการโดยไม่มีวงเล็บกำกับความสำคัญของตัวดำเนินการ ลำดับศักดิ์คือ NOT ทำก่อน ตามด้วย AND แล้วปิดท้ายด้วย OR
