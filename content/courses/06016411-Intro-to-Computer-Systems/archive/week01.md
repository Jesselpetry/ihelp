- อ่านค่าจากหน้าปัดมัลติมิเตอร์แบบเข็ม และเลือกย่านวัดให้ถูก

### ตอนที่ 1 — มิเตอร์เข็ม

อ่านค่าจากรูปหน้าปัดที่พิมพ์มาให้ 3 ชุด (อุปกรณ์ A, B, C) ระบุย่านวัดที่เลือกและค่าที่อ่านได้

### ตอนที่ 2 — ไล่สายเคเบิล

ใช้มิเตอร์เข็มตรวจความต่อเนื่องของสายสี่สีที่มีหัวสองด้าน แล้ววาดลงในกรอบว่าเส้นไหนต่อถึงเส้นไหน

### ตอนที่ 3 — มิเตอร์ดิจิทัล

วัดอุปกรณ์อีก 4 ชิ้น (D, E, F, G) ด้วยมัลติมิเตอร์ดิจิทัล

### ตอนที่ 4 — เขียนวิจารณ์

เปรียบเทียบความละเอียดและความคลาดเคลื่อนของการอ่านค่าแบบเข็มกับแบบดิจิทัล

## สาระในสไลด์

- **หน้า 1–11 เป็นส่วนแนะนำรายวิชา** — ตารางเรียน 24 ส.ค. ถึง 19 ต.ค. กำหนด quiz และวันสอบแล็บ พร้อมสัดส่วนคะแนน
- วิวัฒนาการเครื่องคำนวณ — ลูกคิด, เครื่องคำนวณของปาสกาล (1642), หลอดสุญญากาศ, หลอดภาพ CRT
- กระบวนการผลิตชิป — ซิลิคอนบริสุทธิ์ → เวเฟอร์ → exposure → ตัด → package
- การโดป — P-type ด้วยโบรอน, N-type ด้วยแอนติโมนี
- ระดับการรวมวงจร SSI / MSI / LSI / VLSI / ULSI พร้อมตารางปีและขนาดโพรเซส
- อุปกรณ์ passive (C, R, L, หม้อแปลง) กับ active (ไดโอด, ทรานซิสเตอร์, LED, IC) และ PCB
- ความต่างของ processor / CPU / core และตระกูล microprocessor, GPU, DSP, ไมโครคอนโทรลเลอร์
- องค์ประกอบภายในเครื่อง — processor, main memory, system bus, I/O module

## ข้อควรระวังของคาบนี้

- คำถามข้อสุดท้าย (วิจารณ์ความละเอียดและความผิดพลาดในการอ่านค่า) **ไม่มีเส้นบรรทัดให้เขียน** ต่างจากข้ออื่นในใบงาน — น่าจะเป็นความคลาดเคลื่อนของต้นฉบับ เตรียมกระดาษเพิ่ม
- ใบงานสั่งให้ดูวิดีโอก่อนเริ่ม แต่ **ไม่ได้พิมพ์ลิงก์ไว้** — ลิงก์อยู่ในหัวข้อวิดีโอด้านบนของหน้านี้
