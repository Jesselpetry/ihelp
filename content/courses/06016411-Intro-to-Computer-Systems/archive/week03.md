## เป้าหมายของคาบนี้

- อ่านรหัสสีตัวต้านทานและหาค่าได้โดยไม่ต้องวัด
- ต่อวงจรบนโพรโทบอร์ดโดยเข้าใจว่าแถวไหนเชื่อมถึงกัน
- วัดแรงดันตกคร่อม LED และตัวต้านทาน แล้วคำนวณกระแสด้วย V = IR
- อธิบายการหน่วงเวลาด้วย RC และเทียบกับค่าที่คำนวณจาก T = R × C
- อธิบายการทำงานของ MUX, DEMUX, tristate gate, latch, buffer และ SR flip-flop จากสไลด์

### ทฤษฎี (ประมาณ 1 หน้า)

ขา anode/cathode ของ LED ดูจากความยาวขา, พิกัดราว 2V / 30mA และคำเตือนเรื่องแรงดันเกิน · การเดินสายภายในโพรโทบอร์ด (คอลัมน์ C กับ D ต่อแนวตั้ง, ราง A กับ B ต่อแนวนอน, แบ่งครึ่งกลางบอร์ด) · สวิตช์กด 6 ขา มีขา A ร่วมกัน 4 ขาและขา B ร่วมกัน 2 ขา พิกัดต่ำกว่า 30V / 100mA · ตัวต้านทาน 220Ω 1/4W อ่านจากแถบสี แดง-แดง-น้ำตาล-ทอง พร้อมตารางสีครบ · ธรรมเนียมสายแดง/ดำ

### การทดลองที่ 3.1 — สวิตช์สองตัว LED สองดวง

ต่อวงจรตามรูป วัดแรงดันตกคร่อม LED และตกคร่อม R ทั้งก่อนกดและขณะกดสวิตช์ แล้วคำนวณกระแสที่ไหลผ่าน

### การทดลองที่ 3.2 — หน่วงเวลาด้วย RC

สวิตช์กดขับวงจร RC (220Ω กับ 10µF) เข้าอินเวอร์เตอร์แล้วไปจุด LED จับเวลาหน่วงตอนติดและตอนดับ แล้วเทียบกับค่าที่คำนวณจาก T = R × C

## สาระในสไลด์

- สวิตช์เลือกช่องแบบกลไก ใช้เป็นภาพเปรียบของมัลติเพล็กเซอร์
- ภายในมัลติเพล็กเซอร์ — decoder 2-to-4 บวกวงจรเลือกและวงจรรวม และวงจร demultiplexer
- MUX คู่กับ DEMUX บนสายส่งเส้นเดียว และอุปกรณ์จริงที่ใช้หลักนี้
- Tristate gate — สามสถานะ H, L และ high impedance Z (>1 MΩ ทำตัวเหมือนวงจรเปิด)
- Latch กับ buffer ต่างกันอย่างไร — latch เก็บค่าไว้ภายใต้ clock/enable และมีขา output enable ส่วน buffer แค่ส่งผ่านและขยายกระแส/แรงดัน
- ไล่การทำงานของ buffer และ latch เมื่อ OE = 0 (เอาต์พุตเป็น Z) และ OE = 1
- ตารางความจริง SR flip-flop — no change / reset / set / ห้ามใช้ (1,1)
- วิเคราะห์วงจร NOR 6 ขั้นตอน ไล่ A, B, Y, Z จนเข้าสถานะเสถียร แล้วสรุปเป็นตาราง Set/Reset
