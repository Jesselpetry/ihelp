## สรุปสาระสำคัญอ่านสอบ

### 1. สัญญาณอนาล็อกและดิจิทัล (Analog vs Digital)

- **สัญญาณอนาล็อก (Analog Signal):** เป็นสัญญาณที่มีค่าต่อเนื่องทั้งในมิติของเวลาและขนาด (Continuous in time and amplitude) เช่น เสียง อุณหภูมิ แรงดันไฟฟ้าตามธรรมชาติ
- **สัญญาณดิจิทัล (Digital Signal):** เป็นสัญญาณที่ไม่ต่อเนื่อง (Discrete) ถูกแปลงผ่านกระบวนการ Sampling และ Quantization ให้เป็นค่าระดับแรงดันแบบไม่ต่อเนื่อง เช่น ค่าทางตรรกะ `0` (Low / 0V) และ `1` (High / 5V หรือ 3.3V)
- **ข้อดีของระบบดิจิทัล:** ทนทานต่อสัญญาณรบกวน (Noise immunity) สูงกว่า จัดเก็บ คัดลอก และประมวลผลทางคณิตศาสตร์ได้แม่นยำไม่ผิดเพี้ยน

### 2. รูปแบบจำลองระบบดิจิทัล 3 แบบ (Three Representations) ⭐

ระบบดิจิทัลทุกระบบสามารถอธิบายและแปลงสลับไปมาได้อย่างสมบูรณ์ผ่าน 3 วิธี:
1. **ตารางค่าความจริง (Truth Table):** แสดงความสัมพันธ์ระหว่างอินพุตที่เป็นไปได้ทั้งหมดกับเอาต์พุต สำหรับอินพุต $n$ บิต ตารางจะมี $2^n$ แถว
2. **สมการพีชคณิตบูลีน (Boolean Expression):** นิพจน์เชิงพีชคณิตที่ใช้ตัวดำเนินการ AND, OR, NOT
3. **แผนผังวงจร (Schematic Diagram):** สัญลักษณ์รูปภาพของลอจิกเกตและการเดินสายสัญญาณเชื่อมต่อ

### 3. ชนิดของวงจรดิจิทัล (Digital Circuit Types)

- **Combinational Logic:** วงจรที่เอาต์พุตขึ้นอยู่กับสถานะของอินพุต ณ ขณะนั้นเท่านั้น ไม่มีหน่วยความจำภายใน (เช่น Gate ทั่วไป, Adder, MUX, Decoder)
- **Sequential Logic:** วงจรที่เอาต์พุตขึ้นอยู่กับทั้งอินพุตปัจจุบันและสถานะในอดีต (มี Memory / Feedback Loop เช่น Flip-flop, Register, Counter)

## ปฏิบัติการ Logisim (Lab 01)

- ติดตั้งและเปิดโปรแกรม Logisim (ต้องการ Java Runtime)
- เครื่องมือพื้นฐาน:
  - **Poke Tool (`Hand`):** ใช้สำหรับคลิกเปลี่ยนค่าอินพุต (`0` / `1`) เพื่อทดสอบวงจรแบบอินเทอร์แอคทีฟ
  - **Edit Tool (`Arrow`):** ใช้วางลอจิกเกต ย้ายอุปกรณ์ และลากสายสัญญาณ (Wiring)
- การสร้างวงจรพื้นฐาน: วาง Input Pin, Output Pin และลอจิกเกต AND, OR, NOT
- **การสร้าง Subcircuit:** การรวมวงจรย่อยไว้เป็นบล็อกโมดูลาร์ เพื่อนำไปใช้ซ้ำในวงจรหลัก (Main Circuit) เช่น การสร้างโมดูล `myXNOR` และนำไปประกอบเป็นวงจรเปรียบเทียบขนาด 4 บิต (4-bit Comparator)

## ข้อควรระวังและกับดักข้อสอบ

- **การระบุขั้วอินพุตและเอาต์พุตใน Logisim:** ตรวจสอบคุณสมบัติ `Facing` (ทิศทางของขา) และ `Data Bits` ให้ตรงกับโจทย์เสมอ
- **จำนวนแถวใน Truth Table:** สำหรับอินพุต $n$ ตัวแปร ต้องมี $2^n$ แถวเสมอ หากมี 3 ตัวแปรต้องมี 8 แถว ไล่ลำดับเลขฐานสองจาก `000` ถึง `111` ห้ามกระโดดข้ามแถว
- ในข้อสอบกลางภาค บทนี้มักออกเป็นโจทย์พื้นฐานจับคู่ความหมาย และการเขียน Truth Table จากโจทย์คำบรรยาย
