## 3. สรุปเนื้อหารายหัวข้อ

### บทที่ 1 — ความรู้พื้นฐานเกี่ยวกับคอมพิวเตอร์

- ฮาร์ดแวร์ 4 ส่วน — CPU · หน่วยเก็บข้อมูล (ชั่วคราว/ถาวร) · input · output
- ซอฟต์แวร์ระบบและระบบปฏิบัติการ (DOS · Windows · OS/2 · Unix)
- ภาษาคอมพิวเตอร์ 3 ระดับ — machine · assembly · high-level
- **Interpreter vs Compiler** ⭐ — interpreter แปลทีละคำสั่ง (Python) · compiler แปลทั้งหมดก่อน (C, C++)
- ระบบเลขฐาน 2 / 10 / 16 · หน่วย bit · Byte · Word · KB
- **รหัส ASCII** ⭐ — `'A'` = 65 = 0x41 · `'a'` = 97 = 0x61 · `'0'` = 48
- `print` และ comment

### บทที่ 2 — ตัวแปร นิพจน์ การรับและแสดงผล

- กฎตั้งชื่อตัวแปรและคำสงวน · ชนิดข้อมูล `int` `float` `str` `bool`
- **f-string** ⭐⭐ — จัดชิด `<` `>` `^` · `d` `b` `x/X` `f` · `,` คั่นหลักพัน · `:f` ไม่ระบุ = ทศนิยม 6 ตำแหน่ง
- **ตัวดำเนินการ** ⭐⭐ — `/` ได้ float เสมอ · `//` หารปัดลง · `%` เศษ · `**` คำนวณจากขวาไปซ้าย
- **`input()`** ⭐⭐ คืนค่า `str` เสมอ — ต้อง `int()` / `float()` · `.split()` แยกข้อความ
- การแปลงชนิดข้อมูล (casting)

### บทที่ 3 — การเขียนโปรแกรมแบบมีเงื่อนไข

- Boolean expression และเครื่องหมายเปรียบเทียบ — `=` กำหนดค่า vs `==` เปรียบเทียบ
- **Indentation** ⭐⭐ กำหนดขอบเขตบล็อก
- `if` · `if/else` · if ซ้อน · `if/elif/else` ทำจากบนลงล่าง เจอเงื่อนไขจริงอันแรกแล้วออก
- **`try / except`** ⭐ — error แล้วโปรแกรมไม่พัง บรรทัดที่เหลือใน `try` ถูกข้าม
- ตัวดำเนินการตรรกะ `and` · `or` · `not`

### บทที่ 4 — การวนซ้ำด้วย while

- Indefinite loop — ต้องเปลี่ยนค่าตัวแปรควบคุม ไม่งั้นเป็น infinite loop
- **`break` / `continue`** ⭐⭐
- `ord()` · `chr()` · `len()` · การเข้าถึงตัวอักษร `name[i]`
- **Nested loop** ⭐⭐ — พิมพ์พีระมิด: ช่องว่าง `num − row − 1` · ดาว `2*row + 1`

### บทที่ 5 — การวนซ้ำด้วย for

- Definite loop · **`range(start, stop, step)`** ⭐⭐ ไม่รวม stop
- **Loop idioms** ⭐⭐⭐ — largest · smallest · count · sum · average · filter · search
- `is` / `is not` · `in` ตรวจสมาชิก
- `for` วนกับ string · list · ผลของ `.split()`

| | `while` | `for` |
|---|---|---|
| ประเภท | indefinite loop | definite loop |
| จำนวนรอบ | ไม่รู้ล่วงหน้า | เท่าจำนวนสมาชิก |
| เสี่ยง infinite loop | เสี่ยง | ไม่เสี่ยง |

### ภาคผนวก — จาก cheat sheet

- list · string method · format string 3 แบบ (`%` · f-string · `str.format()`)
- function (`def`) · dict · tuple · การอ่าน/เขียนไฟล์

## 4. สิ่งที่ต้องจำ

| เรื่อง | ค่าที่ต้องจำ |
|---|---|
| ASCII | `'A'` = 65 · `'a'` = 97 · `'0'` = 48 — เลข 7 ≠ ตัวอักษร `'7'` |
| หน่วยข้อมูล | Byte = 8 bit · Word = 16 bit · KB = 2¹⁰ Byte |
| ลำดับความสำคัญ | `()` → `**` → `* / // %` → `+ -` → เปรียบเทียบ → `not` → `and` → `or` |
| หาร | `/` float เสมอ · `//` ปัดลง · `%` เศษ |
| f-string | `f"{x:>8.2f}"` · `:,` คั่นหลักพัน · `:b` ฐานสอง · `:X` ฐานสิบหก |
| `range` | `range(start, stop, step)` ไม่รวม stop |
| Float | `0.1 + 0.2 == 0.3` → `False` |
| หาค่าน้อยสุด | เริ่มด้วย `None` แล้วเช็ค `is None` |

## 5. การประเมินและเตรียมสอบ

### 5.1 รูปแบบการประเมิน

- **กลางภาค** — บทที่ 1–5 · ข้อสอบจำลองในเว็บเป็นแบบ 60 ข้อ 5 ตัวเลือก
- **แล็บ Python สัปดาห์ 1–5** — 25 โจทย์ ตรวจด้วย test case · สัปดาห์ 1–5 ห้ามใช้ `import` (ข้อสอบจริงไม่รับ)
- สัดส่วนคะแนน *ยังไม่ยืนยัน*

### 5.2 หัวข้อที่ออกบ่อย

1. Interpreter vs Compiler
2. แปลงเลขฐานและรหัส ASCII
3. จัดรูปแบบด้วย f-string
4. ลำดับการดำเนินการและ `/` `//` `%` `**`
5. ไล่ `if/elif/else` หา branch ที่ไม่มีวันทำงาน
6. `try / except`
7. `break` / `continue` และ nested loop
8. Loop idioms

### 5.3 จุดที่มักพลาด

- ลืมแปลง `input()` เป็นตัวเลข
- ใช้ `==` เทียบ float
- `**` คำนวณจากขวาไปซ้าย — `2 ** 3 ** 2` = `2 ** 9`
- `range` ไม่รวม stop
- while ที่ลืมเปลี่ยนค่าตัวแปรควบคุม → infinite loop
